# GMP-03：自然事务兑现与成本记录

> 2026-09-14；契约 `gmp-contract-v1`，实施基线 `e01cd06`。[小规划](../../plans/cpu_refinement/gmp_03_natural_backend_plan.md)在运行前冻结输入与配额；[执行契约](greedy_multipass_contract.md)、[组合推导](transaction_batch_derivation.md)保持不变。

## 1. 阶段结论与证据范围

**自然网格上已经找到并应用非平凡预算交换批次，无需 Legacy 提供目标 J；后续 GMP-04 及评审确认原型前 Gate 为 PASS。** test129 两个快照分别执行 21、23 个交换；Peking 分别执行 0、1 个交换。证据足以进入持续原型规划，不证明实际多核收益、持续质量或论文新颖性。

同时出现明确风险：固定当前视图的采样屏幕最大误差未增加，但两个快照的全域高度误差明显上升。当前认证只约束冻结视域样本；不能把这次局部可执行性称为长期 LOD 质量通过，也不能隐藏视图外误差。后续必须明确高度自由度与视域返回后的恢复义务；全域高度保护是可比较的保守变体，不据此回改本次参数或判定原型前失败。

一般后端的前缀 `R_local` 均为 1；`R_execution` 分别为 21/45、23/46、0/1、1/1。Peking14 的批宽 2 是两次使用空额度的细分，**不是两次预算交换**；5 份命名空额度中 3 份因冲突闲置，按冻结规则没有回流。唯一需回收需求局部可行，但与已经预留的事务冲突。

因此 Peking14 的交换链是 `64 个已检查需求 → 6 个接收认证成功 → 1 个需要 donor → 1 个局部可行 → 0 个交换执行`，不是 `6 个 D_need`。另 5 个接收方获命名空额度，实际执行 2 个。no-reflow 在本批主动保留资源归属，未填满预算不是最优分配声明；跨批账本重建及失败重试尚待持续实现验证。

四个共同池内均没有三价中心。因此三价对照只表明这个旧限制不能表达本池的回收，不能充当有竞争力的传统 ROAM 基线。一般回收在 test129 解除 21/23 个具体高优先级需求的执行阻塞，需求/中心 ID 保存在逐行结果中；不声称整个一般回收空间或最优选择器的兑现率。

21/23 排除了“这些自然来源没有非平凡批次”的疑虑，只证明存在性；后续由新算法自己产生的状态能否持续提供宽批次，尚无数据。test129 的主要兑现流失在冲突、donor 复用和预留，不代表这些阶段必然最耗时；发现/认证的计算成本须按 §5 单独判断。

限定 oracle 共检查 53 个失败 pair：4 个为快路径漏解且 oracle 构造的 cavity 与接收方兼容，49 个在指定边界、角度、固定 Q 和 τ 下质量不可行。4 个正例分布在 test129 两个快照各 2 个。**没有用 oracle 替换快路径再运行批次**，因此这些不是额外 D_executed，也不是实测的“快路径加 oracle 兑现数”。未审计 pair、池外中心及接收拟合失败不归入数学不可行。

## 4. 正确性、质量及未覆盖状态

已应用批次通过参数域覆盖、共享边/点、顶点 link、最小角、活动预算、共享高度、全部 Q 覆盖及下一轮需求生成核查；正序/反序的逻辑核心相等。接收高度和新非 dyadic 参数坐标保留有理值，未通过重新吸附到栅格掩盖续接误差。

P 的浮点运算顺序与同分身份冻结；V 是本次按固定矩阵/运算确定的 reference 视域样本集合。局部接受在该集合上使用精确有理投影平方复核，不将浮点拟合失败或视域边界判定升级为连续几何证明。全局 sampled maximum 可能被未修改区域固定；局部认证才提供被修改可见样本的证据。

高度上升揭示的是 **当前单视图契约容许的质量退化**。旧高度自由度具体限于 H 接收提案的指定中心与新点，须覆盖中心全部 incident faces；E/F 只拟合新点，donor 固定存活边界高度，不是任意旧点改高。它不是预算/裂缝检查失败，也不是可以忽略的数值噪声。视图外降低精度可以属于 view-dependent LOD 的取舍，但这些区域重新可见时能否及时恢复尚未测量。本轮不追调高度域或 η；下一原型保留原规则作可重复基线，显式记录允许范围、退化、返回视图误差与恢复工作/轮次，不能从高度量直接换算未来像素损失，也不能把所有高度上升自动判为非法。

有限副本验证了几何、样本和新需求，不等于生产法线、脏区间、持久候选缓存、物理分配器及消费者已实现。GMP-02 的完整续接义务仍是后续实现的硬条件。没有真实多线程提交；反序检查不是数据竞争检测或对所有未来实现的证明。
