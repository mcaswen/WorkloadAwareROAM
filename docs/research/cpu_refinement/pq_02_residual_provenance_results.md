# PQ-02：冻结旧点策略的残余质量来源与恢复阻塞

2026-09-15。对应[小规划](../../plans/cpu_refinement/pq_02_residual_provenance_plan.md)、[代码事实](../../codebase/cpu_refinement/pq_02_residual_provenance_facts.md)、[阶段审查](../../reviews/cpu_refinement/pq_02_residual_provenance_review.md)。本轮接续 PQ-01，只追加一个事先冻结的残余见证；没有实施质量修复或性能优化。

## 1. 阶段出口

**残余来源追溯完成；持续质量目标仍未通过。** PQ-01 B 的 frame15 最大点不是另一处“新点无约束被选成高度6”，也不是回收删点直接造成。该点只被两个 E 接收事务改变：frame6 在改善可见补丁时加重离屏误差，frame7 小幅改善，然后再没有几何变化。

更关键的是：这个点在初始 DOD 种子中已经存在离屏近似误差。把初始曲面统一投影到 frame15 的视图，误差是 **2.003422px**；两次局部修改后是 **2.351050px**。这是固定视图下的几何分解，不是说初始视图已有2px可见最大误差。后续 DOD 在 frame15 同一点的实际误差为 **0.056118px**，因此种子中的残差不能替代新算法的恢复义务。

恢复阻塞已经分层：可见后的第一次修正接近最低进展门槛；frame8 进入前缀却在当前接收目录的形状检查中全部失败；frame9–15 覆盖根未进入前160；返回初始视图后该点不可见、几何未恢复。扩大前缀本身不能解决已经观察到的形状阻塞。

| 判断对象 | 本轮结论 |
|---|---|
| PQ-01 B 残余最大点的来源 | 已闭环：种子残差、两次 E 修改及恢复链均有记录 |
| 默认诊断与生产结果身份 | 相同：原两见证输出逐字节一致；24帧与五份实际网格一致 |
| 当前可见样本认证 | 没有发现本见证涉及的两次接受违反该局部契约 |
| B 的持续质量接近 DOD | 未通过，原质量结果没有改变 |
| 当前目录的恢复能力 | 存在具体阻塞，不宣称所有局部修复数学不可行 |
| 生产策略调整 / 性能竞争力 | 本轮未实施 / 未重新评价 |

## 2. 输入、身份与证据定义

沿用 PQ-01 的 Peking547²、尺度80/12、深度20、预算50000、阈值.25/.10、前缀 `r=m=160`、8线程、1280×720、NO深度域。B 为 `PreserveSurvivingHeights=true`，新点仍进行原一维拟合，`HeightGuard=false`。原生 Windows/MSVC 无渲染探针复用平台公共相机及种子，Ubuntu WSL 编排。

24帧的轨迹 sample 索引仍为：

~~~text
14,14,14,15,16,18,22,26,30,34,38,42,46,50,54,58,14,14,14,14,14,14,14,14
~~~

frame 从0起算。本轮追加见证 q2 完整精度为 `(0.97985345125198364, 0.94871795177459717)`，直接取自 PQ-01 B 的 `quality-15/quality.json`；独立样本序号1699028，`sampleHash=12881002172889809993`，q=1790881。原两个见证仍保留编号0、1。

修改前、修改后默认、追加见证三次回放，均与 PQ-01 B 全24帧网格哈希和主要决策/工作字段一致；frame0/2/15/16/23 实际 `mesh-N.bin` 的 SHA256 也一致。因此复用五关键帧的原独立质量结果，不重跑全Q评价。

三种误差口径分开：

- **当前可见误差**：仅在 `visible=1` 时解释为当前画面上的误差。
- **固定未来视图投影**：将各时刻曲面投影到同一个 frame15 视图，仅分解几何变化，不能冒充当时可见误差。
- **实际输出独立评价**：原 float 网格、公共独立采样及双线性参考；探针内部 double 插值不能替代它。

q2 的双线性参考高度为 **1.720302076311345**。

| frame6 E 后 | 1.530441609357682 | -0.189860466953663 | 2.364680370951609 |

q2 当时不可见。最近可见认证样本位于 `(0.9642857142857143,0.88003663003663)`，参数距离约0.070424；因此当前可见证书没有直接约束这处离屏残差。

与 PQ-01 的两次 H 不同，这里自由变量在489个可见样本上都有非零系数。不能称为“完全未被观测的新变量”或二维拟合器选错无约束中心；它是**当前可见目标与离屏几何保真之间的取舍**。

### 3.2 frame7：已经看到坏点，但只取得接近0.01px的进展

frame7 / sample26 / exchange0，E 接收根 `-99`，旧支持面599、`-99`。新点 `-828436` 的 UV 为 `(0.96875,0.96875)`；初始高度1.640409588813782，拟合后1.647886036568396，源高度1.738946269169146。

本次可见/补丁样本数均为7056，新高度在6953个样本上有非零系数。最近核心样本离 q2 仅约2.88×10⁻⁸参数距离，排除了“这次附近根本没有认证样本”作为主要解释。

q2 的当前可见误差为 **1.734468343524267 → 1.724467946704489px**，只改善约0.010000397px。补丁最大误差1.734469295321048px，对应接受目标1.724469px。

这与当前 `Fit` 的选值规则吻合：目标为旧见证误差向下取整后减0.01px；一维可行区间中选择**最接近零的高度增量**。它求满足既定门槛的可行值，不求该新点靠近源高度，也不最小化最终补丁误差。不能据此推断“更多改善必然可行”，但它没有提供快速恢复保证。

本次只把新点恢复为初始插值高度，q2 又恰好回到本事务前高度。因此两次 E 的几何增减都能单独归因到各自的新点拟合，不存在本点的直接 donor 修改记录。

| 6 / 22 | 不可见 | 7 | 第二个 E 认证并执行，离屏见证加重 |

| 9–14 / 34–54 | 可见 | 331、1135、2206、3485、4021、1074 | 根 `-111` 全部位于前160之外 |

`Recovery` 解释的是**覆盖根**在既有目录中的处理，不是所有可能影响该点的邻近根的完整修复搜索。不过本轮所有实际批准事务都检查了是否覆盖 q2，确实只有 frame6、7 的两次。

### 4.1 为什么当前目录会在形状检查中耗尽

从 frame7 的已记录新面中，唯一严格包含 q2 的面为：

~~~text
A = -583186 : (31/32,29/32)
B = 3       : (1,1)
C = -828436 : (31/32,31/32)
~~~

三个参数域内角分别为 **18.434948823°、26.565051177°、135°**。`TransactionalPredicates::Shape` 对锐角要求 `10·dot² ≤ 9·|u|²·|v|²`，对应最小角 `acos(sqrt(9/10))=atan(1/3)`。A 角的 `cos²=9/10`，恰在合法下限；不是数值略越界导致旧面非法。

对当前 E 边中点规则，仅检查该根的两个子面就能得到：

| 被二分边 | 根侧子面结果 | 精确证据 |
|---|---|---|
| AB | 两个子面均合法 | 最小角仍为18.434948823° |
| BC | 不合法 | 锐角 `cos²=25/26`、`64/65` 大于9/10 |
| CA | 不合法 | 一个锐角 `cos²=49/50` 大于9/10 |

BC、CA 的失败不需要依赖高度或相机。AB 的根侧子面合法，但 frame8 三个 E 都被形状判据拒绝；结合 E 同时二分两侧面及 `Fit` 逐新面检查，可推断 AB 的失败发生在相邻面的子面。这里没有重建该邻面的精确坐标，不能进一步宣称是哪一个邻角失败。

F/H 都向根的严格内部插点并连接根三个角；A 原角已经等于最小角，内部连线会将它分成两个正角，至少一个小于下限。因此在**保留根边界并做当前扇形插点**的范围内，F/H 无法继续合法细分。这一局部角度论证与实测目录失败吻合，但没有否定换连接、扩大补丁或其他合法细分模型。

该局部推算使用已采集的精确二进制参数坐标及有理数比较，归约脚本输出 `localShape`；角度小数仅供展示。不新增 C++ 执行器，不通过串行调用顺序推断必需依赖，也没有建设一般可行性 oracle。

### 4.2 返回后的0.441886px不代表这个点恢复

frame16–23，q2 的高度始终为1.531537070207988，高度残差始终为-0.188765006103357。它离开当前可见域，所以不再决定当前可见 `Emax`。

探针仍输出约5.882284px的离屏投影偏移，该值**不是当前可见误差**，不能拿来替换 PQ-01 的返回后 Emax=0.441886px。反过来，也不能用全局 Emax 降回0.441886px宣称该点的曲面已经恢复。

## 5. 对下一次质量决策的约束

本轮支持把问题拆成三项，而不是只给新点再加一个高度限制：

1. **新引入退化**：frame6 说明一维、已有可见约束的新高度仍会牺牲离屏几何。源高度或受限拟合可以作为后续候选，但本轮没有证明其认证可行性与事务密度。
2. **已有误差的恢复**：即使完全删除 frame6 的新增退化，初始曲面在未来视图仍有约2.0034px残差。只阻止继续变坏不能替代持续细化能力；DOD 同点0.0561px是明确对照。
3. **恢复操作与进展**：当前最小角及插点目录会形成具体不可继续细化的根，且一维拟合只追求最低可行进展。优先级更高、前缀更长、更多 donor 都不能单独保证解除形状阻塞。

因此本轮不建议仅凭“返回最大值恢复”提升 B 为完整质量修复，也不建议直接扩大前缀或恢复轮数追求更低数字。下一次应在明确事务语言与恢复目标后再决定实现；没有在本小阶段自动扩几何原语、放宽角度或重新优化预留。
