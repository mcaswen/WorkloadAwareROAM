# QPC-06B：同代次空批复用推导

2026-09-17。纸面推导＋随后有限夹具/轨迹核查，不新增Lean。

## IDLE-01 固定输入

定义X=(Pipeline/State实例、Version、Config、Source/Q、拓扑及样本/候选持续状态、执行诊断模式)。在没有异常/资源截断的运行中，原Plan的逻辑结果F(X)确定；线程完成顺序不影响按全局前缀收集和预留。elapsed time和实际work不是逻辑批次的一部分。

完整运行F(X)=B且B.Exchanges为空时，Apply(B)不改State/Samples。故X'=X，再执行得到F(X')=B。归纳可连续复用到X首次改变。保存完整逻辑B而非仅返回一个新空vector，是为了保持候选人口、失败理由、预算分配与诊断目录。

## IDLE-02 失效与反例

该实例State/Samples在正常API下只由初始化、SetView成功发布和拓扑成功发布修改。前者只发生一次，后两者推进Version并清缓存；初始化后的Source不可写，几何/预算/质量/前缀配置在SetView被禁止改变。相同相机不改变Version，也不改变读取输入。缓存绑定实例地址排除两个都叫Version=1的状态误命中；Diagnostics也绑定。

不使用mesh哈希：相同公开曲面不代表相同候选、内部身份或矩阵。也不使用单根局部几何指纹：附近owner、Q、预算、目录身份可能改变。整个代次键更保守，任何局部成功事务后全失效，不声称局部复用定理。

## IDLE-03 异常、资源与生命周期

只有正常返回且空批的Plan可记入。超时/超访问量是未完成，没有失败证书，不能存入缓存。命中仍检查当前Deadline/VisitLimit；减少实际Touch后可在更小计算预算下完成是预期成本变化，不能声称原运行在同一小计算配额也会完成。

Apply准备失败时状态仍旧，可以保留旧同代次事实；但本次半成品绝不记入。真正发布前清除，清理账本的潜在分配失败不能发生在状态已改变之后；Reset重建Pipeline，实例缓存随对象销毁。缓存不持有成功Proposal或共享证书，不会将过期证书复用到新几何。

## IDLE-04 复杂度与结果边界

令r为前缀、m为池大小、a为保存的目录尝试条目。空结果大小O(r+m+a)，a受冻结目录上限控制；查键O(1)，返回值复制/释放O(r+m+a)，不是零成本。一次冷求解后连续z次不变机会从(z+1)W_plan降为W_plan+O((z+1)(r+m+a))，存储一份有限B，不随帧数增长。更改视图/拓扑仍支付原完整Plan。

物理检查次数下降而逻辑失败保持。省去空批重试不让坏区域恢复，也不提高事务兑现率；不能从静止平均值推导动态LOD性能已解决。
