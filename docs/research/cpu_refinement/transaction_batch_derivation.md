# 事务批次的组合与续接推导

> 2026-09-14；依据 [v1 契约](greedy_multipass_contract.md)与 [GMP-02 小规划](../../plans/cpu_refinement/gmp_02_transaction_batch_plan.md)。纸面命题针对明确前提；脚本只核查有限实例，不是 Lean 证明或生产多核实现。

## 1. 先排除两个不充分条件

尝试一：只要求删除面集合不交。失败：若事务 A 改变保留顶点 v 的高度，而 B 的质量证书读 v，B 即使不删除 A 的面，其证书也失效。完整 H 接收必须写中心高度并纳入其全部邻面。

尝试二：只重定位删除面的 owned samples。失败：q 位于补丁外边界，其 owner 可能是 ID 更小的外侧保留面；改连接后 owner 或闭面关联仍可能变化。删除面 owned samples 的并集不足以枚举这些点，必须收集 closed support 上的全部样本并检查边界外侧关联。

尝试三：把顶点度数、法线和脏位全部作为普通事务写。安全但可能过度拒绝。若两个补丁仅共享保留顶点而不共享边，它们可分别产出带唯一身份的关联增删，屏障后统一重算该点派生状态，不必互读中间度数。这里减少的是派生状态写冲突，没有忽略几何/证书依赖。

## 2. 状态分层与逻辑资源

核心状态 C 包括实际顶点坐标/高度、活动面、边的定向面关联、边界与身份。派生状态 A 包括点的关联面集合/度数、面评分、证书缓存、样本双向归属、法线与脏输出。分层不意味 A 可丢弃：提交后必须恢复完整 A，才发布下一代。

事务 T 的核心读包括：删除面与完整修改域的实际几何，证书全部样本及其参考/视图，环的完整性，边关联以及拟新增边/点不存在的谓词。核心写包括：面生命周期、内部边与外边面关联、新/删点、改变的旧高度。不存在性谓词也有资源键，两个事务同时认为同一边不存在不能成为漏边。

保留边端点高度只读；替换面仍使用相同边界。若边关联以整边为记录，两个事务同时更新同一外边按 W/W 拒绝。以后若改为有所有权的 `(edge,face)` 增删并统一重建，需另证，当前不偷偷扩大接纳。

派生修复贡献带 `(transactionID, resource, action)`；重复贡献拒绝。脏集合并集、关联集合增删只在各面生命周期唯一且不存在同一元素同时增删的条件下归约；整数溢出先检查。法线不并行累加浮点值，而按稳定面 ID 重算，避免把浮点加法当结合律。

## 3. 一般组合命题及证明

前提：所有局部提案在同一合法 M 上认证；每个提案覆盖完整修改域并保留外接口；批准事务之间不存在未解决的 R/W、W/W 冲突；新身份和输出槽位唯一；预算/内存预留有效；派生修复只在核心批次完成后读取最终状态。

**命题**：任何批准事务的应用排列，都产生相同的逻辑核心状态，随后按相同规则修复得到相同的可续接投影。

证明过程：对任意两事务 A/B，B 不写 A 的读取资源，所以 A 在 B 前后的局部结果相同，反之亦然；不同写资源可以交换。共享不可变参考/视图不产生写。允许的派生贡献满足唯一性和集合规则，所以贡献并集也与顺序无关。任意排列可由相邻交换得到，故核心结果和贡献集合相同。派生状态是最终核心状态、固定参考/视图和该并集上的确定函数，修复后相同。物理槽位顺序不属于这个等价定义。

几何合法性：每个替换在原完整域内覆盖一次，固定外边坐标/高度；互不冲突域的并集仍覆盖原域，不制造裂缝。参数最小角由每个新面检查，旧保留面继承。回收 d→d−2，接收净 +2；交换净零，空额度至多 floor((B−N)/2)，故发布后 N≤B。

质量：每个受改样本的新误差≤其事务的 τ<L≤旧全局最大值，其余样本几何不变。边界共享样本已纳入证书，故冻结 V 上 sampled maximum 不增。这个结论不涉及连续表面最大值、RMS、下一相机或遮挡变化。

私有准备可能同时持有新旧面，不受活动预算等式限制，必须独立计临时峰值。发布采用屏障后的整批可见状态；准备失败丢弃私有结果，不发布半个交换。纸面交换性不证明任意无锁 C++ 存储安全。

## 4. 续接支持定理

令 F 为删除面和修改旧高度的完整邻面集合，V_F 为其顶点，E_F 为相关边。新面 F' 含在同一参数区域。收集 `Q_F=Q∩closed(union F)`，包括 owner 在外侧的边界样本。对于 q∉Q_F，旧覆盖面的几何、生命周期和边界都不变，因此它的覆盖集合、owner 与误差保持。

对于 q∈Q_F，在 F' 及保留外接口面中重新求覆盖集合；取最小稳定面 ID 为 owner，更新全部闭面贡献。只改高度时覆盖/owner 可以不动，但 Q_F 上误差必须重算。缓存复用必须比较全部几何、参考、视图版本，不只比较主中心。

| 字段 | 来源、支持与修复 | 工作计费 |
| --- | --- | --- |
| 活动面/点、边关联 | 批次有限增删；外接口面关联修复，稳定 ID 不全域压缩 | O(Σd)，有序容器访问另乘 log N |
| 顶点邻面/度数 | V_F 的贡献集合，屏障后重建；删除点不得保留邻接 | O(Σd + Σ受影响点度数) |
| owner 与反向样本 | Q_F 加外接口关联；不依赖旧 owner 是否被删 | 朴素 O(Σs d)，存储 O(N+Q) |
| 面误差/P | 新面、改高度的全部邻面、边界样本涉及的外面；新候选仅在下一轮出现 | 求值次数、共享贡献次数分别记录 |
| 回收资格及代理 P | 度数/边界改变点，以及受评分改变面的邻点；固定角界约束邻域 | 最多两层邻域，O(D²) 因子不能省略 |
| 局部证书 | 依赖范围任一版本改变即失效；有限证书索引或本批丢弃 | 索引构建/失效访问另计；不要求持久缓存 |
| 法线/输出属性 | 改几何面和其顶点；若平滑法线，所有相邻输出面跟随 | O(D²)；稳定顺序浮点重算 |
| 脏集合/槽位/预算 | 唯一增删贡献；预算净额；新槽位先预留，旧槽位过可见代后回收 | 数量及临时内存独立记录 |
| 拒绝寿命 | 输入依赖版本不变可复用；视图/几何改变后重试 | 无跨版本永久抑制 |

局部定理依赖有效反向索引；第一次建立可以全域且必须计费。相机变化时 owner 不变，但可能 Q_V 和全部 P 改变，成本可为 O(N+Q)，没有得到次线性视点更新结论。完整重建只用作离线 oracle，不能被隐含进未来正常修复路径。

## 5. 有限验证范围

脚本复用 CR 几何函数构造两个远离的 ±2 交换，检查正反序、预算、精确嵌入与边界；用额外相邻例审计共享点派生写和高度证书冲突。对一个固定样本集合，局部 owner/闭面摘要/邻接修复与全量独立重建比较。简单诊断 P 使用正交高度误差及投影边长，足以检查失效支持，不声称覆盖自然透视拟合求解器。

脚本独立几何验证会全域查边/点，诊断成本完整计时。有限通过不替代 §3/4 的一般条件，也不证明生产分配器、并行内存模型或长期缓存实现已经成立。自然证据、数值认证成本和原型准入留 GMP-03/04。
