## 2. C1：同一参考曲面不等于同一采样集合

### 2.1 对角线导致真实位置差异

运行时`TransactionalSamples`在每个栅格单元使用六分格余数：顶点`(0,0)`、中点`(3,0)/(0,3)/(3,3)`、两个重心`(4,2)/(2,4)`。独立评价器沿`TerrainMeshBuilder`固定面`(i0,i2,i1)/(i1,i2,i3)`发射顶点、边中点、重心，后两组实际是`(2,2)/(4,4)`。

**两条对角线选择相反，两个重心组不重合。** 这里对角线用于产生评价点；primary reference仍然是raw U16高度样本与双线性插值，没有退回分片线性reference。

| 栅格宽度 | 两边各自样本数 | 共同理想位置数 | 每边独有的位置数 | 独立UV相对其自身理想六分格的最大差 |
|---|---:|---:|---:|---:|
| 513 | 1,574,913 | 1,050,625 | 524,288 | 0 |
| 547 | 1,790,881 | 1,194,649 | 596,232 | 2.969316e-8 |

“共同理想位置”按栅格整数坐标定义，不宣称547的实际float UV逐位相同。547有1,790,865行相对自身理想位置不逐位相等；513没有这一舍入差，但仍有524,288个几何位置不重合。发射顺序也不同，不能用运行时样本编号直接读取独立`errors.f64`。

首次归约尝试检验两组位置一一对应，实际失败；`analysis.log`保留此失败。后续回查实际发射规则，将差异作为结果记录，未修改生产采样、评价器或数值容差。

### 2.2 已对齐与未对齐的部分

| 项目 | 实际对应关系与限制 |
|---|---|
| 参考与尺度 | raw U16、双线性参考、地形尺度/高度比例沿冻结配置；没有使用DOD网格当真值 |
| 投影与像素单位 | 比较同一相机/投影身份和分辨率，误差为参考点与同UV网格高度点的投影偏移；运行时存平方，报告开方为px |
| 可见性 | 以参考点可见性定义支持；参考可见而网格投影无效/跨近面不能静默跳过。不同Q不能逐位对比mask |
| 独立跨算法人口 | 16份质量证据中，同一帧各算法的source/Q/pose/projection身份与可见mask一致，质量状态均为`sampled_only`，缺失/歧义/无效项为零 |
| 几何精度 | 运行时内部double与实际输出float有差异；QPC-01选定见证的内部/输出最大差为9.923905e-8px，仅代表这些点 |
| 共享边支持 | 根评分使用全部闭面贡献，同一个样本可贡献多个覆盖根；唯一owner不能代替候选支持审计 |
| RMS/分布 | 当前统计是参数域采样人口上的RMS与计数，不是屏幕面积权重，也不是像素占比 |

**影响边界：** 独立评价仍公平，旧报告不因Q不同而失效；但`Q_runtime`上的认证不能无附加证明推广到`Q_eval`。本次坏见证及其根最大值已经在运行时被看到，因此不能用集合差异抹去后面真实的触发、排序和接受问题。差异到底改变多少未选见证、事务决定或总体质量，当前没有反事实运行证据。

## 3. C2：触发值、局部进展值与绝对目标是三个量

现行公式是`P(t)=max(E_runtime(t),0.2L_screen(t))`，只将有限且严格大于`SplitPixels`的评分加入索引。`SetProgressTarget`在提案的当前可见支持中选旧误差见证，以精确误差向下取整至微像素，再减0.01px；这不是绝对误差目标。

在同Q、有效有限评分和完整贡献前提下，`E_runtime>τ_request`必然有`P>τ_request`。边长项不会压低该根的资格，但可以挤占其排名。三个全根快照均没有非有限评分，没有证据把这里的请求缺口归因于近面排除或索引损坏。

| 输入/帧 | 触发数字px | 实际面数：B关 / B开 / DOD | 独立Emax：B关 / B开 / DOD，px | 独立误差超过触发数字：B关 / B开 / DOD |
|---|---:|---|---|---|
| Peking50k/15 | 0.25 | 49,999 / 49,999 / 50,000 | 1.996557 / 1.996557 / 0.418727 | 39,496 / 39,020 / 675 |
| Peking200k/15 | 0.25 | 200,000 / 199,999 / 199,999 | 1.996557 / 1.872770 / 0.193772 | 22,880 / 22,568 / 0 |
| Canyon50k/48 | 4 | 50,000 / 49,998 / 49,999 | 9.274477 / 7.626984 / 1.839557 | 2,555 / 1,660 / 0 |
| Canyon50k/95 | 4 | 50,000 / 49,999 / 50,000 | 2.348193 / 2.348193 / 2.348193 | 0 / 0 / 0 |
| Sierra50k/48 | 4 | 8,960 / — / 12,085 | 2.015012 / — / 1.041680 | 0 / — / 0 |
| Sierra50k/95 | 4 | 8,976 / — / 15,919 | 1.133568 / — / 1.089577 | 0 / — / 0 |

完整`0.1/0.25/0.5/1/2/4px`操作点、RMS、Hmax、Dmax和可见样本分母保存于summary，不删不利档位。它们是离线诊断操作点，不是本阶段批准的生产数值或感知阈值。表中Sierra没有B开启对照。

Sierra95的Emax看似接近，但绝对误差`>0.25px`为473,740对236,929个可见样本，且两边实际面数相差很大。不能据相同4px控制参数声称同质量任务；也不能把比DOD粗解释成违背一个从未承诺的1px目标。Peking50k的DOD同样超过0.25px，进一步说明入口阈值不是独立评价的统一保证。

DOD评分包含层次几何包络、保守投影与边长项，另有深度/迟滞等规则。当前Transactional评分直接使用当前样本误差。两者的政策并不等价；本阶段没有证明任何一方对连续双线性曲面的严格最大误差界。

## 4. C3：几何需求与密度需求在有限前缀中的竞争

观察时刻严格是`SetView`完成、当前批次`Plan`之前。对每个活动面独立重算密度项，并用既有闭面贡献重算几何项；全部重算评分与持久评分、合资格数量和生产前缀**精确一致**。离线再对同一合资格集合按`(−E_runtime², stableId, slot)`排序，不改变资格、不生成或提交新事务。

| 批前快照 | 活动面 / 合资格根 | 原前缀数量 | 原前缀无根内可见样本 | 原前缀E大于触发值 | 同人口按E排序：无可见 / E大于触发值 | 两种前缀交集 |
|---|---:|---:|---:|---:|---:|---:|
| Peking50k/15 | 49,999 / 49,999 | 160 | 158 | 2 | 0 / 160 | 2 |
| Sierra50k/48 | 8,960 / 2,950 | 160 | 160 | 0 | 0 / 0 | 0 |
| Sierra50k/95 | 8,976 / 150 | 150 | 150 | 0 | 150 / 0 | 150 |

Peking共有451个根的误差超过0.25px，其中449个在原前缀之外。所有活动根都由密度项主导；原最坏根`-112`的`E=1.996557px`、`P=15.972324px`，原排名194，同人口误差排名1。原QPC-01正文“192”与批前记录有时刻口径差，本阶段统一采用`roots.jsonl/targetRoots`的194。

Sierra48全部2,950个合资格根均因密度项越过4px；其中2,214个没有根内可见样本。最坏点覆盖根`-236`的`E=2.015012px`、`P=4.936132px`，排名1849，同人口误差排名1；同点另一个覆盖根`-234`评分3.107538，尚未入集合。部分大误差簇根2160/8007评分约2.679/2.690，也没有资格。

Sierra95的150个合资格根已全部进入前缀，均没有根内可见样本。最坏点覆盖根428/4812的`E=1.133568px`、`P=1.489287px`，都低于4px。**该帧没有前缀截断；在同一人口内换排序或扩大前缀不能创造所缺请求。**

以上“无可见样本”严格指根自身闭面支持，不代表E/H等可能包含相邻面的提案必然没有可见证据。数据证明前缀与几何误差机会错位，不能直接证明全部密度项无用，也不能保证反事实前缀具备可认证、可预留的目录项。原轨迹中Peking15形成2个接收方并执行1次交换，Sierra48/95没有接收事务；离线排序没有改变这些事实。

## 5. C4：实际接受事件说明了什么

### 5.1 Canyon/frame8：可见点退化，并非只有未来视图风险

04B开启轨迹的B根`-335`：闭面支持817个样本，其中当前可见356个。旧支持可见最大误差4.911466153px，目标4.901466px，新支持认证上界4.637617055px，正确满足现行接受条件。

然而同一事务的近内部见证3在当时**可见**，误差由0.071696717升到3.116942515px；高度由4.131909982变为3.776019267。它仍然低于4.901466px，所以接受没有违反当前规则。旧外边界见证0在该时刻不可见，其诊断投影9.61498→2.45816不能混入当前接受分母。

该B使用空额、没有donor；旧顶点高度不变，新点已经固定取源高。故这条反例既不是donor损伤，也不能通过“继续禁止旧点拟合”消除。改变连接和加入源高点可以重新分配局部误差：**最大值下降，不代表每个点下降。** 04B固定frame48视图下该近内部点约0.068657→2.921px，后续仍约2.918px，与当前视图数值分列。

### 5.2 Peking200k/frame13：改善目标点仍可使邻点变坏

B根`-495`支持1,820个样本，全部可见。旧最大值1.133541800px，目标1.123541px，新认证上界1.057312040px。

| 当前视图见证 | 修改前px | 修改后px |
|---|---:|---:|
| 原主要见证 | 1.133541790 | 0.281961001 |
| 邻近见证 | 0.007142803 | 0.030704818 |

这也是空额B，没有donor。固定frame15投影下主要见证约1.996557→0.496758px，但整帧Emax为1.872770px；单见证的改善不能替代整帧最大值。

### 5.3 保证的真实范围

接收提案`SetProgressTarget → Measure → Accepts`要求其当前可见样本误差不超过旧见证减0.01px后的阈值。Donor测量自身支持，但按接收方目标认证；空可见donor支持与空可见receiver支持的处理不同，后者直接拒绝。翻边R仍复用同一进展目标/认证，只是净预算与目录触发不同。

若完整支持、数值证书和冲突发布前提均成立，可解释固定视图、同运行时Q上的局部最大值约束；本阶段不是重新完成这些前提的形式化证明。该约束不提供：逐点不退化、独立Q_eval上界、绝对E*达标、全局最大值每批严格下降、下一视图质量、有限恢复时限。存在多个相同全局最大点时，只改善一个也未必降低全局最大值。

## 6. C5：恢复失败必须按观察点和原因分开

| 有限证据 | 当前可以归类 | 未被证明的外推 |
|---|---|---|
| Peking50k原边界见证 | 旧轨迹几何高度始终不变；frame15已有请求但排名194被截断，其他机会还有目录拒绝 | 返回后屏幕误差下降即已恢复；提高排名即可跨越边界目录限制 |
| Peking200k、Canyon的04B事件 | 新B可以真实改变边界残差，同时存在邻点误差转移 | 主要见证恢复即持续全域质量通过 |
| Sierra48主要见证 | 有合资格覆盖根但被密度前缀挤出；同点另一覆盖根尚未触发 | 只能归因于Fit或所有覆盖根均无资格 |
| Sierra48较大误差簇、Sierra95 | 对应根低于4px政策；后者前缀并未装满160 | 扩大前缀、donor搜索或重复相同静止机会即可强制恢复 |

原QPC-01的观察计数保存在summary的`witnesses`：它们是跨机会的根/事件次数，不是独立候选人口。目录失败、翻边耗尽、认证失败等记录只能限定当前目录与根边界，不能当成一般局部几何空间无解证明。

当前视图误差、固定未来视图投影、世界高度三者继续独立。没有增加未来信息到生产决策，没有延长恢复机会。0.01px局部改进不能推导“若干批后全域到E*”；候选资格、目录可行性和全局最大点覆盖均可能中断进展。

## 7. 可提交Review的误差目标契约

建议先明确**达到目标后停止的质量政策**，与“给定预算继续尽量降低误差”的政策分开。这里只提出契约，不新增参数或选择新数值。

1. **目标对象。** `E*(view,Q_target)`是独立双线性参考、指定当前可见采样集上的绝对最大误差目标；记录分辨率、可见性、样本版本与实际float输出。`E*`不与`SplitPixels`或DOD质量自动同义。
2. **完成判定。** 指定更新机会后若独立评价达标，报告达到目标；否则明确报告残差与首个已证阻塞层。未达标且预算/目录不足是一种可报告失败，不是目标已经满足。
3. **请求分离。** 几何误差需求与密度需求应明确标识优先级角色。当前“复合P全局排序”可以保留为旧政策，不能继续把它解释为“最坏独立误差优先”。
4. **认证边界。** 局部进展认证不代替绝对完成判定。若宣称生产认证保证Q_target，必须先统一采样/投影定义或提供覆盖界；若保留独立采样，明确它只是额外评价，不伪称受到同一证书保证。
5. **非目标退化。** 保留Dmax、完整分布和Hmax，并在下一次生产修改前冻结允许代价。不能自动升级为所有点必须单调，也不能仅因Emax下降就撤销04B已有退化记录。
6. **时间。** 固定当前视图完成机会与连续轨迹分列；恢复时限尚无证据，不承诺随相机瞬时达标。持续失败必须暴露，不能永远记作“下批再处理”。

**至多一个后续有限候选：同一候选集合内采用几何误差优先的前缀，做明确的策略A/B。** 它直接检验C3所发现的机会错位；冻结资格、前缀数量、目录、预算、采样与tie-break，完整计费并检查真正执行与质量，不把离线排名当成功。此候选属于新选择政策，不是等价性能优化。

这一个候选的能力边界已知：不能修复Sierra95未触发需求，不能补齐C1采样保证，也不能保证C4不发生误差交换；若下一阶段目标要求一并解决这些问题，必须重新限定小规划，不能顺手混入。现阶段不建议同时取消密度、调低阈值、放宽接受或扩展目录。样本定义应先在契约中显式版本化，但本阶段不改变历史评价数据。
