# GWR：契约、生命周期与可削减工作审计

2026-09-14；源码 `114c00d` 的事务模块，复用 [FPR](../profiling/cpu_function_profiling_findings.md) 与[函数模型](../profiling/fpr_function_cost_analysis.md)。本表为源码事实和实施义务，不是时间下界。

## 观察点与生命周期

| 对象 | 当前产生/观察 | 不变量与失效 | 可实施削减 |
|---|---|---|---|
| boundary | `State::IsBoundary` 在 BuildOrders 与 H 目录扫描邻面/边 | 与相机/高度无关；初建根据单面边确定；已认证事务固定外接口，新点来自域内 E/F/H，回收只删内部点 | 存入 VertexRecord；旧点保留，新点内部，独立验证继续对实际边表核查。degree 已是 Incident.size，不另存副本 |
| 参数位置、连接、owner | Samples 初建和局部 Prepare；Certification/Probe 读取 | 改连接影响闭补丁样本，外侧 owner 也可能共享边；H 改高不改包含关系 | 当前双向关联继续复用，不在 SetView 重建，不取消局部边界贡献 |
| ReferenceHeight/MeshHeight/HeightError | 静态样本及局部发布 | 源固定；实际拟合高度的改动进入完整支持 | 与新视图数组分开，不为换相机复制几何样本 |
| ErrorSquared/Visible | PrepareView 全 Q、按面归约；Fit 见证、VisibleSupport、Probe、Validation | 视图变化全部可能失效；参考决定可见域，被测跨近面仍拒绝 | 当前/备用数组，成功后交换；Value(sid) 合成只读观察，禁止遗留直接旧列读取 |
| 原始候选/回收顺序 | BuildOrders 全树，Prefix/DonorPool；A 每次成功后重新查询 | 精确平方 P/稳定 ID；RawCount、旧尾部提升、空证据需求都可观察 | 连续记录和持续摘要，不只保留 top-64，不令 A 每步全扫 |
| 接收目录 | 全 E/F/H 构造，随后 Fit 至首个成功 | ordinal 决定临时新点 ID；样本见证与顺序固定，donor 不改变目录 | 惰性 Next；成功前尝试相同，成功后未使用构造不必发生 |
| 定位/权重证据 | Fit 重找覆盖面/权重，Measure 再查；区间/精确分支各有事实要求 | 同提案参数坐标/连接不变；高度变后重新计算高度/投影；视图系数绑定本快照 | 单提案不可变证据；普通浮点、区间及精确类型不能相互冒充 |
| donor 证书/足迹 | B/C 已整池认证一次并缓存；配对反复构造足迹；A 已按需缓存 | 证书与几何/视图绑定，Accepts 的 receiver 阈值每次不同 | 足迹缓存/尾扫描削减先做；按需 donor 只有实际不同中心触达量减少才可能省工，也可能损失并行准备 |
| 预算与批次 | receiver 成功项先命名空额度，顺序配对/预留 | 无同批回流，已用 donor 唯一，R/W 冲突及失败仍是动态事实 | 保持选择；全审计的 D_feasible 与额外失败枚举分离，未取值显式标识 |
| Pending/发布 | Commit、Samples、Mesh 先全准备后发布 | 旧 Pending 不清空；所有失败点前保留旧可见代际 | 新缓冲/索引准备亦遵守；内部容量可以预留，但不得发布一半逻辑状态 |

## 必须保留与允许取消的工作

独立全域 Validation 已在诊断/ROI 外，不能将其当作未来可回收热路径成本。耳切的包含/方向、实际新面角度、事务的读写冲突，是构造所需的动态谓词；不能因为“构造正确”删掉。Measure/ErrorBounds 主要是输入相关质量决策，不是重复全网格合法性证明。

可以去掉的是同一未变事实重复恢复、无用途目录尾部构造和统计尾扫描；可以换表示的是完整排序及视图复制；尚需新证据的是跳过 Q 的精确评价和以普通浮点过滤替代区间表达式。数值配额/异常不同造成未完成运行不能计为加速。

正常模式必须保留批准事务、Intent/Pool 身份、接收选择、实际高度、预算和下轮状态。统计失败计数允许不同；完整审计另取精确四层分母，不以未知填零。A 与 B/C 的反馈语义不同，不把共享实现导致的 A 变慢当成算法收益。

## 原型映射与未决条件

GWR-02 将 `Values()` 的直接混合数组观察拆成样本数量和按 ID 的合成读取；采样/认证使用当前代视图，不允许保留旧列兼容。备用数组具有单一所有者，填充失败仍可复用，下次必须完整覆盖。事务局部修复同时更新几何样本和当前视图，备用数组直到下一次全覆盖才可使用。

GWR-03 必须覆盖 Prefix(r)、DonorPool(m)、RawCount、Raw 的诊断展开；节点删除/复用/降分后从全部记录提升尾部。全量与局部性能分别检查。

GWR-05 才审计一个具体层次界；当前没有规范浮点 P、全域近面异常、回收最小前缀和见证四者统一的已证明跳过机制。不创建 ViewEvidence，不认定层次结构或小 top-r 自然带来次线性求值。

结论：同任务削减契约清楚，结构事实/视图存储可进入实施；性能、持续质量与精确按需视图均未通过新的 Gate。
