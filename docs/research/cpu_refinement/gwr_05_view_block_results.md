## 推导与验证

固定参考 u/v/ReferenceHeight 块界不随 topology 改变。按原 Clip 运算树向外舍入并检查每个中间域，四个最终区间有限且完全在同一 frustum 半空间外时，可精确填原规范的 false/0。未知一律逐样本求值。证明义务及归纳见小规划，未改变浮点优先值、可见集合或近面失败语义。

候选实现通过 300 组有限随机块、frustum 边界、相机后方、overflow 不掩盖的检查，以及相关持续样本 oracle。两场景 C4 与 Peking A 共 24 个 mesh 与 GWR-04 一致。没有用此正确性通过代替性能通过。

## 数据与撤回理由

| 配置 | 完整帧 before → candidate (ms) | 换视图投影跳过数 |
|---|---:|---:|
| test129 C4 | 14.973 → 15.148 | 五次合计 5 / 494085 |

| Peking A | 27.170 → 29.705 | 0 / 8954405 |

Peking 每视图检查 6996 块，没有排除任何块；test129 每视图 387 块，仅最后单样本块被排除一次。SampleEvaluations+ViewSkippedSamples 与旧版求值总数相同，证明没有偷偷缩减人口。当前块包围盒不能获得足够排除能力；本轮不继续定位第二机制、调块大小、加层或更换优先值。

由于目标工作基本没有删除，已经满足机制退出条件；无需为时间波动重复采集来判断是否“可能还有一点收益”。额外初建 O(q)、空间 O(q/256) 和每视图块界运算不值得保留。原始数据、候选可执行文件及源码在 benchmark-output/cpu-refinement/gwr-05，先归档后撤回所有运行路径、字段和测试接线。

最终生产候选回到 GWR-04；完整 view 工作仍有 Θ(q) 投影和闭面贡献归约。当前没有获得次线性 view update，也没有证明其不可能。GWR-06 收口已有削减，不用未实现的 hierarchical query 预支后续收益。
