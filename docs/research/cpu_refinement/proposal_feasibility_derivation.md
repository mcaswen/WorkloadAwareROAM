# QPC-04G：提案可行域推导与核查日志

2026-09-17；上承[规划](../../plans/cpu_refinement/qpc_04g_proposal_feasibility_plan.md)。以下纸面推导与有限有理核查已完成，见[自然结果](qpc_04g_proposal_feasibility_results.md)。它们不是Lean定理、生产完整性证明或运行时性能保证。

## 1. PF-01：固定几何只剩一个高度

`Prepare`在固定存活点政策下令E/F/H的Free仅含新点。固定参数域三角形及q后，精确重心权重不随高度z变化，因此`h(q;z)=a+bz`。a必须由提案的固定顶点求得；浮点初高未必使未拟合曲面精确等于旧曲面。参数域形状与z无关；形状失败不是拟合搜索问题。

B的中点高度由源规定，提交还核对这一事实。它是单例，不因为存在Free字段就能改变高度。对当前B的一个精确违规样本足以否定该提案，不否定其他边界原语。

## 2. PF-02：从透视平方误差到一维条件

固定q，将高度为h的齐次坐标写成`m(h)=d+c h`，参考高度为r。参考可见性固定且参考分母`w_r>0`。屏幕差的x分量为

\[
\frac{W}{2}\left(\frac{d_x+c_xh}{d_w+c_wh}-\frac{d_x+c_xr}{d_w+c_wr}\right)
=\frac{W(c_xd_w-c_wd_x)}{2w_r}\frac{h-r}{w(h)}.
\]

y分量同理。因此存在非负有理数K，使

\[
A(h)=K\frac{(h-r)^2}{w(h)^2},\qquad w(h)>0.
\]

原始二进制矩阵、参考双线性有理值和q的整数比决定K；没有用旧Fit向上量化的k代替。K=0时屏幕误差恒零，仍需检查投影定义域与高度条件。

对样本上限`T=max(A0,E*²)`，若K>0且w>0，条件等价于

\[
|h-r|\le s\,w(h),\qquad s=\sqrt{T/K}.
\]

代入h=a+bz得两条仿射不等式；正w和近面另给仿射约束。高度条件则直接用有理上限`max(|h_old-r|,H*)`生成两条仿射不等式。完整核心安全域是一维区间交，可能空、单点或有正长度；严格分母边界必须保留开闭性。

## 3. PF-03：必要外包与充分内包不能混用

有理t≥0、固定B=96，取`j=floor(sqrt(t·2^(2B)))`。使用整数除法和整数平方根可精确得到j；`l=j/2^B`、`u=(j+1)/2^B`包住sqrt(t)，若j²恰与t·2^(2B)相等则上下界相同。对正w，l的两条线性约束是充分条件，u的约束是必要条件。

全样本求交后有`F_inner ⊆ F_true ⊆ F_outer`。外包空可证明无解；内包非空可选择安全点；内包空而外包未空只能记数值未决。每次收紧保存样本/约束行及上下界；不以浮点epsilon消灭单点或窄区间。

若T由旧误差支配，`sqrt(T/K)=|h_old-r|/w_old`本身为有理数，可直接计算而无根包络；若目标支配则用上述包络。实现先做等价性解析核查，再自然运行。此改写替代一般二次根隔离，仍在规划的一维有理/定向区间边界内。

## 4. PF-04：旧统一门槛与新进展不同

设样本1不依赖z，误差固定2px；样本2可从1px降至0.5px。目标0.5px时两点都不增加损伤、超标平方和严格下降，但任何要求补丁最大值≤1.99px的提案均不可能。旧`SetProgressTarget`的0.01px统一门槛会排除它。

这只证明两政策不等价，不证明自然输入必有这种机会。自然诊断要分开旧Fit实际结果、旧保守模型、旧精确统一门槛和新域。新见证若不满足旧门槛，后续利用它属于政策修改；若满足旧门槛但旧模型排除它，再归因保守系数/数值求交；若旧模型有域但原选值失败，再归因选值。

## 5. PF-05：安全、进展与发布表示

在核心安全域内每个可见样本的超标平方损失非增，故接收进展是非负项和。有限试值找不到严格正和不构成全域无进展证明。若所有旧超标样本均有`b=0且a=h_old`，它们保持原误差；旧未超标点在安全域中仍无超额，因此不可能有正进展。只有`b=0`不够：改连接可能已经改变常数项a。其他情况要证明整个区间的进展上界，或保留未知。

自然结果又给出一种可精确结束的情况：必要域`F_outer={z0}`，且对完整Q均有`a_q+b_q z0=h_old(q)`。任何安全z只能等于z0，它的全部误差等于旧值，故g(z0)=0；整个域没有接收可行解。若z0不能由binary64精确表示，还可单独排除可存储安全高度；即使可表示，也不能把安全单点当成严格进展。此判据不依赖有限试值、epsilon或经验门槛。

选值必须先舍入到实际binary64高度并重新检查。公开float世界x/z与高度另形成曲面：x/z固定，但高度是z的分段常值函数；不能沿用核心a/b或核心闭支持。独立精确评价重新枚举公开旧补丁的Q、定位和插值，再检查逐点条件与128位定向和的正下界。通过后仍要原生认证私有提案，不能把实数域见证直接发布。

## 6. PF-06：失败的生命周期

参数域形状依赖目录连接/坐标，固定源高B的高度拒绝还依赖源、闭Q及目标；屏幕条件和进展另依赖视图及可见域；旧Fit门槛又依赖旧局部最大值。预算/批内冲突不属于此可行域。相同失败字符串不推出相同输入，相同局部几何也不推出同一视图求解问题。本轮只用原轨迹输入指纹核对重复，不把它升级为生产缓存失效证明。

## 8. 自然反例与条件证据的对应

PF-04的“固定最大值但其他点可改善”不再只有解析例：Peking599/E0在高度`1.6703567465237084`时核心超额降低约1476.909px²，局部最大值精确不变。sample597857使旧门槛出现零系数负右端；Sierra95相应例中sample144696提供相同结构的反证。28项的原生旧`Accepts`均为false。

PF-05的单点例中，Sierra4182/E0的两个高度条件分别要求`z≥27556153/4194304`及`z≤27556153/4194304`，来自259951/259954。全Q证明该高度只重现旧曲面，所以“选可行区间里更好的高度”在这个固定问题中没有自由度。Canyon803的两个E也由相反高度约束锁成单点；Peking599/E2由屏幕约束锁成单点。

B的固定源高反例保留：Peking/Canyon局部Emax与总超额都下降，但分别有682/220个屏幕损伤点和577/225个高度损伤点。因此最大值、分布总量和逐点约束三个量词不能互相替代。

本轮的无解结论都是**当前固定目录/插点/旧高/参考Q/view/目标下无可接收进展**。没有证明连续曲面误差界、全目录完备、任意局部重构不可能或未来视图恢复时限。
