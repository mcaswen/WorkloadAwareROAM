# QPC-04D之后：事务化LOD的质量与成本结构重审

日期：2026-09-17。依据：[04C契约审计](qpc_04c_quality_target_results.md)、[04D实验及原因分析](qpc_04d_error_first_results.md)、[代码事实](../../codebase/cpu_refinement/qpc_04d_error_first_facts.md)。这是用户要求的算法审视与候选设计讨论，**不是已确认的生产修订或下一阶段实施规划**。本轮不改算法、不采新数据、不改变历史验收。

## 1. 判断：现在要修的是目标与接受规则之间的关系

04D说明，接收顺序可以显著增加真实适应工作，但没有给这部分工作一个足够完整的质量目标。当前链路分别使用：

```text
复合P决定有没有请求
→ P或E决定先尝试哪个根
→ 首个可认证目录项决定做什么
→ 接收局部旧最大误差减0.01px决定允许多大代价
→ 捐赠方仅在当前可见支持上满足这个目标
→ 冲突与命名额度决定实际执行
```

这几项各有明确实现，却没有共同推出“在固定预算和更新费用内趋近一个明确的持续质量目标”。不能继续用“执行了更多事务”代替质量进展，也不能把多做的真实工作全部称为实现冗余。

应保留的部分是快照、全局优先决策、事务读写冲突、硬预算、批量物化与局部续接。需要重新审视的是**什么才构成需求、什么损伤可以支付、什么才算进展，以及为这些决策付多少工作**。这不是再次寻找未知目标J，也不要求回到Legacy逐步模拟。

## 3. 先明确哪些保证仍然成立，哪些不存在

已有纸面条件支持：在**同一视图、同一运行时Q、完整修改支持、有效数值证书与无冲突发布**下，接受事务不提高该Q上的全局最大屏幕误差。它不保证逐点误差、RMS、下一视图或独立Q_eval的最大值不增。相机变化也会改变误差函数。因此“有些位置边修边坏”不直接反驳旧的窄命题，却说明该命题不足以支持持续LOD目标。

需要区分三个问题：

1. **达标**：是否达到指定的独立质量操作点；相同numeric `SplitPixels`不是跨算法同质量。
2. **允许交换**：可以让哪些位置变坏、最多到什么程度；不能隐含为“只要仍低于别处最大值就行”。
3. **可恢复与费用**：存在违规位置时能否产生请求、能否找到合法操作、有限时间内能处理多少。

不应直接改为所有点每次都不退化。原网格精确经过的采样顶点误差接近0，删去中心通常会失去这种插值；逐点零损伤规则可能排除大量回收。反过来，单个全局Hmax不增太弱：已有1.1659的最大高度残差并不能阻止另一区域新增长0.3403。

**已有HeightGuard也不能直接等同于新保证。** `PreservesHeight`对receiver和donor的完整闭面Q分别求值，再比较两补丁联合的旧/新最大高度误差。它仍允许联合最大值以内的空间转移，没有逐位置损伤预算。不能不运行反事实就断言它一定会拒绝Canyon5928事件；也不能将“打开旧开关”写成持续质量已经修复。

## 4. 建议先论证的最小质量结构

### 4.1 质量请求与密度请求分离

定义显式质量操作点`E*`及其Q、投影、可见性和实际输出精度。几何请求至少要满足：在声明的测量域中，误差超出E*的位置不能因为另一个复合触发数字更大而被当成无需求。密度请求可以保留，但须明确其优先级与停止条件，不能继续隐式占满用于解决几何违规的前缀。

E*尚未选数值，也不要求每次都达到DOD的逐点结果。若E*=4px，Canyon返回2.78px本就达标；若论文目标要求明显更小的误差，生产策略必须表达那个目标，不能用4px停止后再靠排序解释未恢复。

04C已经确认Q_runtime与Q_eval约三分之一位置不同。可选方案是统一目标样本定义，或为目标域补充覆盖界；两者均需单独核算成本。若暂不做，只能保留“运行时采样契约＋独立评价”，不能承诺评价器所有点均受证书保证。

### 4.2 在目标以下允许交换，在目标以上限制退步

一个值得先核查、尚未批准的充分条件是：对整个交换的受影响可见样本q，要求

\[
e_{new}(q)\le\max(e_{old}(q),E^*).
\]

它允许原来精确的位置退化到E*以内，保留预算回收空间；但不能为了改善一个坏点，把一个好点推到E*之外，也不能让已超标点更坏。receiver、donor以及无donor的Free事务都要遵守，不能只给捐赠方加检查。

在固定视图和固定样本权重下，定义仅作决策与证明辅助的超标量

\[
\Phi(M)=\sum_{q\in Q_{visible}}w_q\,[e_M(q)-E^*]_+^2,\qquad w_q>0.
\]

权重须预先冻结，不随网格或提案改变；共享边样本仅计一次。这不是替代Emax/RMS/Hmax的论文综合分数。上式逐点条件推出Φ不增；再要求每个被接受的质量事务使Φ减少至少δ>0，则在固定视图、共同Q和支持条件下，受限于该规则的成功事务总数不超过Φ初值/δ。无冲突批次可按唯一受影响样本贡献合并。

**该推导不证明一定达标。** 可能没有任何满足条件的合法事务、存在预算或目录阻塞，δ也可能拒绝有用的小进展；移动相机还会改变Φ。它的价值是建立可审计的“做了工作应减少什么”，并把停止区分为达标、无可行操作、搜索未完成或费用耗尽。替代的更弱净收益条件也可以讨论，但不能再宣称它阻止逐点超标转移。

该规则会改变原首个可行目录项和配对结果，属于新质量政策，不是等价性能优化。若有限反事实显示它让当前事务基本消失，应报告与原语能力冲突，不自动放宽条件继续寻找正结果。

### 4.3 离屏损伤需要独立的持久约束

当前可见Φ无法约束不可见区域。候选是对整个修改域维护与相机无关的固定空间误差包络，例如

\[
|h_M(q)-h_*(q)|\le\varepsilon(q).
\]

包络须在事务之外定义，不能根据当前提案、另一区域的大误差或每轮旧状态重新抬高，否则会形成逐轮放宽。种子若不满足，需要显式记录初始违规和修复义务，不能悄悄把每个坏值设成新容许值。具体空间尺度、数值、采样或保守几何界仍是待Review的设计问题；当前不增加参数。

这只能限制持久几何损伤，**不自动保证任意未来视图的屏幕误差**。只有在声明的视图域中投影深度有正下界，并控制参考到网格高度段的投影导数，才可把高度界转换成像素界；任意接近近面的视图不能获得统一的小像素保证。若用固定视图邻域或速度上界替代全域包络，也必须显式声明，不能读入实验未来相机。

成本不可能凭公式消失：直接检查全修改域样本是O(s_patch)，保守摘要要计构建、维护、失效和模糊分支。最小验证应先用已有完整局部证据判断约束是否保留足够事务，再决定是否值得设计摘要。

## 5. “质量目标”必须带明确失败出口

请求→目录→认证→资源四层继续保留，但结果应回答：当前是否仍有E*违规，不能只回答本批执行几次。

- 有超标但不入资格：请求政策不完整，或声明的采样域不同。
- 已入资格但没进本批：有限查询/费用选择，仍是未处理需求。
- 目录已尝试完：只说明当前目录无可用解；不能当成所有局部网格无解。
- 合法事务被资源/预算阻止：须保留未完成原因，不能作为质量达标退出。
- 同视图再次运行没有依赖变化：可以复用适用的失败证据，不能每轮重复昂贵判断，也不能跨失效边界永久屏蔽。

有限原语无法保证任意初始网格、任意预算都能达到任意E*。是否需要扩原语只能由新的失败分布决定；目前不把2-ring、任意重剖分或扩大前缀作为默认下一步。

## 6. 成本结构：分别处理必要工作与表示放大

令q为样本数、a为闭面关联量、N为槽规模，r/m为前缀/捐赠池，c为实际配对检查次数、b为批准批宽、f为单事务资源集合规模。s_i是实际认证支持，z/aΔ为局部定位/关联访问。固定最大度数不使s_i、z、aΔ成为常数。

| 成本 | 当前来源 | 可以争取的结构改变 | 不能预支的结论 |
|---|---|---|---|
| 换视图 | 全q投影、全部a归约及槽/块索引工作，至少有Θ(q+a)工作 | 后续用可验证上界剪枝，或更适合实时的误差表示 | 没有紧界时精确最坏查询仍可能访问全部Q；旧GWR失败不等于所有界都无用 |
| 认证 | Σ实际尝试s_i、局部几何定位、拟合及精确分支 | 先排除无收益/结构失败；按依赖版本复用不变证据 | 新质量规则通常增加检查，不能预设比当前认证更便宜 |
| 配对/预留 | c≤rm；联合有序资源集合，并逐个比较已批准事务；保守O(c(b+1)f log(f+1))，另计模糊质量比较 | 在相同顺序上用读/写资源占用索引查询，去掉逐事务b因子 | 不能消除rm最坏搜索；不能仅看资源查询就宣布完整提速 |
| 续接 | 新面包围框定位、owner/闭面修复、接口评分和脏块索引 | 复用完整局部证据、减少重复关联访问；费用随实际触达计 | 不能用O(bd)替代全部样本维护，不能把写出几十个面当成完整费用 |

资源索引具有一个可独立论证的等价方向：请求读资源时查询已有写占用；请求写资源时查询已有读或写占用。保持同一完整资源定义、内部冲突、donor复用和原贪心顺序，成功后才登记，失败不占用。用有序索引，查询/登记可争取O(f log(R+1))，R是已登记资源数；哈希的O(f)只能是期望界，建表、清理和空间O(bf)均须计入。改变允许的共享写规则则是另一项正确性变更。

其依据是集合恒等关系：与任一已预留事务发生读写冲突，等价于与它们的读集合并集/写集合并集发生对应冲突。当前批次只追加预留、拒绝不登记，故只判断冲突存在性时不需要逐事务回看。质量接受、交换内部冲突和预算命名仍分别处理；此等价不替代它们的证明。即使查询因子被削掉，最坏c=rm、精确认证及后续O(b²)批次复核仍须计入完整账本。

这个方向针对Peking确有价值，但Sierra没有配对，无法由此获益。Peking暖新增成本63.2%在预留；Sierra88.6%在认证与续接。两组要求不同的工作削减机制，不能先写一个统一“优化后会快几倍”的承诺。

## 7. 把一次事务的收益与全部费用放在同一本账上

算法优化目标应是：在结构、预算和声明的持久损伤约束下，用有限CPU费用减少质量违规，而不是最大化事务数量。至少并列记录：Emax及误差分布、超标量变化、实际N、独立完整CPU、认证样本访问、配对/资源查询、续接触达以及阻塞原因。

“≥50k优于DOD”的性能目标也应注明实际N和质量操作点；Sierra本轮最终仅约11k，不能因cap=50k就代表50k实际负载。相同阈值、相同cap和不同实际质量的时间差不能直接成为该目标的验收。

不能只报告单次commit成本，也不能用“每次成功事务耗时”衡量有效性：大量事务可能只带来0.01px局部最低进展，还可能把误差移到别处。Φ收益/CPU可以作为分析量，但不建议立即拿它重排全局贪心；那会再引入一个策略变量。

性能约束也不能藏在前缀中。r/m是搜索配额，不是质量目标；限制搜索意味着可能延后更高质量收益，需报告未处理需求与恢复延迟。若要实时费用上限，应显式区分确定的操作配额与墙钟截止，不能在有限时间内未完成时宣称达标。

## 8. 建议的下一步与停止条件

优先做一个**质量接受与进展规则的小型契约验证**，不立刻全量重跑、不加线程、不先做预留性能改造：

1. 冻结E*目标域、允许退化和离屏约束候选；将4px停止与“接近DOD质量”明确分开。
2. 复用已保存的Canyon可见误差转移、5928不可见删点及Sierra目录阻塞，判断候选规则分别能解决哪一层；不能只验证它拒绝已知坏例，还要检查已有有效事务是否大量被拒绝。
3. 在原有限输入中估计新证据访问和保留的真实进展；离线过滤旧提案只能证明这些旧提案的适用性，不能替代新政策下的反事实状态演化。
4. 只有契约具备合理可行域，再写实现小规划和一次原轨迹对照。通过后冻结政策，进入原QPC-05的等价资源索引优化；认证/续接仍重，则交QPC-06按新工作量定位。

若无法选定可解释的质量目标，或者必要损伤约束使当前目录基本无进展，就停在算法契约问题，不能靠优化预留掩盖。若质量规则成立但认证/续接费用已吞掉≥50k性能空间，也要重新评估表示，而非继续承诺线程会解决。

**当前建议保留执行架构，重做质量需求—事务接受—进展判定之间的契约。** 所提充分条件尚未证明适合自然输入，也没有实施；需要用户Review后再收敛成一个有限小规划。当前不宣布研究路线失败，也不把后续收益写成既定事实。
