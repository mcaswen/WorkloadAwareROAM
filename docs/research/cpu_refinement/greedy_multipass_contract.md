# 快照全局贪心预留：执行与质量契约

> 2026-09-14；规则身份 `gmp-contract-v1`。来源：[GMP-01 小规划](../../plans/cpu_refinement/gmp_01_execution_contract_plan.md)。用户已授权本大规划内自主闭环。本页是确定性算法规格和手算，不是运行时实现或自然实验结论。

## 1. 任务、输入和结果

给定当前共形参数域三角网格 M、共享顶点的实际高度、不可变原始高度场、相机、公共样本 Q 和硬预算 B，直接产生本批局部替换事务。无需 Legacy 提供目标 J。拓扑可离开二叉层次；保留的是全局优先思想、硬预算与声明的独立质量约束，不是原 ROAM 逐请求轨迹或优先值最优定理。

输入要求：域为矩形圆盘；面正定向、无重叠或悬挂点；共享边高度一致；N≤B；所有参数角满足下述 θ；高度有限。顶点/面有稳定逻辑 ID，面 ID 不随数组压缩变动，边键为排序后的端点 ID。任何局部读都带快照版本。源网格身份、参考、相机、规则参数共同标识本次输入。

结果为 `RefinementIntent[]`、有限 `LocalProposal[]`、`BatchDecision` 与原因/工作账本。提案仅携带本地面替换、有限高度和证书支持；规划器不构造完整最终活动数组或邻接。新逻辑 ID 按 `(snapshot, intent, proposal, localOrdinal)` 预分配，物理槽位另计。

## 3. P、G、C、E 与样本边界

每个当前面最多一个主需求。有效 P 超过阈值即进入 `D_raw`，按 P 降序、面 ID 升序。未投影或空样本面另报；不能从原始需求中按回收后端过滤。P 决定先处理哪里，不是接收收益，也不是最大误差的全局最优权重。

闭面上的 V 样本共同定义面误差。物理存储的 `owner(q)` 取覆盖它的最小稳定面 ID，但共享边/点样本对所有关联面摘要有贡献。误差可求一次后分发；统计 `sampleEvaluations` 和 `sampleFaceContributions` 两项。没有 V 样本不代表连续误差为零。

对接收提案的完整修改区域 F_r，计算旧真实见证下界 L_r；不能用原主需求面的 P 代替它。G 包含 `(F_r,L_r,τ_r,U_r)`，τ_r=L_r−η，U_r 为新曲面在 `Q∩V∩closed(F_r)` 上的误差上界。C 包含回收区域 F_d 的旧误差、回收后 U_d、固定边界高度和证据状态；U_d 不是增量损害。

交换要求接收/回收几何内部不交且状态冲突已解决，并满足

\[
\max(U_r,U_d)\le\tau_r=L_r-\eta.
\]

空额度接收仅需 U_r≤τ_r。同一 Q/V 上，所有被改点的新误差不超过旧全局最大值，其他点不变，因此全局 sampled maximum 不增；不保证每点误差、RMS、连续最大值或后续相机的误差下降。某个大误差在另一不动区域时，全局最大值可保持不变。

## 4. 有限接收目录与可计算认证

每面按下表顺序生成，目录稳定，几何不适用则保留明确失败。每个提案的 τ、拟合结果都在接触回收后端前固定。

| 次序 | 位置、变量、支持与身份 |
| --- | --- |
| E，至多 3 个 | 内部边按边键排序，q 为边中点；2→4，仅新点高度自由；两邻面为完整支持；提案键 `(edge, midpoint)` |
| F，至多 2 个 | 先取本面屏幕误差最大的公共样本（同分样本 ID），仅严格内部且不是旧点时生成；再取面重心，位置相同去重；1→3，仅新点高度自由；支持为该面 |
| H，至多 3 个 | 该面三个内部顶点按 ID 排序；q 固定本面重心；该中心完整 incident-face set 内仅中心和 q 高度自由，原面 1→3，其余连接不变；支持为完整邻域 |

E/F/H 均净增 2 面。H 不适用于“共享边插点加旧高度调整”这一未推导连接。域边细分的 +1 不在目录中；边界需求依然记录。三者首先检查新面形状；高度自由不能修复参数角。相邻主需求可引用同一 E，但其成功仅归一个主需求，不能重复计算释放的预算或兑现数。

设新曲面 `h=h0+φ·a`，φ 一维或二维，初始 a=0 复现旧曲面。采用[单高度透视阈值推导 §5](local_height_minimax_derivation.md#5-透视屏幕误差仍可作精确阈值判定)：固定正深度下每点屏幕限制为两个线性半空间，再加高度域与正深度/近面限制。K 的非有理平方根以 ε 网格向上包围；增加一个单位后的上界也允许，但必须报告保守性。先用这些保守半空间求候选高度，不能从空集推断原精确透视条件无解。

一维按区间取交，选择距离 0 最近的可行值。二维从有界高度矩形出发，按 `(sampleID, constraintKind)` 次序裁剪，选择可行多边形各不同顶点的算术平均；退化成线段/点时同样定义。两者处理零系数、相反约束及退化，不额外最小化 τ。二维朴素裁剪最坏 O(s²)，不得引用 O(s) 的随机 LP 界。

最终高度和每个原始数据视为精确有理输入，独立重算齐次投影；直接比较二维有理像素距离平方与 τ²，无需开方即可验真。浮点求解仅提供提案，未完成该检查不得标为认证。sqrt 的定向网格界可用整数平方根实现。自然输入矩阵来自已冻结的二进制浮点值，其精确有理解释不等于无限精度重新计算相机。接受保证只针对这一定义的输入。

固定高度域和有限样本使数学规格闭合，不代表廉价。认证工作超限返回 `unknown/cap`，不建设无限精度通用求解平台。`shape_infeasible` 只对当前固定连接成立；`fit_bound_failed` 只说明保守约束未找到解，不能否定所有插点/精确阈值。

对每面冻结**目录中第一个认证成功提案**为 receiver。后续回收失败不换 receiver；这样不同后端完全共用 G，并限制发现成本。其余提案不是“被证明更差”。无成功提案时不进入需预算层，但逐类失败仍保留。

## 5. 回收后端、共同分母与空额度

三价后端仅删除内部度数 3 点，使用存活邻点的当前高度。一般后端删除任意合法内部点，固定当前 one-ring 边界；净减 2 面。两者读取同一前 64 中心池。中心不适用单列，不在不同后端重新补池。

一般快路径为确定性耳切：每步在几何/形状合法的耳中按中间顶点 ID 取首个，禁止跨越其他环点，固定边界高度；完成后检查全部样本质量。失败不称 one-ring 无解。DP oracle 使用全部可见对角线、形状合法三角形与相同样本代价，最小化最大误差，同分取最小分割位置。它只在 GMP-03 预冻结的少量需求上检查同池失败，费用单列，不静默加入快路径主结果。形状 DP 无解可以否定该固定边界类别；质量 DP 必须完整且算术可靠才可否定同一 Q 阈值。

令 C_rec 为所有有冻结 receiver 的主需求，s=floor((B−N)/2)。前 min(s,|C_rec|) 个需求获得具名空额度，集合记 D_free；其余记 D_need。初始奇数剩余 1 单列为原语粒度余量。空额度只属于该需求，冲突失败本批不回流；下一快照才重新分配。此规则可能降低利用率，`unusedAssignedCredits` 必报，不计作回收后端失败。

四层集合：

\[
D_{raw}\supseteq D_{need}\supseteq D_{feasible}^{b}\supseteq D_{executed}^{b}.
\]

`D_feasible^b`：在尚未施加任何请求预留的完整原池中，冻结 receiver 至少有一个已认证、内部兼容的 donor。`D_executed^b`：实际全局顺序选择后获批的交换。前者不使用真实预留账本，否则局部能力和选择损失混淆。仅有限需求完成审计时同时给已证实下界和未知数量，不能用未检查者充当失败。

`R_local=|D_feasible|/|D_need|`，`R_execution=|D_executed|/|D_need|`；分母为零写 N/A。空额度接收另报；两个后端 D_raw/C_rec/D_free/D_need 必须逐身份一致。

## 6. 完整预留伪代码

```text
read immutable M, Q, View, Config
refresh all face priorities; freeze ordered D_raw
for each intent: certify finite receiver list; freeze first success or reason
freeze common D_free / D_need and donor pool
ledger := empty reservations; approved := []
for intent in D_raw priority order:
    if no receiver: record receiver reason; continue
    if intent owns a free credit:
        try its receiver against approved R/W and resources
        accept and reserve atomically, or record reason and leave its credit unused
    else:
        for donor in frozen pool order:
            obtain backend proposal and full certificate on M
            test receiver-donor compatibility, then conflicts against approved
            if resources can be reserved: accept; break
            otherwise record attempt reason, leaving ledger unchanged
        if none accepted: record principal failure and coverage status
seal batch; publish no partial result
prepare/apply only the sealed local replacements
repair local continuation state; publish next snapshot
```

所有位置和证书读 M；批准结果不更新本批的 P、样本归属或连接。不能在 apply 期间换回收方、补 receiver 或寻找 closure。主失败原因按流水线最早未通过的关卡分类，详细多次尝试另表：接收形状/拟合、无池、回收类别/形状/质量、事务内部冲突、已预留资源冲突、临时资源不足、未知/配额。单个失败不终止后续请求。

正常结束为完整列表走完（可空批）；配额终止为部分覆盖。活动预算批准时以 `N+2|acceptedFree|≤B` 核查；交换净零。私有准备可以同时持有旧/新面，因此临时存储另计。消费者只在整批完成后看到新网格，不能依赖“先发布超预算接收，再等回收”。

## 7. 续接义务与成本

| 状态 | 变化与维护方向 |
| --- | --- |
| 面、边、存活点、逻辑 ID | 删除/加入有限面，邻接入口按受影响边/点修复；不压缩全域逻辑身份 |
| 实际高度 | E/F 仅新点，H 包含中心完整邻域；回收不回滚历史高度 |
| Q 双向归属 | 改连接只重定位完整补丁及其边界样本；仅改高度/相机不变归属 |
| 闭面摘要 | 更新所有关联受影响样本的面；共享边样本不能只更新 owner |
| 资格与 P | 当前局部连接/高度或视图版本失效；相机变化可全域求值，不能承诺局部视点更新 |
| 证书 | 快照依赖版本完整匹配才可复用；不得只看中心版本 |
| 法线、脏输出、槽位 | 所有受改高度/连接影响的面及约定共享属性邻域，屏障后按确定顺序合并 |
| 拒绝状态 | 当前输入依赖版本内的缓存证据，不是永久 blocked；未知必须允许后续重试 |

GMP-02 补支持/组合证明与有限下一轮核查。这里不声称已有持久运行时。没有旧 SplitBuild/History/Γ 被暗中搬到新引擎。

完整工作账本为

\[
W=W_{import/index}+O(N+Q_V+D Q_{boundary})+O(m\log m)
+W_{receiver}+W_{donor}+W_{pair/conflict}+W_{reserve}
+W_{prepare/apply}+W_{repair/output}+W_{diagnostic}.
\]

实际共享贡献数优先于 D 的粗上界。二维拟合最坏 O(s²)，回收朴素认证加 DP 可达 O(d⁴+d³s)，局部归属重定位 O(sd)。池×需求重复查询、失败尝试、精确有理位成本和 oracle 单列。提交局部独立不证明总工作高效，也不承诺完整更新时间或加速。

## 8. 四类参考及手算留痕

A 为同 P/G/C、同原语的动态串行参考：每成功一个事务后更新受影响状态并重新观察全局最高需求；失败只在依赖版本未变时跳过，版本改变可重试。预算足够时直接使用当前余额，不沿用 B/C 的具名空额度。当前状态所有需求均试过且无成功时停止。允许局部缓存，不要求每步全扫。A/B 的差异包含排序反馈和额度策略，不能单独归因于线程。

B/C 使用完全相同快照、需求和批次，分别串行/并行应用；只有 B→C 是同任务多核对照。D 为 Classic/DOD 家族整体质量、行为和完整成本参考。给定批次应用时间不叫完整更新；完整时间必须含所有发现/认证/选择与输出。

| 手算 | 初始、步骤、结果与限制 |
| --- | --- |
| 新生延迟 | M 上 A=10、B=9；A 应用才产生 C=9.5。B/C 先封闭 A/B，C 下一轮；A 参考先 A 再 C。因此不是 strict NextRequest 等价 |
| 顺序匹配损失 | 高 P 接收允许 U_d≤10，低 P 接收仅≤5；池顺序 donor1=1、donor2=7。高需求先用 1，低需求失败；交换配对本可用 7/1 完成两项。L 分别取 10.01/5.01 与 η=.01 对齐；P 与 L 不必同序 |
| 空额度不回流 | B−N=2，C_rec=[A,B]，A 获名额，D_need={B}。A 因资源冲突失败，B 无合格回收仍失败；余额保持 2，unusedAssignedCredits=1。不能把 B 改算成无预算需求以缩小分母 |
| 高需求失败继续 | A receiver 未认证，B 已认证：A∈D_raw 但不占空额度；B 继续。另一情形 A 已预留 donor u，B 只能访问 u：B 局部可行而实际失败，分别落在 D_feasible 和 D_executed 的差额 |
| 公共边样本 | q 位于 t1/t2，owner=t1，但 e(q)=3 同时贡献两面。只换相机：归属不变，e 和两个摘要变；改公共端点高度须覆盖全部 incident faces。只刷新 t1 会漏掉 t2 |
| 形状 | 直角等腰面重心分割最小角为 atan(1/3)，由最尖角方向向量点积 3、叉积 1 得到；30° 拒绝，v1 等号接受。此选择没有证明任意新面以后均能再细分 |
| 完整交换 | 复用 CR-04：16 面、无三价点；(1,1) 的 6 面回收为 4 面，接收共享边中点 (3.5,.5) 的 2 面变 4 面；16→14→16。高度单位 L=1、η_h=.5、U_r=.25、U_d=0，组合通过。原例形状≥30°故也过 v1；这是解析高度实例，不冒充自然像素认证 |

手算只审计语义。CR-04 数据和连续高度证明引用[原推导](cavity_budget_recovery_derivation.md)，未重跑其脚本；本页没有产生新自然数据。

## 9. 已有方法与当前贡献边界

Garland/Heckbert 的[地形贪心插点](https://www.cs.cmu.edu/~garland/scape/)已研究由误差选择点；Franc/Skala 的[并行三角网格简化](https://dspace.zcu.cz/items/28e7e6d9-1d44-4d08-a762-2f237226f849)已使用独立集合避免修改冲突。因此插点、删点、独立集合或多个处理阶段本身不作原创主张。

本契约待验证的是完整同代需求、独立接收/回收证据、硬预算预留、局部事务、完整续接与 CPU 工作账本的组织；是否有足够自然事务且发现成本合理尚未验证，已有工作是否覆盖整体组合仍须 GMP-04 定向核查。不能凭本页宣称算法创新已被证明。
