# QPC-06H 认证准备：推导、失败尝试与验收

## 1. 问题与实施边界

只改变认证前准备和成功证书创建时机。保留06G的数值表达式、06F当前失败点重证、核心/公开两个域、正进展、发布绑定。数据目录`benchmark-output/cpu-refinement/qpc-06h/`，同输入基线为06G after，另保留必要的Sierra当轮复测，不筛除慢样本。

## 2. CP-01：提示资格不需要先排序整个集合

核心支持面集合S及持久闭面样本A(f)满足

\[
q\in\operatorname{unique}(\bigcup_{f\in S} A(f))\iff\exists f\in S:q\in A(f).
\]

因此按支持面逐表查找即可证明当前成员资格。实现用线性find，不依赖额外有序性前提。找到以后仍使用当前旧/新面、可见人口和同一高度谓词重证；未知或不拒绝则执行原排序去重和全部认证。结构/接口失败仍先于提示，不改变翻边资格。公开域支持不受此捷径影响。

反例：只查owner会漏共享边贡献；只用旧缓存命中就拒绝会错拒已恢复区域；把核心支持套给float曲面会漏舍入位移点。三者均未采用。

## 3. CP-02：完整成功后绑定证书

认证期间提案和state冻结，未发布的几何副本不参与CheckSample。故可以先把两域样本放入局部数组，所有检查通过后再创建证书并逐字段复制原绑定值。失败/异常仍没有QualityProof，成功样本次序与几何绑定一致。支持逐域累计、各域低界和原返回理由不改。发布前的篡改、代次和实例检查保持。

删除的是失败提案的无用分配，不是安全检查。内存失败时刻可能变化，不属于正常完成等价定理；完整事务发布原子性仍必须保持。这是纸面推导及有限C++验证，没有新增Lean。

## 4. 根内复用候选：实际无复用，撤回

试作`TransactionalQualitySupport`，单根只缓存最近一个核心支持，键为state/samples实例、version及有序Support。实际Sierra移动4,891次完整域检查只复用1次，构造4,890次。原因是大量重复失败已经被06F的提示提前拒绝；剩余需要完整认证的提案很少连续遇到同一支持。因此不能从“理论上F/H支持相同”推断当前有足够复用人口。

该组件已撤回，不保留无收益缓存和参数传递。候选源码在`after/*/timing/sources.zip`及`with-support-cache.patch`中，独立程序`ParallelROAM-06H.exe`和首轮结果保留。首轮Sierra完整114.107ms（06G 106.031），接收69.829（67.265），样本修复25.378（21.485）；后一阶段未修改，提示环境波动，不能把8ms全归因缓存。Canyon63.150ms近乎持平，旧Fit66.971ms。撤回首先依据只有1次复用，并非把慢样本隐去。

更重的整样本旧数值对象缓存没有建立：其缓存键与生命周期费用更大，而本轮完整认证的相同支持复用人口已经不足。不能将此负结果推广成任何跨根/跨帧复用不可能；后者需要新的依赖与容量设计，不在本轮范围。

## 5. 复杂度和保留实现

令支持样本总条数s、面数d。提示资格从先O(s log s)整理改成最坏O(s)查找，再付原单点取证；未拒绝项仍执行原O(s log s)整理及O(sd)覆盖。早拒绝不再分配成功证书；成功项仍保存完整支持。面证据准备O(d)仍在，未声称认证成为O(1)。剩余可省集合准备原先只占小比例，因此不承诺重复06F的35%收益。

最终版本只保留延迟证书和提示资格前移，无生产新增文件、接口或持久状态。

## 6. 最终测量

| 输入 | 06G移动ms | 最终06H移动ms |
|---|---:|---:|
| Sierra源高 | 106.031；当轮复测110.827 | 107.427 |
| Canyon源高 | 62.744 | 62.544 |
| Sierra旧Fit代表 | 70.332 | 67.179 |

不能选择较慢的110.827作为唯一分母：相对原06G，Sierra为+1.32%；相对当轮参考为−3.07%。因此只称没有确认超过工程门槛的完整退化，不签发显著完整提速。详细阶段/返回/静止、均值中位P95以及两次候选结果全部保留在[精简JSON](data/qpc_06h_certification_preparation/summary.json)。

最终移动支持整理4,891次，较原完整域进入4,891+提示早拒绝7,838=12,729次，少7,838次；排序输入3,831,573条。证书分配1,495次，而原认证入口11,234次。样本检查保持1,235,382，提示拒绝7,838，全部96帧结果与公开网格哈希保持。原影子重放全部拒绝，没有错误拒绝。由此可确认准备减工，但数值工作未减少，解释了总收益小。

原生构建、最终逐点和高度拒绝专项完成，候选阶段另含面证据专项。最终没有新容器或状态管理，保留两个简单准备改动；同支持缓存按负结果撤回。本阶段结论为“准备工作削减成立，完整性能无明确突破”。首次波动与有限复测见[分析](../../reviews/cpu_refinement/qpc_06h_timing_analysis.md)，不追加测试凑显著性。
