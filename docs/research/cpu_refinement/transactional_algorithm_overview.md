## 算法到底在做什么

**从当前网格自行决定“哪里增加细节、哪里释放预算”，在同一快照上认证并预留一批局部替换，再构造可继续更新的新状态。** 输入是共形参数域三角网格、实际顶点高度、原始双线性高度场、相机、固定样本集 Q 和预算 B；输出是更新后的拓扑、邻接、样本归属、优先级索引及增量 mesh。

它借用 ROAM 的全局优先思想，但允许一般三角连接和有限高度拟合，**不是原 ROAM 二叉层次算法，也不复现 Legacy 的逐请求 greedy 轨迹**。不需要 Legacy 提供目标 J。当前策略为“快照全局优先序贪心预留”：全域计算紧迫性 `P=max(样本屏幕误差, 0.20×最长投影边长)`，按 P 降序及稳定 ID 排序，只处理前 r 个需求；本批新生候选到下一批才参与决策。

```text
换视图时刷新样本与全局顺序
→ 取需求前缀 → 接收提案/高度拟合/认证
→ 命名空额度，必要时生成共同回收池的提案与证书
→ 按需求优先序配对、检查冲突、不可回退地预留
→ 私有准备拓扑、样本续接和 mesh → 统一发布下一代
```

## 推导为什么能成立

1. **先把固定预算改写为局部交换。** 接收目录包括内部边中点 `2→4`、面内插点 `1→3`、插点并调整一个旧中心的完整邻域，均净增 2 面。删除内部度数 d 的顶点，固定其 one-ring 边界重剖分；简单 d 边形有 d−2 个面，因此净减 2 面。配对后净变化为零；有空额度的接收单独增加 2 面，故 `N'=N+2b_free≤B`。合法回收是否存在仍须检查，不能从面数公式推出。
2. **连接固定后，求有限高度变量。** 样本高度写为 `h=h₀+φ·a`，a 只有一或二维。在有效正深度域内，用保守透视约束得到关于 a 的半空间：一维求区间交，二维裁剪可行多边形。解只产生拟合候选；对实际舍入后高度再做区间过滤，必要时精确有理比较。求解失败不等于所有合法几何都无解。
3. **把接收收益和回收代价约束到同一阈值。** 在接收完整修改域取旧误差见证下界 L，令 `τ=L−η`，当前 `η=0.01px`。只有接收与回收的可见样本误差上界均满足 `max(U_receiver,U_donor)≤τ` 才可交换。因为 `L≤旧全局最大误差`，改动区域新误差不越过旧最大值，域外不变，所以同一相机、同一 Q 上的 sampled maximum 不增。**不保证逐点/RMS/全域高度误差不增，也不保证换视图后的质量或全局最优性。** 当前采集配置未启用可选高度保护。
4. **用完整支持和冲突规则组合交换。** 固定外接口、覆盖改高点的全部邻面；两个事务的写集合不得与对方读写集合相交，共享派生状态按确定规则归约。于是可以交换局部应用顺序，统一恢复邻接、样本与输出。原型并未把全部共享维护并行化。全局 greedy 只保证优先尝试并保护既有预留；失败会继续后续需求，已命名但未用的空额度本批不回流。

以上来自[局部回收推导](cavity_budget_recovery_derivation.md)、[高度拟合推导](local_height_minimax_derivation.md)、[执行契约](greedy_multipass_contract.md)和[批次组合/续接证明](transaction_batch_derivation.md)。旧 Lean 的已知目标端点修复定理是相关背景，**没有证明本算法的目标选择、几何认证或完整 C++ 正确性**；当前依据是纸面条件证明与有限原型核查。多边形 DP 仅作此前离线 oracle，不在正常运行路径。

## 每阶段实际时间复杂度

以下给出**单线程抽象时间上界/总工作量**，不是实测毫秒。定义 `log⁺x=log₂(2+x)`：

- n 为活动面数；N 为面/点槽数组及边索引的总规模，包含空槽；q 为 Q 的数量；a 为闭面—样本关联总数，共享边样本会重复关联。
- r 为需求前缀，m 为回收池，c 为每个需求的提案上限，b 为最终批准事务数；当前 `r,m≤64，c≤8`。
- d 为最大邻面数。合法输入及输出满足参数最小角 `θ=atan(1/3)`，内部点 `d≤⌊2π/θ⌋=19`；**这不限制补丁中的样本数**。
- 提案 i 的可见样本数为 sᵢ，收集前关联数为 aᵢ；局部续接涉及 t 个面/候选记录、sΔ 个样本、aΔ 次关联访问，包围框位置测试数为 z；u 为尚未消费的脏块数。
- 表中普通固定精度算术按常数计。**Bidx=ceil(N/K) 为索引块规模，h 为本次脏块数；每行还须加自身 Xᵢ**：精确分支的额外扫描/定位和变长有理算术成本；后者随中间位数变化，不能当作一次普通浮点运算。

| 阶段与源码入口 | 当前实际工作 | 单线程工作上界 | 当前并行边界 |
|---|---|---|---|
| 首次初始化：`State`、`Samples::Refresh`、`Mesh::Initialize` | 建身份/边索引，逐面包围框枚举 Q，建立双向归属、分块索引和完整 mesh | `O(N log⁺N + q + a + z₀)`；z₀ 是初建全部位置测试，不默认等于 q | 串行；初始化单列，不在正常逐帧重复 |
| 视图刷新：`PrepareView/PublishView`，不含下行建序 | 复用备用投影数组；投影全部 q；按面归约全部 a；交换投影指针，释放旧索引 | `O(q + a + N + n log⁺N)`；相机/分辨率不变时 O(1) 早退 | 投影和按面评分可并行；索引准备、发布串行 |
| 全局建序：`BuildOrders` | 扫面/点槽生成连续 key；读缓存边界及邻面优先级，每 K=256 槽排序 | `O(N log⁺K + nd)`；固定 K/d 时按槽数线性 | 串行；只在初建/换视图全量执行 |
| 前缀与目录：`Prefix/DonorPool/Receivers` | 归并 Bidx 个块首得到精确前缀；按需构造 E/F/H，成功后不构造尾部 | `O(Bidx+(r+m)log⁺Bidx+S_root+rcd log⁺N+Σ_tried aᵢlog⁺aᵢ)`；S_root 只含到达 F 的见证扫描 | 不同需求并行，单需求内顺序构造 |
| 接收拟合和验真：`Fit/Measure/Accepts` | 每个需求试到首个成功；Fit 缓存覆盖面/普通拟合权重，Measure 复用面选择并重读实际高度 | `Σ_tried O((d+sᵢd)log⁺N+sᵢlog⁺sᵢ+Fᵢ)`；一维 `Fᵢ=O(sᵢ)`；二维见下文 | 不同需求并行；每个提案内样本/约束仍顺序处理 |
| 回收提案：`Ring/Donor/Measure` | 共同池全部生成环、固定顺序耳切，保留边界高度，认证样本；没有交换需求时跳过 | `O(md³log⁺N)+Σ_donor O(aᵢlog⁺aᵢ+sᵢd log⁺N)` | 不同回收中心并行 |
| 贪心配对：`Reservation::Plan` | 最多 r×m 对；复用提案足迹、查冲突和已预留，正常模式成功后停止尾部审计 | `O(rm(b+1)d log⁺N)`；模糊误差比较触发的额外样本扫描归入 Xᵢ | 串行；完整诊断保留尾部统计，正常模式仍有精确 D_feasible |
| 拓扑准备/发布：`Commit::Prepare/Publish` | 再核对批次冲突，排序身份，准备局部邻接、槽位及活动尾交换，最终发布 | `O((b²d+bd²)log⁺(N+bd))` | 独占新面记录填写并行；分配、关联、映射和发布串行 |
| 样本与候选续接：`Samples::Prepare/Publish` | 新面包围框枚举、重选 owner、更新闭面贡献，重建 h 个候选脏块 | 保守 `O((z+aΔ+sΔ+td)log⁺(N+sΔ+bd)+hKlog⁺K)` | 串行；固定视图可局部修复，但代价不只是 O(bd) |
| 增量输出：`Mesh::Prepare/Publish` | 生成实际几何法线/属性，复制已有 Pending，合并脏块，更新活动索引 | `O(bd log⁺(N+bd)+(u+bd)log⁺(u+bd))` | 新面属性填写并行，其余串行；消费脏区间另计 O(u) |

**二维拟合的实现偏离了纸面平方界。** 对第 j 个约束，令裁剪多边形规模为 vⱼ；源码先遍历边，再对输出点逐个线性去重，因此 `Fᵢ=Σⱼ O(vⱼ+vⱼ²)`。在通常凸半平面模型 `vⱼ=O(j)`、约束数 `O(sᵢ)` 下，得到保守 `O(sᵢ³)`，不是此前规格中的 `O(sᵢ²)`；未证明自然输入实际触达立方增长。

完整帧成本为：

\[
W_{frame}=\mathbf1_{view\ changed}(W_{refresh}+W_{orders})
+W_{directory}+W_{fit}+\mathbf1_{need>0}W_{donor}+W_{reservation}
+\mathbf1_{b>0}(W_{topology}+W_{samples}+W_{mesh})
+\sum_iX_i+W_{dispatch/ledger}+\Lambda.
\]

Λ 是本帧真实扩容搬移成本，可能涉及旧全数组，不能因“局部事务”省略。各组件先全部准备、后依次发布；表格按职责计费，不表示准备后立即单独发布。有限阶段分块还需派发/同步和账本合并，每个阶段等待最慢分块；**整帧不能直接除以线程数 p**。即使 d、r、m、c 都固定，q、关联量和局部认证样本仍可很大；空批次也已支付发现与认证成本。
