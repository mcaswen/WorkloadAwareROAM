# QPC-06A：认证等价降本推导记录

2026-09-17。纸面推导与随后独立数值/运行核查分开；本页不声称Lean已验证C++。

## QCOST-01：局部不可变证据

固定一次Certify的State实例/Version、Config、Samples源与Q、sid、核心或公开域，以及old/next提案几何。Reference只读Decode、Denominator、Source四个U16及HeightScale；Coordinate再读TerrainSize和域；reference Clip只读参考值、Matrix和TerrainSize。因此同一上下文内这些值不依赖覆盖面、旧新插值高度或进展累计。

原执行old Cover、next Cover、CheckSample分别重建Reference和Coordinate；边谓词不确定又重复精确Reference。将这些调用按首次访问存值，后续返回同一值：输入不变且保留原表达式求值顺序，区间端点逐位相等，精确值相等。面循环/边循环顺序不变，所以第一覆盖面相同。Visibility与两个Screen共享同一reference Clip，不共享被测高度的Clip。

域不能混用：核心Coordinate是参数UV，公开域是世界XZ；即便同sid也创建不同上下文。上下文借用State/Samples但不越过当前样本，不能跨View、事务或线程复用。精确数仅在原路径需要时构造。创建证据不能提前读取会失败的精确数据；支持遍历、Touch和CheckLimit检查点不改。

## QCOST-02：有限binary64到定向整数

记无符号存储位的指数E、52位尾数F、符号s。正规数m=2^52+F，e=E−1023−52；次正规数m=F，e=−1074。故准确值x=(−1)^s m2^e。乘固定尺度2^128只改变整数移位j=e+128，不做浮点乘法。

- j≥0：整数绝对值m<<j，无余数。
- j<0：令v=m>>(-j)，r表示被截断位是否非零；得到绝对值商v和余数。
- 正数floor=v，负数floor=−v−[r≠0]；ceil(x)=−floor(−x)。m=0时±0均为零。

因此新整数与原cpp_rational(x)经分子乘2^128、分母除法、负余数修正得到的值完全相同。j最大1099，最小−946；右移超过有效数位数时商零、余数等于m≠0，不执行C++超宽移位。非有限输入继续走原有理构造的异常路径，不能截断为零。

反例：直接double乘2^128可溢出；int向零取整把负微小进展错误变成零；以epsilon接受微小正数改变unknown语义。这三种实现均排除。

## QCOST-03：从局部等价到相同决策

保持接口检查、两个域顺序、候选排序去重、旧新覆盖和拒绝优先级。QCOST-01使每样本的损伤/投影判断相同，QCOST-02使累计整数相同。对原样本序列归纳，首个拒绝位置和理由相同；完成时两个域的进展结论与支持相同。证书绑定和ValidateBatch不改，确定的目录/资源顺序于是给出相同批次。

运行核查仍需实际对比编译后行为：抽象推导不覆盖编译器浮点重排、悬空引用或状态漏绑定。CheckLimit的逻辑访问预算保持；真实墙钟超时可能随提速改变是否完成，超时样本必须单列，不能当作等价拒绝。

## QCOST-04：费用与边界

每样本每域每种数值表示至多一次Reference、Coordinate和reference Clip。旧Cover每次边谓词歧义都构建精确参考，新机制仅复用相同输入事实，不改变精确谓词数量。仍有O((s+c)d)覆盖、支持排序、接口检查、任意精度插值和批次共享复核。快速累计消除有理规范化/除法，但cpp_int移位/加法仍按位长计费；不是任意精度常数时间证明。

本机制不处理旧Fit、不增加目录可行性、不保证恢复、不消除静止重复。失败或无完整收益时按规划退出，不另添第三种优化挽救数字。
