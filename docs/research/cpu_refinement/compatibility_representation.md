## 1. 范围、文件归属与问题

母问题：能否设计天然适合共享内存 CPU 并行的地形细分模型，同时尽量保持 ROAM 的硬预算与几何质量特性？本轮只研究“无裂缝是否一定要求继续细分邻居”，不继续推闭包求解、批次选择、activation-spectrum 或最小修改量算法。

文档职责：本页集中保存表示候选、结构分析、来源与未解条件；[研究入口](../README.md)保存方向状态；[recourse 暂存页](../roam_recourse/minimum_change_note.md)独立保留已有讨论；[本轮自审](../../reviews/cpu_refinement/compatibility_representation_review.md)核对证据与授权范围。原阈值工作区只增加状态入口链接，不改写已关闭 Gate。这里不制定运行时目录、公共接口或实现阶段。

已读取开发规范、规划规范、审查规范和当前 CPU ROAM 研究定义；定向查看 TerrainMeshBuilder.h 中的 CPU 顶点/索引输出，以及 DOD 的拓扑与网格更新边界。当前输出仍是分片线性三角网格。后续若改成曲面片、体网格或新的输出结构，需要另行 Review，不能在研究笔记中默认接入。

## 2. 先区分四种约束

| 约束 | 本轮含义 |
| --- | --- |
| 几何无裂缝 | 相邻曲面在共享参数域边界上具有相同的三维轨迹；不依靠裙边、遮挡或重叠掩盖缺口 |
| 共形三角剖分 | 三角形交集是完整公共边、公共顶点或空集；几何共线的 T 接点仍不满足此条件 |
| 形状规则 | 最小角、长宽比、有限相似形类别、层级差等额外要求；不能和前两项混为一谈 |
| 几何近似质量 | 对 raw height samples + bilinear interpolation 的独立误差；不是三角形形状，也不是调度分数 |

输出默认继续要求共形三角网格。只满足几何无裂缝的方案列为对照，不能静默放宽拓扑合法性。ROAM 的强制传播与其指定二分边、层次及形状规则有关；共形性本身没有规定邻居必须沿自己的最长边细分。

局部性也须分别计数：受影响的区域数量、区域内的实际元素数量、读取量、写入量和关键路径。只影响两个区域，不代表只需要 O(1) 工作。

## 3. 无法靠更名消除的边界条件

### 3.1 保持粗侧不变的必要条件

设共享边的粗侧仍是空间直线段 AB，细侧插入点 X。若两侧仍要沿同一参数域边界几何无缝，则 X 必须位于线段 AB 上，且两侧沿整条边的插值必须一致。若 X 按参考高度取样后离开 AB，至少需要改变粗侧边界、约束 X 回到公共轨迹，或更换曲面表示。细侧单独改变边界形状而粗侧完全不变，一般不可行。

这是限定在固定共享边和分片线性曲面的必要条件，不是所有细分模型的不可能性定理。它要求共享边状态一致，不要求在远处递归传播。

### 3.2 只在内部插点的误差底限

若仅进行三角形内部的 1→3 插点，全部旧边保持原直线插值，则拓扑可以局部细化而不触碰邻居。但对任何仍被固定的边 e：

\[
H_{\max}(M)\ge\sup_{x\in e}|h_*(x)-h_e(x)|.
\]

若右侧非零，无论内部插点多少都无法消除该世界高度误差。此结论不自动给出同大小的屏幕误差下界，因为投影可能压缩高度方向。加入换边或边界细分可以解除固定边假设，但必须重新分析这些操作的邻域。

### 3.3 任意细的接口不能免费输出

粗区域一条边对应 m 个需要保留的细分段时，共形输出必须包含这些分段；其边界表示及显式相邻三角形数量不能保持与 m 无关的常数。将它们放入“接口状态”只能改变职责位置，不能消除 Ω(m) 的显式输出规模。改变一个分段仍可能局部更新，不能把此累计规模下界误写成每次更新都必须扫描全部 m 段。

## 4. 各类表示的首轮筛查

| 表示候选 | 兼容性如何表达 | CPU 局部性与代价 | 本轮判断 |
| --- | --- | --- | --- |
| 悬挂点约束到粗侧边界 | 细顶点服从公共边界插值 | 可独立改变内部层级；边界几何被约束，T 接点仍存在 | 有直接先例，只作几何无裂缝对照，不作为共形输出新模型 |
| 纯内部 1→3 插点 | 旧边完全不变 | 一次操作仅替换一个面，三角形增量为 2；固定边误差不能消除 | 不能单独承担任意精度地形细分 |
| 内部插点加换边 | 改变旧边的存在方式 | 局部基本操作可保持共形；长期形状、邻域和层级规则须另外分析 | √3-subdivision 有强先例；不能由“自动无裂缝”推断 O(1) 自适应请求 |
| 共享边决策加逐面模板 | 相邻面消费同一边细分状态 | 每面读取三个边标志，局部重建；不强制加入其他边；三角形成本可精确计算 | 最直接的非传播模型，但基本结构已有，详见第 5 节 |
| 接口曲线与区域内部剖分分离 | 共享一维边界，内部网格各自适应 | 依赖可限于接口两侧；接口复杂度和区域重建成本仍可能增长 | 是有效的表示分离，但不能仅凭分层方式主张新颖性 |
| 固定单元中的子网格表达 | 共享边/面数据决定局部曲面连接 | 不通过加深背景网格表达全部细节；局部输出数量可变 | 近期 Subgrid Marching 提供结构性先例；不是现成的高度场硬预算解 |

普通拼接、过渡三角形、固定块及边界对齐都有先例，不直接列为新算法。表中后两项需要解释边界状态的产生、更新和全部输出成本，不能只把原传播转移到预处理或网格生成阶段。

## 5. 一个可明确分析的非传播模型：边决策与面重建

### 5.1 状态和局部规则

冻结当前共形二维三角剖分 T，将其顶点按参考高度提升成地形曲面。一个当前边 e 只有一个公共细分标志 x(e)∈{0,1}，每轮最多在该边中点加入一个新顶点，其位置与身份由两侧共享。

一个旧三角形只读取自身三条边的标志。有 k 条边被选中时，用无退化、覆盖原参数域的局部模板产生 k+1 个三角形，k∈{0,1,2,3}。两条边被选中时允许的内部对角线须有确定规则；选择会影响几何质量，但不改变外边界的一致性。一次逻辑细分不要求继续选择邻居的其他边。

这不是新发明。Larsson 2012 的 §4.1 明确给出按选中边细分单元的局部规则，并指出边状态确定后可独立处理相邻单元。[原文](https://onlinelibrary.wiley.com/doi/full/10.5402/2012/134097)

### 5.2 无裂缝来自共享状态

对任意旧公共边，两侧读取相同标志、同一个新顶点和同样的边段，因此输出边界相同。每个模板只剖分原面内部，不改变其他旧边。原面参数域互不重叠，故局部输出合起来仍是共形三角剖分；提升为单值高度图后仍在共享边处一致。

这里需要共享边的规范身份和一致坐标。每个线程各自计算“数学上相同”的顶点，不能自动保证浮点位级一致。逻辑独立也不证明现有可变邻接、分配器或压缩标志写入没有竞争。

### 5.3 硬预算不必通过递归闭包计数

记本轮选中的内部边和外边界边分别为 S_int、S_boundary。按面累计新增三角形：

\[
\Delta N=\sum_{f\in T} k_f
=2|S_{\mathrm{int}}|+|S_{\mathrm{boundary}}|.
\]

每条内部边关联两个面，外边界边只关联一个面；共享一面内的多个选中边不会重复增加整套闭包成本。只要先确定全局接受的边集并满足 N+ΔN≤B，局部输出的三角形总数即满足硬预算。

该恒等式是此处对已知模板的纸面计数，不是新颖性或高质量预算分配证明。预算选择仍会耦合全局决策；它不要求递归修改邻居的细分状态，但其选择成本必须计入。该模型只分析单轮细分，不声称已解决任意连续合并。

### 5.4 它没有从表达能力上排除 ROAM

在相同初始剖分、相同中点位置与高度取样规则下，如果所有 ROAM 合法二分动作都仍被允许，一次内部 diamond 二分就是选择那条公共边的一种特例。允许逐次单边操作的新网格族因而包含相应的 ROAM 网格族：

\[
\mathcal M_{\mathrm{ROAM}}\subseteq\mathcal M_{\mathrm{edge}}.
\]

于是对于同一个独立几何误差 E、同一预算和非空可行集合：

\[
\inf_{M\in\mathcal M_{\mathrm{edge}},\,N(M)\le B}E(M)
\le
\inf_{M\in\mathcal M_{\mathrm{ROAM}},\,N(M)\le B}E(M).
\]

这只是表示空间的存在性比较：不是说一个固定边选择算法已经达到该最优值，更不是把严格串行 ROAM 当作 E 的最优解。若加上新的深度、形状、换边或并发选择限制，必须重新核对包含关系。不能将当前 DOD 的任意运行行为直接等同于上述抽象前提。

### 5.5 尚未解决的核心代价

1. **形状退化。** 反复二分同一三角形靠近端点的一段边，可得到平面顶点 (0,0)、(2^(-j),0)、(0,1) 的三角形；最小角随 j 趋于零。单轮合法不提供长期形状界。
2. **几何质量分配。** 小角不必然意味着高度误差大，但任意边选择也不保证减少独立最大几何误差。有限元误差指标不能直接当作地形屏幕误差。
3. **形状修复可能重新引入耦合。** 若为维持形状不断强制选择其他边，就需要重新分析是否恢复传播。Larsson 的 Remark 4.1 也讨论了极端各向异性时的形状控制。[原文](https://onlinelibrary.wiley.com/doi/full/10.5402/2012/134097)
4. **持续状态与合并。** 一轮细分模板没有定义可逆历史、预算回收和下一轮快速邻接维护。
5. **实际 CPU 成本。** 评分、接受边选择、边身份与顶点生成、逐面输出、邻接更新、持久状态维护及网格提交都须计费；只把逐面模板并行不能证明完整更新收益。

这个模型回答了“是否存在无递归传播的共形细分表达”：存在，而且已有非 GPU 文献。它尚未回答“我们能否提出不同于已有工作的 CPU 质量与预算算法”。

## 6. 接口与区域分离：有界邻接不等于有界工作

另一个概念模型是固定区域划分、公共一维接口和各区域内部三角剖分。内部修改不改变接口，接口修改只要求相邻区域更新，停止于其他接口。它允许细化状态与最终输出剖分分离，但固定区域划分、公共边界采样和局部剖分本身不是创新。

对单连通、无孔的平面区域，若内部顶点数为 i，边界顶点数为 b，且所有额外 Steiner 点已经计入，则任意共形三角剖分满足：

\[
F=2i+b-2.
\]

证明由 V−E+F=1 和 3F=2E−b 消元得到。固定区域划分下，全局面数可由各区域相加；内部接口增加一个共享顶点会使两侧 b 各增一。它提供可核算预算，但不限定重新剖分工作量或近似质量。

需要区分两种质量负担：固定粗接口产生第 3.2 节的误差底限；不断提高接口分辨率则增加两侧显式输出和预算需求。若通过固定最细接口换来内部完全独立，还须计入长期常驻的接口开销。不能将这些代价排除在同预算比较外。

Subgrid Marching Tetrahedra 的启发在于：背景单元和内部表面复杂度可以分开，并借助共享边界编码实现单元内重建。但目前只核对作者项目页和摘要；没有将其正常坐标构造移植到高度场，也没有推导地形误差或预算选择算法。[作者项目页](https://www.cs.cmu.edu/~kmcrane/Projects/SubgridMarching/index.html)

## 8. 本轮判断与后续边界

本轮得到三个不同结论：

- **结构可行性：有正证据。** 无裂缝可以由共享边状态和局部面规则表达，不必保留 ROAM 的远距离强制传播。
- **新颖性与完整算法：尚未成立。** 最直接的局部模型已有先例；精确预算计数与表示包含关系也不等于已经解决质量选择和持续更新。
- **研究状态：母问题保持开放，没有实现准入。** activation-spectrum 继续关闭，recourse 独立暂存；不因为发现旧机制而重启 closure/batching 或 CPU-CBT。

若继续，只核对一个具体结构能否同时保持局部依赖、完整三角形计费、独立几何质量和多轮可用性，并说明超出已有工作的机制。需要的证据必须落在表示和原语上，不能仅添加线程池、排序策略或新名称。若最后只剩已知结构的直接复用，或质量维护必然依赖原传播而没有新机制，则结束这类新算法候选投入，回到既有 CPU ROAM 执行与特征分析主线。

本页没有提出已获确认的运行时架构，也没有证明新的并行工作量/关键路径界。所有纸面计数只服务于可行性审查，不报告真实加速。
