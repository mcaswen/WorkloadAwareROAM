# 参数化成本语义 Gate：同任务审计与阶段出口

> 日期：2026-09-12；依据：[已确认 PCSG 小规划](../../plans/roam_parallelism/parametric_cost_semantics_gate_plan.md)；源码基线：`24c6391`。
> 结果：**本轮 No-Go，在 PCSG-01 的拓扑同任务审计处提前结束；未进入完整成本模型或 Lean 实现**。
> 含义：在限定的候选与不新增拓扑/物化算法的范围内，尚未取得三个阶段都满足要求的同任务成本比较。这不是对参数化分析、增量细分或批量执行的不可能性证明。

## 1. 实际执行与结论

本轮依次完成规范和规划复核、三个阶段的任务定义、评分/脏写的纸面等价论证、拓扑固定目标的叶集合论证，以及可复用状态生成能力的定向核对。没有用运行时间拟合模型，也没有将旧 CPU-CBT 结果带入成本判断。

**主要缺口在拓扑的结果层与执行层之间：** 固定细分目标可以唯一确定逻辑叶集合，但这不同时提供一个生成最终连接、可用索引及声明的持久状态的批量程序。只有集合谓词、一个扫描前缀或“此后发布”的占位步骤，不能构成成本完整的比较对象。

当前材料没有封闭这一步。补写状态生成、连接恢复与维护编排，即使使用普通排序或现有局部操作而没有新颖性，也需要明确另一套物化过程及其对应证明；不能仅以某个通用步骤“应该可行”视为已经完成。根据小规划第 3.1 节及 PCSG-01 停止条件，本轮到此结束，不继续建设证明框架。

这不是因为必须先有 C++ 才能做理论分析。一个说明充分的纸面程序及一般正确性论证也可以满足 Gate；本轮被检查的候选尚不具备规划要求的全部步骤和成本义务。

## 3. 评分与脏写：一般分区等价能够成立

设 I 为有限、无重复的身份集合，`v(i)=f(x,i)` 只读固定输入 x。分区 `I₁,…,I_b` 两两不交且并集为 I；空分区允许存在。每项只写与 i 唯一对应的位置。

顺序执行与各分区独立执行具有相同结果：任取 i∈I，它恰好属于一个分区，最终写入值都为 `f(x,i)`；任取 i∉I，两种执行均不写它。因此逐位置相等，而不仅是数量或哈希相同。若之后组合相同确定性后处理 H，函数保持相等，故 `H(Result_S)=H(Result_A)`。

评分中的镜像位置由唯一条目身份确定；网格中的写位置由唯一槽位及槽内固定顶点/索引偏移确定。它们都满足上述形式。这里证明的是满足前提的抽象程序，不是 C++ 内存模型、全部浮点环境或现有验证器的机器证明。

### 3.1 内核成本的可保留部分

用 `e_Q`、`e_M` 表示原语计数向量中的对应单位分量，则两种评分内核均执行 n 项，脏写内核均执行 d 项：

\[
\mathbf W^{\rm kernel}_{S,Q}=\mathbf W^{\rm kernel}_{A,Q}=n e_Q,
\qquad
\mathbf W^{\rm kernel}_{S,M}=\mathbf W^{\rm kernel}_{A,M}=d e_M.
\]

Q/M 在此分别指一次规定输出的评分/三角形生成工作；若展开其子步骤，应对双方采用同样展开，不能为了成本优势改变单位。分区、分配和维护尚未计入这两个内核等式。

对相同非负单价且项成本一致的特例，块 j 含 mⱼ 项时，其顺序计算 span 为 `mⱼc`，并行组合为 `maxⱼ(mⱼc)`。仅当最大块长有相应界时才得到 `⌈n/b⌉c` 或 `⌈d/b⌉c`。b 是块数，p 是处理器数；没有把分区数当作同时运行的处理器数。

这说明评分与脏写可以共享同一个证明结构。它没有证明完整阶段工作量不变、没有证明二者必须表现不同，也没有从少量输入推断真实交叉阈值。

### 3.2 不能省略的外层

现有评分在分区完成后串行重建堆。若共享外层成本为 G，不能把 `nc_Q/p` 称为完整阶段成本；G 必须回到工作量和 span 中。

脏写前的排序、容量调整和最终区间维护也有成本；脏项数量 d、区间数量 r 与分块数量 b 应分别保留。不能只因写入循环可并行，就把其余步骤统一设成与 d 无关的 h。

本轮没有进一步给组织成本指定参数曲线，没有据此宣称“工作高效”或给出非空加速区。这两项局部论证作为后续可复用基础保留，不能代替未通过的拓扑项。

## 4. 拓扑：固定目标为什么只解决了一部分问题

### 4.1 已有论证能得到相同叶集合

沿用[标准规则层次的纸面模型](../roam_threshold/model_and_proofs.md)，I₀ 为初态已执行事件，J 为包含 I₀ 的合法闭合目标，`k=|J\I₀|` 为唯一单三角形细分事件数。目标叶集合为：

\[
L(J)=\{t:(t\text{ 为根}\lor parent(t)\in J)\land t\notin J\}.
\]

将合法菱形/边界二分按前置先于后继的顺序应用至 J：每次移除相应旧叶，加入其两个子叶；按所执行事件归纳，当前叶恰为当前事件集的叶切割。因此最终得到 L(J)。扫描完整固定层次，选择满足上述谓词的 t，也恰好枚举 L(J)。这是一项一般的叶集合论证，不依赖三个有限例子。

目标合法性沿用既有标准网格族的纸面结论，未新建几何形式化对象。split-only 每事件净增一片叶，最终 `N₀+k≤B`；合法逐菱形完成点的叶数单调且不超过最终值。私有物化的存储量另计，不由这个预算不等式限制。

**到这里比较的是叶集合投影。** 合法几何在数学上决定哪些完整边相接，不等于两段程序都已经生成可消费的连接记录。将连接改成未计算的关系查询，既改变输出表示及查询成本，也不能作为原任务完成的证据。

| 候选/材料 | 已提供的内容 | 未封闭之处 |
| --- | --- | --- |

局部修改和常规边排序/匹配都是已有方法，不意味着其组合自动成为一个成本完整、与逐项程序结果等价的算法。需要给出节点身份、边所有者、连接写入、活动/路径索引、预算和声明状态的一致数据流，并证明任意合法输入上的结果；目前材料缺少这一层。

这项缺口是**当前比较对象没有完成规格与程序对应**，不是“未知毫秒单价”、不是线程池不好，也不是“没有找到某个 C++ 文件所以数学上不可能”。本轮没有为满足输出契约新增另一套物化编排。

### 4.3 工作密度公式现在能说明什么

若某个同任务串行程序确实具有成本 `U_S`，某个完整的批量候选包含无法省略的 n 次扫描，则即使不给扫描之后的工作计费，仍有条件下界：

\[
T_A(p)\ge nc_S/p.
\]

于是 `nc_S≥pU_S` 足以排除该候选严格快于这个串行上界。若再有依据取 `U_S=k(c_select+c_edit)`、n>0 且分母为正，才可写成关于 `ρ=k/n` 的区域。

本轮尚未取得这对满足全部输出要求的程序及该串行成本界，因此不将上述条件代数作为拓扑项通过的证据，也不填任意参数使区域显得非空。n 是完整潜在域还是活动域、k 是否包括强制事件、目标索引维护与连接访问量，均会影响条件。失败原因不是除法或不等式难以形式化。

## 5. 没有采用的补救与结论边界

- 不把 `L(J)` 的集合相等升级为完整拓扑状态相等。
- 不把所有状态恢复装进一个没有步骤来源的 `H_state`，再假设它很小。
- 不让串行免费得到差分列表，而让另一方承担完整目标发现；也不把目标列表的生成/验证重复只收某一方的费用。
- 不用原生串行加一遍无用扫描作为“高并行批量算法”的替身；它只能得到人为附加工作不利的常识结论。
- 不以较弱的“都合法、都没超预算”替代同结果，也不重新引用 CPU-CBT 性能解释理论结果。

评分与脏写的分区等价保留；固定 J 的叶切割等价保留。**没有证明完整拓扑比较不可能，也没有证明任何参数化成本模型只能得到常识。** 本次停止仅针对小规划要求的三个阶段闭环，以及不新设计算法的授权边界。
