# ROAM 目标差分物化：续接状态、构造与成本

> 日期：2026-09-12；源码基线：`69ab803`；依据：[已确认小规划](../../plans/roam_parallelism/target_materialization_gate_plan.md)。
> 状态：本轮理论 Gate 在限定抽象事务下通过；完整构造为纸面证明，12 项支持集及队列等式通过 Lean 检查。验证层级与准入限制见第 10 节；没有 C++ 或性能实验。

## 1. 本次取得的结构与适用范围

除叶差分的 3k 界以外，本轮得到一个直接涉及持久合并队列的支持集：令 d(t) 为三角形事件 t 所属的固定菱形，边界单事件也视为一组，则可能改变合并资格的菱形包含于

\[
\mathcal C_\Delta=d[\Delta]\cup d[\operatorname{parent}(\Delta)],
\qquad |\mathcal C_\Delta|\le2k.
\]

这里不是说合并时只需两次内存访问，而是说逻辑候选变化可以从至多 2k 个组标识中找到；定位、评分和有序容器维护仍需计费。在本报告定义的固定环境、固定事务轮次和无反复撤销的目标应用规格下，禁止本轮反向操作的标记也能由差分恢复。

由此可以给出一个不重演中间网格的完整**抽象状态物化程序**。它包含活动内部节点、显式叶邻接、菱形资格、有效队列、历史标记和下一次增量网格消费所需信息。它不是现有 DOD 对象的逐字段程序验证；尤其不声称任意 greedy 历史、全部调试输出或原生部分失败路径都已复现。

目标发现仍在程序之外。给定 J 的物化能力，不解决如何便宜地找到与原生串行 greedy 完全相同的 J，也不证明当前 CPU 执行会加速。

## 2. 冻结的任务与独立顺序规格

### 2.1 输入条件

复用[固定层次的纸面几何模型](../roam_threshold/model_and_proofs.md#2-theorem-0-的几何部分为什么依赖可以固定)：两个直角等腰根、固定底边中点二分、有限深度 H。合法事件集对父事件和同底边伙伴闭合；伙伴组成大小为 1 或 2 的组，组成员同深度。该几何模型未在本轮 Lean 中重新证明。

I₀、J 为两个合法事件集，均满足三角形预算 B。提供去重、完整、带加入/移除方向的差分 Δ；存在性/合法性证书及发现成本另列。定义

\[
\Delta^+=J\setminus I_0,\quad\Delta^-=I_0\setminus J,\quad
C=I_0\cap J,\quad k=|\Delta^+|+|\Delta^-|.
\]

完整 M₀ 包含有效的活动结构、冻结环境下的队列键、历史集合、索引和待消费网格差分。历史不能从 I₀ 反推，而是原题 M₀ 的组成部分。环境包括地形、尺度、评分函数、阈值、最大深度及稳定身份破同分规则；本次不推进相机或事务轮次 e。评分值与身份比较必须形成总序；浮点实现须先规定非有限值策略，不能依赖不同容器自行处理 NaN。

旧键若无效，进入边界之前必须刷新并计费。当前 DOD 改变视图后会评分并建堆；本报告不消除此项，也不把旧哨兵分数当作已经恢复的真实优先级。静态数据查询成本见第 7 节。

### 2.2 顺序参考 R，不由物化输出定义

R 接收同一输入，按下列固定顺序执行合法原子菱形/边界操作：

1. 将 Δ⁻ 按深度从大到小、同深度按组身份排列，合并至 C。
2. 将 Δ⁺ 按深度从小到大、同深度按组身份排列，细分至 J。
3. 每次操作均更新活动成员、邻接、逻辑队列、预算与本轮反向操作标记，并按第 6.4 节合成待消费网格差分。

这是**已给定目标的应用规格**；不用分数再次筛掉目标指定事件，不是完整 greedy 目标选择。顺序 R 只作为定义结果的独立参考，物化程序不执行这些步骤。

合法性：闭合集的交集 C 闭合。删除阶段，若某待删成员还有已细分子事件，该子事件不能在 J 中，否则 J 的祖先闭合迫使父事件也在 J；故子事件也在 Δ⁻，已先删除。同组伙伴一起删除。加入阶段，父事件要么在 C，要么在 Δ⁺ 且已先加入；伙伴一起加入。因此每一步都合法，且每个差分事件恰被修改一次。

预算：先合并使叶数下降，再细分使叶数升至最终值，所有完整发布点不超过 `max(N₀,N_J)≤B`。单个内部菱形净变化 2，边界组净变化 1；不重复计数。

### 2.3 历史与事务边界

事务不执行结束帧/开始帧操作。上一帧迟滞集合 H₀、已有本轮 blocked 集合 K₀ 及轮次 e 保持；它不位于一个尚未完成的根请求内部。已有本轮细分/合并标记分别为 S₀、G₀，可包含历史缓存节点身份。R 完成后：

\[
H'=H_0,\quad K'=K_0,\quad
S'=S_0\cup\Delta^+,\quad G'=G_0\cup\Delta^-.
\]

保留标记不会使停用节点成为候选，因为候选还检查当前活动资格。采用“不清除旧标记”的定义，与标记轮次等于 e 的语义对应；增加/删除标记不能靠全池清零实现。

此规则由 R 的无反复撤销性质推出，不增加历史证书。若要求复现任意其他历史，例如先细分又合并回到同一个 I₀，则 k=0 但 S/G 可能变化；这时 `(M₀,J)` 确实不足。这样的历史不属于本次已冻结参考，不据此宣布所有目标物化不可能。

后续结束帧将迟滞集合设置为当前 I；若复制整个集合，就计 O(|I|) 工作，不能计入本次局部标记更新。开始新轮次使旧本轮标记失效并刷新必要队列。若这些操作涉及 h 个过期标记或全量评分，就分别计 O(h) 或全量评分/建堆成本；本次事务并未暗中完成这些全局操作。旧 M₀ 的持有、静态缓存和跨轮回收都不是免费资源。

\mathcal S=(I,L,T,\mathrm{Adj},\mathrm{Groups},Q_s,Q_m,H,K,S,G,e,B,N_I,\mathrm{Slots},\mathrm{Pending}).

T 是活动节点 `I∪L`；每个活动内部节点有显式父子引用及同层伙伴引用，叶有三个显式邻接槽位。内部节点的左/右侧不保存任意历史时刻的旧叶指针；执行合并时从其当前直接子叶的外部邻接取得父区域接口。这是声明的表示选择，查询范围与代价如下表，不能直接写回当前 DOD 数组并假定原调用方兼容。

## 4. 叶与邻接的局部性证明

### 4.1 叶与活动节点

对任意潜在节点 t，叶谓词只读取自身事件位与父事件位：

\[
\ell_I(t)=(\operatorname{root}(t)\lor\operatorname{parent}(t)\in I)\land t\notin I.
\]

若 t 和其父事件都不在 Δ，两项布尔值完全不变，故叶资格不变。取逆否得

\[
L(I_0)\triangle L(J)\subseteq\mathcal F_\Delta
=\Delta\cup\operatorname{children}(\Delta),\qquad |\mathcal F_\Delta|\le3k.
\]

从去重的 F_Δ 分别计算旧/新叶谓词即可枚举 R、A；检查不可细分的最深层仍可成为叶。根按无父节点处理。本命题不依赖细分或合并方向，也不依赖 priority 单调性。

活动记录 T(I) 在合法祖先闭合集上等于“根加 I 中事件的孩子”。因此 T 的增删也由 children(Δ) 覆盖；另外对 Δ 中仍活动的节点修改内部/叶标志。无需生成中间曾短暂存在的叶数组。

### 4.2 区域与外部接口

I₀、J 都是同一参数域的完整三角剖分。删去共同叶后，R 与 A 覆盖相同的剩余区域（按三角形内部及其闭包解释边界）。共同叶的几何域未变。

取 A 中与共同叶 u 相接的一条边。两目标严格共形，故该接口必为 u 的一条完整边，不能是 u 边上的真子段。沿该边的另一侧，旧网格也必须有一片 R 中三角形完整共享这条边，否则另一侧仍是共同叶，与其现在被 A 占据矛盾。因此该新—旧接口必定已出现在旧 R 的外部接口表中。反方向同理。

于是从 R 的旧邻接提取的边界条目充分且必要：每条保存精确边身份、外部叶身份和外部槽位，至多 3|R| 条。A 中所有边排序分组后：两新叶共享的边配成一对；新—旧接口匹配一条边界条目；域边界是一条合法单侧边。其他单侧、多重或同向匹配是输入/生成错误，不能静默忽略。

这证明全部叶邻接能由 O(k) 条边恢复；排序去重给 O(k log(k+1)) 工作。共同叶被改的是有明确边所有者的槽位；多个槽位落在同一记录时先归并再写。仅点接触不生成邻接。

## 5. 合并资格与队列支持集

令成员集合 D_d 的大小为 1 或 2。其合并资格是

\[
\mu_I(d)\iff D_d\subseteq I\ \land\
\forall t\in D_d,\ \operatorname{children}(t)\cap I=\varnothing.
\]

在合法状态中，这恰好表示成员全部细分、孩子全部为活动叶。删除 D_d 保持闭合：不留下以被删成员为父的已细分孩子；其他组不以成员的同组伙伴为前置。反之，如果有直接孩子仍被细分，删除其父立即破坏祖先闭合。故这不是仅用于枚举的近似资格。

改变 μ 只可能因为组内某个 t 的事件位改变，或其直接孩子 c 的事件位改变。第一类组是 d[Δ]；第二类组是 d[parent(Δ)]，从而得到第 1 节的 2k 候选界。一个变化事件的父仅有一个；去重不会增大上界。

本轮合并抑制检查成员是否属于 S'=S₀∪Δ⁺，其额外变化组只在 d[Δ⁺]，已包含于 C_Δ。细分抑制由 K₀、G'=G₀∪Δ⁻ 和固定深度决定，其新增影响只在 Δ⁻，已包含于 F_Δ。评分环境不变，未受影响身份的原分数不变。因此：

\[
\operatorname{supp}(Q_s'-Q_s)\subseteq\mathcal F_\Delta,
\qquad
\operatorname{supp}(Q_m'-Q_m)\subseteq\mathcal C_\Delta.
\]

这里队列差分指完整逻辑条目（成员资格、分数及抑制状态）变化。对支持集内的每个身份删除旧项、按目标重算后插入新项；支持集外直接复用旧项。没有一遍全量“发现新候选”的扫描。

## 6. 物化程序与可续接性

### 6.1 具体有限步骤

```text
Materialize(M₀,J,Δ):
  检查共同输入契约；整理 Δ⁺/Δ⁻，定位旧事件位
  F := unique(Δ 与所有直接孩子)
  对 F 分别求旧/新叶资格，产生 R/A；求 N_J 并检查预算
  准备活动记录增删和内部位变更
  从 R 读旧外部接口；为新活动节点分配目标槽位
  并行按身份填写域、父子、伙伴；不修改任何已发布旧接口
  对 A 的边和外部接口排序连接，归并每个记录的最终邻接补丁
  CΔ := unique(d[Δ] 与 d[parent(Δ)])
  在 F/CΔ 内求目标队列条目，生成删除旧键/插入新键的有序批次
  在 R/A 上合成旧待消费网格更新，整理槽位分配/延迟退役
  批量更新身份索引、活动集合、两队列、S/G 标记及待消费差分
  完成补丁写入与屏障，发布可消费状态
```

目标事件查询不建立 J 的全量新数组：对 Δ 中身份使用指定新位，其余复用 M₀；索引更新采用批量集合差分/并集。首行的输入契约依赖已声明的完整差分与合法目标证书，不声称仅凭 O(k) 局部检查就能认证任意未经验证的全量 J。预算检查在修改可变旧索引之前完成。所有新引用在目标身份到槽位映射就绪后填写。未变化记录复用；节点退役在没有并发读者、所有引用已更新且待消费记录已持有必要描述符后进行。不会同时重演 R 的中间网格。

有序结构采用支持批量集合运算的平衡树；旧键可按身份索引取得。先排序 O(k) 个更新键，再分区更新旧树，避免把全部插入串在一个堆根上。叶邻接按稳定记录句柄定位，树旋转不搬动网格节点记录。现有向量、堆位置和数组扩容逻辑不自动享有这些性质。

### 6.2 对参考结果的证明

事件位按 Δ 改为 J；叶/活动索引由第 4.1 节得到同一集合。内部父子和伙伴关系由固定身份唯一确定；叶邻接由第 4.2 节得到同一完整边连接。两队列按第 5 节复用外部条目并重算全部可能变化条目，故每个逻辑身份的成员、键和抑制位与 R 相同。H/K 不变、S/G 按第 2.3 节更新，预算相同。网格差分表达同一最终叶增删；物理槽位不同通过身份映射比较。

因此，物化状态与独立顺序 R 的上述逻辑投影相等。物理堆形状、休眠缓存容量与调试过程信息不属于该投影，但其空间/性能成本不能因此删去。

| 本轮阻止重试/阈值迟滞 | 同一 K/H/S/G 和分数产生同一可尝试性；被拒操作采用同一参考规则修改 K 或保持状态 |
| 增量网格消费 | 第 6.4 节保留并合成尚未消费的旧差分，按同一几何函数生成相同最终结果；如果消费者只接受历史日志，需要适配，不能直接调用原消费者冒充已验证 |

每一步更新后都恢复相同投影，故按有限序列长度归纳得到任意有限续接序列的逻辑一致。这是对本报告规定操作接口的纸面模拟论证，不是任意 C++ 内存读取的验证。

特别限制：当前 DOD 的递归根失败可能保留部分修改；本轮不定义它与所有其他失败策略相同。只有双方使用**同一个**确定的失败/预算控制规则时，上述逐步论证才成立；将本表示接入原生实现需另做对应审计。固定目标 R 本身不发生预算失败，因为合法目标和预算已给定。

### 6.4 旧待消费网格差分不能丢弃

Pending 是按稳定叶身份存放的规范化差分映射，不是必须按时间重放的操作列表。条目保存“消费者上次确认的旧描述符 b”和“当前目标描述符 v”；不存在以空描述符表示。描述符包含固定大小的几何身份、输出参数和必要槽位信息，实际顶点字节生成在消费成本中。旧新相同的条目消去。M₀ 中该映射已正确描述消费者基线到 L(I₀) 的变化，不要求它为空。

物化只需访问 R∪A。对每个身份 t，若有旧 Pending 条目，取其中的 b；否则消费者基线与 M₀ 在 t 上相同，可由旧叶记录或不存在标志取得 b。把目标端改为 L(J) 的描述符，得到 `(b,v_J)`；相同则删除条目，否则替换。其他条目保持。固定环境下，共同叶的目标描述符不变，因此没有遗漏其余新变化；此前已经积累的脏更新也未被清空。

逐身份的“保留最早基线、替换最后目标”具有结合性，中途出现又消失的叶条目相消，故 R 的逐次合成与直接合成给出同一最终逻辑差分。只需 O(k) 个固定大小条目及其字典查询/更新，不扫描旧 Pending。槽位由稳定身份间接引用；旧消费者仍引用的槽位保留至确认消费，退役义务跟随差分条目。其存储计入 N，确认时按实际消费/退役数收费。要求全局紧凑槽位或完整连续网格的消费者仍可能付出 Ω(N) 搬移成本，不在本物化界中。

## 7. 完整成本与未被消除的费用

### 7.1 模型和步骤账本

采用有随机访问的抽象共享内存模型，固定大小记录的读写/分配计单位成本，排序、字典查询、树旋转与同步逐项计。字长至少容纳身份、索引与精确参数域坐标；若 H 超出固定字长，位运算及比较还要乘相应多字成本。边排序采用工作 O(k log(k+1))、span O(log²(k+1)) 的并行比较排序，不把排序算一次原语。

N 为本次涉及的活动状态、历史标记及索引总规模上界，不是完整潜在域 n。令 Γ_W、Γ_D 为新/重算身份的几何与评分计算总工作量及最大独立计算 span；其数量 O(k)，但单次费用不无条件设为常数。

| 步骤 | 工作量 | span 上界 |
| --- | --- | --- |
| 差分整理、支持集、旧身份/键查询 | O(k log(k+1)+k log(N+1)) | O(log²(k+1)+log(N+1)) |
| 路径域/伙伴解码与目标记录准备 | O(kH)+Γ_W | O(H)+Γ_D |
| 边连接、写所有者归并、计数 | O(k log(k+1)) | O(log²(k+1)) |
| 常数套批量有序集合/映射更新 | O(k log(1+N/k))，另加已列更新键排序 | O(log(N+1) log(k+1)) |
| 记录发布、差分网格描述符、退役列表 | O(k)；有序结构的实际修改/回收计入上一行 | O(log(k+1))；树节点回收沿上一行相同分治结构计费 |

k=0 单列为 O(1) 无状态变化事务；公式中的除法不用于 k=0。上述保守查询方式没有证明最优的 `k log(N/k)` 总界，因此**本轮完整算法的主界采用**

\[
W_{\rm mat}=O(kH+k\log(N+1))+\Gamma_W,
\]
\[
D_{\rm mat}=O(H+\log^2(k+1)+\log(N+1)\log(k+1))+\Gamma_D.
\]

此处包含已枚举的索引、队列与状态费用，未把 k 次查询藏进批量集合的更好界。Γ 对应明确的有限函数调用，不是容纳任意全局维护的占位项。

### 7.2 几何、分配与生命周期

当前 DOD 的 `VarianceError` 查询已有静态误差数组；`ComputeScreenErrorScore` 使用固定数量高度采样及投影。对**已有该缓存、同一函数和字长模型**的输入，新增项查询可按固定成本计；缓存的初次建立与地形变化重建仍另列，空间为 P，不能声称从原始高度图开始也只有 O(k) 工作。本算法不额外创建 n 项潜在节点/邻居表。

若没有上述可用静态数据，保留 Γ 的真实计算界；不能用零误差或改评分函数来换取常数。静态身份确定几何域，不等于几何误差证书免费存在。

主构造采用独占事务、复用旧记录的可变有序结构。不会复制整个 M₀，也不要求无限保留旧版本。批量分裂/连接复用未修改子树；每个访问项只产生常数个树节点操作，退役节点沿相同分治结构处理，不另接一个串行全树析构。独立记录与临时输出通过已计费的前缀分配取得唯一位置；单位记录分配/释放是本抽象内存模型的明确前提，不覆盖系统 `malloc`、向量扩容或缓存失效。若实现采用串行分配器、不可变快照或引用计数版本回收，必须另计其路径，不得照抄主界。

活动结构空间 O(N)，临时支持集/边/键为 O(k)；批量树算法的临时路径存储可达 O(k log(N+1))，不声称峰值只有 O(k)。静态缓存另为 O(P)。按本轮身份保存的历史标记在跨轮失效后可批量回收，工作与过期条目数 h 成正比；跨序列摊还可向产生这些标记的更新收费，但单次开始新轮的最坏工作不是 O(k)。历史节点缓存若永久保留，N 必须采用累计已分配规模，不能改称当前叶数。

### 7.3 并行机会与端到端边界

在 Γ 的单项费用有界、H=O(log N) 时，主界为 `W=O(k log N)`、`D=O(log N log(k+1)+log²(k+1))`。当例如 `k=⌈√N⌉` 时，D=o(k)，低于逐项顺序参考至少 k 次事件修改的 Ω(k) span；这是非空的理论参数区间，不是所有 k 都获益。

若 k 很小或 H 很大，这个界不提供实用优势。与工作接近 O(k) 的高效顺序实现相比，排序和字典可能增加对数工作；没有证明常数因子、缓存或有限核数加速。和使用同类有序索引的逐项参考相比，两者可同为 O(k log N) 工作，但本构造有较低 span 上界。

完整时间必须恢复目标发现、差分/证书、视图评分、网格生成/输出和生命周期费用。若 J 靠串行模拟发现，其 span 足以抵消物化改善；这不被本定理排除。硬预算是最终合法状态的资源约束，不自动提供质量最优性或目标选择方法。

## 9. 边界检查与反例

| 检查 | 结果/解释 |
| --- | --- |
| k=0、视图/轮次不变 | F/CΔ 为空，I、叶、队列和标记保持；物化 O(1) |
| k=0、视图改变 | 多数或全部优先级可能改变，必须计评分；不满足局部物化的固定键前提 |
| k=0、历史先细分再合并 | G/S 可以变化，说明不能恢复任意历史；独立参考 R 明确禁止这种无目标需要的反复撤销 |
| 单边界事件 | k=1，叶增删为旧父加两孩子，达到 3k；合并逆向相同 |
| 内部菱形 | k=2，一组操作增/减两叶；四子叶和两父的叶差分为 6，预算不得把组另计两遍 |
| 多层目标或深层合并后再细分 | 每个合法目标通过共同粗化 C 连接；未来新调用仍使用稳定身份，内部字段由当前活动索引判定，不读取休眠 IsSplit 作为活动证据 |
| 不同区域同时细分/合并 | C 保持闭合，先删后加参考不超预算；物化只发布最终状态，不公布超预算中间网格 |
| 保留叶多个边被改、点接触 | 按节点归并槽位，整边匹配；仅点接触不进入邻接 |
| 最大深度、同分与唯一代表 | 最大深度叶可入队但被抑制；分数同序后按固定身份比较；组只保留一个代表 |
| 迟滞/blocked/本轮反向操作 | H/K 不变，S/G 按差分取并集；不能简单重建空历史队列 |
| 旧网格差分未消费、删除后重新出现 | 保留最早基线、覆盖最终目标；其他旧条目不变，尚被消费者引用的槽位不提前复用 |
| 预算恰满与非法超预算目标 | 前者可物化；后者在发布前拒绝，不能作为合法目标的正例 |
| 向量重分配/完整网格输出 | 可能 Ω(N)，属于实现或消费成本；不包含在理想字典/差分写入的 O(k) 项中 |

### 10.2 验证层级与没有证明的内容

Lean 使用一般身份类型上的集合谓词，不实现有限三角形坐标、每个节点两个孩子或每组至多两个成员。**支持集包含关系已机械检查，3k/2k 的数值计数仍是纸面推论。** `Option (Option Nat)` 是资格/抑制/评分的逻辑代理，不是浮点评分或具体平衡树。`Repair` 是函数等式，其高效求值依赖纸面枚举算法，不是已编译的可执行网格物化器。
