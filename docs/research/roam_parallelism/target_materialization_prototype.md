## 1. 阶段出口与主张范围

**MPR-01 完成，限定任务下的完整串行原型通过。** 正确性、自然来源对应和冻结性能配对均已完成。直接路径从给定的 M₀、合法 J 和完整 Δ 物化完整抽象续接状态，没有调用逐菱形参考、生产细分/合并或全量重建来完成事务。

本轮比较的是**目标应用／状态物化事务**。目标发现、差分认证、DOD 导入、测试副本恢复、网格消费及换轮维护全部另外记录；没有得到严格 greedy 目标发现的并行算法，不能将事务速度比称为完整 ROAM 更新加速。暂不启动 MPR-02，不据两个自然输入作工作量泛化或新颖性结论。

输出可在固定地形、视图和评分环境内继续执行评分查询、队首读取、合法菱形修改、预算拒绝、换轮和 Pending 消费。原型没有原生 DOD 写回或相机变化入口，也不覆盖原生部分失败控制流、调试颜色和历史操作统计的字节等价。

## 2. 实际结构与费用边界

核心位于 `src/experiment/roam_materialization/`，只编译到实验静态库。`MaterializationHierarchy` 按稳定身份解码几何与伙伴；`MaterializationState` 拥有稳定节点记录、活动索引、两组候选、历史、版本、槽位和消费者基线；`MaterializationReference` 与 `MaterializationPatch` 分别实现独立逐菱形应用和差分直接连接。

`MaterializationValidation` 独立遍历目标、重建期望整边、队列和消费投影。`MaterializationDodBridge` 是唯一解释 DOD 字段的适配器；只读借用期间复制数据，返回对象不保留源节点、线程池或高度图引用。验证器与桥接仅进入测试和探针，生产 DOD、应用、渲染器不依赖新模块。

两条执行路径共享底层记录和评分函数，但不共享高层支持集或连接程序。参考每个组只处理至多四片叶，用常量局部接口枚举连接；没有每步全量建堆、排序全局索引或扫描全网格。直接路径支付差分集合、支持集、有序容器和整边排序成本，收益不靠人为降低参考质量获得。

| 边界 | 实际工作与复杂度口径 |
| --- | --- |
| 静态环境复制 | 拥有高度样本和两棵既有误差树，按实际项数复制；不隐藏 O(2ᴴ) 的静态数据来源 |
| 初次导入／完整验证／认证 | 允许全量访问，并用标准有序容器和逐节点伙伴解码；不能笼统记作线性 O(N)。保守包含 O(NH + N log(N+1)) 与全量评分／几何复核费用 |
| 直接事务 | O(kH + k log(N+1) + k log(k+1))，另外加实际评分／几何调用费用；N 包含当前持有的全部历史缓存和目标新增记录 |
| 顺序事务 | 只处理差分组，按深度排序后逐合法菱形执行，局部维护；实际重复候选复核和中间叶成本保留 |
| 副本恢复 | 全量复制并遍历 O(N) 个记录重绑指针；当前有序字典的重绑查询包含 O(N log(N+1)) 工作，分配也单独发生 |
| 网格消费 | 遍历全部 Pending；生成新增叶几何、确认删除、归还槽位，不能只按本次 k 计费 |
| 跨轮维护 | 全量历史复制、标记失效和两队列重评，单独计时及记录扫描项；本轮未将其增量化 |

复杂度中的 N 应取相关持久容器规模的共同上界，包括节点缓存、活动索引、候选、历史和消费者义务；表格的 `cachedN` 只报告节点记录数，不把任意历史集合的查找费用偷算成与其规模无关。

整数身份支持 H≤20；伙伴定位用三倍整数重心和精确整边复核，`6G²` 静态范围检查保护有符号叉积。节点记录地址稳定，叶邻接同时保存身份与当前副本记录指针。数值槽位不必在两种方法间一致，但共同叶在一次事务内保持原槽位和记录地址。

认证结果绑定同源副本共用的版本对象，不用概率哈希替代输入有效性。目标、方向重复／遗漏、父伙伴闭合、预算在修改前检查；发布、换轮、历史变更、消费均产生新版本。资源异常退出的自有状态标为不可用，不承诺任意内存不足后的强回滚。

## 3. 参考的一般合法性与独立核查

参考使用 `I₀ → I₀∩J → J`。父／伙伴闭合在交集下保持。按深度递减删除 Δ⁻ 时，待删事件的已细分孩子不可能保留于 J，否则违反 J 的父闭合；删除组因此具有叶孩子。按深度递增加入 Δ⁺ 时，其祖先已在交集或前面加入，伙伴共同处理。叶数先降后升，中间预算不超过两端最大值。

这是一条对声明网格族的一般论证，有限域测试只核查实现。验证器不用参考保存的邻接作为答案，而从完整目标事件集独立生成活动切割、整边分组、面积、绕序、所有队列条目、抑制和 Pending。

实际覆盖：

- H≤3 的 48 个合法切割、2304 个有序目标对；每对均比较最终完整投影，并在未消费第一份差分时继续返回旧目标，再消费。
- 深度 20 的局部链、混合增删、域边界、内部完整菱形、共同叶接口和冷记录创建／缓存复用。
- 手算前置例子：路径 4 的伙伴是 7。先细分边界路径 2，路径 4 因伙伴未出现而拒绝；细分路径 3 后，路径 4 所属完整菱形成功应用，并恰好达到 B=8。
- H 迟滞、K/G 抑制、S 合并抑制、最大深度、稳定同分队首、NaN 评分、非法预算、重复／冲突／缺失差分和过期认证。
- 消费前删除再恢复、多事务合成、确认后槽位复用；共同叶槽位和地址保持，范围外细分条目保持。
- 两个冻结自然输入的完整来源对应、共同目标应用、Pending 消费与换轮后全量复核。

没有运行全 CTest、后端矩阵、旧 Lean、GATE-03 或 CPU-CBT。实际执行了定向测试程序；其无参数核心入口也注册为 CTest `RoamMaterialization`，未再重复跑同一核心测试来增加数量。

## 5. 工作量与诊断步骤

`WorkCounters` 只在诊断遍安装。`RecordsReused` 对应输出列 `cachedEnsureCalls`，是命中缓存的 Ensure 调用次数，不能解释为独立重新激活记录数。`queueWrites` 是队列刷新调用次数，每次可能涉及成员与有序键增删，并非硬件写指令数。记录／槽位分配与复用单列，标准容器内部的每次 allocator 调用没有逐一追踪。

`FullScanItems=0` 配合源码循环边界审查，说明被测目标事务没有全域恢复；计数器本身不能单独证明不存在隐式扫描。直接路径所有主循环只遍历 Δ、FΔ、CΔ、新叶／旧边界；所有完整验证、导入、消费与换轮的循环都位于独立边界。

两档均匀输入分别有 512／8192 片旧叶，缓存记录为 1022／16382。相同 k 下支持集、评分调用和刷新数量相同；实际时间仍受深度、索引查找及内存状态影响，不能因计数相同宣布时间与 N 无关。

直接事务的 `PrimitiveGroups=0`；参考自然任务分别实际执行 39／6 个合法组。直接准备边记录在 Peking／test129 为 450／72 条。自然状态同时覆盖已缓存记录和实际新建记录；解析任务的新增孩子在事务前没有预创建，不是反复对已经完成的目标测 k=0。

诊断步骤分为支持集／旧边界准备、记录与槽位修改、边排序连接、候选维护与发布。计时含诊断开销，只用于粗粒度构成。尤其“记录”和“维护”都混合几何计算与串行容器操作，不能把整个步骤视为纯并行计算或不可并行下界。

## 10. MPR-02 实际执行边界

用户已确认 MPR-02。实现沿用 `d876cea` 的状态投影和合法目标契约，将直接物化组织为同一条准备路径；串行内联执行，2/4 线程经同步回调执行。独立顺序参考仍逐合法菱形局部更新，没有改为补丁调用，也没有加入全局维护。

| 并行区 | 输入与写入所有权 | 留在主线程的工作 |
| --- | --- | --- |
| 静态记录 | 已分配稳定位置的缺失记录，按 ID 独立构造静态字段 | 缺失查询与插入；缓存记录不重新解码 |
| 派生值 | 新叶域、候选资格/抑制及至多两个评分成员的固定描述；边与候选值各有固定输出区 | 目标集合/历史/Pending/槽位修改，资格判定和描述生成 |
| 邻接填写 | 边排序后按记录归并的最终邻接数组，每条记录仅一个写者 | 边分组、槽位重复检查、目标指针解析、队列安装与最终发布 |

`MaterializationExecutor` 只进入测试/探针，包装既有 DOD 线程池。核心库不依赖该线程池或来源状态。任务不调用会增加共享计数的 State 查询，评分只读桥接拥有的冻结数据；评分调用量在成功完成后由主线程按描述中的实际成员数归并，线程身份和异常槽由各分块独占。

任务异常在完成所有分块后重新抛出；线程池提交本身异常时，适配器先排空并停止线程池，保持所有捕获对象存活。WorkSession 使失败事务不可用，不承诺强回滚。夹具验证了任务抛出和 NaN、并行结果失败标记、以及自定义同步执行边界部分提交后的等待；真实线程池分配器故障未作全局故障注入，部分入队失败的 `Shutdown` 路径另经源码生命周期审计。二者证据不混称为内存不足的穷尽验证。

新的暂存包括记录指针、叶域、候选描述、评分值、边端点、槽位更新和记录补丁。`scratchPayloadBytes` 是这些向量按容量计算的载荷和，**不是进程峰值内存或所有堆分配总字节**；不含已有/支持集树节点、分配器元数据、执行器异常槽和诊断对象。分块异常存储另为 O(p)，全部实际分配/释放仍在完整事务时钟内，线程池首次创建除外。N、k、H 的原工作界保持，不声称标准容器及串行排序具有理论多对数 span。
