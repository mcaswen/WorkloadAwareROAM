## 1. 分析对象与证据等级

任务仍为给定 `(M0, J, Δ)` 后构造完整可续接状态。目标发现、差分生成/认证、来源导入、测试副本恢复、Pending 消费及换轮分别计费，均不能用物化事务时间替代。历史全量结果保留在[MPR-02 实施记录](target_materialization_prototype.md#12-mpr-02-冻结性能与工程出口)。

本页区分三类证据：源码可数的逻辑操作；已冻结的诊断/五进程测量；依赖假设的收益估算。诊断分段来自一次 `audit-m1`，只用于定位候选成本；它含诊断扰动，不能作为稳定耗时比例，更不能与关闭诊断的进程中位数混合计算加速比。

来源为 `benchmark-output/roam-materialization/mpr-02/after/prototype/audit-m1/results.csv`、`comparison/summary.json` 及已归档程序。事务路径见 [Patch](../../../src/experiment/roam_materialization/MaterializationPatch.cpp)，持久状态操作见 [State](../../../src/experiment/roam_materialization/MaterializationState.cpp)，差分认证见 [Validation](../../../src/experiment/roam_materialization/MaterializationValidation.cpp)。以下两个自然输入均固定 sampleIndex=14；大解析输入为 `uniform-d12-diamonds128`，其中 d12 表示初始均匀细化层次，不是环境最大深度。

项目数不等于同成本任务数。派生准备包括每个新增叶的边生成和每个候选的求值；被抑制或不存在的候选不执行评分。邻接填写通常只是两组固定数组写入，不能因为有数百条记录就推断存在大量可摊薄派发成本的计算。

三个易误读的口径：

- `cachedEnsureCalls` 是调用次数，不是独立记录数；当前 Patch 已先预留记录，随后 `SetEvent/SetLeaf` 再次查询，因此这里恰为 `k+R+A`。
- `queueWrites` 在每次 `InstallCandidate` 后加一，包括旧/新都不存在的情况；它不是实际树插入或删除次数。现有 `recordQueries` 也不是全部 `_nodes` 字典访问的完整统计。
- `scratchPayloadBytes` 只计已列向量的容量载荷，不包含临时树节点、分配器开销、所有执行器存储或进程峰值内存。

## 4. 可以明确减少什么，哪些仍未知

### 4.1 第一优先：事务内表示与重复定位

认证已经提供排序、去重后的 Δ+/Δ− 向量，热路径再次复制成两棵树没有新增语义。F/C 和 R/A 也只服务于本次确定性枚举、去重与成员查询，可以用局部向量排序及二分查找。当前六个临时集合持有 `k+F+C+R+A` 个树元素，三个输入分别为 **614、98、2,008**；这是元素数，不是测得的 malloc 次数。

记录分配后再次 `Ensure`，以及连接阶段从已知端点身份重新 `_nodes.at`，可以通过事务内稳定记录指针避免。当前 `k+R+A` 次命中查询是明确候选；最终净减少量还须扣除建立局部表的查询。不得只把查询搬进 helper 就宣称工作消失。

拟议变化仍保留标准持久容器、静态记录缓存、历史和 Pending 生命周期。它降低常数与重复工作，不将现有 `O(kH+k log N+k log k)` 加评分成本改写为已经实现 `O(k)`；向量排序、局部查找、扩大的指针载荷及析构都要计费。

### 4.2 队列维护不能先定罪

对合法 cuts，F 中不存在两端共同叶：事件差分本身至少一端为内部节点；差分事件的孩子在另一端不可能同时为活动叶。因此当前 split 刷新不存在大量“未变化叶重新评分、删除再插入”的当然收益。三个输入中 `F−(R+A)` 仅为 **12、1、0**，直接跳过两端均非叶的刷新不构成主要收益依据。

Merge 候选可能有未变化条目，但现有输出不足以量化。下一步只区分刷新、成员/排序索引真实插入删除及旧新值相同的情况；不预设树更新是所有 `queueWrites` 的若干倍，也不提前实施新队列。

### 4.3 暂缓项

并行分配器、批量平衡树、并行排序、跨事务缓存和自适应派发都可能改变成本，但当前缺少相应收益预算。极短邻接填写在 M4 诊断比 M1 多约 0.008–0.011 ms，去掉这一派发即使完全有效，单独收益也有限；本轮不围绕几微秒增加策略或反复测量。

## 5. 预期收益如何表达

选取互不重叠的“支持集 + 状态维护 + 描述 + 连接”作为候选成本包络 `C`，其余工作保持。三个输入的 C 分别为 0.5865、0.1759、0.9454 ms，占本次 M1 诊断约 56.8%、56.0%、53.5%。包络包含仍然必需的工作，不能视为全部可删除。

若净减少包络比例为 g，新增工作为 h，在同一计费边界下：

`Tnew = T0 − gC + h`，改善条件为 `gC > h`。

| 假设 h=0 的敏感性情景 | Peking：减少时间 / 速度比 | test129：减少时间 / 速度比 | d12-128：减少时间 / 速度比 |
| --- | --- | --- | --- |
| g=10% | 0.0587 ms / 1.060 | 0.0176 ms / 1.059 | 0.0945 ms / 1.057 |
| g=25% | 0.1466 ms / 1.166 | 0.0440 ms / 1.163 | 0.2364 ms / 1.154 |
| g=50% | 0.2933 ms / 1.397 | 0.0880 ms / 1.389 | 0.4727 ms / 1.365 |

这些是**条件收益预算，不是预测或验收承诺**。50% 是较强假设；目前没有测量支持将任何一行称为预计可实现的加速。先检验减少的查询/临时树工作是否足以覆盖局部表与排序费用，再用新五进程数据更新估计。M1 和 M4 的分母分别取自己的旧版本，不能把本表收益直接叠加到旧 M4 中位数。

缩短公共串行部分可能改善新 M1、新 M2 和新 M4，但不保证 `M1/M4` 比值提高：小任务的派发成本可能仍占主导。报告应同时给旧 M1→新 M1、新 M1→新 M2/M4、当前参考→新物化和旧 M1→新 M4，区分工作压缩、线程收益与净事务收益。

## 6. 实施前判断

有明确且受 Δ 控制的优化对象，可以进入 MPR-03 评审。首轮优先验证“少建临时树、少做重复全局索引查询”能否降低完整事务成本。队列真实维护比例、局部表新增代价和小任务的净收益仍待测，暂不据此承诺端到端 ROAM 加速。

用户随后指出 2 万预算覆盖不足，要求复用以前的极限压力路径。已在[MPR-03 §3.0](../../plans/roam_parallelism/target_materialization_prototype_03_plan.md#30-前置复用极限路径测量当前核心)加入前置测量：Peking/20 万预算、旧 64 点环绕几何路径的固定 sample14，先测当前核心，再决定优化优先级。历史 `runtime-benchmark-20260831-035247.csv` 中该点 DOD split/merge 计数各为 16,206、活动叶 200,000；这些是旧版本整帧操作数，不能当作当前 split 阶段净差分 k。新输入尚未测量，本页成本比例不能外推为大工作量结论。

此前强验证结论保持；如果本次常数优化收益有限，应据实际剩余成本决定下一步，不将其改写为直接物化构造或理论低 span 结构失败。

## 8. 尚保留的费用与解释边界

本轮仍串行执行局部支持集排序/定位、真实记录分配、事件/叶/历史/Pending/槽位维护、候选资格描述、边连接整理、队列索引维护及版本发布。静态记录、边/候选求值、最终邻接填写沿用原三段并行。A/B 减少查询和暂存树费用，没有改变持久容器、并行边界或复杂度 `O(kH+k log N+k log k)` 加评分成本。

旧/新压力 M1 的一次诊断中，支持区间为 66.3234/59.5220 ms，状态维护为 89.1849/52.2958 ms，连接整理为 33.5713/20.2848 ms；这是识别剩余费用的证据，不能当作稳定耗时改善或把未做消融的时间分摊给 A/B。新 M1/M4 的静态区间为 20.5861/5.0989 ms，但完整收益必须另看关闭诊断的事务时间。

目标发现、差分、认证、导入、旧状态恢复、消费与换轮仍在外围。其中压力状态的导入/认证本身需要秒级时间，不能把给定目标的数百毫秒事务改称完整 ROAM 更新时间；包含来源轨迹的总时钟也不能与内部各项直接相加。本轮没有优化这些外围步骤。

旧/新核心使用同一 schema 3 探针。用户要求开发验证从简后，已停止完整矩阵；前两组压力配对中旧/新 M1 约 332.04/239.71 ms，新 M4 约 226.39 ms，M1/M4 配对比约 1.059。压力点支持公共工作压缩有初步收益，多核收益仍有限，不能外推为自然轨迹整体加速。

原八项仅有单次开启诊断的前后记录，Peking 1.2807→2.3002 ms，提示小输入可能承担不同代价；没有关闭诊断的同期对照，不能确认原因或宣称小输入性能通过。完整数值、取消范围和证据限制见[实施报告 §14](target_materialization_prototype.md#14-mpr-03-开发快验结果与停止记录)。本轮不再补跑，未来若追查，应先做这一具体风险的短配对，不恢复整套正式矩阵。
