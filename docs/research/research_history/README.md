## 时间、消息与身份规则

1. 提交台账由`git log --reverse --topo-order`导出，不按标题猜阶段，也不把文件修改时间当实验时间。作者时间和提交时间同时保留；日期沿Git中的时区，当前台账为`+08:00`。
2. 当前分支与`--all`可达数量均为131。首项`aa6bb71`在8月20日，截止`c95ace0`在9月18日。早期里程碑中的7月日期只由文档支持，当前仓库没有对应早期提交链。
3. 本会话可见用户提示词是意图证据，`U01`～`U43`为人工定位号。没有原始消息ID、逐条时间戳或完整早期会话导出，不声称本页覆盖所有历史提示词。用户贴入的评审意见包含假设与建议；只有已确认动作或报告证据才能写成事实。
4. 本次没有检索其他私人会话或根据聊天情绪推断正式停止。用户的“只是讨论”、后续重新授权和阶段限定优先于较早建议。
5. 历史报告可能追加后续说明。本文引用的是截止提交下的版本；如需查看当时落盘文本，使用`git show 提交:路径`。主文中数值尽量引用正式结果/审查，而非只引用规划目标。
