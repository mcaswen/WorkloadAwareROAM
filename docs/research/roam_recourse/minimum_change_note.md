# 最小拓扑修改量候选暂存

> 日期：2026-09-12；状态：有独立研究价值，暂存，不属于当前 CPU 并行结构探索。
> 本页只归档已讨论结论，不继续推导或实现。

## 1. 问题与适用边界

在满足当前质量目标和硬预算时，最少需要改变多少细化事件？用固定事件集合上的对称差定义修改量：

\[
\min_J |J\triangle J_0|,
\qquad J\text{ 为合法闭合集},\quad N(J)\le B,\quad F_t(J)\le\tau_t.
\]

这里的 F 暂指已建立假设的最大单调优先级，不自动等于独立屏幕几何误差。几何质量仍应对原始高度样本及冻结双线性插值定义的参考曲面评价。质量目标放宽可能扩大可保留旧网格的空间，但不预设视觉可接受阈值。

该方向优化工作量；当前并行母问题优化必须执行的工作的依赖结构。修改量减少甚至可能降低可供多核分摊的工作，不能把前者的成功写成后者的证据。

## 2. 已讨论的等成本结论

在固定前置模型中，假设每个事件成本相同，固定公共初始集合已扣除；事件容量为 b。旧集合 J0 合法且不超预算，当前给定质量目标的最小必选闭合集 C 已知，且 |C|≤b。令 u=|C\J0|，则：

\[
R_{\min}=u+\max(0,|J_0|+u-b).
\]

已有论证：必须加入 u 个新事件，预算还要求至少删除超额数量。J0∪C 闭合；删除其中不属于 C 的可移除最大事件，直至满足容量，即达到此下界。这是端点集合的事件修改量结论，不代表中间超预算的并集可以直接提交。

不包含 C 的发现成本、几何评价、不同事件成本、邻接写入、并行提交或实际更新时间。只做纸面讨论，未接入 Lean 或 C++，不主张此公式本身有新颖性。

## 3. 保留价值与暂停决定

未来可以独立研究质量—修改量交换，也可以用于现有 CPU 执行研究，区分必要修改和策略引入的额外修改。当前不扩展加权版本、动态一致性、滞回或质量余量算法。

相关借鉴是动态算法中的低修改量维护，例如 [Fully Dynamic Consistent k-Center Clustering](https://arxiv.org/abs/2307.13747)。其点插入/删除模型不等于相机引起的全局优先级变化，不能移用复杂度保证。ROAM 已有时间连贯性利用，也不能把“尽量沿用上一帧”作为创新。
