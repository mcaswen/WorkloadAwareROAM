# 资源约束自适应三角化事务：理论研究入口

日期：2026-09-17。状态：**ATT-01～03已按授权自主闭环，条件一般模型成立**。先读[最终结论与范围表](generalization_results.md)，过程见[大规划](../../plans/adaptive_triangulation/resource_constrained_transaction_theory_plan.md)、[推导与反例](model_derivation.md)和[验证账本](verification.md)。本模块不改生产算法，也不替代 QPC 的持续质量调查。

## 1. 对建议的判断

建议合理，适合做一轮有界的理论审计。当前质量代数已不依赖 ROAM；面数记账和独立资源写入也有一般化基础。真正需要验证的是：能否给出非空、可构造的非 ROAM 局部操作实例，且它们确实满足几何拼接、证书稳定和完整续接前提。不能只定义一个名为“合法事务”的黑盒，再从“它保持一切”推出一切保持。

本轮目标是判断一般**事务语义与组合模型**成立到哪里，不预先宣称得到了一般自适应三角化求解算法。总定理即使成立，也未必使用优先级 P；发现事务、搜索可行解、选择批次、恢复超标误差和获得多核收益，仍是另外的义务。一般性、算法有效性和新颖性分别判断。

## 2. 已发现的必要修订

| 用户建议中的简写 | 需要补充或拆开的条件 |
|---|---|
| 固定外接口等于 `∂K=∂K′` | 完整补丁边界与其连接未修改网格的接口不是同一对象。完整边界固定的圆盘只能有偶数面数差；当前外边界 +1 需要单列兼容细分扩展 |
| 任意有符号资源变化 | 账本接受整数，几何可实现值仍受欧拉关系和操作前提限制；不推出所有整数都可由单个原语实现 |
| 最终有符号和满足预算 | 只保证最终发布的活动面数；任意顺序中间状态、临时分配峰值及部分失败需独立处理 |
| 读写集不交推出交换 | 读集包含使能条件、证书依赖、不存在性查询；写集包含生命周期和逻辑身份。分配与公共归约另有协议 |
| 任意非负局部损失 | 非负性本身不意味着局部性。必须证明损失的影响支持以及证书在其他事务后的稳定性 |
| 单项质量通过推出批次通过 | 固定 Q、权重、目标与参考；共同快照证书需可迁移。进展可加比单调性需要更强的独占变化支持 |
| 一般三角曲面合法 | 抽象流形拼接、几何无翻转和三维无自交分别判断；远处曲面碰撞不能由局部边界条件排除 |

## 3. 模块边界

```text
有限网格、附件接口与局部替换
                ↓
资源读写语义 + 有符号预算 + 损失证书
                ↓
有条件批次组合定理
                ↓
非 ROAM 操作实例 / 当前算法实例 / 失败边界
```

“附件接口”指补丁和未改动网格共享的带身份子复形，正文统一称**连接接口**。模型首先研究二维有限流形网格的局部替换，不建设任意维度几何框架，不要求高度场或二叉层次。三维嵌入只在列明外部不相交条件时给几何保证。

## 4. 有限的既有理论定位

边折叠保持拓扑类型需要明确条件。Dey 等的 *Topology Preserving Edge Contraction* 给出 link 条件及局部修改范围的研究，说明“折叠是局部操作”并不自动保证拓扑保持；本模块需将操作适用前提映射清楚，不能把边折叠、link 条件或局部拼接本身列为新贡献。[原论文 §4–5](https://graphics.stanford.edu/courses/cs448b-00-winter/papers/dey_edge_contract.pdf)

Reynolds 的分离逻辑已有根据受影响存储进行局部推理的框架。因此资源不干涉与局部框架条件属于需要借鉴的既有基础；本项目的集合读写模型不等于实现了该逻辑，也不能仅凭类似的组合命题主张创新。[作者原文 §1、§4](https://www.cs.cmu.edu/~jcr/seplogic.pdf)

本轮只核查这两项直接相关的基础来源，并复用[原事务近邻检索](../cpu_refinement/transactional_lod_prior_art.md)。未进行穷尽性新颖性检索；“能够一般化”和“已经是新的一般算法贡献”保持分开。
