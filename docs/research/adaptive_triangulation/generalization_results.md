# ATT 最终结论：一般事务组合模型成立到哪里

日期：2026-09-17。依据[大规划](../../plans/adaptive_triangulation/resource_constrained_transaction_theory_plan.md)、[完整推导](model_derivation.md)、[原语嵌入](operation_embeddings.md)及[验证账本](verification.md)。

## 1. 裁决

**有条件的一般资源约束局部三角化事务模型成立，核心不局限于ROAM。** 它覆盖明确接口下的局部替换、整数净资源记账、完整资源独立、固定观察环境下的加权质量组合；存在非ROAM、非高度误差实例。

这并非一般自适应三角化求解器。P没有进入安全定理；发现/认证/选择的代价、greedy最优性、质量恢复能力、实际多核速度和学术新颖性均未随之证明。最准确的定位是**可复用的算法说明与正确性骨架**。本轮没有证据将这些既有局部更新与代数组合直接包装成独立算法创新。

## 2. 一般性边界

| 命题 | 结论及证据 | 边界 |

| 单事务逐点目标与加权超标势 | ROAM-free；显式标量规律Lean＋纸面实数实例 | 固定Q/环境/目标/非负权重；非连续曲面严格最大值 |
| 单快照证书迁移和批次质量 | 条件成立；观察投影/读域覆盖Lean | 非负损失不自动局部；依赖可退化到全域 |

## 3. 典型操作能否装入模型

| 操作 | 实际净额 | 局部条件与支持 |
|---|---:|---|
| 内部edge split | +2 | 两侧完整受影响面、新点/邻接/属性；几何与质量证书另查 |
| 自由外边界split | +1 | 与未改网格连接接口保持；完整外边界允许细分，不冒称完全固定边界 |
| interior edge collapse | 通常−2 | 满足完整link条件、合法几何、包含端点全部受影响邻域；支持随度数变化 |
| boundary edge collapse | 合法实例−1 | 合法边界身份/几何契约，link和外接口额外核查 |
| edge flip | 0 | 合法四边形和对角线替换；凹四边形不是总能翻 |
| interior vertex removal + cavity retriangulation | −2 | 单圆盘one-ring、固定边界与合法三角化；d面→d−2面 |
| ROAM refinement / donor | +1/+2/−2/0的当前特例 | forced prerequisites必须纳入完整补丁，不能声称任意严格ROAM请求O(1)支持 |

完整边界固定的圆盘满足F=2Vint+b−2，因此δ=2ΔVint是偶数。有符号账本接受任意整数，不等于单个几何操作能实现任意整数。若fixed-interface定义得过窄，边界+1无法嵌入；本轮明确分成严格类和自由外边界扩展类。

## 4. 总定理的可审计条件

给定合法初态及已找到的一批事务：局部圆盘/接口和声明几何证据有效，逻辑读写及证书依赖完整、身份预定且两两独立，固定观察质量证书可迁移，净额来自实际面数，全部发布项通过预算与使能。共享派生项按确定协调协议恢复。

于是最终：

$$
\operatorname{Valid}_{\mathcal G}(M')\land N(M')\le B_{\max}
\land \Psi_{e,\tau,w}(M')\le\Psi_{e,\tau,w}(M),
$$

且合法顺序给出同一带身份逻辑状态与相同确定续接观察。几何类G和预算发布语义必须明示。Lean组合的是资源预算与观察质量；几何拼接属于纸面层，有限实例核对这些条件可以同时满足。

这里没有donor唯一性或一对一exchange公理。其一般替代是“删除资源不得重复消费、创建身份不得碰撞”。当前donor唯一性只是这种资源独立的具体实现。+2和−2可以独立组成最终预算安全批次，但先+2可能中间超限；原子可见或先释放的安全顺序是额外发布义务。

## 5. 三种质量实例及生产缺口

1. **屏幕平方偏移**：固定相机/分辨率、固定参考和Q，且投影定义域有效，令ℓ=‖π(gM(q))−π(g*(q))‖²，τ=E*(q)²。它是参数对应点几何偏移；若引入遮挡、最近点或自适应可见Q，必须新增依赖/环境条件。跨相机不能沿用同一个Ψ下降结论。
2. **高度平方残差**：固定参数域与双线性源参考，ℓ=|hM(q)−h*(q)|²，τ=H*(q)²；完整支持含不可见点。局部证书只控制有限Q，不证明连续高度曲面严格最大值。
3. **一般属性平方残差**：固定参数化曲面的标量场，ℓ=|aM(q)−a*(q)|²。本轮用平面几何/非几何属性、常零参考做有理实例，不依赖ROAM或高度质量；ATT-01另有不属于固定xy高度场的竖直嵌入。

| 当前代码事实 | 与一般模型关系 | 尚缺的实例义务 |
|---|---|---|

| [Footprint/Conflict](../../../src/algorithms/greedy_transactional_lod/TransactionalReservation.cpp)记录边、面、高度资源并查R/W | 覆盖核心几何依赖 | allocator、samples、owner、normal、index及全局发布走其他阶段，不能把该Footprint独自认作全部状态证书 |

## 6. 实际证据与成本

ATT-01：8个正例、4个反例，覆盖split/collapse/flip/删点/ROAM和三维失败边界。ATT-02：两个Lean模块检查具体更新、计数和一般排列。ATT-03：一个新质量模块、批次模块扩展，检查加权逐点目标、观察框架、证书迁移、预算与质量组合；全部最终声明无未证明占位。

ATT-03有限实例含split(+2)、flip(0)、remove(−2)，9面→9面，9个固定观察点，Ψ由25/4降到3/8；六种排列的逻辑状态和派生邻接相同。三种排列中途11面，只能作为私有结果或换安全顺序发布；没有隐藏这项失败。五个质量反例限定负权重、零权重、全局耦合、重复收益及环境变更。

Lean采用显式代数法律，非完整Real几何库；通常实数实例为纸面，有理夹具为有限数值核对。旧QC只重建必要导入缓存，未重跑历史整个证明/实验矩阵。耗时、源码指纹和确切命令见[验证账本](verification.md)。本轮无生产代码修改，无性能提升结论。

运行时成本仍须完整记为：

$$
W=W_{discover}+W_{select}+W_{conflict}+W_{coordinate}+W_{continuation}
+\sum_i(W_{support,i}+W_{certificate,i}+W_{prepare,i}).
$$

写入至少有实际输出成本。有限局部面数di、资源规模fi、样本/证书规模si不是同一个量；任意损失可使si或依赖查询接近全网格。相对接口同胚存在不提供快速证书生成算法，精确算术位成本、身份/索引和派生维护也不消失。一般交换定理不给work/span复杂度或实测加速承诺。
