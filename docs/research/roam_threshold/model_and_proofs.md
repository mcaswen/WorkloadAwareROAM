# 固定依赖、阈值最小闭包与预算可行性

> 状态：抽象定理已由 Lean 检查；第 2 节的几何对应是纸面论证。
> 不把抽象假设、源码事实或有限反例称为实际 C++ 算法的形式化验证。

## 1. 对象与假设

本轮只研究冻结相机与参考数据下的 split-only 目标选择。`M₀` 是初始合法网格；允许的结果只能细化 `M₀`。合并、跨帧资源迁移、运行时间预算和浮点执行细节不在定理内。

| 符号 | 含义与约束 |
| --- | --- |
| `V` | 固定有限层次中的潜在三角形细分事件，包括不能执行的最细层细分请求 |
| `t` | 由根标识及左右子路径确定的几何三角形；不是 pool index 或一次函数调用 |
| `t → u` | 执行 `t` 必须包含 `u`；边从请求指向前置 |
| `I₀` | 初始网格已经执行的细分事件，要求依赖闭合 |
| `Allowed` | 可执行事件集；最细层三角形可以成为叶，但不能再被细分 |
| `I` | 目标已执行事件集，要求 `I₀ ⊆ I ⊆ Allowed` 且闭合 |
| `q(t)` | 冻结的非负优先级；若 `p` 是 `t` 的树父节点，则 `q(t) ≤ q(p)` |
| `cᵥ` | 非负事件成本；解释为三角形数时必须采用唯一、不重复的 primitive 或 diamond 编码 |

父节点深度严格小于子节点深度。已经生成且没有细分的三角形构成叶集：

\[
L(I)=\{t:(t\text{ 为根或 }parent(t)\in I)\land t\notin I\}.
\]

Leaf 条件是 `max_{t∈L(I)} q(t) ≤ τ`。Lean 用自然数表示有限优先级的序数；它表达严格大小与相等关系，不表示把像素误差取整。有限组有限实数可以先按不同取值映射成序数；该映射与实数几何评价器未在 Lean 中实现。

## 2. Theorem 0 的几何部分：为什么依赖可以固定

### 2.1 本轮可论证的网格族

限定为正方形参数域、固定对角线的两个直角等腰根三角形，以及固定底边中点二分规则。细分深度有统一上限。所有顶点高度都由冻结 reference 规则赋值，拓扑首先在参数域中讨论。

设 `Γd` 是把两个根统一细分到深度 `d` 的网格。该规则的 uniform refinement 保持匹配：每个内部底边在 `Γd` 上有唯一同层底边伙伴；边界底边没有伙伴。这个性质可按 uniform subdivision 归纳，配对三角形一起二分时外轮廓边不变，生成下一层匹配结构。这也是本节依赖构造适用的前提；不推广到任意初始三角网格或任意最长边细分规则。

对每个潜在三角形建立两类静态前置：

1. 细分 `t` 需要其树父节点已经细分，除非 `t` 是根。
2. 内部底边上细分 `t` 需要其唯一同层伙伴 `mate(t)` 也被细分。

第二类关系是双向的。因此，**以单个三角形为事件时，图并非 DAG**。将同底边的两个事件收缩为一个 diamond，边界事件单独成组，剩余前置边只指向更浅层级，得到 DAG。不能把“固定依赖关系”和“未经收缩就无环”混为一谈。

### 2.2 必要性

任意由该固定层次生成的网格都满足父节点先细分，否则子节点尚不存在。若 `t` 被细分，其底边中点进入网格；底边另一侧必须出现相同顶点，否则出现 T-junction。在规定的二分层次中，另一侧对这个底边的二分正对应 `mate(t)` 事件。

若另一侧已经更细，则伙伴事件已经执行；若另一侧更粗，则必须先生成伙伴，再细分伙伴。两种情形都只是在兑现同一条预先存在的前置路径，不因第二个请求的出现而新增一条“联合触发”的几何规则。

所以合法目标的事件集对上述关系闭合。

### 2.3 充分性、顺序无关与计数

给定有限闭合集，将 diamond 按前置优先的拓扑顺序执行。轮到某个 diamond 时，其各树父节点已细分，成员三角形已经生成；成员自身尚未细分，因而仍是叶。内部 diamond 同时二分底边两侧，边界 singleton 只二分域边界。操作只在该底边引入一个中点，外围边不变，故保持合法三角剖分。按执行序列归纳即可得到目标网格。

固定细分集合唯一确定每棵二叉树的叶切割，因此任何这样的执行顺序都得到相同的**逻辑三角形集合**。这没有证明多个线程可以无同步地写邻接数组或共享分配器。

每个三角形二分使叶数增加 1。因此使用 triangle-event 编码时：

\[
N(I)=2+|I|.
\]

使用收缩后的 diamond 编码时，内部事件成本为 2，边界事件成本为 1：

\[
N(I)=2+\sum_{v\in I}c_v
      =N_0+\sum_{v\in I\setminus I_0}c_v.
\]

只能选择一种编码计数；不能既为 diamond 计费又为其中的两个三角形计费。闭包调用数、root 请求数不等于三角形增量。

上述论证与 ROAM 的配对细分及既有规则层次依赖表示相符，但几何归纳、唯一伙伴构造与事件/实际网格双射尚未编码为 Lean 对象。[ROAM 原文](https://doi.org/10.1109/VISUAL.1997.663860)、[Pajarola 原始工作入口](https://www.ifi.uzh.ch/en/vmml/publications/vis-98.html)

### 2.4 与当前实现的距离

当前 `SplitNode` 会递归修改邻居并重新读取底边邻居；这一实现方式不反驳静态几何依赖的存在，但也不能作为静态模型已经验证的证据。深度停止、预算中断、节点分配和部分执行需要独立对应证明，详见[源码依据](sources.md)。

本轮 Theorem 0 的准确状态是：**标准固定网格族的纸面建模可成立；固定关系上的代数部分已形式化；实际 DOD/Classic 的实现对应仍未证明。**

## 3. Theorem 0 的代数部分：闭包与并集

对任意固定关系，包括有环关系，定义：

\[
\operatorname{cl}(A)=\{v:\exists r\in A,\ r\leadsto v\},
\]

其中允许零步路径。零步路径证明扩张性；保留路径起点证明单调性；拼接路径证明幂等性。并集性质来自路径有一个具体起点，该起点属于 `A` 或 `B`：

\[
A\subseteq\operatorname{cl}(A),\quad
A\subseteq B\Rightarrow\operatorname{cl}(A)\subseteq\operatorname{cl}(B),
\]
\[
\operatorname{cl}(\operatorname{cl}(A))=\operatorname{cl}(A),\qquad
\boxed{\operatorname{cl}(A\cup B)=\operatorname{cl}(A)\cup\operatorname{cl}(B)}.
\]

`Closure.lean` 还证明了该集合是包含输入的最小闭合集。DAG 条件用于可执行次序，不是上述等式的必要条件。

对于冻结初始网格，将未执行事件作为相对全集：

\[
\operatorname{cl}_{M_0}(A)=\operatorname{cl}(A)\setminus I_0,\qquad A\subseteq V\setminus I_0.
\]

相对闭包也满足四个性质。因为 `I₀` 闭合，先取 `cl(I₀ ∪ A)` 再减去 `I₀` 得到同一结果。令 `K(r)=cl_{M₀}({r})`，即可得到用户提出的地基：

\[
\boxed{K(A)=\bigcup_{r\in A}K(r)}.
\]

对任意非负权重，闭包成本

\[
C(A)=\sum_{v\in\operatorname{cl}(A)}c_v
\]

单调且次模。证明利用并集等式，以及 `cl(A∩B) ⊆ cl(A)∩cl(B)`，逐元素计数得到：

\[
C(A\cup B)+C(A\cap B)\le C(A)+C(B).
\]

相对成本可以把 `I₀` 内权重置零得到。`Threshold.lean` 的 `closure_cost_submodular` 已检查此不等式。它只谈成本，不把最大误差下降当作可加收益。

## 4. Theorem 1：阈值必选集合

设 `Rτ={t:q(t)>τ}`，这里必须考虑**潜在层次中的全部三角形**，不能仅观察当前队列。

**必要性。** 假设所有叶优先级不超过 `τ`。若 `q(t)>τ`，沿父链所有祖先也超过 `τ`。从根开始，它们不能保留为叶，必须细分；于是 `t` 被生成，也不能保留为叶，故 `t∈I`。形式化证明按深度强归纳，没有把必选等价预设为公理。

**充分性。** 若 `Rτ⊆I`，则每个没有细分的叶都不属于 `Rτ`，优先级至多为 `τ`。

所以：

\[
\boxed{\max_{t\in L(I)}q(t)\le\tau\iff R_\tau\subseteq I}.
\]

优先级单调性不可删去：根优先级为 0、未生成子节点优先级为 10 时，保留根即可满足阈值 5，却不需要细分隐藏子节点。这个反例已在 Lean 中检查。

## 5. Theorem 2：最小阈值闭包与硬预算

定义：

\[
J_\tau=\operatorname{cl}(I_0\cup R_\tau).
\]

任意满足阈值的合法目标都包含 `I₀ ∪ Rτ`，因此包含 `Jτ`。反过来，若 `Jτ ⊆ Allowed`，它自身闭合、包含初始集和必选集，所以就是一个合法阈值目标。

于是 `Jτ` 是唯一的包含关系最小解；非负成本使其成为最小成本解，但零成本时其他集合也可能同成本。合法 triangle/diamond 事件成本严格为正。

定义当前网格细化族内的最小三角形数：

\[
N_{\min}^{M_0,q}(\tau)=
\begin{cases}
N_0+\sum_{v\in J_\tau\setminus I_0}c_v,&J_\tau\subseteq Allowed,\\
+\infty,&\text{其他情况}.
\end{cases}
\]

得到：

\[
\boxed{\exists M\succeq M_0:\ \max q(L(M))\le\tau,\ N(M)\le B
\iff N_{\min}^{M_0,q}(\tau)\le B}.
\]

Lean 的 `hard_budget_iff` 验证抽象闭合集与权重版本。其 `baseCount + WeightSum(I)` 有两种一致解释：根叶数加全部事件成本；或者 `N₀` 加上在 `I₀` 内置零后的增量权重。**不能把 `baseCount=N₀` 与未置零的全部事件成本混用。** 实际叶数公式依赖第 2 节的网格对应及无重复完整枚举。

若 `τ₁<τ₂`，则 `Rτ₂⊆Rτ₁`，故 `Jτ₂⊆Jτ₁`，最小计数随阈值降低而不减。最细层误差超过阈值会产生禁止事件，判为不可行；不得为便于证明把最细层对 bilinear source 的误差强行设为零。

## 6. 定理没有证明的内容

1. `M⪰M₀` 是只细化可达域。若当前网格已经占满预算，定理不能把远处三角形合并后重新分配预算。从根计算全局目标与从当前网格增量更新是不同问题。
2. 优化目标是 `max q`。当前生产 score、真实连续几何误差和保守几何上界不是同一个量。上界可行只能推出真实误差可行，不能反推真实误差不可行。
3. 任意一般闭包系统未必保持并集；联合前件规则 `a∧b⇒c` 已有机器检查反例。几何对应若不满足固定单前件关系，不能继续套用本轮结论。
4. 无同步邻接更新、物理节点标识一致、线程安全、队列维护成本、实际 wall-clock speedup 均不在定理内。

本轮不以这些未证明项为新一轮工程任务授权；后续若进入实现，应另行评审相应边界。
