# 连续视点下的增量 activation spectrum 理论 Gate

> 日期：2026-09-12；前置工作区提交：`f1f1b1d`。
> 结论：**No-Go，关闭本轮 dynamic activation-spectrum 候选支线，返回 CPU ROAM execution/characterization 主线。**
> 验证方式：纸面算法、证明与定向原文核对；没有新增 C++ 或 Lean。

这轮确实得到一个有局部复杂度的条件算法，但它的核心是既有 change propagation 与加权次序统计。对实际视点变化，发现/评价 priority 和维护证书的成本仍未得到新的局部界。显式刷新完整精确 spectrum 在最坏情况下需要线性工作；惰性表示可以避开这个特定下界，但本轮推得的证书机制又与已有方法重合。因此没有形成满足用户 Pass 条件的新算法。

**此 No-Go 不等于证明所有增量地形算法不可能，也不等于找到一篇完全覆盖“本项目任意 score 的精确动态硬预算解”的论文。** 已成立的下界、已有机制覆盖和未解决缺口分别记录如下，不互相替代。

## 1. 跨帧究竟持有什么

沿用[固定闭包模型](model_and_proofs.md)。先将配对 triangle events 收缩为 diamond DAG `G=(V,E)`；边 `u→v` 表示 `u` 需要前置 `v`。静态保存正的叶数增量 `c(v)`、可执行掩码、前置/反向邻接以及层级。规则二维图的两个方向度数都有常数界。

固定一个合法 anchor 闭合集 `Ibase` 和其叶数 `Nbase`，预算 `B≥Nbase`，剩余容量 `b=B−Nbase`。允许目标在 anchor 的细化族内来回变化。**不能每帧令 anchor 等于上一帧 `Jt`**：那会只许增加细分，无法回收预算。最简单的 anchor 是两个根三角形、尚未执行任何 split。

相机为 `zₜ`；原三角形 priority 为 `qₜ(r)=q(r,zₜ)`，继续要求前一轮的单调/认证契约。一个 diamond 内 source 值 `gₜ(v)` 取成员 `qₜ` 的最大值。对任意节点：

\[
a_t(v)=\max\{g_t(v),\ \max_{u:u\to v}a_t(u)\}
      =\max_{r\leadsto v}g_t(r).
\]

| 状态 | 帧末不变式与下一帧用途 |
| --- | --- |
| `gₜ(v), aₜ(v)` | 当前 source 和精确激活值；先分析逐节点显式保存的版本 |
| `Dₜ` | 按 `aₜ` 排序的加权平衡搜索树，只含 `Allowed\Ibase`；同值成组，保存组内 ID 及子树权重和 |
| `Fₜ` | 禁止事件激活值的有序多重集，提供 `θₜ=max({aₜ(v):v∉Allowed}∪{0})` |
| `τₜ` | 满足硬预算和禁止事件约束的最小非负阈值 |
| `Jₜ` | `Ibase∪{v:aₜ(v)>τₜ}`，目标事件集合；不等于已发布的生产邻接状态 |
| dirty 队列及 epoch 标记 | 按依赖层级处理变化；去重不通过每帧清零长度 `n` 的数组实现 |
| 可选几何/时间证书 | 若使用，必须另计构造、检查、更新和失效事件成本 |

目标是得到同一 anchor、预算及 reference 下的 `(aₜ₊₁,τₜ₊₁,Jₜ₊₁)`。记 `ΔJ=Jₜ₊₁△Jₜ`。它描述目标事件变化，不包括实际 mesh 提交成本。

显式版本的静态图、状态、索引需要 `O(n)` 内存，首次构造 spectrum 为 `O(n+m)`，建有序索引为 `O(n log n)`；几何 priority 预处理另外计费。这些成本不会因进入“增量”阶段消失。

## 2. 增大与减小：不需要保存所有后代的次大来源

### 2.1 source 增大

若 `g(v)` 增大，仅可能提高 `v` 及其 prerequisite cone 中的 `a`。新值没有超过现有最大值时，可以停止向该路径的前置传播。多个请求的 cone 相交时对节点去重，不能按路径数重复收费。

### 2.2 source 减小

对当前节点，只保存一个全局 `argmax` 确实不够：胜者下降后，可能轮到任意未记录来源。固定长度 top-k 同样没有一般保证，连续失效可以耗尽保存的候选；仅存并列最大值数量也不知道下一档的值。

但这里无需扁平化所有可达来源。**完整保留直接输入的当前值即可**：

\[
a'(v)=\max\bigl(g'(v),a'(u_1),\ldots,a'(u_d)\bigr),\quad d\le d_{max}=O(1).
\]

每个直接输入自己递归负责其后代最大值。因此原胜者失效时，重新比较常数个直接输入就能恢复正确最大值；并列值自然保留，不需要特别的“删除最大来源”规则。共享来源可能经多个输入到达，但 `max` 的幂等性使它不会被重复计费或误增。

全局 multiset/top-k 不是本图的必要数据结构。若推广到无界入度图，就必须计入输入扫描或每节点 tournament/multiset 更新成本，不能继续写常数重算。本轮不作这种推广。

### 2.3 混合批量更新算法

前提：已经取得所有改变的 source 集 `S` 及其新值，`s=|S|`。这是假设在本节单独分析的输入接口，**不是对相机移动的假设**。

```text
先写入全部 S 的新 source 值，保存旧阈值。
将 S 放入按深层优先排序的 dirty 队列，每节点同一 epoch 只入队一次。
反复取出 v：
    从新 source 值及所有直接输入的当前 a，重算 a_new(v)。
    若值未变，停止从 v 向前置传播。
    若值改变，记录 (v, a_old, a_new)，更新 a(v)，将 v 的直接前置置 dirty。
全部传播完成后，再更新 spectrum 索引、求新阈值和输出 ΔJ。
```

**正确性。** 所有 source 一开始已写入最终值，传播只走向更浅层。深层优先的队列确保处理 `v` 时，所有可能改变的直接输入均已完成。未被处理的输入值与旧帧相同。按层归纳，重算公式与从头计算一致；因此每节点最多重算一次，不会被“先减后增”的中间值多次触发。

令 `K={v:aₜ₊₁(v)≠aₜ(v)}`，`k=|K|`。实际检查的节点集满足：

\[
U\subseteq S\cup\bigcup_{v\in K}\operatorname{Prereq}(v),\qquad
|U|\le s+d_{out}k.
\]

故有界度下传播成本为 `O((s+k) log n)`，堆因子来自 dirty 调度；额外临时空间为 `O(s+k)`。这里 `k` 不包含检查后未变化的节点，它们已由 `s+dout k` 覆盖。对无界度图，准确计费应包含扫描的输入边与通知边，而非只数节点。

对标准规则二维层次，还可给出 cone 的纸面计数界：同层 diamond 中心有与该层尺度成比例的最小间距；一步前置移动距离有同阶上界。由细到粗的尺度构成几何级数，同一 source 在任意一层的全部前置中心落在半径为该层尺度常数倍的圆内，因而每层只有 `O(1)` 个，总计 `O(H)`。于是 `k=O(sH)`，可得 `O(sH log n)` 的条件传播界。**这一几何计数不适用于任意有界度 DAG**，也没有验证当前 C++ 的运行访问量。

## 3. 硬预算阈值与目标差分也能条件增量维护

### 3.1 加权次序统计

`D` 中每个事件只出现一次，值相等的事件整组保留。计数为：

\[
W_t(\tau)=\sum_{v\in Allowed\setminus Ibase}c(v)\mathbf1[a_t(v)>\tau].
\]

用子树权重和查找从大到小的第一组“加入后超过 `b`”的 key，取它为 `τB`；若所有正值组都能容纳则取 `0`。严格比较 `>τB` 使该组全部不入目标，正确处理并列值和预算粒度。最终：

\[
\tau_t=\max(\tau_{B,t},\theta_t).
\]

每个 `a` 改变的节点只需从相应索引删除旧值并插入新值，合计 `O(k log n)`；新的 `τB` 和 `θ` 查询为 `O(log n)`。改变预算也可重新查询，但本 Gate 固定预算，不能用预算漂移制造局部性。

### 3.2 避免阈值变化后扫描所有成员

先对 `K` 内事件用旧值/旧阈值和新值/新阈值比较成员身份。对于 `K` 外事件，值未变，只有 key 落在：

\[
(\min(\tau_t,\tau_{t+1}),\ \max(\tau_t,\tau_{t+1})]
\]

才改变身份。对新索引做范围枚举并跳过 `K`；范围内至多有 `k` 个需跳过的变化节点，其余每个都是实际输出。因此差分成本为 `O(log n+k+|ΔJ|)`，无需重新扫描全谱。

综合 source 发现、评价及证书维护成本 `Tsource`，这一**条件算法**满足：

\[
\boxed{T_{frame}=T_{source}+O((s+k+1)\log n+|\Delta J|)}.
\]

该式已包含 source 写入、dirty 通知、减小后的重算、两类有序索引、硬阈值和集合差分。物理 mesh 更新不在此输出接口内，不能用该式报告完整 update speedup。多帧只可对右侧逐帧求和；本轮没有额外 amortized 消除项。

纸面算例：三个单位成本事件满足 `u→p, v→p`，`g(p)=0`、容量为 2。初始 `g(u)=8,g(v)=5`，则 `(a(p),a(u),a(v))=(8,8,5)`，`τ=5,J={p,u}`。只把 `g(u)` 降到 3 后，得到 `(5,3,5)`，`τ=3,J={p,v}`。`p,u` 的值改变，而 `v` 值未变，必须通过阈值区间 `(3,5]` 找到其新增身份。若同时将 `g(v)` 提至 9，最终为 `(9,3,9)`；先完成同层 `u,v` 再处理 `p`，只需重算 `p` 一次。该抽象算例核对减小、混合更新、并列组和未改值节点的成员变化，不是自然地形实验。

## 4. 相机连续变化并不提供稀疏 source 接口

### 4.1 显式全谱的线性下界

透视深度、距离和投影边长通常随相机移动改变。即使每个值都平滑且排序不变，也可以有 `s=k=Θ(n)`、`|ΔJ|=0`。例如在同一有限模型里令：

\[
q_t(r)=c_tq_0(r),\quad c_t>0.
\]

则 `aₜ=cₜa₀`、`τₜ=cₜτ₀`、`Jₜ=J₀`。若契约要求逐节点物化所有新 `q,a`，非零项都必须改写，成本为 `Ω(n)`。任意小的 `ct` 变化也如此；小相机变化量本身不能替代变化节点数。

**这个例子同时反驳过强的“不可能性”结论**：保存公共因子 `ct` 即可惰性表示全部新值，不需要逐项改写。显式数组下界不能推广成所有隐式算法下界。

### 4.2 source 发现不能藏在复杂度符号里

若新 priority 只能逐点查询，旧值与连续性不足以知道哪些点变了。取一组旧值相同、处于预算分界的候选；新帧可能只有任意一个候选略微增大，且变化函数可以光滑。没有能区分这些候选的额外证书时，未查询的那个位置仍可能改变硬预算目标。最坏需要 `Ω(n)` 次查询，即使最终 `s`、`k` 和输出差分很小。

此论证只针对**逐点 oracle、没有额外选择性证书**的信息模型。它不是对任意预处理过的地形或特殊解析投影函数的普遍下界。预处理可能提供所缺信息，但其空间、构造、查询和失效成本必须写出来。

同样，`q` 若需要先在树上做单调饱和，饱和维护属于 `Tsource` 或同一显式数据流的一部分；不能把原始几何值到 `q` 的全层次传播移出计时。

## 5. 惰性证书能做什么，以及尚未解决什么

### 5.1 有效的跳过条件

设在一段相机区域内持有可靠界 `ℓ(v)≤a(v)≤u(v)`，且有阈值包络 `τL≤τ*≤τU`。则：

\[
\ell(v)>\tau_U\Rightarrow v\text{ 必选},\qquad
u(v)\le\tau_L\Rightarrow v\text{ 不选}.
\]

节点或整组满足这样的不等式时，可跳过精确重算。阈值包络不能直接取旧 `τt`：priority 变化可能移动预算分界。可以用：

\[
\sum c(v)\mathbf1[\ell(v)>\tau]
\le W(\tau)\le
\sum c(v)\mathbf1[u(v)>\tau]
\]

分别求预算分位点，再加上禁止事件的最大值界，形成合法包络。组计数须使用互不重叠的事件划分，不能把重叠 dependency cones 的权重直接相加。即使已认证 `J` 不变，精确数值 `τ` 仍需分界 witness 或进一步评价，不能把区间当作精确阈值。

静态几何包络、嵌套空间界、速度/Lipschitz 界和旧 winner 可以产生这些证书。若只得到一个比精确 `a` 更大的新 priority，则是更换优化目标；不能拿该保守替代结果冒充原 spectrum 的精确维护。

### 5.2 一个确实可推导的阈值移动界

若有证书保证 `||gₜ₊₁−gₜ||∞≤δ`，则最大值传播满足 `||aₜ₊₁−aₜ||∞≤δ`。在固定权重、预算和禁止事件下，还可推出：

\[
|\tau_{t+1}-\tau_t|\le\delta.
\]

证明：新帧在 `τt+δ` 以上的每个事件，旧帧都在 `τt` 以上，因此其加权数量不会超过旧可行目标；禁止事件也不高于 `τt+δ`。这证明新最小阈值至多为 `τt+δ`；交换两帧得到反向不等式。并列值和预算不能花满不破坏这一证明。

于是 `aₜ(v)>τₜ+2δ` 的事件继续必选，`aₜ(v)≤τₜ−2δ` 的事件继续不选。旧索引可在 `O(log n+z)` 时间枚举中间带内的 `z` 个候选。若 `g` 具有可认证的统一 Lipschitz 常数，可取 `δ=L||zₜ₊₁−zₜ||`；当前投影裁剪规则没有自动提供有限且有用的 `L`。

这解决了“阈值自己会动，旧阈值如何使用”的一个条件子问题，但没有完成整体局部算法：带内的精确饱和值查询、source witness 更新和新索引维护仍需付费，`z` 也可为 `Θ(n)` 而 `|ΔJ|=0`。若保留旧索引作惰性查询，`δ` 必须相对该索引对应的相机版本累计计算；不能每帧把相机参照点重置，却免费把所有旧 key 当成最新值。

### 5.3 必须计入的证书成本

记 `z` 为访问/刷新证书数，`r` 为精确几何评价数，`e` 为内部证书失效事件数，`ℓ` 为轨迹参数变化影响的证书数。任何惰性机制都必须计入这些量及求根/区间计算成本。它们不自动受 `|ΔJ|` 控制，也不自动受显式版本的 `k` 控制。

相机连续但未给出速度或 margin 下界时，可以让大量候选一直贴近分界，令证书无法跳过它们。已知低阶轨迹可使用 kinetic certificates，但相机轨迹的一次改变可能影响大量比较式的失效时间；必须有快速验证旧证书仍有效的机制，不能假设全局参数变化只更新一条 certificate。

若维护完整 kinetic sorted spectrum，大量低于预算分界的值可以彼此交换次序而 `J` 一直不变。仅这一内部区域就能让完整排序处理大量事件。只维护预算切割所需的证据可能更便宜，但本轮没有得到其事件数相对 `|ΔJ|` 的新上界。

三类尝试的结果如下：

| 尝试 | 能建立的结论 | 未达到 Pass 的原因 |
| --- | --- | --- |
| 公共视点因子或可分离形式 | 特殊情况下可整体惰性更新，排序/目标不变 | 过窄且是直接代数化简；不覆盖一般平移、方向与裁剪 |
| 静态空间上界加时间有效期 | 有 margin 时可以跳过安全节点/组 | 机制已有直接先例；没有得到证书维护相对真实目标变化的新界 |
| kinetic max 电路加预算次序统计 | 可按比较失效事件维护，避免逐帧改写全部标量 | 属于已有 kinetic/change-propagation 框架；内部事件、全局轨迹失效与硬分界耦合未有新界 |

## 6. 定向 prior-art：activation 是否只是 saturation

**是：在固定依赖图和同一原始 `q` 下，本轮 `a(v)` 就是最小的 dependency-saturated majorant 的可达最大值表示。** 它满足 `a≥g`，并在每条 `u→v` 上满足 `a(v)≥a(u)`；任何满足这两条件的函数沿路径都支配所有可达 source，因此也支配 `a`。换成 activation spectrum 的术语没有改变这个对象。

需要区分上述“精确饱和”与一个便于在线查询、但可能更松的 nested conservative bound；二者不是数值恒等。以下只把原文明确支持的部分列为已覆盖。

| Basch/Guibas/Hershberger，SODA 1997，[原文](https://www.ime.usp.br/~cris/aulas/19_1_6957/BaschGH-DSforMobileData.pdf)，§1–2；[作者版本入口](https://graphics.stanford.edu/~guibas/kinetic_papers.html) | 运动计划、证书、内部/外部事件和 kinetic tournament；讨论排序内部事件可能过多 | 维护 winner 和证书并非新思想；需要区分数值变动、winner 变化和目标变化 |
| Acar et al. 2006，[论文](https://www.cs.cmu.edu/~blelloch/papers/ABTV06.pdf)，§2 | 将比较转成 certificate-generating comparisons，组合 kinetic 算法与 change propagation | “先维护饱和比较电路，再维护排序/选择”不能单凭组合方式主张新颖性 |

本轮定向检索覆盖 dependency graph、nested/saturated error、VDPM、增量 max/change propagation、连续运动 certificate，以及 hard-budget/threshold 的组合。没有找到足以确认“同一几何 q、同一硬预算契约、同一局部界”的完整先例；**也没有推导出超出现有机制的新局部界**。因此不以检索空白支持 Pass。

来源记录：逐段读取了上述原文。Pajarola 的 ETH 技术报告下载返回 429 后，使用作者站的会议版本，不继续请求受限地址；Lindstrom 作者机构 PDF 通过直接下载读取。PDF 与提取文本只保存在被忽略的 `build/roam-threshold-incremental-gate/sources/`。论文版本按表区分，搜索结果的新抓取日期不当成出版年份。

## 7. Gate 出口与范围

| Pass 所需条件 | 本轮结果 |
| --- | --- |
| 明确的新增量维护机制 | 有明确条件算法；核心机制已被 change propagation、saturation、kinetic certificates 覆盖 |
| 包含 source/certificate/threshold 的非平凡局部界 | 仅在已提供稀疏 source 变化时成立；连续视点下 `Tsource` 和证书事件界未解决 |
| 与已有工作有实质区别 | 未建立；不能把精确阈值闭包或加权分位点的组合直接当作充分区别 |

据此作 **No-Go**。显式完整 spectrum 的线性工作下界是有作用域的负证据；核心维护机制的已有覆盖进一步削弱了本候选。没有将“某个最坏输入是线性的”误写成“局部/输出敏感算法不成立”：当 `s,k` 小且可发现时，第 3 节的局部算法仍成立。

本支线停止追加原型、C++、多核映射、一般性 Lean 定理和扩展实验。保留本报告与原证明工作区作为研究记录，回到当前 [CPU ROAM execution/characterization 研究定义](../../plans/formal_experiment/cpu_roam_research_definition.md)。若未来出现新的、具体的几何证书机制及整体复杂度证据，需重新评审；本轮不以“以后可能解决”延长 Gate。
