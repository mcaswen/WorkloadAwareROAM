# 激活阈值算法、几何上界与完整成本

> 依赖：[模型与证明](model_and_proofs.md)。本文件提出数学算法及其条件，不包含生产实现。
> 激活集合等式已由 Lean 检查；几何上界和 work/span 分析是纸面推导。

## 1. Theorem 3：用一个标量编码事件何时必选

对于完整有限事件域，定义：

\[
a(v)=\max\bigl(\{q(r):r\leadsto v\}\cup\{0\}\bigr).
\]

`r↝v` 的方向是请求到前置。它不是仅在 `v` 的二叉子树内求最大值；路径也可能经过配对关系及另一棵树的父链。

对于非负 `τ`，有限最大值的定义给出：

\[
a(v)>\tau
\iff\exists r:\ q(r)>\tau\land r\leadsto v
\iff v\in\operatorname{cl}(R_\tau).
\]

结合闭包并集性质与 `I₀` 已闭合，得到：

\[
\boxed{J_\tau=I_0\cup\{v:a(v)>\tau\}}.
\]

`Spectrum.lean` 已检查这个等式；完整枚举假设显式出现在 `support_equals_closure` 和 `target_activation` 中。Lean 的 `SupportMaximum` 使用不可计算的可达谓词定义数学最大值，**不是可直接部署的可达对枚举算法**。

## 2. 由阈值谱直接判断硬预算

使用唯一 diamond 事件编码，令 `a(d)` 为其成员相同的激活值，`c(d)` 为其叶数增量。则：

\[
N(\tau)=N_0+\sum_{d\notin I_0}c(d)\,\mathbf1[a(d)>\tau].
\]

对禁止细分的事件额外要求 `a(d)≤τ`。任何一个禁止事件被激活，就不能仅因计数未超预算而接受目标。

将不同激活值及 `0` 排序。在相邻取值之间，必选集和计数不变；因此只需在这些断点上寻找最小可行 `τ`。由最小闭包定理，该结果最小化当前可达网格族内的最大 `q`。若 `I₀` 合法且 `N₀≤B`，最大激活值对应保留初始网格，保证至少存在一个非负可行阈值。

相等的优先级不被 `>τ` 选中。降低阈值跨过一个断点时，整组相关事件变成 mandatory，可能使叶数一次跳过预算。因此某些预算不能花满。部分处理同分组可以增加三角形数，却不一定降低当前最大优先级；这属于另一个预算利用率或次级质量目标，不由本定理自动决定。

## 3. 一个可以完整描述的基准算法

以下是用来证明“问题可解”的全层次算法，不把它命名为新颖算法或高效增量方案。

```text
输入：固定二分层次、合法初始集 I₀、可细分掩码、冻结 q、预算 B

1. 计算全部潜在三角形的 q，并确认父子单调性或使用明确的单调上界。
2. 用固定底边配对将 triangle events 分成 diamonds；保留禁止事件。
3. 每个 diamond 的初始值取成员 q 的最大值。
4. 按深度从深到浅，将值沿“请求 → 前置”边传播最大值，得到 a。
5. 按 a 对非初始事件分组排序，计算加权累计计数。
6. 结合禁止事件约束，选出不超过 B 的最小阈值 τ。
7. 标记 Jτ；输出已生成但不属于 Jτ 的三角形叶集合。

输出：逻辑目标网格、叶数、阈值；不输出已经修复的生产邻接数组。
```

第 4 步可以由每个事件独占自身输出，从直接依赖它的更深层事件读取最大值。全部输入在该层开始前冻结，层间同步，避免多个线程竞争写同一个祖先。该规则二分 diamond 图的度数有常数界；如果换成一般 DAG，高度之外还要计入大入度归约的 span。

第 7 步可以通过固定层次索引判断 `Born(t) ∧ t∉Jτ`，再用 prefix sum 分配独占输出位置。它绕开了逐个请求修改邻接的顺序，但没有免费解决持久状态维护、merge 路径或节点池回收。

## 4. 并行 work/span：先交代算法的全部工作

设完整潜在层次大小为 `n`，依赖边数 `m=O(n)`，深度为 `H`。以单位标量操作、共享内存、理想 greedy scheduler 为模型；不计浮点精确算术的位复杂度。`Wq,Dq` 包含优先级计算和必要的单调上界构造，不能省略。

| 部分 | Work | Span | 条件 |
| --- | --- | --- | --- |
| 层次索引、固定配对与依赖生成 | `O(n)` | `O(H)` 上界 | 规则层次；使用隐式配对，不执行一般 SCC 搜索 |
| 激活值传播 | `O(n+m)` | `O(H)` | 有界度，按层独占写入 |
| 事件并行归并排序 | `O(n log n)` | `O(log² n)` | 使用具有对应界的并行 merge；普通串行排序没有此 span |
| 累计计数、阈值选择、叶标记与压缩 | `O(n)` | `O(log n)` | 并行 scan/reduce |
| 叶顶点等输出计算 | `Wemit` | `Demit` | 单独计入采样及输出，取决于所需结果 |

所以完整的**目标选择与叶输出**有纸面上界：

\[
W=W_q+O(n\log n)+W_{emit},\qquad
D=D_q+O(H+\log^2n)+D_{emit}.
\]

任何执行都满足 `Tₚ≥max(W/p,D)`。对于该计算 DAG 的理想 greedy 调度，把执行分成所有处理器忙的步和处理器未满的步：前者至多按 `W/p` 计，后者每步减少至少一个剩余关键路径层级，因此有：

\[
\boxed{T_p=O(W/p+D)}.
\]

这是计算模型上界；不是当前线程池已经达到该界的证明。内存带宽、分配、调度、层间同步及 NUMA 开销会影响实际时间。对持久化 ROAM 更新，还必须增加 `Wstate,Dstate`，包含物理邻接重建、队列更新及状态发布。本轮未给出这些步骤的完整算法，因而没有宣布完整生产 update 的 span 上界或 speedup。

最大的实际问题是 `n`：两个深度 `H` 的完整二叉层次有 `Θ(2ᴴ)` 个潜在事件。当前活动叶数和每帧变化量可能远小于它。即使上述每一阶段可以并行，也可能明显输给串行局部更新。

## 5. bilinear primary reference 的纸面误差上界

本节不改变项目已冻结的 primary reference，也不恢复 GATE-02 evaluator 实施。目标是回答：在数学上是否能为这个 reference 构造有限、独立的上界。

### 5.1 世界空间高度误差可以有限求解

对一个候选三角形 `t`，其高度 `hₜ(x,z)` 是仿射函数。每个原始 raster cell 内，bilinear source 为：

\[
h_*(x,z)=a+bx+cz+dxz.
\]

将 `t` 的参数域与该 cell 求交，得到凸多边形 `P`。残差 `f=hₜ−h*` 仍为双线性函数减仿射函数。

若交叉项非零，`f` 的 Hessian 特征值一正一负，内部驻点是鞍点，不能成为严格局部最大或最小；若交叉项为零，`f` 为仿射函数。因此其最大绝对值可以在边界取得。每条直边参数化以后，`f(s)=As²+Bs+C`。检查两个端点及落在边段内的驻点 `s=−B/(2A)`，即可取得该边精确极值。退化线段/点直接使用同样的低维检查。

遍历 `t` 相交的所有有限 cell，即得到真实的：

\[
H(t)=\max_{(x,z)\in t}|h_t(x,z)-h_*(x,z)|.
\]

这是一项实数算术下的有限算法与纸面证明。可靠浮点求交、区间包络和位复杂度未实现；不能把直接用 double 计算的结果称为严格认证上界。

### 5.2 正投影深度条件下的屏幕上界

将 viewport 变换并入齐次投影分子，令两个像素坐标分别为 `sᵢ(p)=nᵢ(p)/w(p)`，其中 `nᵢ,w` 是世界位置的仿射函数。`y` 为高度轴。

固定 `(x,z)`，沿参考点到网格点之间的竖直线段改变高度。有：

\[
\frac{\partial s_i}{\partial y}
=\frac{(\partial_y n_i)w-(\partial_y w)n_i}{w^2}.
\]

分子中的高度项相消，剩余表达式只对 `(x,z)` 仿射。可在 `t` 的顶点取最大绝对值，记为 `Kᵢ(t)`。若能够证明参考面和三角平面在整个 `t` 上均满足 `w≥wmin>0`，竖直连接线段也满足该下界，积分或中值界给出：

\[
e(t)=\frac{\sqrt{K_1(t)^2+K_2(t)^2}}{w_{min}^2}H(t)
\quad\Longrightarrow\quad
\max_{(x,z)\in t}\|s(p_t)-s(p_*)\|_2\le e(t).
\]

`w` 在 reference cell 内也是双线性函数，在三角平面上是仿射函数；所需最小值可以用上一节相同的有限极值程序确定。这里评价的是同一地形位置的几何投影偏移，不是图像感知差异或遮挡后可见像素误差。

若参考面或三角平面穿越投影奇点，这个有限公式不适用。必须保留不可认证状态或另行处理裁剪，不能用一个普通有限 priority 假装已经约束几何误差。本轮定理只覆盖所声明的正深度评价域。

### 5.3 单调化与保证方向

在有限树上定义：

\[
\widehat e(t)=\max\{e(t),\widehat e(child_0),\widehat e(child_1)\}.
\]

终端取自身的 `e(t)`，不置零。由归纳，`ê` 同时支配本节点真实屏幕误差并满足父子单调性。将 `q=ê` 代入阈值模型，可得到**认证上界不超过阈值的最小事件闭包**。

这不意味着它使用最少三角形满足真实连续误差，因为认证上界可能偏松。树上饱和也不能删除配对依赖；阈值必选集仍必须做完整 closure 或使用第 1 节的激活值传播。误差饱和与嵌套误差条件已有文献基础。[Lindstrom 与 Pascucci 原始论文](https://computing.llnl.gov/sites/default/files/Terrain%20Simplification%20Simplified.pdf)

本节没有 Lean 几何证明，也没有接入 `RoamScreenError.h`。它支持“存在可推导的独立上界”这一受限结论，尚不支持当前实现的质量保证或该界具有实用紧致度。

## 6. 保留的反例与失败边界

| 过强说法 | 反例或修正 | 验证层级 |
| --- | --- | --- |
| 普通闭包自动保持并集 | 规则 `a∧b⇒c` 满足扩张、单调、幂等；分别闭包后并集却缺少 `c` | Lean：4 项 Horn 命题 |
| 最大误差下降可以分成固定收益相加 | 两区误差都为 10，各修一处收益为 0，两处同时修复收益为 10 | Lean |
| 不需要优先级单调性 | 根优先级 0，隐藏子节点 10；阈值 5 时无需生成子节点 | Lean |
| 上界不可行等于真实误差不可行 | 粗网格真实误差/上界为 `1/10`，细网格为 `0/0`；预算只够粗网格，真实阈值 2 可行 | Lean |
| 用成本罚项总能恢复每个硬预算最优点 | 成本/收益为 `(0,0),(2,1),(3,3)`；预算 2 的最优点不能由任何非负有理线性价格选中 | Lean；实数情形同样可由两条不等式矛盾直接证明 |
| 与 raster cell 对齐的最细网格必然对 bilinear reference 零误差 | 单元 `h*=xz`，对角线 `(0,0)→(1,1)` 的两三角面为 `min(x,z)`，中心高度差为 `1/4`，且这是全局最大值 | 纸面解析反例 |

最后一行可直接计算：当 `z≤x` 时，残差为 `z(1−x)≤x(1−x)≤1/4`；另一半对称。它不否定已有 test129/Peking 校准，只说明那些小残差不能升级为一般零残差定理。

## 7. 本轮之后值得保留的有限问题

1. **局部维护是否可能。** 相机变化时哪些激活值必须变化？一次局部 `q` 增大可以向前置传播；降低某个最大来源时可能需要重新找到其他来源。必须分析维护来源信息的成本，不能只讨论单向增大。
2. **隐藏区域是否可安全跳过。** 没有可靠的子树最大值证书，未访问子树可以藏有更高 priority，精确查询最坏情况下需要读取这些值。使用预处理证书能改变信息条件，但证书生成和更新计入总成本。
3. **全局目标如何增量实现。** 从根求出的两个闭合集可以各自合法，但从旧目标切换到新目标的 merge/split、预算中间态和物理邻接尚未得到并行算法。

这些是开放问题，不是已成立的创新声明。当前材料足以排除若干错误推导，并建立后续算法必须满足的契约；还不足以授权或建议立即重做一轮大型实验平台。
