> 建立日期：2026-09-12；代码事实基线：`1601717`。
> 本目录是独立理论探索，未接入运行时，也不替换当前 CPU ROAM 实验主线。

本轮得到了一条**有明确假设、部分由 Lean 内核检查的证明链**：固定依赖闭包 → 单调优先级下的必选细化 → 最小阈值闭包 → 硬预算可行性 → 激活阈值计数。它说明该受限模型不必先求解一般背包问题，但尚未证明一个新的、高效的增量 CPU ROAM 算法。

## 2. 本轮最重要的结果

设 `I₀` 为已经执行的闭合细化事件集，`q(t)` 为冻结且沿父子关系单调的优先级。给定阈值 `τ`，定义：

\[
R_\tau=\{t:q(t)>\tau\},\qquad J_\tau=\operatorname{cl}(I_0\cup R_\tau).
\]

在本文的合法事件模型中，`Jτ` 是满足叶优先级上限的最小集合。若它包含禁止细分的终端事件，则不可行；否则预算判定为：

\[
N_0+\sum_{v\in J_\tau\setminus I_0}c_v\le B.
\]

进一步为每个事件定义激活值：

\[
a(v)=\max\bigl(\{q(r):v\in\operatorname{cl}(\{r\})\}\cup\{0\}\bigr).
\]

于是：

\[
J_\tau=I_0\cup\{v:a(v)>\tau\}.
\]

多个请求共享的前置事件只计一次。不同阈值的查询可以使用同一组激活值；不需要分别模拟每一种 greedy 执行顺序。**激活值计算本身的工作量没有被免除。**

## 3. 结果的验证层级

| 判断 | 当前状态 |
| --- | --- |
| 固定关系的闭包四性质、相对闭包与成本次模性 | Lean 已检查 |
| 单调层次的叶条件、必选集合、最小闭包与硬预算等价 | Lean 已检查 |
| 有限完整事件域上的激活阈值表示 | Lean 已检查 |
| 标准规则二分网格与父节点/底边配对依赖的对应 | 纸面论证；几何对象尚未编码进 Lean |
| 当前 C++ 的指针、数组、预算中断与上述模型完全对应 | 未证明 |
| 对 bilinear primary reference 的连续屏幕误差上界 | 正投影深度条件下给出纸面构造；未在 Lean 验证，也未接入当前 score |
| 增量性、真实多核收益、算法新颖性 | 未证明；不得由抽象定理推断 |

当前最值得继续推导的缺口是：**能否用受影响区域规模而非完整最细层次数量，精确维护阈值可行性和目标网格？** 仅将全层次依赖传播改成并行执行，不足以回答这个问题。
