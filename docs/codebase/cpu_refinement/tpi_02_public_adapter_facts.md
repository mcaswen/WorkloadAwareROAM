# TPI-02 公共适配与输入事实

日期：2026-09-15；依据：[小规划](../../plans/cpu_refinement/tpi_02_public_adapter_plan.md)。这是适配正确性记录，不是新算法优于 ROAM 的结果。

## 实现与依赖

`TransactionalTerrainLodAlgorithm` 的 PImpl 拥有执行器与 Pipeline，销毁时先释放 Pipeline。`SeedBuilder` 是唯一 DOD 依赖：当前视图调用一次公共串行入口，按实际 UV/高度构造初始任意三角网格。正常更新没有 DOD 调用、状态复制或研究 JSON。`RenderBridge` 只转换借用网格、脏范围与有限统计。CMake 单独定义适配库，最终入口提供 DOD/HeightMap/共享执行对象。

HeightMap 同时保留原 float 采样与 raw uint16；一次成功加载发布单调版本。同路径重载仍使适配器重建，逐帧只检查固定身份与参数。raw 新增 2WH 字节，Pipeline 另拥有 2WH 字节源副本；初建暂存通过移动转交，不隐去常驻副本。

源限方形 2～1025、正尺度、深度 1～20、预算 2～200000、线程 1～32、r/m 1～640。首版只验证 test129/Peking，不承诺任意相机或任意规模。180 秒为故障保护，样本访问有明确配额，不是实时帧预算。

相机、drawable、NO/ZO 只走 SetView；其余种子/事务配置变化清除旧借用后重建。NO/ZO 同时覆盖参考可见集合、被测点近面、区间/有理误差与拟合系数。旧默认 NO 的计算路径保持，公共 hash 为非默认深度追加标签。

正常每调用一批。输入/准备失败保留最后完整输出，同一失败输入抑制自动重试；执行器停止必须重置。Consume 后桥接失败保留全量恢复标志。暂停/失败借用不清 Pending；真实上传失败由后续 renderer 保留自己的恢复标志。float 新面转换时验证有限、方向和非退化，不重采源高度。

## 验证与成本

原始记录：`benchmark-output/cpu-refinement/tpi-02/run-01/`，忽略原始数据；保留命令、二进制 SHA256、日志、前后轨迹和 comparison.json。

- 定向 CTest：共享执行器、核心事务、公共适配、渲染包、公共视图、屏幕投影。新适配/包/执行器一组约 1.25 秒，没有运行全套测试。
- test129 一次当前视图种子 3619 面；Peking 547²/80/12/20k 当前视图种子 3233 面。后者只检验种子；不是旧 SVE sample14 的同状态替代。
- 同一 test129 中立种子，1/4 线程直接核心与适配连续四次的索引和活动属性一致。公共输出借用，无整网格复制。解析夹具覆盖非空范围、丢范围后全量恢复、纯视图无字节变化、NO/ZO 和实际 float 退化拒绝。
- 自然静止后续几乎无事务：暖调用 0.002～0.008ms 只说明空批适配成本很小，不支持实际交易加速。直接核心首次调用约 140ms，适配冷调用约 161～164ms；两者冷准备边界不同，且为同进程开发读数，不能作正式比值。

每路径前后各一个独立进程，亲和 0/2/4/6、Release、同源、八轮、相同输出边界；移动为后五轮，静止为前三轮。16 份 mesh.json 字节相同，核心八份 summary 除 seconds 外相同。DOD 静止增加约 0.81ms、移动下降约 3.25ms，结合 TPI-01 已有时序波动，不据此认定速度改善或稳定回归。本阶段没有改旧线程/评分/拓扑策略，也没有反复追微差。

`CpuReadyMilliseconds` 含调用内账本/批次释放；种子、初建和正常阶段分开。AdapterMilliseconds 是完整时间扣除种子/初建/核心包络后的残差，包括范围消费/转换和边界释放，不是精确函数 CPU 时间。实际线程参与数未测，不把配置线程数写入旧 CpuWorkerCount。
