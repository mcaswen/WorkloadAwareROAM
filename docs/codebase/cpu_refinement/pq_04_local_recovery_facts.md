## 2. 输入与控制流

**FACT：** 探针接受`--fit-audit`或`--recovery-audit`中的至多一个。两者都要求`immutable`和冻结q2精确double坐标；参数错误发生在创建输出目录和种子之前。

正常24帧循环：

```text
SetView(当帧矩阵)
→ 原TransactionalReservation::Plan
→ 若为frame8且打开recovery-audit：Run(只读State/Samples)
→ 原Pipeline::Apply(原Plan结果)
→ 原状态验证、追溯和帧输出
```

**FACT：** `ConfigurationFor`不随平台视图更新`Config.SampleIndex`，该字段保留默认值。frame8由探针循环绑定，实际视图是`Matrix`；诊断导出当前和frame15两套矩阵。实现前检查时移除了用`SampleIndex==30`断言当帧的错误假设，没有修改生产配置行为。

`Run`再核对预算50000、固定旧点政策和关闭`HeightGuard`；遍历`ActiveFaces`定位逻辑根`-111`，从其三条边收集直接邻面。域必须至多4面，q2必须严格位于原根内。根缺失、域超限或原7项不再全部`shape_infeasible`会记录输入未知并结束诊断。

旧目录的H支持可能超出D；它们只作为原失败观察。新候选的构造域始终为D。未来视图只用于误差报告，没有参与几何选择或阈值形成。

## 3. 几何构造与身份

**FACT：** 公共静态方法只操作有界私有值：

- `Flip(input,edge)`：规范化边身份，要求恰有两面使用、没有新点、不同对面点、新对角线未在当前小几何出现；精确方向检查两条对角线严格相交，替换两面并规范正方向。最小角在最终几何上检查。
- `SplitEdge`：只允许域内双侧边和一个尚不存在的新身份；插入中点，初高取当前私有两端平均，净+2面；外边界不细分。
- `SplitFace`：新点严格位于指定面内部，初高为当前私有面的重心插值；构造三面扇形，净+2面。
- `Model`：要求恰有一个自由高度，使用新连接和当前提案初高计算仿射基准，再从固定样本参考值形成`FitSampleConstraint`。

内部`Edges/Uses`按点身份恢复局部边使用；`Inside/Interpolate`用于见证归属和新点初值；`Read`只复制指定小支持。域内翻边之后，调用方还排除新边与域外既有边重名。

目录基础状态按根边的身份排序。面构造保留小向量顺序；本冻结q2在各基础状态均只落入一个面，因此没有多覆盖面的选择排序问题。几何去重按排序后的面连接及新UV，新点临时身份统一替换为哨兵；不同临时身份不产生重复搜索机会。

`Difference`将目标面与D旧面按三点身份集合比较，得到真正净改变的旧支持S及新面。未变面不进入认证支持。不同候选的S可能不同，已导出，不提供跨支持统一最优排序。

**FACT：** 原目录7项之外，构造10个新几何；2个翻边因不满足严格凸性而拒绝，1条外边界边不产生E候选。所有带新点的自然几何在形状阶段失败；只有净0的AB翻边进入自然质量认证。

## 4. 质量数据与生命周期

`emit`先生成完整几何记录及逐面`Shape`结果。只有新目录中形状合法、支持和可见样本非空的项才进入质量路径：

1. 旧S曲面由原状态面连接和固定旧点组成，调用原`Measure`。
2. 对误差区间平方根与微像素缩放向外扩。只有上下端落在同一整数格且可以减10000时，形成诊断阈值，否则`target_numeric_unknown`。
3. 净0固定高度候选直接进入`Variant`。
4. 带新点时，`Model`由新曲面建立系数，复用PQ-03 `Query`一次；先认证双线性源高，再认证最接近源高的区间投影值。两者实际double高度相同则复用，不重复认证。

**FACT：** `Variant`清空私有`HeightProof`，通过原`Measure/Accepts`评估实际存储高度。模型可行不会绕过认证；`model_empty`不等于数学几何不可行。生产Fit默认以旧样本高度为基准，不能直接用于已改变连接的提案；本实现没有这样做。

`Variant`同时输出q2批前/后高度、当前和固定未来投影，以及S闭面样本上的最大高度误差、逐点屏幕/高度代价。`Error`不裁掉视口外q2，但对不可投影情况返回未知；该辅助投影不参与当前可见质量认证。`Source`使用原始高度栅格的冻结双线性插值。

`witnessProgress`定义为“认证接受，且q2当前误差至少下降0.01px”。不存在`witnessProgress`不代表已经证明所有恢复操作都无效。

**FACT：** `standaloneBudgetFits`只判断冻结N加净面数不超过B，不查询原批次剩余预留。`Proposal.Kind='R'`仅标识私有恢复诊断，不进入生产候选目录。没有构造donor、发布面/边、修复样本所有权、更新缓存或驱动分叉轨迹。

## 5. 记录、限额和错误

`Run`使用独立`WorkLedger`，60秒截止、200万`SampleTouches`、至多64个几何；每个新点几何最多一次区间查询和两个不同实际高度。原生外层复用180秒/8GiB启动限额。

每个候选行先在内存完成再写入`recovery-candidates.jsonl`，中途超限不会输出半条JSON。`geometries`在开始评估时累加，因此部分失败运行中可能包含正在评估但未完成输出的项，必须结合`status`解释。正常本轮17项全有记录。

异常分类为`candidate_cap`、`budget_exhausted`或`input_or_numeric_unknown`；错误明文留在`detail`。诊断未知不伪装为几何失败，也不改变原批次。文件创建和写入失败启用流异常；外层探针以非零退出报告不可完成的运行。

脚本`collect`冻结相关C++来源和程序身份，拒绝混用不同版本；底层`native_run`复用已有命令记录，不覆盖采集。`freeze`要求指定PQ-03结束二进制，旧默认测量和字段修正版SHA分开保存。`report`可重复归约，无需重跑自然输入。

**FACT：** 原始输出在已有忽略规则下，不进入Git；规划、代码事实、审查和完整数值结果进入Git。诊断图从完整候选中按“首个q2改善项，否则首个形状合法项，否则原AB失败”选择，不进行补采样。

## 6. 独立几何验证与测试边界

`transactional_recovery_geometry.py`对导出的double UV用`Fraction(float)`恢复精确二进制有理数。`validate`核对：旧顶点集合/位置/高度、最多一个新增身份、同有向外边界、内部边反向配对、无多重面/非正面、面积守恒、非关联边不相交、无悬挂点。形状独立按正方向与`10 dot² <= 9 norms`计算，钝角直接满足最小角。

覆盖前提是旧局部域来自已验证的生产状态；本验证器不是任意多连通网格的通用证明器。C++有限构造与独立几何检查共同验证此次具体替换。

原生解析夹具包括非共面方形翻边：旧对角线中心高0.5，新对角线高0，单新点的系数为0仍要在`Difference`中保留新旧曲面差。这里`Difference`指约束行字段，不是同名内部净面差函数。自然例没有进入带新点模型，不能声称该分支已有自然正例。

原24帧关键字段、三份原追溯文件和五份网格全部与PQ-03一致。错误q2和互斥开关有定向负例。没有重新跑全项目测试、其他图形后端或完整质量矩阵。

## 7. 成本与复用代价

**INFERENCE：** 冻结根定位显式O(N)；不是声称生产恢复可以按原实现这样定位。局部面复制/集合操作受有限几何规模约束。证据归属含小面查找及样本排序/二分，保守O(sf+s log s)；一次区间求交O(s)；实际数值认证还有输入位长相关的精确回退。独立几何核查含边/点两两比较，O(f²)次有理操作。

**FACT：** 本轮总诊断20.7845ms；唯一认证项17.7718ms，包含旧/新测量和闭支持代价。扫描49999面、16068次账本样本访问、10712次筛选、0次精确回退、0条自然高度约束。`EvidenceBytes=214240`不是进程内存峰值。默认完整进程4.453036s相对旧5.356993s未见回归；单次降低不能作为优化收益。

`Run`和专用`emit/Variant`同时包含本案例编排与输出，没有抽成通用搜索框架。几何、模型公开方法用于解析测试；Python几何验证与采集/图形脚本分离。`Source/Error`是当前实验类的少量专用算术，与既有诊断有相近表达，生产核心无重复新实现；本阶段不为单案例扩建共享诊断平台。

主要符号路径：

- `RecoveryGeometry`：实验头文件；`Points/Faces/NewVertex`；调用者为本诊断和解析测试。
- `TransactionalRecoveryAudit`：同名实验实现；`Flip/SplitEdge/SplitFace/Model/Run`；依赖生产只读状态与原认证，不被生产调用。
- 内部`Difference`：D目标连接→净S与新面；调用`VisibleSupport`。
- 内部`Variant`：原认证、q2及闭支持代价→单高度记录；不发布。
- Python `validate/angles/edges`：原/目标小几何→精确结构与形状事实；不读取C++控制结果作为证明。
- Python `freeze/collect/report/figure`：身份冻结→限额采集→轨迹/几何比对→固定数据图。
