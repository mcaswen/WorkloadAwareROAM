## 残差定位及参考决策

屏幕最大点 `UV=(0.37109375,0.96484375)`，对应原像素格子 `(47,123)` 的中心。四角原灰度按 `(00,10,01,11)` 为 `[85,82,85,80]`：

- 固定参考对角线高度：`(82+85)/2 × 4/255 = 1.3098039216`；实际参考值 1.3098039627。
- 另一条对角线高度：`(85+80)/2 × 4/255 = 1.2941176471`；实际 DOD 值 1.2941176891。
- 两者实际高度差约 0.0156862736。用冻结相机姿态独立重算屏幕差为 0.6539917306 px，与评价器差约 6.56e-8 px。

像素值、数值核对和投影结果见产物 `calibration/cell-crosscheck.json`、`projection-crosscheck.json`。当前证据支持该点存在剖分表示差异；这是确定性残差，不是计时噪声，也不是排序带来的损失。

需要用户决定的参考取舍如下；当前没有实施任何参考变更：

| 选择 | 具体语义与影响 |
| --- | --- |
| 保留原始资产参考 | 继续衡量相对原资产曲面的总体失真，能解释资产保真度；排序效应与表示残差可能共同决定最大位置，须保留校准背景，不能直接减去本次标量 |
| 改为固定 ROAM 表示空间参考 | 按事前固定的根域、二分规则、深度 14/20 和高度采样定义相机无关的完全细化曲面，作为主要 algorithmic reference；更适合隔离当前工作空间内的排序取舍，但不再等同于原始资产保真度，需明确保留资产参考的辅助角色 |

建议下一次先讨论第二种定义，冻结参考生成与身份后重新校准；它应是预先定义的完整表示空间，不能随 relaxed 结果或某次 serial greedy 输出选择。当前只给出建议，不自动新增规划或修改研究契约。保留原参考也不是逻辑上不成立，本次数据只说明需要明确解释范围。
