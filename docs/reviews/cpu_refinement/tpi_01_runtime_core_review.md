## Major

- **归属与依赖**：核心、纯工具与研究包装分离；同一个对象库为 DOD 和独立入口提供池实现，没有复制计算或调度逻辑。MPR 原状态、参考与物化实现保留。
- **构建边界**：关闭 tests/app 的核心单独构建成立；关闭核心时无 Boost/核心对象依赖。WSL 当前完整应用依赖不齐，关闭特性的应用只构建了 bootstrap，不能声称完整图形回归。DOD 家族 CPU 入口已覆盖受影响真实线程路径；实际图形构建留在对应接入阶段。
- **性能**：首次计时存在明显差值，已单独分析并保留所有正常/诊断结果；DOD/B1 的退化不持续，C4 归因仍有限，未宣称严格性能等价。没有为消除差值改变工作量或将文件输出混入算法时间。
