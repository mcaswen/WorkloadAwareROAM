# QPC-04G规划审查

日期：2026-09-17。对象：[04G小规划](../../plans/cpu_refinement/qpc_04g_proposal_feasibility_plan.md)与QPC大规划本次导航修订。依据规划登记的定向源码核对、[04F事实](../../codebase/cpu_refinement/qpc_04f_target_quality_facts.md)及PQ-03/04、04F报告。同一Agent自审，不代表独立审查者或用户验收。

## Critical

未发现仍未写入处理边界的阻断问题。以下义务不能在实施中降级：

1. **保守判空不等于真实无解。** §4.4已要求区分充分内域、必要外域和精确等价域；有限试值或旧Fit失败仅保留原理由。未知/限额不是不可行证书。
2. **B不具有任意高度自由度。** 源高和中点是构造/提交契约的一部分；§4.5将它作为单例审计，不把放开高度写成同任务求解。
3. **只读诊断不得改变生产决策。** 实验组件持有私有提案，原生复核不Apply。原批次、实际网格及续接必须与04F对齐；局部正例不意味着整个交换能够执行。
4. **双域与完整支持。** 公开float曲面不能继承核心系数/支持；捕获截断不得输出可行证书，投影不定义不得隐去样本。核心判空与仅公开域未找到见证的结论必须分开。

## Major

- **不是旧PQ-03重跑。** 本阶段从未拟合真实几何建立新逐点域，保留旧统一0.01px门槛独立对照；不把历史原认证正例挪作新政策正例。旧诊断的硬编码和模型假设不侵入新组件。
- **避免求解器工程膨胀。** 固定一维、七根、56项上限；无一般SMT/优化平台。安全域可行而进展未知允许直接收口，不要求证明任意有理函数的全局最优解。
- **实际数值输入有来源义务。** 精确系数使用冻结源数据、Q和二进制矩阵，不使用显示CSV的截断小数；旧Fit保守系数与新精确系数分别保留。实际舍入值的见证必须重新认证。
- **成本比较不得越界。** 离线诊断比旧Fit慢不等于生产回归，也不能用几个正例预报运行时收益。规划分别记录新增诊断成本、默认关闭前后开销及不同语义的工作量。
- **重复失败不等于可缓存。** 原因字符串和哈希不足以证明失效完备；本阶段只列依赖和实际重复，不追加缓存或预留优化。

上述风险已进入实施/停止条件，尚未得到运行证据。任何需要移动插点、修改旧点、放开B高度、改变损伤目标或取消旧生产门槛的措施均属于后续政策修改，不能在此诊断阶段顺手实现。
