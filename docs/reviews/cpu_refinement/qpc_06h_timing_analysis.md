# QPC-06H 首轮时间异常与处理

首轮含根内缓存的Sierra完整114.107ms，对前阶段106.031ms超过5%筛查线。接收仅+2.564ms，未修改的样本修复+3.893ms，故不能把完整差额全部归因新缓存；程序与逻辑结果一致，未出现少做任务。

依据用户本轮自主闭环授权，先按实际复用仅1次撤回复杂缓存，再对受影响Sierra补一次旧程序复测。原06G变为110.827ms，最终06H107.427ms；原/新差异方向未持续，保留的准备修改没有确认工程回退。Canyon最终62.544ms对62.744，旧Fit67.179对70.332，未见超过门槛退化。

结论是有限证据下未确认退化，不是“已证明缓存造成8ms，删除后修复8ms”。没有增加独立进程矩阵、换场景或删除首轮慢结果；原始数据、缓存源码快照和程序均保留。后续06I以最终06H为参考，同时保留06F/G原始基线。
