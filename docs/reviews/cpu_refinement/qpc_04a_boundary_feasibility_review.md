# QPC-04A 外边界有限恢复审查

日期：2026-09-16。审查[小规划](../../plans/cpu_refinement/qpc_04a_boundary_feasibility_plan.md)、[代码事实](../../codebase/cpu_refinement/qpc_04a_boundary_feasibility_facts.md)及[结果](../../research/cpu_refinement/qpc_04a_boundary_feasibility_results.md)。结论：**诊断子阶段可收口，生产修复尚不具备无条件准入。**

## Critical

没有未处理的诊断正确性问题。六个有限几何均通过独立有理结构/形状检查；正常算法和三条旧轨迹不变。预算单对可行没有冒充真实提交，原 `+2` 断言未被删除或降低。

## Major

1. **生产质量接受标准未冻结，属于明确停止边界。** 峡谷最大见证改善的同时，另一个内部样本0.068657→2.985201px。该提案合法通过原局部最大值契约，因此不能把新点取源高当成逐点或跨视图保护。报告记录完整退化见证，不直接接入默认生产；后续先确定质量操作点与允许交换范围。
2. **`+1`预算和边界续接尚未实现，属于明确接入义务。** 原命名双面额度、新点默认非边界、无边界点回收均已审计。报告给出按面数命名额度与多余捐赠额度下批可见的候选设计，没有以局部构造成功绕过大规划的Review要求。
3. **诊断与生产选择隔离。** Peking50k根排名194，当前前160不会看到它。明确标为有限反事实，不改变优先级或扩大前缀，也不将单对捐赠成功描述为获批批次成功。

上述三项不阻止诊断阶段完成，但阻止“生产持续质量修复通过”的表述。本次没有悄悄增加质量guard、重连域、线程或恢复轮数。

## Minor

- 首轮证据发现逐点退化后补充最大退化位置，最终版本拆开构造、质量评估、单对预算与输出职责；没有继续向原控制器添加诊断逻辑。`run-01`保留，`run-02`作为最终版本证据，非筛选更快样本。
- 解析夹具初始高度范围超过默认比例时被正确拒绝；修正夹具显式比例4，未修改生产输入校验。
- 原生CPU工具仍使用既有CBT关闭的构建组合，结束后恢复缓存。未把这一既存组合限制纳入新质量修复。
- 默认路径完整均值前后差低于5%工程项；首次局部捐赠/样本维护涨幅后仅做一次反序复测，超门槛局部涨幅未稳定重现。所有慢结果、局部尾部和阶段统计保留，不声称严格无差异或统计显著。无理由继续扩矩阵。
- 参数域图已目视核查并调整标签空间；不是实际修复后的平台画面，用户视觉验收仍未进行。
