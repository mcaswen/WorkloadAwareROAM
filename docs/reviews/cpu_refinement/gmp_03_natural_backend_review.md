## Major

1. 统计限定前 64 需求、同池 64 中心。全域三个后续分母保持未知；Peking14 的两次空额度接收不计预算交换。三价池为空说明原语表达受限，不说明战胜 Legacy。
2. oracle 的 cavity 可行和 pair 兼容分别检查；4 个漏解不是新增执行数。浮点拟合失败不称不可行，DP 否证只限固定边界/样本/角度及已完整求解子问题。
3. 最终派生状态由诊断全量重建完成，不能称局部生产续接已实现。全部复制/重建费用登记；对象峰值字节、每项缓存写/支持分布未测，明确缺项，不建设冗余 profiler。
4. 来源薄探针、值/采样、局部认证、回收/预留、文件编排分离。生产不依赖研究脚本；无新增算法 ID、线程设施或旧 DOD 状态混用。
5. Peking 高优先级前缀多数没有 V 内样本，由 v1 未裁剪长边紧迫性与质量证据域不同导致。不得用换前缀制造较高认证率；后续可以预注册新变体，但不能改写本次基线。
