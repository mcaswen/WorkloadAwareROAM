# GMP-04 原型准入与下一架构审查

2026-09-14；同 Agent 自审。依据[GMP-04 小规划](../../plans/cpu_refinement/gmp_04_prototype_admission_plan.md)、[能力事实 §7–8](../../codebase/cpu_refinement/preprototype_capability_baseline.md)、[准入矩阵](../../research/cpu_refinement/transaction_backend_gate.md)及[下一原型规划](../../plans/cpu_refinement/greedy_transactional_cpu_prototype_plan.md)。

## Critical

未把自然正批次越级解释为完整算法/生产可用。下一规划明确 v1 的单视域边界，记录高度退化反例；全 Q 局部高度保护属于尚未实施的新变体，位于并行之前的硬 Gate。若保护后没有非平凡机会，停止扩建；不直接沿用旧批宽。高度保护自身也不保证所有未来视点屏幕质量。

数值与发布值的差异显式处理：C++ 二进制浮点新几何先舍入再认证，不借 Python 理想有理证书接受另一个状态。精确回退依赖是新规划待审决策，未暗中引入。样本边界归属/闭面贡献、完整旧点高度支持仍为测试重点。

本轮授权止于原型前 GMP，大规划按四阶段提交闭环；下一 GTP Major Plan 仅供 Review。没有通过“自动小规划”把未批准的持久模块、依赖或生产接口变成既成事实。

## Major

1. **新颖性未获证明。** Adams 已有贪心插删点、样本归属和延迟队列更新，Franc/Skala 已有 CPU 独立操作简化。删点、DP、独立集、多阶段或数据布局均不独立宣称原创。候选组合必须经持续状态和四参考实证；部分文献仅核查摘要，不能以未见相同实现声称首次。
2. **性能参考保持公平。** A 使用自然局部维护，慢全域 A 只能是 oracle。B/C 同批同任务；完整时间含发现、认证、预留、状态与输出，给定批次的应用费用另列。三价后端不是 Legacy 性能参考。
3. **状态与依赖方向清楚。** 新核心独立于旧二叉层次；来源只初始化、此后自身演化，不每帧重导入或复制。样本管理、数值、提案、预留、应用、输出各自归属；MPR 执行适配仅在 probe 包装回调，避免重复线程设施或让核心依赖旧状态。
4. **成本门禁仍可能终止方向。** 数值回退和全 Q 刷新可能比拓扑写更贵，预留/派生维护首版串行。后续只允许依次验证，负结果不自动扩大原语或放宽保护。GMP-03 未测微观峰值内存等缺口保留，下一原型记录真实容量/局部记录，不能声称它们为零。

## Minor

文献页独立于事实页，结果按阶段追加不修改旧输入。新目录/文件到阶段再创建，不预建通用求解器或事务平台。公共生产算法枚举、GL/D3D12 上传和旧 DOD 五阶段语义均未改动。

收尾全仓库检查补正原始产物忽略遗漏：原规则没有覆盖 `benchmark-output/cpu-refinement/`，本阶段加入定向规则。没有把诊断 JSON/CSV 加入索引，也没有用全目录规则影响其他历史数据；原始证据保留本地。
