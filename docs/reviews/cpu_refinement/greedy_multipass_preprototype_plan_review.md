## Major

1. **原型前工作仍可能过大。** 已限定为四阶段、有限单轮参考执行和两场景共 4～6 个预冻结快照；没有持久新状态、线程池或完整质量平台。若必须先建设运行时才能测量，规划要求提前 Review，不按文件清单机械扩建。
2. **Natural Gate 不证明长期适应。** 小面板只核查真实种子网格与局部下一轮候选，多时刻不能当作独立场景；不能证明持续回收率、视点轨迹收敛或普遍质量/并行收益。未覆盖预算竞争时保留 N/A 并结束面板，不换阈值/时刻找成功。
3. **完整工作量不能藏在 oracle。** 局部几何合法性、三角形质量评价、DP、配对/冲突、维护分别计数；仅递推 O(d³) 不代表完整复杂度。离线实现耗时不被解释为生产加速。
4. **选择器仍可限制兑现。** 同 donor pool、预冻结规则与少量精确选择审计用于分离损失；一般回收不能沿用三价分支的独立性和数量保证。
5. **原创性与原型价值分开。** GMP-01/04 必须逐项审计已记录的 greedy 插点、固定预算插删、并行简化及误差约束重网格。计划没有把删点、DP、独立集或 multi-pass 本身声明为新技术，也不预先承诺论文录用。

## DOD 接入边界补审（2026-09-14）

**Critical**：新增 §4.1～4.5 已排除共享旧 DOD 状态仅替换一个拓扑 pass 的隐含假设。一般连接破坏原层次/菱形前提，旧写面入口从 source 重建位置而非采用拟合高度；建议新引擎拥有完整状态，经公共算法输入/CPU mesh 输出接入。生产运行不要求 Legacy 产 J 或每帧导入。

**Major**：两类拓扑操作纳入联合事务预算和发布，不能按旧五阶段槽位隐藏规划费用。当前 ±2 交换没有覆盖独立粗化、预算收缩等全部生产语义，已列为 GMP-01/04 的明确任务/后续边界；不得用旧 MergeTopology 在新状态上执行来补齐。旧/新选择需要独立状态及 reset/显式导入，不承诺热切换可续接。

**Minor**：公共投影、只读分块、线程调度及脏区间输出可按依赖复用，但不为统一抽象改慢 Legacy。OpenGL/D3D12 只共享 CPU 输出契约，上传资源仍各自所有。新阶段统计保留独立身份，不伪装 P5 严格等价配对。

本次只补充规划、能力事实和自审；核对链接/差异与接入责任表，不运行代码测试或性能矩阵。独立引擎边界已纳入本大规划，具体生产接口仍需后续设计；未实施、未提交。
