# TPI-04 架构审查

日期：2026-09-15，依据[小规划](../../plans/cpu_refinement/tpi_04_d3d12_consumption_plan.md)与[事实](../../codebase/cpu_refinement/tpi_04_d3d12_consumption_facts.md)。

## Critical

未发现未解决接入阻塞。释放后的失效容量、部分区间积累失败和暂停时意外运行下一批已在本阶段修复。共享 CPU 借用不跨更新保存到帧资源；失败后补齐最新完整 mesh。

## Major

核心算法、线程执行和 DOD 选择语义未修改。D3D12 保持 fence/帧槽/映射资源职责，未套用 OpenGL 上传模型。普通旧 DOD 短回放未出现实质回归。有限注入是分配失败模型，不能扩大到设备移除。

## Minor 与出口

OpenGL 改动限暂停恢复契约，针对检查已完成。每帧追赶的延后上传纳入统计。自然默认回放零事务，后续必须区分持续调度成立与实际交易覆盖。阶段标记为后端接入通过，性能竞争力及连续质量仍开放；完成提交后进入 TPI-05。
