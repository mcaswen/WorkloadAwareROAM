# GMP-01 执行契约小规划自审

> 日期：2026-09-14；对象：[GMP-01 小规划](../../plans/cpu_refinement/gmp_01_execution_contract_plan.md)与已批准的[Major Plan](../../plans/cpu_refinement/greedy_multipass_preprototype_plan.md)。同一 Agent 自审，不是独立评审或契约已完成的证明。

## Critical

小规划只落实已批准的快照顺序预留，不更改新/旧独立状态或公共 CPU 输出边界。P/G/C/E、同代观察、稳定身份与有限提案是契约产物；当前没有代码或自然证据被误当成结论。

**需要 Review 的具体选择**已明确：每面一个主需求与有限接收目录、闭面样本贡献、后端无关回收代理顺序、具名空额度本批不转让。最后一项使共同分母容易保持，但可能牺牲当批预算利用率；小规划明确报告代价，没有把它隐藏为后端失败。

形状前提已前置：30° 的最小角使内部 1→3 只可能从等边三角形出发，原 45° 网格不能以该原语推进；不能误以为自由高度能解决参数角问题。阶段内须先完成已有原语/角度的定案，再冻结自然审计配置，不新增接收类别绕开反例。

## Major

- 单一样本存储归属不等于闭面评价范围；建议显式统计共享边/顶点贡献，避免为降低工作式漏掉 urgency 或质量约束。其维护证明留 GMP-02。
- 接收目录必须给定 q、自由变量与完整支持，不允许把已有面内双高度证明扩展到未审计的其他连接。候选重复、事务复用和成功需求统计分别处理。
- 参数值在阶段产物中一次冻结，现有 30°、0.20 仅是有来源的讨论依据，不伪造为已经选定的自然配置。阶段无解应报告关键冲突，不引入调参矩阵。
- 四类参考仅定义角色，不在本阶段实现；动态串行可用正确局部维护，完整顺序预留、认证及输出成本仍需计入未来对照。
