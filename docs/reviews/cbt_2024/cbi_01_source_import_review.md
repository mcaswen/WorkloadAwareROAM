# CBI-01 来源迁入审查

2026-09-16；依据 [小规划](../../plans/cbt_2024/cbi_01_source_import_plan.md)、[大规划](../../plans/cbt_2024/cbt_2024_integration_major_plan.md) 与 [当前事实](../../codebase/cbt_2024/source_import.md)。范围是迁入与构建门禁，不是 D3D12 执行验收。

## Critical

无本阶段未处理问题。七个核心算法实现和计算 shader 保持来源；没有将 CPU 参考变成 GPU fallback，也没有改变面积分类、传播与容量语义。CBT 参数不进入旧 CPU 输入哈希。

## Major

无阻断本阶段的问题。核心测试、HLSL 和待接通 D3D12 运行文件分开构建；后者尚未编译的事实已明确，不能借核心测试宣称原生接入完成。新增公共头不依赖 Windows；GPU 描述不持有 COM 所有权。HeightMap 只新增只读数组视图，没有拷贝或改变原始参考。

来源权利声明已经随模块保留；本地阶段提交不包括公开发布或远程推送。来源记录和目标 SHA 对 46 项逐项核对，非算法适配可追溯。

## Minor

来源头文件仍保留部分历史注释排版，与新胶水的自然摘要区分；不为格式进行大范围脚本改写。复杂模块原有分层保留，新增核心构建集中到 `cmake/Cbt2024.cmake`，入口 CMake 只挂接。

## 验证与成本

八个定向测试及 106 个 shader 入口覆盖 CPU 核心、ABI、配置隔离和四容量编译，不重复运行旧项目完整 CTest。DOD 两轮各 24 帧结果一致；首组 +14.24% 的时间变化触发唯一复测，复测为 -3.48%。旧程序自身跨轮变化明显，未发现持续版本相关退化；不足以推断稳定性能或尾部性质。

视觉、设备能力、描述符释放、GPU 结果、暂停/切换/Reset 仍属于 CBI-02。最终同代网格与质量比较属于 CBI-03/04。当前阶段可以收口并提交，不提前提升后续 Gate。
