未遗留阻断项。算法资源所有权与渲染借用分离，GUI 帧中资源销毁已移至 Present 后；跨 Reset 资源身份不复用。来源 VS 与当前 PS 的接口错误经真实设备诊断定位并修正。

## Major

未遗留当前阶段阻断项。工厂按构建与设备拒绝，不提供 CPU 冒充；GPU 输出不会泄露旧 CPU 网格。描述符区间沿后端集中分配/释放；独立 render pass 只负责消费，未把 CBT 控制器并入大 renderer。

同代 mesh 证据尚未实现，明确归 CBI-03。延迟统计和 blocking 诊断时间不能解释为当前 GPU 结果或公平性能胜负；事实文档已限制结论。

## Minor

来源迁入文件保留原有写法，新增公共/应用/诊断代码采用 DOD 的展开分支与职责边界。没有顺手重构 Transactional。固定堆与有限诊断足够覆盖此次接口，不扩 uploader 或 GPU 算法研究。

- 已覆盖：两个后端构建、三项公共契约、真实 GPU 连续更新、暂停/单步、多次 Reset、容量/源/算法替换、设备错误、GUI 启动与 OpenGL 拒绝。
