## 2. 验证记录

三个专项一次通过，总计 27.31 秒。规则测试检查空计划完整候选记录与顺序、块形状、分类/安排计数及源状态；既有迟滞停止和非空前缀规则保留。探测试验覆盖工作量传播，真实集成覆盖原第 14 帧、受控两块实际提交、P=1/2/8、诊断设置、回退及后续帧。没有降低既有结果断言。

前一版本的两后端各 40 项 CTest、旧核心输入和新目标全集用于说明方案 A 的已有覆盖，不写成本轮实测。当前修改与后端接口、生命周期、编译分支、输入协议及脚本无关；本轮所选测试足以覆盖新增判断风险，未发现需要扩大测试的失败或新变更。

性能完成两个 OpenGL 默认场景的 36 个独立进程，仅标准规划 P95 相对 A 越线；按原规则追加一次标准场景复测 18 个进程后停止。B/C 的完整非计时字段逐帧一致，标准 A/C 几何也一致。复测规划中位数从 B 的 0.122400 ms 降到 C 的 0.028900 ms，配对 C−A 仅 +0.004900 ms；但规划 P95 配对 C−A 仍为 +0.095875 ms，与首轮 +0.095115 ms 同向越线。C−B 的所选指标未越线。高预算 A/C 仅为历史成本参考，不宣称同结果加速。

源码身份 `ba6e33c4...`、程序、资产与环境前后核对完成；相对直接基线仅规划器和规则测试两个源码文件变化。源码包与当前文件相同，注释覆盖为源码 15.3%、DOD 20.2%。原始报告与最终审计在 `benchmark-output/prep-04-prefix-cost-fix/`，结果已同步小规划与原问题分析。
