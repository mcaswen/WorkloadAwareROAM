## 1. 实现与规划比对

| 要求 | 当前实现与判断 |
| --- | --- |
| 统一全局优先级 | 队列头文件拥有可内联比较函数，堆、计划、冻结展开与结果整理共同调用；原串行比较行为不变 |

| 性能与提交边界 | 性能承接先分代码/文档提交，拓扑修改前保留两后端 72 次基线；采用开发规范第 7.3 节已冻结工程门槛，拓扑工作未自动提交 |

没有发现新增反向依赖、重复生产执行算法、不相关职责堆积或公共接口所有权变更。`Sequence` 注释更新属于数据用途纠正，不改变类型布局或冻结编码。

2026-09-11 后续处理：用户已批准并完成[空前缀成本修复](../../plans/formal_experiment/prep_04_split_prefix_planning_cost_fix_plan.md)，下段保留该决定前的问题记录。短路后只运行三个专项，36 个定向性能进程及一次标准场景复测 18 个进程完成后停止；中位数配对 C−A 仅 +0.004900 ms，P95 仍 +0.095875 ms，剩余非空前缀成本未关闭。当前代码不再无条件扫描，下段“等待用户决定”已由此次授权承接；剩余问题和新增核查见[增量架构审查](prep_04_split_prefix_planning_cost_fix_architecture_review.md)。

自然细分拓扑并行覆盖不足：384 帧中没有多块连续前缀，不能把大量串行回退解释成并行性能。受控正例只验证执行与等价能力，不填补研究覆盖。后续 CPU gate 必须结合其他四阶段判断投入价值，放宽连续前缀或改研究契约需要单独 Review。

### Minor

批次可交换性、多轮前缀、可跳过项与预算充足四类放宽候选仍属于研究提案。当前只确认保守实现和已测输入范围，不把“空间不同块”或“预算足够”写成充分等价条件。
