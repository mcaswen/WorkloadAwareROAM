# EIP-02 性能快验差值调查

> 2026-09-15；仅限基础设施正常路径；不归因到拓扑新算法

## 现象

同一Peking/OpenGL/DOD8、24机会回放；第3～23帧均值：
修改前CPU-ready57.224ms、帧包络60.403ms；
修改后CPU-ready60.273ms、帧包络63.753ms；
一次定向复测CPU-ready60.400ms、帧包络63.712ms。
幅度略高于5%工程筛查，因此保留慢数据，不直接关闭为无回归。

## 已知事实与假设

24帧网格hash/面数量一致。受测入口为历史TransactionalPlatformReplay，不创建Application/实验面板，也不调用新截图代码。
本轮未修改DOD/Classic、线程池、原回放、评分/拓扑/上传实现；新功能编译定义会导致应用对象重新编译和最终布局变化。
目前不能区分环境/调度漂移、重编译/布局变化与功能开关相关成本；不将结构上“未调用”直接当成计时证明。

## 控制步骤与停止范围

保存feature-on程序；同源构建关闭新基础设施的程序，顺序跑同一冻结入口，随后与保存的on程序相邻比较。
这是对新的开关相关性假设的一次隔离实验，不扩大场景/线程矩阵、不继续追逐叶函数优化。阶段出口以该结果及适用范围更新。

结果：同源功能OFF/ON相邻控制均值36.245585/37.592833ms，差值3.72%，低于5%工程门槛；24帧hash和面数一致。此前57～60ms与两者均明显不同，存在跨时段环境漂移，不能把原差值归因于新增资产功能。仅一对独立进程，不证明统计等价或零成本；本次关闭为“未发现超过工程门槛的版本相关回归证据”，不继续重复。原始结果见eip-02/control/comparison.json。
