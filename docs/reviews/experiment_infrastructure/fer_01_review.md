# FER-01 正式实验与报告审查

2026-09-16。对应[阶段规划](../../plans/experiment_infrastructure/fer_01_formal_experiment_plan.md)、[报告](../../research/experiment_infrastructure/fer_01_results.md)与[数据附录](../../research/experiment_infrastructure/fer_01_appendix.md)。本审查关闭实验执行和分析阶段，不授予算法性能、持续质量或论文竞争通过。

## Critical

本次实验实现未发现阻断交付的问题。算法目标仍有明确反例：Peking200k暖CPU约611.9ms且出现秒级运动尖峰；Peking转向和峡谷返回过程的独立屏幕误差仍高于DOD。它们属于本轮需要如实报告的研究结果，不是可以通过删除样本解决的实验错误。

## Major

无新增架构问题。配置连接已在 `2c3ccf8` 单独闭环，本阶段没有修改算法、默认策略、公开拓扑接口、渲染器或实验输入。

`formal_study.py`负责冻结清单与有限采集，调用既有runner/quality/analysis；`formal_report.py`只消费已校验EIP数据，处理本轮进程统计及展示，复用`FigureWriter`。没有向旧开发报告添加“正式统计通过”判词，也没有复制进程管理、网格求值或质量算法。后者的`aggregate`、`figures`、`tables`、`appendix`分别管理本次统计、图像、精确数表和人类阅读出口；状态只存在于离线Python进程与实验输出中，不进入生产热路径。

报告脚本在全部采集完成后编写，因此不属于运行时源码身份。冻结的配置、二进制和原始结果没有随报告调整而变化。正式统计先对每个进程求暖机会均值，再以3个进程为样本归约；没有混入视觉时钟、历史FPR百分比或相关帧构造的置信区间。

## Minor 与解释边界

1. 首次视觉检查发现质量/成本图中山脊Classic和DOD标签重叠，已调整偏移并重新生成该图；PNG/SVG/PDF与FigureSpec同步更新，原始分析未变。
2. 手写报告中Peking100k/200k若干末位数值按当前JSON重新校正；表格是显示舍入，CSV/JSON保留原值。零超额档覆盖计数采用1e-9px浮点比较容差，不宣称数学完全相等。
3. HTML的288个本地引用均存在，实际浏览器交互未验证。实际PNG已查看，不能把链接检查说成浏览器验收。用户视觉未代签，也不因为交付报告要求用户重新批准实验。
4. 三个独立进程仍不足以给出广泛统计泛化；Windows平衡电源、未锁频/亲和性是实验限制。相同预算上限不保证相同实际三角形数，也不保证同质量或同适配任务。
5. 四个时刻的采样质量不代表整个连续轨迹的严格上界。边界见证和返回残差值得后续调查，本轮不自动加入质量修复。

三算法各列镜头和地形方向一致，未出现用另一时刻截图配当前误差的明显情况。Peking、山脊、峡谷和山地局部的事务输出有较明显分片外观；此处不区分法线、密度与连接影响。未在已查看画面中发现明显孔洞，不将该观察扩张成连续无裂缝证明。见证红圈定位参考投影，裁剪保持相同像素窗口；峡谷见证接近下方轮廓，偏移可使红圈位于事务网格外，数值差异仍独立保留。

数值图中文字、轴单位和图例可读，缺失项未填零，分场景独立坐标和范围/非CI说明保留。显示最坏关键帧属于预指定四帧内的展示选择，没有追加测量。实际画面、图像文件完整性、用户视觉和算法质量是四个不同结果。
