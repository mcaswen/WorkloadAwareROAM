# 一般三角化事务理论规划：文档架构自审

日期：2026-09-17。审查对象：[大规划](../../plans/adaptive_triangulation/resource_constrained_transaction_theory_plan.md)、[模型起稿](../../research/adaptive_triangulation/model_derivation.md)、[模块入口](../../research/adaptive_triangulation/README.md)。类型：本轮文档边界与证明义务核查，不是证明完成或人类架构批准。

## Critical

原建议按简写直接应用存在四项正确性风险，本规划已显式拆解：

1. **固定完整边界与 +1 面数操作不相容。** 规划§4.1/§7区分严格类和自由外边界兼容细分类；起稿保留欧拉推导，不偷换“固定边界”。
2. **终点预算不保证前缀或失败子集。** 规划§4.3选择整批可见主模型，保留中间超限/负净额事务失败反例，不依赖隐含的 donor 永不失败。
3. **单独损失证书不能无条件组合。** 规划§4.4/§6把损失局部性、证书迁移和可加支持分区分开；双变量反例指出证书漏依赖。
4. **集合不交本身不证明更新交换。** 规划要求从实际更新函数证明读限制、写封闭和使能稳定，不将交换律或总正确性直接作为结构字段假设。

以上是规划已经纳入的修正，不表示后续形式证明已经完成。未发现需要在本轮修改生产代码才能解决的规划阻断。

## Major

- **一般安全模型与一般算法分开。** P可能不参与组合定理；发现/选择、质量恢复、运行费用和新颖性分别记录，不恢复“目标已给定所以算法已经更快”的旧论证缺口。
- **几何保证分层。** 抽象流形与三维自交、局部角度与全局嵌入不混同。非 ROAM 实例要求先于机械框架扩展，防止空洞公理化。
- **完整续接投影。** 身份参与下一轮排序时不能仅比较无标签面集；分配器、邻接、owner和浮点归约按资源/协调规则单列。
- **模块依赖单向。** 新研究目录独立；质量模块只读复用历史核心，生产不引用研究层。没有移动旧Lean、修改运行时类型或创建通用几何引擎。
- **规模有界。** 三个理论阶段、一个按需有限检查脚本、最多三个Lean源文件；每阶段有独立出口。某原语不能嵌入允许记录部分成立，不以完成全表为由扩展几何类别。

## Minor

- 有符号整数是资源账本类型，几何可实现值仍受欧拉条件限制，规划已保留该差别。
- 非负权重中的零值、空Q、环境变化、有限证书与连续保证均有显式边界。
- 当前生产有 +1/+2/−2/0 的专用政策，论文中的当前事务原语不能统称为原始 ROAM 操作；实例表已经分列。
