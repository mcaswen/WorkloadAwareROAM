# NMP-CB 候选出生证明规划审查

> 日期：2026-09-13；对象：[NMP-CB 小规划](../../plans/roam_parallelism/native_candidate_birth_proof_plan.md)。
> 结论：**规划自审完成，可提交用户 Review；不是出生定理已通过，也不启动队列实现。**
> 事实来源：[契约审计](native_planner_contract_traceability_audit.md)、NMP-01P §9.4/§9.13，以及规划所引用的 Native Simulation、严格控制器和已有测试观察接口。

## Critical

1. **可执行性不能替代严格队首域（规划 §2.2）。** 原控制器遇到不满足迟滞的细分头会停止；合并也存在选出后失败的可观察分支。若以 `ShouldSplit/CanMerge` 过滤队列，可能在出生规则完备的情况下仍改变轨迹。规划已要求先定义 `HeadRelevant`，保留哨兵和失败观察，省略规则另证。
2. **出生完备不能覆盖持续成员改键（§3.1/§3.3）。** “过去曾经发布”不足以保证当前条目存在。规划已加入改键、改组、重新接纳及每个严格查询前的有效条目覆盖，作为通用极值引理的实际前提。
3. **原生端点能力仍有缺口（§1/§3.3）。** 新决策队列不能借用未补证的 `LeafSupport/MergeSupport` 恢复 Γ 或生产队列。规划保留目标发现和端点物化两条证明链，未将测试条件反推成 Lean 定理。

以上是必须守住的证明责任，已进入规划；尚未解决的实例性命题由 Gate 判定，不能在规划自审中标为已证明。

## Major

1. **重新接纳可能来自维护触及而非资格变化（§3.2）。** 当前 `Refresh` 会撤销重新接纳代表/伙伴的失败记录。规划优先核查此点，要求局部触发和生命周期证明，允许出现反例后早停；不得以自然数据中缺少失败略过。
2. **固定菱形映射未确认（§2.3）。** 原生允许 Base 为活动叶时的单节点候选。规划把固定几何身份列为待证映射，失败时显式审计组改组，不从 MPR 直接推定原生固定分组。
3. **测试事件不等于统一稳定边界（CB-03）。** 原有完成事件、整个合并/刷新结束及严格查询不是同一时刻。规划用纸面证明覆盖内部子转移，原生核查只声称实际可观察的范围；不增加生产 profiler 填补所有细节。
4. **删除反向位置不等于消除全量准备（§6）。** 初始成员读取、代表/伙伴、失败状态和真实叶计数可能继续存在；历史延期恢复也已节省一部分删除。规划已分账，不预支全部 Membership 投影或百万级访问的消除。

## Minor

- 本次是已有 NMP 架构下的证明小阶段，采用纸面证明和一个独立测试文件；没有引入第二份控制器、通用证明平台或生产依赖。
- 新测试对照由 Legacy 逻辑投影提供，局部枚举器不得读取全域成员差分生成答案；故意漏出生/漏改键的核查器自测能检验这一独立性。
- 现有严格夹具、自然样本与性能门槛保持。文档无需生产性能复测；测试新增成本单列，二进制未变时复用已有生产报告，符合按影响选择验证的要求。

## 未决问题与架构核对

`UNCERTAIN`：完整原生出生规则、失败重新接纳的最小支持、稳定分组对应以及有效验证器能省多少重复资格查询，均尚未证实。这些正是 Gate 对象，不以设计猜测填为事实。

新增证明文件属于研究记录；测试内规则和无序条目账本只服务核查；生产模块不依赖它们。父规划只增加承接说明，不修改原语义或授权性能实现。没有重复实现生产堆、将测试答案泄漏给局部规则或扩建公共接口的计划。
