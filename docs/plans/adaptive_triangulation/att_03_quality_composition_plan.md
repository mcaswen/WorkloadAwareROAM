# ATT-03：一般损失、批次总定理与适用边界

日期：2026-09-17。ATT-01/02已提交`99947ed`、`f297838`。依据[大规划](resource_constrained_transaction_theory_plan.md)自主闭环，本阶段不引入生产质量政策。

## 1. 问题与出口

证明有限固定Q、参考、视图、逐点目标及非负权重下，逐点阈值条件推出加权超标势不增。更关键的是把单快照证书迁移到批次执行中，不能直接假设“批次最终质量通过”。需要区分：完整资源独立、实际观察依赖、证书读域覆盖、独占变化支持。

总出口是有条件的一般事务组合模型：局部合法性经ATT-01纸面拼接，资源/预算经ATT-02实际更新，质量经本阶段代数及观察模型；不证明全局优化、发现代价、持续相机恢复或生产多核正确性。

## 3. 证明步骤

1. 逐点目标代入`pointwise_iff_excess`；非负权重乘法保序后有限求和。标量是显式有序代数域，不取Nat近似真实损失；Rat/Real的一般实例若未机械建立必须明示。
2. 定义每个观察量只依赖自己的资源投影。对事务未改的观察量由框架条件证明损失不变；对会改的观察量，完整观察资源纳入证书读取域。由独立前序的读取稳定证明旧/新损失预测稳定，再迁移单事务证书。
3. 用批次归纳证明加权势不增，结合实际净额预算和顺序独立。局部几何、无外部自交、身份和确定派生维护不能从代数层冒出。
4. 独占实际变化支持下，按观察点分区推导收益可加；若Lean不适合有限加法交换扩展，保留完整纸面证明及有理数实例，不能标机械证明。一般共享观察仅用迁移单调。
5. 三个相互分离的平面补丁，执行split(+2)、flip(0)、删中心(−2)，逐点属性平方损失作为非高度参考，固定目标/权重。检查六种顺序最终逻辑网格、面数、质量与派生邻接；另保留中间越预算记录。
6. 明确全局耦合损失、共享改善重复计费、负/零权重、环境改变及连续曲面误差的反例/边界。列出屏幕平方误差和高度平方误差实例所需对应。
