# ATT-01：局部替换接口与原语嵌入小规划

日期：2026-09-17。依据[大规划](resource_constrained_transaction_theory_plan.md)。用户已授权本大规划逐阶段自主闭环和提交；本阶段只完成几何/计数纸面证明及有限实例，不提前建立资源或质量Lean模块。

## 1. 目标与前提

验证一般模型是否至少有非ROAM、非高度场的真实实例。先给相对连接接口的圆盘替换定理，再核查边细分、折叠、翻边、一般内部删点和完整ROAM细分的嵌入范围。分别处理拓扑类型、几何嵌入、属性一致及预算计数。

已阅读开发/规划/审查规范、模型起稿、GMP组合记录和旧有限几何检查器。旧`verify_bounded_patch_refit`中的`orient/edge_map/boundary/validate`只做二维有理几何，不需要ROAM层次，可只读复用；其高度插值、拟合、回收搜索不复用。

## 3. 构造和证明步骤

1. 对旧圆盘K和新圆盘K′构造相对接口的PL同胚；与上下文U上的恒等映射拼接，逐项论证连续性、双射、逆映射和流形类型。附加几何不相交才升级嵌入结论。
2. 从真实面集合和圆盘欧拉公式推出净额、奇偶限制。给出不依赖配对的终点预算、全独立条件下先负后正的前缀上界；部分失败反例保留。
3. 冻结小夹具：方形内部边2→4及其合法折叠逆操作；三角形外边界1→2及其逆；方形翻边；不规则五边形中心5→3；竖直平面上的边细分；一个完整ROAM菱形。外边界+1单列扩展。
4. 反例：只细分内部边一侧、非凸翻边、四面体边的完整link条件失败、固定边界补丁穿过远处保留三角形。最后一项给解析交点，不建设一般三维碰撞器。
5. 明确支持、R/W和证书应覆盖哪些资源，有限不等于常数；无法覆盖的任意边折叠/非圆盘closure保留为条件范围，不自动扩展模型。

## 4. 验证与费用

每个平面例核对正方向、相同覆盖面积、边的反向配对、无挂点/交叉、顶点link为圈或区间、欧拉特征、面数差及接口。三维例使用解析单射线性嵌入，不借高度采样判几何。记录真实输入面列表和几何数据，反例必须命中指定前提。

运行单次冻结检查，60秒目标/120秒硬上限。新增工具没有同任务旧基线，记N/A，记录总耗时和峰值内存；不修改生产或旧检查器，不跑自然轨迹、CTests或生产性能矩阵。证据本身不能宣称一般Lean证明。

检查通过、非ROAM例成立且边界明确后提交本阶段。若只能假设整个M′合法则停止；若某类操作只在额外前提下成立，则写条件式结果，不降低局部合法要求。
