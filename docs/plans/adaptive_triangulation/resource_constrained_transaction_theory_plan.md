# 资源约束自适应三角化事务：一般模型证明大规划

日期：2026-09-17。类型：**Major Plan，独立理论模块**。阶段标识 ATT；状态：**用户已批准，自主逐阶段闭环中**。

研究入口：[模块说明](../../research/adaptive_triangulation/README.md)。已有初步分析：[模型推导与失败边界](../../research/adaptive_triangulation/model_derivation.md)。本轮不新增生产机制、不接平台，也不恢复已关闭的 ROAM 理论支线。

## 1. 问题、判断与目标

当前事务算法已经使用局部面替换、质量认证、预算预留和分批提交，但这些机制的证明分散在 ROAM 历史模型、GMP 条件论证和 QPC-04E 质量代数中。需要判断：其中哪些可以脱离二叉层次、菱形、forced split、固定 −2 回收和高度场，形成有内容的一般模型。

用户建议值得推进，但不能按原七元组直接宣称一般总定理成立。初步审计发现四项实质缺口：完整固定边界排除 +1 细分；最终有符号预算不保证所有中间发布安全；任意非负损失不保证局部性；几何写入独立不自动保证证书独立。

本规划的成功不是“给已有算法套通用名字”，而是产出以下可审计成果：

1. 一个不引用 ROAM 特定类型的局部替换/资源/质量模型，以及非空的非 ROAM 实例。
2. 从实际有限补丁更新语义出发的计数、交换与质量证明，而非把结论藏进证书前提。
3. 五类操作的嵌入表：可覆盖类、额外前提、不适用类、支持大小及成本。
4. 有限的 Lean 核心和独立反例，明确几何、数值、生产映射的未证明范围。
5. 一张最终一般性边界表，区分可组合的安全语义、具体算法、实用性及创新性。

不要求肯定结论。若只能得到条件组合模型，明确称为条件模型，不升级为一般自适应三角化算法或当前持续质量问题已经解决。

## 3. 范围与非目标

**范围**：有限二维流形三角网格，已给定的有限局部事务及批次；固定环境下有限 Q 的一般损失；单一活动面数硬预算；完整逻辑资源语义；有限小型纸面/机械/解析实例核查。

**非目标**：新 C++ 后端、运行时参数、一般网格库、自动证书生成器、通用事务调度器、GPU、全场景实验、连续曲面全误差证明、任意维度复形、任意拓扑改变、质量恢复时限、便宜目标发现、新全局优化算法或论文新颖性保证。

优先级 P 作为冻结的调度元数据保留，但不强迫安全定理必须用到 P。若任意可行选择器都能使用组合定理，就如实写明；全局贪心的解质量、饥饿、预算利用率与计算成本不能从该定理推出。

## 4. 分层模型与关键架构决策

### 4.1 第一层：局部几何与连接接口

建立有限带身份网格 M、上下文 U、替换补丁 K/K′、连接接口 I 和几何映射 g。接口保留连接、方向、稳定身份及必要属性。先做圆盘替换，再允许若干相容不连通补丁构成一个复合事务。

严格类要求完整边界剖分固定；外边界兼容细分类独立声明可变的自由外边界。禁止用同一个“固定边界”涵盖这两类。以局部拼接前提证明抽象流形合法；形状、参数域覆盖和三维无自交分别追加证据。

**不采用**泛化到任意拓扑空间的公理框架。原因是本轮需证明真实局部实例，不需要用过大类型域换取表面一般性。

### 4.2 第二层：有限资源更新

七元组仍为主要描述：

$$
\mathcal T_i=(K_i,K_i',\delta_i,R_i,W_i,\mathcal C_i,P_i).
$$

辅助义务必须显式写在模型中：快照身份、连接接口、外部上下文、使能条件、确定的写补丁、证书依赖、观察支持和后处理协议。它们可以由描述符及证书索引派生，不凭空宣称七个字段已经充分。

逻辑状态采用有限有效资源的键值映射，值包含“缺席/已删除”。定义更新函数，再证明读限制、写封闭和交换性。新身份按事务身份及本地序号预定；物理槽位映射放在模型之外单独对应。

派生状态作为核心状态与唯一贡献记录的确定函数恢复。恢复函数只保证数学可定义，不自动有局部复杂度；若某个损失或属性需要全局解，应在局部性和成本表中判为不满足。

### 4.3 第三层：预算与失败/发布语义

净额是实际面集的基数差，不是用户填入的任意整数标签。证书要将声明净额与真实增删对应起来，再推：

$$
N'=N_0+\sum_{i\in\mathcal B}\delta_i\le B_{\max}.
$$

本轮主模型选**封闭批次私有准备、一次完整可见发布**。另给前缀预算的条件推论与 +2/−2 反例；不实现发布机制。预算不对任意失败子集封闭，必须保留全组放弃或子集重认证义务。暂存新旧面、分配失败和数值未知不归入活动面数保证。

### 4.4 第四层：损失与证书迁移

冻结 Q、环境 e、参考、目标 $\tau:Q\to\mathbb R_{\ge0}$ 和非负权重 w。定义 $\ell_e(M,q)$ 及超标势函数：

$$
\Psi_{e,\tau,w}(M)=\sum_{q\in Q}w_q[\ell_e(M,q)-\tau_q]_+.
$$

损失非负与损失局部分开。局部检查需有支持外不变定理；共同快照证书需有对其他独立事务的迁移定理。

优先证明一般单调组合，再在互不相交的实际变化支持及共享不变接口条件下证明可加性。不是所有共享观察量都必须判冲突，但任何例外都要有独立证明；本轮不扩展复杂交换归约。

### 4.5 第五层：实例与生产对应

一般核心不引用 ROAM 名称/类型。操作实例依赖一般核心；生产对应页引用模型解释当前 C++，生产不得反向依赖研究模块。采用“抽象语义—实例满足前提”的组织方式，不建立运行时策略工厂或插件系统。

## 6. 拟证明命题与形式化边界

| 编号 | 待证明内容 | 最小充分前提及验证形式 |

| ATT-T03 | 两事务交换、任意有限排列等价 | 从实际更新函数证明读限制/写封闭、使能稳定、身份和协调规则；Lean核心＋遗漏依赖反例 |
| ATT-T04 | 一般逐点目标、非负权重下超标势不增 | 固定环境/Q/目标/权重、完整支持；纸面逐项证明＋Lean有限和；零权重与空Q单列 |
| ATT-T05 | 迁移单调、独占支持下收益可加 | 证书在前序之后仍有效；可加另需损失分区；Lean有限组合＋双变量反例 |
| ATT-T06 | 预算、质量、合法性和逻辑续接的组合 | 明确引用前五项前提；Lean只组合其已建模部分，几何实例满足性另列，不称完整几何机械证明 |

形式化要求：不用自然数取整误差；整数用于资源净额。质量首选可用的精确有理数实例或明确的有序代数模型，加权需列出乘法保序等额外法律。优先提供至少一个非平凡具体标量/有限状态实例；若工具链不足，标注该层未完成，不静默引入大型新依赖来追求形式化比例。

任何结构字段若直接等价于待证结论，例如 `commutes : T_i ∘ T_j = T_j ∘ T_i` 或 `batchPreservesQuality`，不得作为该主命题的独立假设。允许假设明确的局部几何和损失依赖契约，但必须至少在一个非 ROAM 实例中验证；列明哪些是输入保证、哪些是推导结论。

记录源码指纹、命令、Lean声明、`#print axioms`、无`sorry/admit`核查和失败证明尝试。不要只列通过数量。公理依赖正常也不证明显式前提可满足。

## 7. 原语嵌入矩阵与预期困难

下表是待验证命题，不是五类已经全部通过。

| 操作 | 候选 K→K′ / 净额 | 必查前提及限制 |
|---|---|---|
| 内部边细分 | 两相邻面 2→4，+2 | 完整两侧纳入；新点与外接口相容，覆盖/方向/属性；单侧挂点不是合法例 |
| 外边界边细分 | 一面1→2，+1 | 属于可细分自由外边界扩展；若固定完整边界几何则当前源高 B 不适用 |
| 边折叠 | 在合格二维流形内部通常−2，边界常−1 | 实际面数核对；完整端点邻域、link条件、圆盘支持、无重复边面、方向/几何；不能只检查共有邻点数，边界和特征需额外规则 |
| 内部翻边 | 两面2→2，0 | 四点不同、新对角不存在、适当凸性或几何可行、局部形状和质量；非凸四边形是必要拒绝例 |
| 删内部点并重剖分 | d→d−2，−2 | 简单闭环、合法覆盖和固定接口；度数有限不等于常数，重剖分未必满足给定形状/质量 |
| 严格 ROAM 细分 | 完整共形 forced closure 的最终替换，正整数净额 | 必须包括全部传播；单 root 不自动独立，闭包规模不预设常数，不证明目标发现更快 |
| 当前事务算法 | E/F细分、B +1、R 0、内部回收−2；复合交换可不连通 | 明确它已可离开 ROAM 层次，不称“原始ROAM donor”；实际代码与新模型前提逐项映射，旧生产接受不追认为满足 QPC 新条件 |

至少给出一个一般平面圆盘非二叉网格实例和一个不依赖单值高度函数的三维曲面局部实例；后者明确外部不相交的前提。有限例只检查所列场景，不验证所有三维曲面。若三维例需要全局查询，诚实计费；不能通过改名“局部证书”隐藏查询。

## 8. 实施阶段与交付

用户于本规划评审后明确授权按大规划自主闭环，每完成一个小规划提交一次。各阶段实施前先写相应小规划，完成证明、核查和审查后单独提交，再进入下一阶段，不再逐阶段请求确认。普通证明细节在已确认范围内处理；新增拓扑类别、公共接口、运行时算法或新大型依赖另行 Review。

### ATT-01：接口、面数与原语可嵌入性

**目标**：先回答模型是否能装下真实操作，而非先堆一般 Lean 引理。

工作：完成 ATT-T01 和 T02 的纸面计数；明确完整边界/连接接口/自由外边界；创建操作实例页；构造上述五类原语的接受例与关键不适用例，至少一个不依赖高度场。补齐三维外部碰撞反例和 ROAM forced closure 支持范围。

验证：显式列旧/新面、边和稳定身份，核对流形/覆盖/净额/接口；有限脚本只为难以手算的局部例服务，不实现搜索算法。使用已有检查函数须指出哪些与高度场无关。保留 +1 奇偶限制、非凸翻边、link 失效折叠、全局自交反例。

性能/成本：纯纸面工作不跑生产基准；若创建有限检查器，记录指定小实例的总耗时、输入规模和内存，新增工具无旧同任务基线就明确 N/A。复用函数若修改须按影响快验，本轮优先不修改旧代码。

出口/停止：得到可检查的非 ROAM 实例才能进入 ATT-02；某类操作不能覆盖时缩小表中结论，不为覆盖它扩建一般几何库。若只能假设整个目标网格已经合法，且无法给出局部拼接依据，停止并报告抽象空洞。

**实现情况：已完成ATT-01。** [小规划](att_01_local_replacement_plan.md)、[证明与实例](../../research/adaptive_triangulation/operation_embeddings.md)和[审查](../../reviews/adaptive_triangulation/att_01_review.md)记录圆盘拼接条件、8正/4反有限检查及费用；几何层条件成立，不升级一般3D无自交保证。

### ATT-02：资源更新、预算与顺序独立

依赖 ATT-01 的明确接口和事务实例。建立有限键值更新与面生命周期，完成 ATT-T02/03 的小型机械核心。证明使能/补丁由 R 决定、域外不变，再推出 pair 交换与排列等价。

计数从面生命周期导出，区分最终预算、前缀预算、分配峰值和失败子批次。明确逻辑 ID 与物理槽、共享边、owner/邻接、派生属性、浮点归约和全局账本如何进入等价投影。至少一个续接观察量检查同分身份的影响，不能只比较无标签面集合。

性能/成本：记录机械检查总时间和证明文件规模，检查器只测选定有界例；不构建 C++、不跑全 CTest/自然矩阵。若新证明工具过重，缩减机械覆盖并记录未证层，不追求工具平台化。

## 9. 必须包含的反例与验收口径

| 风险 | 反例/检查 | 排除的过强结论 |
|---|---|---|
| 完整边界固定 | 圆盘欧拉式的面数奇偶性 | +1 无条件属于严格类 |
| 预算 | 满预算下 +2/−2；回收失败只剩+2 | 终点安全意味着任意前缀/子集安全 |
| 几何 | 局部合法三维补丁穿过远处保留面 | 固定接口自动保证全球无自交 |
| 状态 | ID由提交次序分配并参与下一轮同分比较 | 几何同构自动意味着续接等价 |
| 损失 | $(x+y-3/4)^2$，两个独立字段各自更新 | 核心写不交自动意味单快照证书可组合 |
| 观察 | 共用变化样本重复累计进展；改变可见集/权重 | 单批收益可加或跨视图持续单调 |
| 数值 | 不同浮点求和顺序 | 数学归约交换自动意味位级一致 |
| 原语 | 挂点细分、非凸翻边、link失效折叠 | 所有名字相同的操作均合法 |

验收按命题而非测试数：明确对象和量词、证明链不是循环假设、非 ROAM 实例非空、失败边界可复现、源码对应不漏协调状态、复杂度没有把有限支持当常数。保留未证明项和有限测试上限。

有限脚本每次仅跑冻结夹具，首轮目标总计60秒、最多120秒；Lean新增模块目标5分钟、单次硬上限10分钟。超过上限先记录定位，不通过扩大机器/依赖/实验矩阵撑完；这些是工具资源上限，不是算法理论复杂度。理论困难可以在阶段记录未解决，不受“必须三阶段全做完”驱动。

成本至少保留以下分项，不因预算净额只是一个整数而省略构造费用：

$$
W_{\rm batch}=W_{\rm discover}+W_{\rm select}
+\sum_i(W_{\rm support,i}+W_{\rm certificate,i}+W_{\rm prepare,i})
+W_{\rm conflict}+W_{\rm reduce}+W_{\rm continuation}.
$$

令局部面规模为 $d_i$、完整资源规模为 $f_i=|R_i\cup W_i|$、观察支持规模为 $s_i$；三者分别报告，不相互替代。有界拓扑度数不能推出 $s_i=O(1)$，有限证书也不等于低成本证书。实际发布至少要支付其非空写补丁的输出费用；局部支持可能随折叠端点度数、ROAM完整传播或非局部损失查询增至全网格级。资源索引的构建、身份分配和精确数值位复杂度不隐含为常数。本轮不由读写独立性推导实际 CPU 加速。

文档阶段仅检查链接、公式定界、模型状态与目录边界。没有生产修改，性能回归测试不适用；后续离线工具的新增费用单列，旧生产验证复用，不重跑 QPC-04E 的312机会或历史 Lean 全套。

## 10. 一般性与最终出口

最终必须按下表逐项填“已证／条件成立／不成立／未证”，不能只有一句“很通用”。

| 结论 | 首版预期类别 | 需要单独说明 |
|---|---|---|
| 有限更新交换、整数账本、加权超标单调 | 完全不依赖 ROAM | 读取封闭、更新定义、代数法律、发布规则 |
| 圆盘替换与边界拼接 | 固定接口局部三角化 | 完整边界与连接接口的两类定义 |
| 屏幕/高度实例 | 特定损失实例 | 固定环境、完整样本支持及数值证书 |
| 有限可计算局部证书 | 条件成立 | 任意非负损失并不保证局部证书 |
| 三维自交、最近点/遮挡、全局目标 | 不自动覆盖 | 外部查询可能全局化，需额外证明/费用 |
| 任意拓扑改变和全局最优网格 | 不在范围 | 不以局部圆盘定理暗示支持 |
| 一般贪心自适应求解器 | 仍需算法设计与验证 | P不参与安全证明，未给选择质量或恢复保证 |
| 当前生产实现满足一般前提 | 逐项映射，非自动成立 | 协调、缓存、样本、失败生命周期与新增质量政策 |

**有限正面出口**：具有完整条件链和非 ROAM 构造例，结论可脱离层次/高度场；定位为可复用的资源约束局部三角化事务模型。不得自动开启 C++ 泛化。

**部分成立出口**：代数与资源部分一般，但某些几何或损失只能在更窄类别成立；公布最小充分条件与覆盖矩阵。这个结果也完成本轮问题，不强求全覆盖。

**否定/关闭出口**：总定理只能靠把待证结论作为假设、无法建立具体非 ROAM 实例，或核心“局部”义务在所选实例中必然变成未计费全局工作。关闭对应一般性/局部性主张，保留已成立的子命题；不据此宣布现有生产算法全部失败。

**学术增量单列**：即使所有数学条件成立，若只是既有局部更新/资源不干涉/有限和的直接组合，则注明“可作为算法说明与正确性骨架，未形成独立一般算法创新”。不预支论文竞争力。
