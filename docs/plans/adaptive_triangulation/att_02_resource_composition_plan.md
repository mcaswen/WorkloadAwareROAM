# ATT-02：资源更新、预算与顺序独立小规划

日期：2026-09-17。前置ATT-01已提交`99947ed`；依据[大规划](resource_constrained_transaction_theory_plan.md)自主执行。本阶段不改几何操作或质量政策。

## 1. 目标与模型

从真实键值更新定义推导交换性，不把交换律当事务字段。采用有限读取/写入键列表、键→可缺席值的状态、只接收读取投影的使能函数与写值函数；应用时仅更新写列表中的键。删除是写成缺席，创建前的缺席检查必须在读取列表中。

对独立事务证明：读取投影不变→使能稳定→写值稳定→逐键交换→任意独立批次排列等价。再用有限面键上的0/1存在值导出实际计数变化与整数预算，计数覆盖范围和键唯一性明确列为实例义务。

逻辑身份预定、共享派生状态在屏障后按确定规则恢复。资源定理只给逻辑状态及该确定投影等价，不声称任意物理槽分配等价、C++无数据竞争或低跨度。

## 2. 文件与依赖

- Create `formal/StateTransactions.lean`、`lean-toolchain`：有限资源更新、使能与交换、面存在计数；不导入几何或ROAM。
- Create `formal/BatchSafety.lean`：基于相邻交换的排列、批次应用、整数预算；ATT-03再组合质量。
- Extend `model_derivation.md`：一般证明过程、身份/归约与失败边界，区分机械和纸面。
- Extend `verification.md`及`data/att_02.json`：实际命令、耗时、源码指纹、公理依赖和未证明范围。
- Create 本阶段审查，更新大规划/模块和推导索引。

仅使用现有Lean 4.8.0；构建和日志写`benchmark-output/adaptive-triangulation/att-02/`。不引入mathlib或通用验证平台。小型有限反例可直接放入Lean，不增加第二个检查脚本。

## 3. 实施与核查

1. 定义读取投影/实际更新，证明域外不变和独立读取不变。
2. 证明两个更新交换与使能稳定；用有限相邻交换构造排列证明，不以全排列枚举替代一般证明。
3. 从每个面键的实际旧/新存在位推出整数差，再求和；导出批次望远镜式及独立时冻结净额有效的前提。面键枚举必须无重复并覆盖实际活动/写入面，不能只证明一个任意声明的delta账本。
4. 给出创建、删除、正/负/零净额、缺席谓词冲突、共享计数、次序分配ID和+2/−2预算反例。未知/分配失败不进入成功应用定理。
5. 记录Lean声明/`#print axioms`，没有`sorry/admit`；纸面补充先负后正前缀安全和协调派生状态范围。

## 4. 费用与验收

新证明没有旧同任务基线，记录实际检查时间/输出和文件指纹；单次Lean上限10分钟。局部开发失败可修正后只重查相关模块，成功后不重复历史证明矩阵。生产无变化，不跑CPU或渲染基准。
