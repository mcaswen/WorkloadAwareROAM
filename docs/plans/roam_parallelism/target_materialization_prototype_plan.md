## 1. 要验证的问题与范围

给定同一完整旧状态 M₀、合法目标 J 和完整事件差分 Δ，验证直接物化能否生成与独立顺序参考相同的**可续接状态**，并在有限 CPU 核数下保留值得继续研究的成本空间。

本原型新增独立状态表示、对照执行与验证入口，按[规划规范](../plan_guideline.md)属于大规划；不是直接给 DOD 添加一种执行策略。只拆两个阶段，每阶段有停止条件，实施前另有小规划。本轮一并提供 [MPR-01 小规划](target_materialization_prototype_01_plan.md)，确认后可以先实现它。

阶段范围：

1. MPR-01：单线程完整状态、独立逐菱形参考、直接物化、续接和差分成本核查。
2. MPR-02：仅并行直接物化中已有明确所有权的计算与写入，测量完整事务，保留串行维护成本。

不新增目标选择算法、质量恢复、运行时排序松弛、通用并行树、profiler 或正式实验框架；不接入 GUI、算法注册表、渲染器、GPU 或原生 DOD 写回。旧 CPU-CBT 等实现不恢复。原型通过只支持讨论进一步投入，不代表论文新颖性成立。

## 3. 三方结果契约与计费边界

### 3.1 共同任务

沿用理论报告的固定事务：地形、视图、评分环境、最大深度和轮次冻结，旧状态无在途根请求；I₀、J 均对父事件及同底边伙伴闭合，最终三角形数不超过 B。旧历史 H/K/S/G 完整提供。

独立参考 R：先按深度递减合并 Δ⁻ 至 I₀∩J，再按深度递增细分 Δ⁺ 至 J，同深度以稳定菱形身份排序。逐步修改真实状态，不调用直接物化器。它不重新按分数选择目标，也不强行执行原生 DOD 的部分失败语义。

比较对象：

| 名称 | 行为 | 可以回答什么 |
| --- | --- | --- |
| `reference-serial` | 在原型表示中逐合法菱形执行 R，局部维护状态 | 同一表示、同一任务的顺序成本 |
| `materialize-serial` | 从 Δ 直接准备和应用最终补丁，不重演中间网格 | 直接构造引入/省去了哪些工作 |
| `materialize-parallel` | 与直接串行相同程序和数据结构，只改变允许的执行边界 | 真实线程收益与完整事务成本 |
| 原生 DOD 串行 | 产生自然 J，可能含不同操作历史/停止语义 | 目标发现成本和来源校验；不进入上述等价速度比 |

完整代价分别保留：来源轨迹恢复、DOD 目标发现、差分及合法性认证、旧状态导入/有效键建立、测试副本恢复、目标应用、网格消费、跨轮历史维护。前几项可以在物化微基准外，但必须记录；应用所需支持集枚举、分配、排序、队列维护及发布全部在事务计时内。

### 3.2 输出及后续行为

按稳定身份逐项比较事件/叶集合、活动内部记录、三条叶邻接、父子/伙伴关系、合并资格和代表、两队列全部逻辑条目、H/K/S/G、预算以及 Pending 的旧/新端点。浮点键使用共享评分函数与相同计算顺序；有限值精确比较，非有限值在输入边界拒绝，不用宽容差掩盖队首改变。

随后让两个结果持续经历相同操作：评分/队首检查、合法菱形细分与合并、含强制前置的根请求序列、预算拒绝、跨轮标记失效及网格消费。每步都重新核对，不允许重新导入一个“正确状态”替换被测结果。首版不实现新的全局 greedy 控制器；强制前置测试序列由当前状态查询取得，并在每个原子步前验证资格，不从直接补丁中抄出答案。

物理槽位可通过身份映射不同，既有共同记录须保持可用。原生调试颜色、历史操作统计及内存字节布局不要求一致；它们不进入“完整抽象续接投影”。不能将该投影等价改写为所有生产输出等价。

## 4. 状态与最小数据结构

### 4.1 层次、评分和存储

首版冻结 `0≤H≤20`，覆盖 test129/Peking 已用深度；复用 DOD 根身份 1 与 2³² 及左右孩子编码，输入检查避免溢出或根身份混淆。精确参数域边使用整数网格和固定绕序，不用世界坐标浮点 epsilon 拼边。整数运算范围需在 MPR-01 给出静态检查和最大深度测试。

按身份解码父/子、深度、域和同层伙伴，工作 O(H)；不提前枚举完整潜在层次。几何采样转浮点时遵循原共享二分规则。误差树来自相同只读数据，首次构造、缺失项和视图评分全额登记；缺失误差不得默认为零。

首版用标准有序容器保存身份索引、事件集合、队列和标记；节点记录地址在插入时稳定，叶邻接持有明确记录句柄及身份，删除前修复全部引用。数值槽位独立于逻辑身份；有未确认消费者引用的记录/槽位延迟回收。没有全局紧凑数组要求，也没有自制无锁分配器。

此选择提供差分相关的查询/更新，但**单线程容器维护有串行路径**。首版不实现理论报告中的并行批量平衡树，不能声称已实现其多对数 span。未来若该路径成为瓶颈，只记录当前表示成本，另行 Review 是否值得引入更强结构。

### 4.2 直接物化

```text
共同旧状态 + 已认证差分
→ 生成 FΔ 与 CΔ，判定旧/新叶及活动记录
→ 检查预算，读取旧外部边接口，准备新记录与槽位
→ 新叶边排序连接，按记录归并邻接写入
→ 重算受影响队列条目、更新本轮标记
→ 合成已有 Pending，维护索引/队列/退役义务
→ 独占发布 → 原状态继续增量更新与消费
```

验证器可全量重建目标投影，直接物化热路径不得全量扫描 I₀/J、活动节点、队列、Pending 或潜在域。允许初始化/输入认证做全量工作，但用独立边界和计数记录。补丁不得读取来源副本的最终邻接、队列或物理槽位作为答案。

先完成输入/预算/版本检查，再准备新记录及所需存储，进入独占提交；提交中不允许异常退出后仍返回可用状态。包括容器分配在内的资源异常若无法恢复，首版将该次标为失败并丢弃自有状态，不承诺任意内存不足的强事务回滚；必须保留失败记录，不发布部分状态，不能计入成功样本。

### 4.3 MPR-02 并发所有权

共同旧状态在准备期只读；新增记录在主线程分配完毕，线程只填写各自的固定位置。可并行部分为身份/域解码、局部条目计算、新叶边记录准备及最终互不重叠记录写入。按节点合并多邻接槽位补丁后才派发，每条目标记录只有一个写者。

排序、标准容器增删、槽位分配、全局计数发布和退役先保留串行；均纳入完整计时。线程使用局部统计并在屏障后归并；禁止并发 `push_back`、同一 `std::map` 写入、共享可变评分缓存或抢写邻居整份记录。线程池准备可在统一热身边界，但每次 dispatch、等待和合并不能排除。

这是**有限并行原型**。只加速几何准备、完整事务没有收益时，不得称为成功的 CPU 拓扑加速；也不得称为已否定理论物化结构。

## 6. 输入与可复现测量契约

### 6.1 最小输入

解析夹具覆盖 k=0、边界/内部菱形、多层变化、混合增删、共同叶多个槽位修改、深层合并再细分、历史抑制、同分、预算满/拒绝、未消费更新相消和槽位复用。小深度 H≤3 可枚举全部合法事件集两两比较；大深度用固定构造，不随机搜“漂亮”状态。

自然核查只取既有清单两项：

| 场景 | 资产与尺度 | 目标边界 |
| --- | --- | --- |
| `test129-a-b4096` | 129×129，TerrainSize=30、HeightScale=4、H=14，其他参数读原行 | 轨迹 A，sampleIndex=14 的已评分细分阶段输入及其严格串行输出 |
| `peking547-a-b20000` | 547×547，TerrainSize=80、HeightScale=12、H=20，其他参数读原行 | 同上 |

来自[冻结场景清单](../../parallel-roam/cpu-pilot-scenarios-v1.csv)，相机由既有生成器得到并校验身份。两项只作来源/非 dyadic 兼容检查，不代表覆盖整个工作量空间。若 k=0 或无法导入，保留结果及原因，不为制造工作量调整阈值、预算或改选样本。

DOD 桥接在自有副本上推进原严格阶段产生 J，认证两端共形/闭合及预算；不将来源最终 S/G、队列或槽位塞给直接物化器。旧 Pending 从消费者已持有的槽位/记录与当前活动叶建立规范化映射；若无法取得可靠消费者基线，明确失败，不能清空 Pending。初次导入允许 O(N)，记录其读取和时间。

### 6.2 成本和统计

每行至少记录输入/源码/程序身份、方法、线程请求、N/k/H、Δ⁺/Δ⁻、R/A、FΔ/CΔ、事件查询、边数、候选重算、队列增删、分配/退役记录、Pending 更新、扫描/复制项及分阶段与完整事务时间。完整扫描与 O(log N) 字典查找分列，不把工作计数等同 CPU cycles。

计时分两遍：诊断遍打开逻辑计数、完整验证和实际线程 ID；计时遍关闭全量验证/哈希/细粒度计时及诊断计数，保留固定顶层事务时钟，结束后在计时区外验结果。诊断结果与计时样本按共同身份关联，不能拿错误/不完整结果报告速度。

初始分配、后续重新激活和延迟消费分别保留；不能只测所有目标记录预先缓存好的最快情况。每个计量重复从同一 M₀ 的独立副本开始，恢复成本单列；同一副本重复物化 J 只会测出 k=0，禁止这样累计样本。持续续接测试另作真实状态链，不逐步重新导入。

MPR-02 首轮线程 1/2/4；机器不足四个可用核则按实际范围冻结并报告，不改用超额线程填矩阵。先比参考串行与直接串行，再比直接串行与并行；只报告物化事务速度比，不命名为 DOD 完整 update speedup。标准容器串行维护占比必须同时报告。

独立进程为主要统计单位：一次独立热身进程、五次独立计量进程；方法/版本顺序交替，进程内重复数在实施前固定。每进程中位数/P95、跨进程配对差、绝对差和相对差一起记录。微秒波动或不一致方向记“无可分辨收益”，不无限复测。

## 7. 实施阶段与停止条件

### MPR-01：完整串行原型

先核对状态/来源契约，构造独立参考与全量验证，再实现直接物化及持续续接；只测参考串行和直接串行，详见配套小规划。

验收必须同时满足：合法输入下全部续接投影一致；参考不借用直接补丁；直接路径没有未登记的全域恢复或 split/merge replay；典型/压力构造的 FΔ/CΔ 与实际修改规模满足界，所有运行时费用有边界。性能是否优于参考不是正确性通过条件。

停止：旧状态信息不足、原生来源不属于已声明合法网格族、只能生成最终叶而不能续接、或者直接路径仍靠 replay/全域修复时，先报告具体缺口，不开始多线程。若只是标准容器贵，记录瓶颈，不擅自实现并行树。

**实现情况：** 未开始。基线、后测、报告和审查在实施后回填。

### MPR-02：有限并行与成本出口

以前阶段合法结果为前提，单独编写小规划，冻结可并行边界、线程矩阵及执行证据；扩展现有 Patch、Tests 和 Probe。直接串行与并行共享同一逻辑补丁及串行容器规则。
