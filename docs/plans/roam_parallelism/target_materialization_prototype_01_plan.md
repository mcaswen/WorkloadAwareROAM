# MPR-01：完整串行状态物化原型小规划

> 日期：2026-09-12；状态：MPR-01 已完成，限定任务下正确性、续接、成本与工程核查通过。
> 上位规划：[原型实现大规划](target_materialization_prototype_plan.md)；理论依据：[目标物化报告](../../research/roam_parallelism/target_materialization_gate.md)。
> 本文件与大规划一并获确认，范围仅为 MPR-01；不自动开始 MPR-02。

## 1. 本阶段回答什么

在一个可运行的 C++ 状态表示中，完成同一合法目标的逐菱形应用与直接物化，验证最终结构、持久队列、历史与网格差分一致，并让输出状态真正继续更新。同步记录两种串行方法的工作量和事务成本。

不实现线程并行、并行有序树、目标选择或原生 DOD 写回，不比较“原生 greedy 总时间”和“已经免费知道 J 的物化时间”来宣布加速。即使直接串行更慢，只要结果和成本边界清楚，也可以形成有效阶段结果；是否值得并行另作判断。

## 2. 文件与职责决定

使用大规划第 5 节的文件边界。本阶段实际创建 Types、Hierarchy、State、Reference、Patch、Validation、DodBridge，以及一个测试入口和一个测量入口；只修改 `tests/CMakeLists.txt` 接入。各自职责不得合并进 DOD 的大型拓扑文件。

- Reuse：共享二分几何、采样/评分/误差树、场景与相机、CSV 和时钟。
- Wrap：DodBridge 负责生产状态读取和目标来源，核心状态不依赖 DOD 内存布局。
- Create：新持久表示、独立参考、直接补丁及新表示的独立验证器。
- Extend：测试构建、研究报告/索引和本规划实施记录；不修改生产算法行为。

目标命名：`parallel_roam_materialization_core` 为仅供实验目标链接的库；`parallel_roam_RoamMaterialization_tests` 对应 CTest `RoamMaterialization`；`parallel_roam_materialization_probe` 不注册为性能 CTest。库及可执行文件沿用项目编译选项和警告，不更换依赖版本。

核心库只编译 Hierarchy、State、Reference、Patch；Validation 和 DodBridge 编译到测试/探针，两入口再显式复用 DOD/正式输入源码清单及必要地形/视图文件。这样桥接可依赖 DOD，核心库没有该依赖；每个可执行文件中共享源码只编译一次，不重复链接同一实现，也不将新库加入应用。

初次编译只使用 `relwithdebinfo-fetch` 这一现有配置，启用测试；不构建整个后端矩阵。命名空间为 `ParallelRoam::Experiment::RoamMaterialization`。新公共 C++ 边界摘要按开发规范使用 `<summary>`，行尾及正文长度规则保持，不复用理论 Lean 的注释格式。

## 3. 输入、状态与独立参照

### 3.1 输入认证

`TargetTask` 持有旧逻辑版本/环境身份、完整有方向差分、目标预算和目标集供**外部验证**；直接路径只查询旧事件位与差分覆盖，不遍历完整目标集。认证器独立检查差分完整性、父/伙伴闭合、最大深度、预算和身份范围，返回绑定旧版本的认证结果。认证允许 O(N+kH)，单独计费；状态或环境改变后旧认证失效。

预设合法来源不是绕过检查的理由。非法差分、缺伙伴、孤立孩子、重复冲突方向、超预算或过期认证，均在修改活动结构之前拒绝，源状态保持；内存耗尽的执行失败按大规划声明处理，不计为成功。

### 3.2 完整状态

| 状态族 | 本阶段必须实现的内容 |
| --- | --- |
| 层次/身份 | 两根及二分路径，最大深度 20；精确整数参数域与完整边身份；同层伙伴双向且边界可识别 |
| 节点与活动索引 | 所有活动内部/叶记录、父子引用、同层伙伴；休眠缓存不能冒充活动成员，稳定身份与数值槽位分开 |
| 邻接 | 每片叶三条显式邻接、方向与槽位对应；共同叶仅修改命中的接口，删除前处理悬空引用 |
| 队列 | 细分叶和合并组的全部逻辑条目、当前分数/抑制、稳定破同分；未变化条目保留，不每次全量建堆 |
| 历史/预算 | H/K 不变，S/G 按目标方向取并集；本次不推进轮次，无在途预算预留 |
| Pending/消费 | 最早已消费基线与最新目标的规范化差分，保留旧未消费条目；提供 CPU 逻辑槽位消费者及明确确认点 |

用标准有序容器和稳定记录建立第一版，不自制并发容器。容量增长、分配次数、仍待消费的退役记录和历史缓存纳入报告；旧状态恢复用完整自有副本，复制和重建句柄成本单列，不隐藏在物化初始化之外。

### 3.3 独立顺序参考和验证器

Reference 按理论定义逐菱形合并/细分，使用局部邻接更新和局部队列维护。不得为了简化对照而每次全量重建队列、邻接或故意采用全域扫描；否则会人为抬高串行成本。它可以共享身份、评分和底层状态操作，不能调用 Patch 的 FΔ/CΔ 枚举或边连接程序。

一般合法性沿用理论报告 §2.2：交集保持父/伙伴闭合；待删父的已细分孩子若留在 J，会与父不在 J 矛盾，因此先删深层后可合法删除父组。加入时祖先已经在交集或此前加入，同组共同执行；每步预算先降后升且不超过两端最大值。本阶段既保留该一般论证，也在有限域及运行时逐步检查，不将有限例子替代证明。

Validation 从目标事件集独立枚举完整叶/内部状态，按精确边分组重建期望连接，并检查面积覆盖、绕序、边重数、父/伙伴闭合及预算。检查实际记录指针/槽位对应、完整队列条目和历史，不只比较哈希。其全量计算位于计时外。

静态几何和评分可共同复用，但需另用解析边界/手写小网格检查共享函数的输入组装，避免两个实现共享相同错误。相机冻结时用同一优先级函数；优先级不冒充独立几何质量，本轮不跑质量 Pareto 或恢复评价器矩阵。

## 4. 实施顺序

### 4.1 固定环境和原有路径基线

记录 HEAD、当前源文件差分、编译器/编译选项、CPU/可用核数和电源/后台负载；在修改 C++/CMake 前保存原有运行时探针程序及必要依赖、哈希和一个默认场景基线。已有二进制若与当前生产源码对应且报告条件一致，可复用；不能仅凭文件存在认定对应。

同时冻结输入清单与自然 sampleIndex、下面的解析成本用例、计时次数、诊断集合和停止规则。源码当前还有未提交理论文档，使用源码/差分身份记录，不擅自提交来取得基线。

### 4.2 最小状态、层次和顺序参考

实现根路径、孩子/伙伴、精确边身份及稳定记录；创建可独立运行的 Reference 与 Validation。先通过一次边界细分、内部菱形、多层合并以及历史抑制例子，再制作批量物化。

同时做两个自然输入的导入审计：从已评分细分阶段的只读观察器取得自有 M₀；借用高度图/静态误差时，确保来源生命周期覆盖全部调用。桥接可以复制静态数据，但需记时间和空间。源状态实际活动/邻接/候选语义与固定闭合模型不符时停止该输入并报告，不默默增加目标事件或重写来源状态。

原生网格的 `SlotOwners`、CPU 数据及当前活动叶用于确认消费者基线与 Pending；可在导入中全量规范化，不能在每次物化重新导入。若基线不足以恢复，作为具体接口缺口退出，不用空 Pending 顶替。

### 4.3 直接物化与持续更新

从完整差分生成 FΔ、CΔ，取旧边界接口；直接填写最终活动记录、拼接精确边、更新队列和标记，合成 Pending，最后发布。每次记录事务内扫描量、修改集合和分配量，断言没有逐事件调用 Reference 或生产 split/merge。

在同一输出对象上执行后续操作链，至少跨三个事务和一次轮次变更，包含“删除后重新出现且尚未消费”和“已消费后槽位复用”。原子细分/合并先读取其父子/伙伴/邻接和队列条件，不能每步从 J 全量重建真实状态。

含强制前置的续接例子，按独立手算的局部结构给出应有根目标；运行时读取当前状态确认前置与预算，再通过合法原子步完成。分别核对抑制导致的不执行、预算不够时的明确拒绝和合法完成。此测试覆盖新状态能提供前置查询信息，不宣称复现 DOD 任意部分失败过程。

### 4.4 定向验证、成本和完成自审

只运行第 5 节集合和第 6 节性能协议。回填一份研究报告与本阶段自审，检查文件边界、实验对生产的依赖方向、未计费用和与理论的偏差；未解决的错误不能靠放宽等价字段关闭。

## 5. 正确性验收

| 测试组 | 固定范围和断言 |
| --- | --- |

| Pending 和复用 | 旧非空 Pending、两次更新后才消费、删除后恢复、消费确认后再分配；与直接生成目标 CPU 几何属性一致 |

冷分配与记录复用分别覆盖；全量验证的访问计数不得混进热路径局部计数。主要局部性断言是 `|FΔ|≤3k`、`|CΔ|≤2k` 及范围外逻辑条目不变；有序树操作 O(log N) 读取不误报为全域扫描。

### 6.2 新增路径的串行成本

原型不存在修改前耗时，不虚构前后加速。MPR-01 先建立 `reference-serial` 与 `materialize-serial` 的共同任务基线，供 MPR-02 复用。

固定六项解析成本输入：旧网格分别为均匀深度 8 / 12（512 / 8192 片叶），各取稳定身份最小的 1 / 16 / 128 个内部完整菱形进行细分，故 k 分别为 2 / 32 / 256；H=14，B=20000。选择完整菱形保证合法，不动态挑选计时更快的位置。资产使用 test129 及冻结评分环境；只改研究夹具的合法切割，不称其自然轨迹。再加入两个自然任务，共八项；自然无工作保持无工作。

探针最小接口拟为：

```text
parallel_roam_materialization_probe
  --mode audit|measure
  --method reference-serial|materialize-serial
  --cases mpr-01
  --asset-root <repo>
  --scenario-manifest <frozen-scenarios.csv>
  --camera-manifest <frozen-camera-samples.csv>
  --warmups 5 --repeats 30 --output <new.csv>
```

该入口本阶段尚不存在，参数由探针本地解析，不修改应用 CLI。拒绝未知方法、缺失文件、重复输出和不完整案例，不默默退回其他方法。`audit` 不报告性能胜负；`measure` 不把全量验证、细粒度计时或逻辑计数放进事务时钟。即使缓存未命中，也不得把本次必要几何计算移出时钟。

每种方法一次独立热身进程、五次独立计量进程，外部按 AB/BA 交替。每进程各输入 5 次内部热身、30 次计量；每次都从共同 M₀ 的新副本开始，复制/句柄恢复单列。不要把 150 次内部重复说成 150 个独立统计样本。单次太短时只报告不可分辨，不临时增加重复次数寻找正结果。

记录一次完整事务时钟和诊断遍的步骤分解、逻辑工作/分配/Pending 规模、峰值持有记录、消费及跨轮复制成本。阶段前比较约定固定，不按结果增删指标。给出完整结果表，不要求出现正速度比，不从串行测量外推真实并行加速。

### 7.1 实施结果
