## 1. 问题与准入目标

研究：给定完整旧状态 M₀、其细分事件集 I₀，以及同一规则二叉三角层次中的合法目标 J，能否直接物化差分，得到完整且可继续增量更新的状态 S_J，而不逐项重演细分/合并历史？

核心义务是**可续接状态局部性**：最终叶和邻接正确之后，后续评分、队列选择、细分、合并及必要索引维护所读取的行为相关状态，也能在差分控制的范围内恢复。只输出合法三角形网格不足以通过。

本规划允许提出纸面物化算法、抽象状态表示与证明；这正是前一 PCSG 范围之外、此次单独提请确认的工作。PCSG 的原出口保持，不将其范围内未完成误写成物化算法不可能。本阶段不以得到新算法、低 span 或正性能作为预设结论。

最终交付限于一份研究报告、必要时至多两份 Lean 源文件及完成自审。不建立 C++ 原型、分析器、通用证明框架、CLI、CSV、性能采集平台或新运行时模块；不恢复 CPU-CBT、排序松弛 Gate、activation-spectrum、recourse 或 GPU 实现。

## 3. 输入、输出与续接语义

### 3.1 固定对象与输入信息

采用固定正方形参数域、两个根三角形、底边中点二分、最大深度 H 的网格族。I₀ 和 J 都满足祖先与菱形兼容性约束，且只包含允许执行的事件；本轮同时覆盖细分和合并，**不要求 I₀⊆J**。旧 split-only 证明不能未经核对整体搬用。

\[
\Delta=I_0\triangle J,\qquad k=|\Delta|.
\]

抽象输入写为 `(M₀, J, Δ 的可枚举表示, 环境与阶段边界, B)`。差分中的每项注明加入或移除；它是目标信息，不是按时间排序的操作轨迹。需要核对完整性、去重和目标合法性前提；若这些由调用方保证，记录证书来源和成本，不能给并行一方免费信息。

分别计费：

\[
W_{\rm total}=W_{\rm discover}+W_{\rm diff/certify}+W_{\rm materialize}+W_{\rm consumer}.
\]

时间也保留相应前后依赖，不能只把工作量相加后当作墙钟。普通独立数组的差分发现可能需要全扫描；结构共享、版本或哈希证书必须说明持有与维护条件，不能默认存在。严格 greedy 目标若仍通过串行模拟取得，该模拟工作/span 全额保留。物化通过不等于严格目标选择已并行化。

地形、层次规则、最大深度及当前评分环境在一次物化事务内冻结。首次几何误差构造、身份解码和域坐标生成有明确成本。相机变化引发的全量旧优先级刷新另列为公共评分工作；不能以只刷新变化叶冒充所有分数都已更新。

### 3.2 选定的比较边界

拟采用**独立目标应用事务的完成边界**：入口旧状态无在途修改；目标应用完成后，允许开始下一次声明合法的评分、选队首、细分或合并。它不处在一个尚未完成的严格 greedy 根请求内部，不承诺恢复该根请求的临时预算预留或重试栈。

MAT-01 先给出与物化程序独立的顺序规格：固定目标应用、明确的阶段转移规则和后续操作集合。定义逻辑状态投影及关系 `S_a ≈ S_b`，至少包含事件/叶集合、叶邻接、行为必需的内部关系、活动成员、队列资格与排序键、预算和迟滞状态。证明义务为：

\[
S_J\approx S_{\rm specification},\qquad
S_a\approx S_b\Rightarrow
\operatorname{Step}(S_a,u)\approx\operatorname{Step}(S_b,u),
\]

其中 u 遍历契约中的合法下一操作；同时要求可执行前提、逻辑输出、停止/失败结果一致。通过单步保持再推导有限续接序列，不以几次运行成功替代一般论证。评分后取队首使用同一优先级与稳定身份破同分规则。

允许活动数组次序、堆的内部形状、内存地址和物理槽位不同；但若某消费者依赖这些次序决定逻辑行为，就不能简单排除。不能先定义 `S_spec=物化输出` 再声称等价。

阶段清理只能依据双方共有的边界规则。迟滞集合保留旧帧还是转为 J、blocked 标记何时失效、预算余额如何形成，都须在 MAT-01 冻结。若相同 M₀、J 和阶段信息仍对应不同的未来行为，应给出反例并指出缺少的最小信息；不通过额外输入整个历史或清空行为状态挽救契约。需要增加行为证书或改变边界时，先报告并提请 Review。

## 4. 待证明的物化结构

### 4.1 叶差分局部性

拟证明一般命题，而不只列例子：

\[
L(I)=\{t:(\operatorname{root}(t)\lor\operatorname{parent}(t)\in I)\land t\notin I\},
\]
\[
L(I_0)\triangle L(J)\subseteq\Delta\cup\operatorname{children}(\Delta),
\qquad |L(I_0)\triangle L(J)|\le3k.
\]

从候选集合分别判定旧/新叶资格，生成删除集合 R 和新增集合 A；最深层只可成为叶，不产生非法细分。证明与操作重演顺序无关；3k 只是上界，不要求紧界。

### 4.2 变化区域与邻接恢复

拟证明 R、A 覆盖同一几何变化区域；共同叶内部不被补丁改动。以旧邻接取得 R 与未变化叶之间的外部接口，新叶边与接口按精确参数域边身份连接。

证明重点是：两端均严格共形且保留叶几何不变时，外部接口可以逐完整边继承，无需沿邻居继续细分。给出内部新边配对、外部接口唯一匹配、域边界单侧边、双向邻接及定向槽位的正确性论证。若成立，外部槽位数不超过 3|R|；顶点接触不能误当共边。

排序/分组只需处理 O(k) 条边；同一外部节点的多条修改先归并为一份记录。优先采用确定性边连接作为纸面方案，不并行写同一节点的整份记录，不为输出补丁额外计算连通分量。共享顶点的高度/属性规则保持固定；讨论的是严格参数域共形，不新增 stitching 或过渡三角形。

### 4.3 可续接状态与发布

物化顺序候选为：

```text
差分与输入证书 → 变化叶/内部状态 → 槽位批量分配与节点准备
→ 内部/外部连接 → 活动与候选差分 → 队列、预算和阶段状态
→ 一致发布 → 下一次评分/选择/细分/合并及增量网格消费
```

所有箭头代表待计费的数据依赖，不把每个框当作常数原语。内部父节点、合并菱形资格及历史状态的恢复须由第 3.3 节逐项推导；不能把尚未解决的部分总称为“最终维护”后设成 O(k)。

拟使用复用旧存储、私有准备与独占更新屏障；本轮不研究任意并发读者的无锁发布。最终叶数为 `N_J=N₀−|R|+|A|`，发布前检查 `N_J≤B`，发布后无悬空邻接、失效队列或残留预留。私有准备空间、节点分配与回收另计；原子切换描述符不意味着补丁写入成本为 O(1)。同时细分与合并时不发布临时超预算的网格。

## 5. 工作量、span 与空间账本

N 表示旧/新已维护状态及索引的规模上界，n 表示完整潜在事件域，H 表示层次深度；不得混用。k 为唯一事件差分，不是根请求数或历史操作次数。若只提供压缩差分，还须计入展开成必要输出的成本。

为每个步骤列工作量与 span，显式保留受影响队列条目数 r、辅助祖先/缓存更新数 a、存储搬移/回收量 g。只有推导出 r、a、g 与 k、H 的关系之后，才能消去这些参数。小范围写入不等于小范围读取；找到影响集合的搜索也必须计费。

可能争取的结果形状是 `O(kH+k log(k+1)+k log(1+N/k))` 工作量和深度/多对数级 span；它们**不是前提或验收时默认成立的公式**。若使用批量有序集合，需说明已排序更新输入的取得、查询接口、确定性/期望界、结构共享及内存模型。不得把一般有序集合的性质直接当成当前二叉堆或整个物化程序的性质。

还须报告：首次建立身份索引/静态缓存的时间与空间、每次增量维护、保留历史节点的累计空间及必要回收。不能将未来评分或下一次弹队首承担的补偿扫描隐藏为本次零成本。O(kH) 可以是有意义的结果，但必须说明其在 `k≪N` 时的适用区间；k=0、k 与 N 同阶、H 可变及固定字长分别处理。

span 是选定纸面算法的上界，不是所有 ROAM 算法的必要关键路径。不从串行 trace 制造依赖。使用标准调度界时单列处理器模型与调度成本；本轮不声称现有线程池、缓存或真实 CPU 达到该界。

## 8. 实施顺序与停止条件

### MAT-01：先审计可续接状态和已有机制

**验证/停止：** 若输出行为由输入不能确定，给出同输入不同续接的反例；若某字段必须全域恢复，区分算法必要性、当前表示限制和尚未找到局部方法。已有工作本质覆盖时记录对应。上述问题未解决则提前完成报告，不为保持探索进度自动增加证书、删减续接操作或扩大算法族。

### MAT-02：叶与邻接的纸面一般证明

推导第 4.1/4.2 节命题，给出直接枚举、边连接和槽位所有权的伪代码及计数来源。重点检查细分/合并混合、多层变化与外部保留叶，不只展示一次菱形细分。

**验证/停止：** 任意局部匹配需要追踪历史或继续全局搜索时，写出具体反例及修正成本；不把最终网格合法当成邻接生成算法已经证明。叶/邻接成立但续接未成立时，仅保存局部成果，不判完整物化通过。

### MAT-03：续接局部性、具体程序与完整成本

按字段表证明影响集合的大小及其可枚举性，给出内部关系、活动索引、候选、队列、阶段状态和网格消费记录的完整恢复步骤。对声明的下一操作证明前提、结果及状态关系保持。处理批量数据结构的排序/查询/生命周期，并推导工作量、span、额外空间和跨调用成本。

**验证/停止：** 不能用“完整状态由 J 决定”替代计算过程；不能用无步骤的 `W_state` 或 `D_state` 补空。若只剩依赖全域扫描、逐项历史重演或长串行维护的方案，给出限定模型/表示下的原因，停止本候选；未找到算法不等于证明所有物化算法不可能。

### MAT-04：必要机械检查与出口

仅在 MAT-03 已形成实质一般证明后，选择最容易发生逻辑错误的有限层次/状态命题做 Lean 检查。优先检查续接关系或其关键支持集引理；若只机械检查 3k 界，明确其不能替代续接证明。几何对应、外部数据结构界和具体内存模型可保留纸面证明，但每项必须标出验证层级。

## 9. 验证、性能边界与阶段出口

定向纸面反例/边界覆盖：k=0；根和域边界；最大深度；只有细分、只有合并、不同区域混合变化；多层变化但远处叶保持；同一保留节点多个邻接槽位变化；深层合并后再次细分；同分队首与菱形代表；迟滞区间和代际失效；预算恰好满、拒绝超预算目标；槽位复用与休眠节点；视图变化但 k=0 的全量评分成本。可以复用必要依赖审计的纸面例子，不重跑其 C++ 实验。

有限例子用于发现反例，一般局部性和续接保持须有一般证明。不能以哈希相同、一次 split 成功或截图无裂缝代替输出/状态对应。非法目标只用于确认前提边界，不伪装成合法输入的反例。

本轮无生产代码、构建或运行配置变化，**运行时性能前后对照不适用**；符号工作量/span 是研究对象，Lean 耗时只是验证工具开销。不开 CTest、后端矩阵、自然轨迹或新 profiler。将来另行批准原型后，按[开发规范](../../standards/development_guidelines.md)冻结必要性能基线与前后报告，并遵守非冗余测试和工程退化处置要求。

**通过：** 所声明网格族和阶段边界内，叶、邻接与全部行为相关续接状态的恢复均有具体算法及一般证明；读取、写入、查询、空间和跨调用成本完整；在明确的非空参数区间内，成本受差分/深度控制且相较逐项参考具有非平凡 span 改善。直接相关文献没有已经明确覆盖所声称的新增机制，并精确写出尚需核实的新颖性边界。通过只允许讨论下一份原型规划，不自动授权 C++ 或宣称端到端严格 ROAM 加速。
