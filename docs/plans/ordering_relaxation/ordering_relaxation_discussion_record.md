## 3. 已形成的核心共识

> 拓扑合法性和三角形预算属于硬约束，不参与性能交换；严格 greedy 排序可以放松，但由此产生的代价必须通过独立于调度评分的参考地形几何质量指标测量。离线 Gate 首先刻画不同质量预算下能够释放多少可行独立工作以及模型估计的执行收益，不预设视觉不可感知阈值。严格串行 greedy 是执行与质量比较基线，不自动视为独立几何指标下的全局最优解。

选择的是允许明确几何损失的第三层，而非继续要求所有策略产生同一网格。以下三层不能混写：

1. 相同网格及后续状态语义。
2. 不同网格、相同几何质量目标。
3. 不同网格、允许明确且独立测量的几何质量变化。

第三层仍不允许裂缝、无效邻接、非法覆盖或预算超限。独立误差降低时记录负的差值，不截断为零，不将其视为异常。

本 Gate 要检验的候选假设是：在严格保持拓扑合法性和硬三角形预算的条件下，有限放松 ROAM 式 greedy refinement ordering，是否能够以较小且独立可测量的几何质量代价，显著增加共享内存 CPU 上可利用的独立拓扑工作，同时不过度增加总工作量。这里记录候选假设，不替换原研究问题。

## 4. 区分优先级、质量和执行策略

- `P`：调度优先级及其比较规则。
- `E`：相对参考地形计算的独立几何误差。
- `S`：严格串行执行策略，包括同分顺序、动态候选、合并优先、预算交换、失败和停止语义。

原始 ROAM 的最优性结论具有特定网格空间和单调优先级等前提。当前项目不能直接继承该结论。`S` 的结果称为“严格串行基线”，不称为 `quality optimum` 或几何质量 oracle。

参考地形、`S` 产生的网格和排序松弛产生的网格三者独立。两种结果都与参考地形比较。调度器不能读取离线质量评价、未来相机、严格结果或其他变体结果来选择本批候选；若未来需要这些信息，必须另立可实现的方法并计算成本。

## 5. 几何质量的数学语义

**用户最终决定（2026-09-11）：`Primary reference = raw height samples + bilinear interpolation`。GATE-02 最小参考校准通过，主参考已确定；完整质量评价能力按需暂停，不作为 GATE-03 最小筛查的前置阻塞。** 原始解码、归一化、边界和投影继续沿用已冻结规则，不因后续实验结果改换参考。该决定不等于连续误差证明或完整质量评价验收。

2026-09-11 经用户确认，primary reference 改为原始 height samples 与冻结双线性插值规则定义的连续高度场。它是实验参考曲面，不代表未采样真实地貌，也不由被测 ROAM 网格定义。`TerrainMeshBuilder` 固定对角线三角曲面保留为首轮 reference-mismatch 证据；最细 ROAM 表示只作可选 secondary diagnostic。

每个原始 cell 内，以局部坐标 `(s,t)` 对四角归一化高度计算 `h_*=(1-s)(1-t)h00+s(1-t)h10+(1-s)t h01+st h11`。原始解码、归一化、边界及世界映射规则冻结于 [GATE-02 单项修订](gate_02_mesh_quality_evaluation_plan.md#8-双线性主参考与单项重跑修订)。

对地形域位置 `q`，记参考位置为 `X_*(q)`、被测网格的对应位置为 `X_M(q)`，固定相机和分辨率的像素投影为 `π_c`：

\[
e_{\mathrm{px}}(q;M,c)=\|\pi_c(X_M(q))-\pi_c(X_*(q))\|_2.
\]

主要质量指标为参考地形落入视锥的固定域 `D_c` 上的最大屏幕几何偏移：

\[
E_{\max}^{\mathrm{screen}}(M,c)=\sup_{q\in D_c}e_{\mathrm{px}}(q;M,c).
\]

域不能随被测网格的可见性变化。原始屏幕几何失真定义见[ROAM 第 6.2 节](https://www.classes.cs.uchicago.edu/archive/2003/fall/23700/docs/roam.pdf)。该指标不完整覆盖颜色、法线、光照和遮挡变化，不据此宣称感知质量保证。

辅助指标分开报告，不合成综合分数：

| 指标 | 建议评价域与解释 |
| --- | --- |
| 屏幕 RMS | 参考图像可见地形像素等权；用参考曲面的像素对应点评价被测网格的几何位移 |
| 最大高度误差 `H_max` | 固定完整地形域及统一世界单位，相机无关；不能只评价当前视锥 |
| 实际三角形数量与利用率 | `N`、`U=N/B` 和剩余预算，描述资源使用 |

屏幕 RMS 的建议定义为：对参考地形像素集合 `Ω_c`，由参考曲面确定对应域点 `q_c(p)`，计算

\[
E_{\mathrm{RMS}}^{\mathrm{screen}}
=\sqrt{|\Omega_c|^{-1}\sum_{p\in\Omega_c}e_{\mathrm{px}}(q_c(p);M,c)^2}.
\]

不能对每个被测网格各自选一套可见像素。近裁剪、投影不可定义、参考无可见像素和覆盖缺失必须有独立状态，不能静默删点或记为零；具体处理见 Gate 规划。

绝对 `E_max`、RMS 和高度误差继续相对独立双线性 source 报告；未来 RMS 的参考像素对应点也必须来自该曲面，不能沿用旧三角曲面的射线交点。增加逐点超额退化 `D_max(R,S)=sup_{q∈D_c}(e_R(q)-e_S(q))`，实际有限采样字段为 `sampledPointwiseExcessMaxPx`。两侧使用同一参考、相机、域和公共样本，保留符号；异常样本不能静默删除，没有配对结果时不能填零。

`D_max` 用来发现共同全局峰值之外的局部退化，不等于两个全局最大值相减，也不替代绝对质量或保证表示误差被代数消去。最细三角网格对双线性曲面的有限逼近残差允许非零；仅因其与研究质量变化同量级，不再自动判定参考失效。先完成 test129/DOD/sample5 的 k=0；随后经用户明确授权，完成同一输出 k=1/2 和 Peking/DOD/sample9 的单项 k=0，具体见小规划第 9 节，不实施配对 `D_max` 或 RMS。

新增有限证据：test129 三层屏幕/高度最大值与最大位置相同，满足冻结的经验稳定条件；Peking 的 547×547 原始 16-bit 灰度图与深度 20 网格不整齐对齐，但 k=0 查询无异常、原始 source/相机核算吻合，屏幕 sampled maximum 约 0.036424 px。后者仅支持本输入首层表现正常，不证明 Peking 收敛或所有非二次幂输入成立，也不以跨资产像素大小比较算法优劣。原研究问题保持不变。

## 6. 质量预算与资源公平性

比较形式可以保留：

\[
E(M_{\mathrm{relaxed}})\le(1+\varepsilon)E(M_S)+\delta_{\mathrm{px}}.
\]

这表示相对严格基线的操作点，不证明该结果具有足够的绝对质量。串行误差接近零时不只使用比例。`+0.1 / +0.25 / +0.5 / +1 px` 是可报告的质量预算候选，不是已确认验收阈值，更不是视觉不可感知阈值。评估精度参数 `η` 与质量预算分别管理。

同一预算上限不足以分离质量变化来源。需要同时报告同上限结果和接近同实际数量的结果；无法匹配时保留缺口，不跨相机、地形或未经说明的参数匹配。

预算利用率下降可能是排序松弛的真实代价。剩余预算应区分阈值已满足、操作粒度、闭包成本、保守预留、提前停止和失败等原因。不能事后把任意缺口归为“不可避免的 `ΔB`”，也不能为了凑数量额外细分后仍声称只改变了排序。

## 7. 采样误差与数学保证

当前 Gate 接受高密度离线评价，主要字段必须明确为 `sampled/observed maximum`。有限点集最大值不是连续域最大值，不能只采被测网格顶点。

建议正式指标使用由参考几何和相机确定的公共嵌套采样序列，保留各级结果与样本身份。两轮最大值变化小于 `η` 仅是经验稳定证据，不排除漏掉窄峰。需要预定的全域加密和代表性高误差变化场景敏感性检查。

若使用被测误差驱动的局部加密，应作为补充检查，或将各配置触发的位置汇合后统一重评并明确其共同自适应性质，不能仍称为严格算法无关采样。

以后可以通过保守上界、带误差界的评估器或算法不变量证明讨论数学保证；不要求当前 Gate 提前完成。离线重型评价不进入生产时间，但运行时用于保证质量的任何检查都必须计时。[CGAL 的采样距离与有界误差距离接口](https://doc.cgal.org/latest/Polygon_mesh_processing/group__PMP__distance__grp.html)可作为保证层次的参考，不代表决定引入该依赖。

## 8. 排序松弛必须具有明确参数

排序松弛首先扩大当前状态下“允许考虑”的候选集合，不直接代表质量损失，也不直接决定有效批次。

细分优先级带是首个建议家族。最高优先级为正时：

\[
C_\alpha(S_j)=\{t\in C(S_j):P(t;S_j)\ge(1-\alpha)P_{\max}(S_j)\},\quad\alpha\in[0,1].
\]

归一化排名窗口是另一个候选：

\[
K(\rho,S_j)=1+\lfloor\rho(|C(S_j)|-1)\rfloor,\quad\rho\in[0,1].
\]

前者限制分数相对差，后者限制当前候选比例。二者不等价。同一参数会得到不同实际窗口，必须记录候选数、窗口占比、分数范围及限制原因。

零松弛显式复现 `S` 的下一步和停止语义；不能把优先级带中全部同分项自动视为零松弛。参数连续可调，但有限候选集合呈阶梯变化是正常现象。正松弛同分、浮点边界、非正优先级和无候选都需有确定行为。

排序松弛与批次选择是两个变量：`C_λ(S_j)` 只规定允许集合，`B_j=F(C_λ(S_j),S_j)` 才是选择器在依赖和资源约束下找到的批次。首版固定确定性 greedy selector，扫描 `λ` 时不更换选择器、候选检查上限或批次容量；结果称为“当前选择器找到的可行批次”，不称该松弛级别的最大并行度。

少量小状态在有必要时做有上限的选择器质量审计，对同一候选子集搜索更强结果，判断 greedy 是否明显低估潜力。已知所有成员均与必选头请求冲突时，无须再穷举证明单根批宽。审计不回填主变体或扩充参数矩阵；即使穷举完成，最优性也仅针对声明的有限子集和依赖/资源模型。

首版只放松细分根请求之间的排序。合并仍按 `S` 执行，原阶段先后、预算交换、迟滞和停止规则保持；不同时研究合并排序、跨阶段重排或两侧批处理。窗口、选择器和失败处理的具体协议见[实施规划](ordering_relaxation_offline_gate_plan.md)。

首版还要求批次包含严格头请求，因此是 **head-preserving bounded relaxation**。头闭包可能阻挡其他本可共同处理的请求；当前方案不会观察“先跳过头请求”的机会。本轮不增加跳头矩阵，负结果只能说明这个受限方案未显示足够机会，不能推出一般排序松弛无价值。

## 9. 批次的信息边界

\[
B_j=F(C_\lambda(S_j),S_j),\qquad S_{j+1}=G(S_j,B_j,\sigma_j).
\]

`S_j` 是完整的批次开始状态；`F` 构造批次；`G` 以规定顺序应用已封闭批次。构造期间只读 `S_j`。为了分析一个请求的必要闭包，可以在该快照的独立工作副本上执行共享操作逻辑；副本演化不得影响其他请求的构造输入。

必须保持：

1. 资格、闭包、读写冲突与联合资源预留基于同一 `S_j`。
2. A 完成后才合法或才生成的 B 不属于同一独立批次。
3. A 的必要内部依赖可以归入 A 的闭包，但不能再计为与 A 并行的独立根任务。
4. 单线程顺序应用成功不等于可以并行；缺少依赖证据的操作标为未知。
5. 批内禁止扩充成员。计划失效、追加前置操作和串行回退如实记录，不继续计作原独立批次。
6. 空间独立不代表资源独立；预算、节点分配和共享队列维护均需明确可实现的处理边界及成本。
7. 固定集合内部的依赖阶段可以另建模型，但不能把多个波次合并为同一批宽。

首版采用不相交读写足迹的保守独立模型，直接拒绝共享强制闭包和未分离的协调依赖。已验证集合表示逻辑内核独立机会的保守下界；未被接受不等于不存在其他可实现方法。大量 `shared_forced_closure` / `coordinator_dependency` 拒绝应优先解释为模型边界，不当作一般 constrained bulk refinement 的否定证据。本 Gate 不实现可交换共享写或闭包去重。

小批次增加排列审计：从同一 `S_j` 分别应用预定排列，按逻辑标识比较拓扑、三角形数量、预算、有效队列及新候选、每个根的闭包结果和停止语义。数组下标不同不算逻辑差异；会改变后续执行的状态不能被规范化掉。排列间逻辑结果不同，或某一排列失去合法性，应撤销该集合的独立批次资格并调查依赖或控制约束漏项。按一个顺序可执行、或有限排列均相同，都不能代替完整依赖论证；这是一项依赖模型健全性检查，不是一般并发正确性证明。

## 10. 离线 Gate 的能力边界

原串行 trace 只描述已经发生的执行路径。重新排列 trace 不能生成另一种排序下的新候选、状态和最终质量。必须从同一初始状态执行单线程反事实变体，保持状态真实演化。

Gate 区分三层结果：

| 层次 | 名称与边界 |
| --- | --- |
| 当前选择器在候选及依赖模型下找到的集合 | 可行批宽与可独立工作，不称最大独立集合或整个算法的理论并行上限 |
| 根据任务工作量、依赖和串行维护计算 | 模型估计的执行收益；假设、额外工作和未建模成本显式列出 |
| 真正多核实现的完整更新时间 | 实测加速；当前离线 Gate 不提供此结论 |

参数扫描研究 `λ → (ΔE, 可行独立工作, 总工作量)`；Pareto 图以实际质量代价与模型估计的执行收益为轴，参数只标记配置。前沿仅属于已探索的配置、选择器与输入。只有未来完成多核实现并测量完整墙钟更新时间，才可报告 `Speedup=T_serial/T_parallel`；离线模型字段和图表不使用无修饰的“更新时间收益”或“加速比”。

正确性依赖足迹与成本观测是两种需求：前者必须保守完整地覆盖唯一逻辑资源 `R/W` 集合，后者只需足以识别明显额外工作的粗计数。首版分别报告 `W_root`、实际基础操作 `W_primitive`（附尝试与失败数量）、节点创建/邻接更新/队列操作等 `W_coarse`，保留闭包长度、串行维护和部分成功。去重足迹大小不能命名为访问次数；精确 `W_touch` 不再是 Gate 前置要求，不为统计每次字段读取大规模改造 accessor。相对 `S` 的额外工作仍分口径报告，不能只用根数或微秒噪声计时。

每批尽量为未入批候选记录唯一主阻塞原因及已观察到的附加原因，区分窗口外、读写/写写冲突、共享闭包、预算、分配、未解决前置依赖、未知依赖和工具容量限制。`RejectReasonDistribution(λ)` 必须附分母与检查覆盖；重复出现在多批的同一候选是多次暴露记录，不是独立样本。窗口缩小导致的分母变化不能被解读为结构冲突减少。

进入正式算法设计的正向建议，需要同时观察 `ΔE_max`、`U=N/B`、`W_feasible` 和相对严格执行的 `W_extra`，结合模型关键路径和负载不均衡；批宽变大本身不构成通过依据。独立工作同时与同操作能力的严格前缀对照比较。若在当前 **head-preserving + disjoint-footprint** 模型内没有足够机会、或已测代价抵消潜力，可以提前停止该模型的投入；未测质量等维度明确留空，不要求先做完完整 Pareto。保守模型限制、证据不足和观测到的代价分别记录，不能将停止当前投入写成否定一般排序松弛，也不自动扩样或改规则寻找正结果。

## 11. 时间稳定性与推广范围

逐帧误差能够暴露积累和滞后，但不能完整评价 popping。正式实验阶段可增加拓扑更替、细分/合并突变、误差尖峰分位数与近似残差的时间变化。操作数量只描述行为，不直接等于视觉跳变。

当前单阶段、同初态 Gate 不证明连续轨迹质量或自适应切换收益。未来连续轨迹实验必须让各策略维护自己的历史状态，不能每帧重置到串行结果后宣称没有长期代价。

CPU 本身可以作为共享内存不规则更新的研究对象，使用视图相关几何误差并不改变执行平台定位。但只验证 ROAM 时，应限定在这种层次网格更新问题上，不自动推广到所有科学计算网格。

## 13. 下一步与状态

2026-09-11 用户评审结论为“方向通过，实施前小幅收紧”。本轮已将窗口与选择器分离、排列审计、细分限定范围、离线措辞、多口径工作量、阻塞原因和联合投入判据同步到 Gate 规划；研究契约不再继续扩展理论范围。实现前由相应小规划明确访问覆盖、逻辑等价、采样精度和有上限的审计协议。

现有公共采样与独立 evaluator 设计足以支撑本 Gate，目标是公平、算法无关、可重复，并对明显局部尖峰敏感；不扩成严格连续误差证明、感知模型或完整时间稳定性项目。下一步按数据验证候选假设，不实施正式多核拓扑算法，不恢复 PREP-06，不开启 GPU/CBT 路线。

后续评审进一步明确：**大规划是最大范围，不是必须全部实现的任务清单。** GATE-01 先检查依赖能否以局部改动可靠获得，GATE-02 先校准参考，GATE-03 用解析夹具、锚点及 3 个自然工作量代表运行 `α=0/0.1/0.25/1` 与严格前缀。若已足以停止当前模型，不建设 GATE-04/05 的批量工具。每阶段设投入上限和停止条件；不以长期可维护性或平台完整度为先导目标。

自然输入改为基于 P5 已有执行前队列规模、活动数量和预算压力分层，保留原特征与输入身份；取消最早/最晚帧选择。新闭包复杂度未在旧记录中冻结，只用于解释，不回填初始选样。精确字段级成本计数和更强选择器只在已有信号确实需要时再议，不作为取得第一批数据的前置工程。

本记录不宣称已经存在质量—并行度有利区间，不修改原研究假设，不改写 P5 统计或排除规则，也不把新 Gate 的潜在成功视为已经决定转向。
