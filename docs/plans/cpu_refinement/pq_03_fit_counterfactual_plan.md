# PQ-03：固定拓扑下的单自由高度拟合反事实诊断

2026-09-15；小规划，修改前基线 `64e478a`。用户已确认实施，现已完成诊断、结果与审查闭环。PQ-02保持关闭，不回填为质量修复；本阶段按任务已有授权独立提交，后续小规划另行承接。

## 1. 问题、目标与分阶段判断

PQ-02 的 frame7 / sample26 / exchange0，E 接收根 `-99` 为 q2 提供约0.01px的当前可见改善。当前一维 `Fit` 在满足旧见证误差减0.01px的约束后，选择最接近零的高度增量；还不知道当前提案是否存在显著更好的、可被相同认证接受的高度。

本阶段只回答：**相同旧状态、连接、自由变量和可见样本下，当前选值留下多少可认证的改善空间？** 区分“选值只取最低收益”“当前保守拟合模型限制”“数值或预算不足，尚不能判断”。不预设某个新高度一定更好。

形状恢复另列为后续 PQ-04：先补 AB 相邻侧的坏角，再在冻结局部范围内调查恢复操作。本阶段不翻边、不扩大补丁、不增加生产原语。原因是固定UV/连接时，改变高度不会消除已经证明的参数域最小角阻塞；两项机制应分别归因。

前置阅读：[开发规范](../../standards/development_guidelines.md)、[规划规范](../plan_guideline.md)、[PQ-02规划](pq_02_residual_provenance_plan.md)、[代码事实](../../codebase/cpu_refinement/pq_02_residual_provenance_facts.md)、[结果](../../research/cpu_refinement/pq_02_residual_provenance_results.md)、[审查](../../reviews/cpu_refinement/pq_02_residual_provenance_review.md)。已扫描 `TransactionalCertification`、`TransactionalProposalEvidence`、`TransactionalProposals`、`TransactionalSamples`、原追溯探针、归约脚本及测试目标。

## 2. 冻结输入、目标函数与数值口径

### 2.1 唯一自然主样本

- PQ-02 B 的 Peking547²、尺度80/12、深度20、预算50000、阈值.25/.10、前缀160、8线程、1280×720、NO；`PreserveSurvivingHeights=true`，`HeightGuard=false`。
- 24帧相机、种子与实际主轨迹保持不变，不增加恢复轮次；只在原 frame7 批次已冻结、应用前执行一次只读诊断。
- 唯一被优化的提案是接收根 `-99` 的实际第三个E；支持面599、`-99`，新点 `-828436`，UV=(0.96875,0.96875)，初高1.640409588813782，原拟合高1.647886036568396，源高约1.738946269169146。
- 原可见样本7056、非零系数样本6953、目标1.724469px及完整提案身份先复现。q2沿用原冻结完整UV；frame15/返回视图仅用于报告，不参与选值。
- frame6不另做优化或回放分支；它仍是已经成立的离屏退化证据。本轮结果不得扩大成frame6问题也被解决。

### 2.2 同任务比较

设新点初高为 `h0`，原一维拟合完成约束交集后得到增量区间 `[l,u]`；换算实际高度区间为 `I0=[h0+l,h0+u]`。旧点的UV/高度、所有新面连接、可见样本及原接受目标 `τ0` 均固定。

在同一个 `I0` 内比较：

| 方案 | 选值与职责 |
|---|---|
| 原选值 | `h0+clamp(0,l,u)`，严格复现当前代码 |
| 源高度接近选值 | 将新点双线性源高度投影到 `I0`；仅代表几何来源偏好，不称质量最优 |
| 保守模型最小阈值选值 | 在原一维约束族内搜索最低可行误差阈值，始终与 `I0` 相交；最终候选仍须通过原认证 |

源高度偏好与误差最小化不能合并。主要质量目标是**同一认证补丁所有可见样本的最大屏幕误差**；不以单个 q2 的误差替代它，不用全局最大值掩盖局部变化。

每个候选分别报告：新高度/增量、与源高度距离、认证补丁最大误差上下界、原 `Measure/Accepts` 结果、q2当前误差、q2固定frame15/返回投影，以及完整闭补丁样本的高度误差和逐点超额。不可见投影继续单列；不据此宣称跨视图质量保证。

### 2.3 “模型最优”与真实可行域分开

当前一维拟合以固定旧曲面为基准，用保守线性约束求交；目标减小时得到嵌套区间。离线诊断允许在 `[0,τ0]` 对目标作最多 **32次**二分，分辨率 **0.001px**，求原约束模型的可行/不可行阈值括区。分辨率只是诊断精度，不是视觉阈值或新生产接受标准。

约束重建必须先在 `τ0` 与真实Fit观测的 `[l,u]`、原选值对齐；不对齐则停止优化归因，记录公式/数值映射未成立。二分只改变被调查的目标，不改变样本、近面条件、高度范围、原保守系数或运算定义。

最低可行阈值选值只能称为**当前保守模型中、给定分辨率下的解**。它不自动是独立几何误差的精确全局最优。低端区间被浮点裁剪判空，也不能称作真实几何无解；靠近退化系数、区间端点或舍入边界而不能可靠判定时记录 `numeric_unknown`，保留已被原认证接受的最好候选。

所有候选转换为真实存储的double高度后，重新执行原 `Measure/Accepts(τ0)`；不能靠区间求交、误差估计或epsilon代替发布值认证。复测更低阈值时，以不放宽该阈值的整数微像素值另列认证证据。任何接受失败不回写高度、不静默抬高原 `τ0`。

达到分辨率或查询上限立即停止。不实现通用优化库、全Q全局优化、二维自由高度搜索或连续曲面误差证明。

## 3. 文件归属与关键架构决定

既有Fit不暴露一维区间。首选在原函数增加可选、定长结果输出，直接观察真实区间；不复制整份生产认证器，也不把离线搜索塞入原算法。

| 处理 | 文件 | 职责及独立理由 |
|---|---|---|
| Extend | `src/algorithms/greedy_transactional_lod/TransactionalCertification.h/.cpp` | 声明小型 `SingleHeightFitInterval` 和可选输出参数；只记录一维成功构造区间时的初高、下/上界及有效标记。保持原运算、选值、返回原因和默认调用不变 |
| Create | `src/experiment/greedy_transactional_lod/TransactionalFitCounterfactual.h/.cpp` | 借用固定状态/样本，重建一维约束、比较三类选值、调用生产认证复核并记录局部质量；数学诊断独立于既有历史追溯，避免继续堆入 `TransactionalQualityProvenance` |
| Extend | `tests/TransactionalQualityProvenanceProbe.cpp` | 添加显式 `--fit-audit` 模式，仅B且指定原q2时有效；在frame7原Plan后调用独立诊断，仍只应用原批次；默认CLI/24帧输出不变 |
| Extend | `tests/CMakeLists.txt` | 新诊断实现仅链接追溯目标；增加必要的有限诊断夹具目标，不加入自动自然回放 |
| Create | `tests/TransactionalFitCounterfactualTests.cpp` | 闭式一维例子及观察开关等价检查；验证选值、阈值括区和数值未知的含义，不镜像整个Fit实现 |
| Create/Wrap | `scripts/run_transactional_fit_audit.py` | 复用 `native_run`、`identity`、PQ-02身份检查和原报告工具，负责版本冻结、两种观测模式运行、有限归约及绘图，不复制控制器或质量算法 |
| Create | 对应 `docs/research`、`docs/codebase`、`docs/reviews/cpu_refinement/pq_03_fit_counterfactual_*` | 分别保存诊断结果、真实代码和规划比对，不修改PQ-01/02的历史结论 |

关键接口/所有权：

- `Fit(..., SingleHeightFitInterval* interval=nullptr)`：未请求时不分配、不记录样本、不调用回调；请求时入口置无效，一维区间形成后一次性写定长记录。输出与`Fit`最终认证成功分别判断，不能将区间有效当作提案已认证。
- `TransactionalFitCounterfactual::Run(state,samples,approvedProposal,output,limits)`：输入均借用const；只复制局部 `Proposal` 和一维诊断数据。任何改高均作用于私有副本，清除该副本旧误差/高度证据缓存，使用独立工作账本。
- 区间诊断重建使用 `TransactionalProposalEvidence`、当前矩阵/样本和冻结保守公式。共享输入事实，最终认证继续调用生产实现；不新增第二套接受规则。
- 实验层依赖核心；核心只知道定长数学结果类型，不依赖实验、文件输出或优化器。生产控制器、预留、提交、种子和渲染均不改。

**复用边界：** 当前Fit的基准是旧曲面。此设计只覆盖保持旧曲面作为未拟合基准的原E提案；未来翻边后必须重新构造新连接的仿射曲面，不能直接复用本轮旧基准约束。PQ-04另行处理，不能在此处暗中扩大模型。

## 4. 执行顺序与验证

1. **冻结基线。** 保存当前追溯程序、相关源码、PQ-02运行身份及质量来源；以当前q2模式的24帧结果和完整进程费用作为修改前对照。同环境已有可追溯基线可直接复用，环境改变时只补一次旧程序运行。
2. **增加区间观察与最小夹具。** 原一维提案在观察开/关时输出必须完全一致；空样本、形状失败和非一维路径不输出伪有效区间。闭式单样本、相向约束、源高度区间外、退化区间/近面边界覆盖选择规则和失败分类。
3. **构造只读反事实。** 原批准提案还原新点初高后重跑Fit，验证原目标、连接、高度和证书结果；检查重建的原区间一致，再比较源接近选值和最小阈值选值。原高度不在重建区间或输入身份不匹配时立即停止。
4. **有限自然核查。** 新程序q2默认观测运行一次；`--fit-audit`运行一次。两次均与PQ-02全24帧主要工作/网格哈希及五份实际网格身份对齐；原轨迹不采用反事实，所以仍复用旧全域独立质量，不重新跑全Q或分叉未来轨迹。
5. **结果与视觉核对。** 报告原区间、限制下/上界的样本/约束来源、每次阈值查询、候选高度及实际认证结果。画一张高度—局部误差图，标明原选值、源高度及模型搜索点；以记录的查询/候选为主，不为曲线平滑追加稠密采样。目视检查单位、可见域、图例和截断，不冒充平台画面验收。
6. **核查闭环并提交。** 对照规范与本规划完成代码事实、结果和架构审查，独立提交PQ-03，再根据结论编写PQ-04；不把两个阶段长期堆在工作区。

最小新增查询验证要求：模型求得的候选仍由原区间/精确回退认证复核；所有失败、较差选值与未收敛查询保留。一个候选改善q2但加重整个认证补丁时，不能当作本阶段正向结果。

## 5. 工作量、性能与停止条件

设可见认证样本数为s=7056，一维阈值查询数为L≤32，最终候选数≤3。局部事实构造预期O(s)，模型查询O(Ls)，最终认证和闭补丁辅助质量分别计费；精确数值回退的位复杂度不能隐藏在“单次O(1)”中。记录约束数、样本访问数、认证次数、精确回退、内存及各段耗时，不把模型搜索计成生产更新收益。

- 每个变体先对一个发布高度执行 `Measure/Accepts`；必要时最多再试2个相邻可表示高度，即每变体最多3次发布值认证。选定后最多另做一次对应更低阈值复核，不靠无限 `nextafter` 循环搜索接受。
- 诊断累计样本访问上限 **200万**，额外诊断墙钟 **60秒**；原生启动继续180秒/8GiB。超过上限输出已有结果与 `budget_exhausted`，不提高上限继续找正例。
- 新增自然运行原则上两次24批；必要的旧环境基线最多一次。正常目标小于2分钟，总上限5分钟，构建另计。没有性能矩阵、后端矩阵、更多样本、额外恢复批或500k压力输入。
- 实施核查例外：初次结果把“未查询更低阈值”输出为`false`，容易误读成拒绝。改为`lowerTargetChecked=false, acceptedLower=null`，并增加初高身份核对；只追加一次同输入的诊断模式验证到`fit-audit-schema/`，保留初次结果，不重跑默认模式或扩大搜索。此修正不改变查询、选值、原认证或实际批次。
- 默认q2诊断费用对照PQ-02同模式 **5.226964s**；只读区间输出关闭时的运行与开启搜索的费用分开。原生同条件各一独立进程，报告绝对/相对差和计时边界，不把24帧当24个独立统计重复。
- 生产Fit签名/观察分支虽不改变算法，也必须核查默认行为与相关费用；实际影响超过开发规范门槛才对该输入最多复测一次。确认退化则记录原因并按已有授权/规范处理，不借诊断需求强行保留生产开销。
- 定向构建追溯目标和新诊断夹具；不跑全部CTest或重建所有渲染后端。原始文件放在显式忽略的 `benchmark-output/cpu-refinement/pq-03/run-01/`，不覆盖PQ-02。

## 6. 出口及PQ-04承接边界

| 观测 | 本阶段可下的结论 | 后续意义 |
|---|---|---|
| 相同区间内找到明显更低的认证补丁误差 | 原选值没有利用已有改善空间 | 可以讨论一维选值政策；不能称持续恢复已修复 |
| 源接近选值可认证，但不是补丁误差最低 | 两个目标确有取舍 | 分开记录几何来源偏好和当前视图收益 |
| 原保守模型只允许接近原结果 | 在当前模型内改善空间有限 | 不排除更精确可行域；不把结论扩大成真实几何最优 |
| 模型/原实现不对齐、认证失败或额度耗尽 | 对应来源未解决或数值未知 | 保留负结果，不强求选一个修复策略 |

阶段完成标准是给出可复核的区间、选值与认证对照，或明确未能完成的原因。`诊断完成`、`找到更好局部值`、`持续质量通过`是三个不同状态；本轮最后一项始终不作通过主张。

PQ-04后续小规划至少冻结：frame8批前真实邻接和AB相邻坏角；根及其直接边邻接构成的固定局部域；有限翻边/一次翻边加细化目录；旧点不移动、原最小角和预算不放宽；最终复合事务的认证与中间私有构形分开；相同高度求值口径的原目录对照。任何+2面的恢复都单列预算来源，不用几何可行代替完整预算交换可行。

PQ-04不纳入本阶段实施范围，在PQ-03闭环后另写小规划承接；不能因PQ-03收益不够就自动加入2-ring、连续翻边搜索、角度放宽或更高自由度。未来诊断若找到局部恢复，也仍不代表生产续接、批次并行或成本已成立。

## 7. 实现结果

已完成[结果报告](../../research/cpu_refinement/pq_03_fit_counterfactual_results.md)、[代码事实](../../codebase/cpu_refinement/pq_03_fit_counterfactual_facts.md)和[架构审查](../../reviews/cpu_refinement/pq_03_fit_counterfactual_review.md)。阶段结论是**反事实诊断完成，持续质量未修复**。

1. 核心只增加可选定长区间观察；离线模型、查询、认证对照在独立实验类中。初高、原增量区间`[0.0074764477546143543,0.28311707736884578]`、原选值和证书均与真实Fit一致。
2. 12次有限查询得到阈值括区`[1.6183737392578126,1.6192157651367189]px`，宽0.000842025879px。选当前可行增量区间中点作为确定性内部值，不按未来视图再次挑选。三个候选均一次原阈值认证成功，没有相邻高度重试；模型点另通过1.619215px复核。
3. 原/源高度/模型点的认证补丁最大误差约为1.724469/1.618929/1.618929px。q2固定frame15投影由2.351050降至2.185029/2.031100px；但最大逐点屏幕代价为0.527315/1.019701px。不能把后两者直接升为生产政策。
4. 零权重样本解释约1.618929px的误差平台，说明原Fit有未利用空间，同时固定连接及单自由高度也限制继续改善。该结论不覆盖其他恢复操作；frame8形状阻塞仍待PQ-04。
5. 原24帧、三份诊断文件和五份实际网格身份不变，因此复用原全域质量。仅追加一次字段修正验证；非法新模式在建目录前拒绝。解析夹具最初近面导数方向错误，修正夹具后核查完成；旧失败和初次自然输出均保留。
6. 新默认完整进程5.356993s，对照5.226964s，约+2.49%，未过快验筛查门槛。额外诊断0.150314s，128141样本访问、258530约束；证据构造的排序/查找实际含O(s log s)，不按规划预期简化为O(s)。没有追加全CTest、渲染矩阵或全Q质量运行。
7. 诊断图已目视核对，仅画已认证高度和全部查询；没有新增生产状态写入、拟合政策或形状恢复代码。原始文件置于既有显式忽略目录，规划/事实/结果/审查与实现按本阶段提交。
