# QPC-06J 最终剩余成本核查小规划

## 1. 目标和边界

06G/H/I已分别提交，完整成本只有限下降。本阶段核对最终热点、时序和未采用候选，回答哪些空间已验证、哪些无收益、哪些仍需新算法；不宣称穷尽任意优化。质量政策、原语、并发边界和View查询算法均不修改。

源码核查发现当前Donor不是全惰性认证：共同池提前并行Certify，只有足迹按触达构造。此前讨论中的“Donor已有惰性认证”必须纠正。用已有DonorCertified/DonorTouched账本核对冗余人口，再决定是否有足够证据实施一个按需机制；若全部被实际配对触达，则以无减工关闭该候选，不把并行认证搬回串行以凑改动。

## 2. 文件职责

- Extend `src/benchmark/experiment/TransactionalRecoveryTrace.cpp`：仅诊断CSV导出已有捐赠认证/触达、样本定位/投影计数，生产算法无新探针。
- Reuse `scripts/run_experiment.py profile`及既有perf/Tracy分析器，最终Linux程序单独记录身份。
- Create 本阶段研究报告、精简数据与审查；同步06队列及大规划。无新增生产组件，无公共架构调整。

## 3. 有限输入与验收

Linux最终构建：Sierra/Canyon各一次perf、Sierra一次Tracy；各自有同构建未捕获对照，复用06I原生Windows普通时间作为主性能边界。两个场景各一次既有恢复诊断，完整96机会、r=m160、8线程、原Q/相机，不扩大预算矩阵。捕获/诊断顺序运行，不与构建并行。每个进程最长180秒，明确捕获扰动和采样权重不等于Windows墙钟占比。

比较最终捕获/普通/原生结果哈希；普通诊断没有改变生产代码，原生性能复用06I，不再重复Windows矩阵。导出所有已解析函数self/inclusive及现有时序，不把未知栈隐藏。新增CSV列以原WorkLedger字段为源，不新增求值。

## 4. 判定顺序

1. Receiver：准备和旧支持复用已探索；核对剩余是否仍逐点损伤/进展和精确回退。过滤器替换须保守证明，不改epsilon或精度。
2. Samples：拆局部定位与`next_order`，结合新增实际工作量，不能把“省了38万次算术”直接当总体必要成本已低。
3. Donor：核对提前认证但未触达比例，查Measure与PointwiseQuality各自保留的义务；不把不同质量政策当等价消融。
4. View：确认双缓冲、有限前缀查询已存在；剩余全Q投影是当前表示的算法工作，不证明任何精确剪枝不可能。记录改变查询表示需要的界/生命周期前提，停止本轮实现。
5. 预留/提交/更多线程：以当前绝对时间上限和Tracy尾部判断，不套用历史200k不同人口。

最终为每项给“已保留/试作撤回/暂无减工人口/需要新算法契约/尚未证明”等明确状态。若新增机制必需改变质量、候选或长期状态，记录开放项后结束，不自动扩展本轮范围。

## 5. 实施结果

已完成。见[完整结果](../../research/cpu_refinement/qpc_06j_remaining_cost_results.md)、[事实](../../codebase/cpu_refinement/qpc_06j_remaining_cost_facts.md)与[审查](../../reviews/cpu_refinement/qpc_06j_remaining_cost_review.md)。本阶段无生产算法改动，只补诊断导出及复用现有分析器的有限脚本。

- 两场景perf、Sierra Tracy及同构建无捕获对照、两条恢复诊断完成；各96机会结果与06I原生一致。perf未知祖先及Tracy约4.64%捕获扰动均公开。
- 数值认证仍是主要CPU热点；Sierra接收平均38.790ms、最长任务38.602ms、最后任务后的收尾0.096ms，不能把控制线程等待当同步税。
- Canyon移动捐赠提前认证/触达均4,640，返回均5,120；本输入没有未触达人口，不把现有并行认证改成串行惰性。旧Measure的投影拒绝义务仍未被新证书蕴含证明覆盖，记录开放项，未删除。
- 样本定位仍多；删除38.7万次无用算术不代表完整续接近最低成本。视图已有双缓冲/分块前缀，下一步精确剪枝需要新查询证明，本轮停止扩展。
- Canyon65～95静止帧诊断直接Plan、正常路径复用空批，物理配对数不同但结果完全相同；分析器单列并严格限制差异条件。没有重跑或替换原捕获，未用这段诊断推普通成本。
- G～I累计原生移动110.643→105.708ms、67.743→62.893ms，有限下降而非突破。所有未采用方案和剩余问题分别结账，源高仍为实验分支；没有宣布优化空间耗尽。

日常原生构建配置已恢复CBT开启/测试关闭，不覆盖冻结计时程序。有限队列闭环，准备独立提交06J。
