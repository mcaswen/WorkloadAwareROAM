# QPC-04A：外边界恢复可行性与接入契约

日期：2026-09-16；基线 `e0a69c7`。用户已验收 QPC-01 的诊断结论，并要求按质量前移的新顺序实施。本轮作为 QPC-04 的第一个可独立验收子阶段；完成后提交并交用户验收，不自动开始其他小阶段。

## 1. 问题、范围与出口

QPC-01 已证明，在固定旧点的当前生产事务语言下，Peking/峡谷所选最大残差位于不可改变的种子外边界折线。扩大前缀或运行轮数不能改变该折线。本阶段先回答一个具体问题：**只在当前单侧外边界边上插入中点，旧点固定、其余边保持不变，是否存在满足原形状与当前质量认证的有限恢复？**

该操作将一个面替换成两个面，净增加一个三角形。当前生产接收方固定增加两个面，预留按双面额度计费，提交器也只接受 `+2` 或翻边 `0`。因此先形成可复核的私有提案和生产接入设计，不把 `+1` 冒充现有 `+2` 类型通过提交断言。大规划 §7 QPC-04 要求预算粒度和事务类型变化先设计并 Review，本阶段不绕过该要求。

不改变优先级、前缀、旧点高度、最小角、原 E/F/H/翻边目录、捐赠方或生产控制器；不增加运行轮数，不开展 Sierra 策略修复、预留性能优化、多环搜索或强制传播。有限反事实可行不等于持续恢复成功。

出口为：有限候选可行及最小接入契约，或本轮候选不成立及明确阻塞。只有后续生产接入获得相应语义确认、质量操作点冻结，才运行改变策略的持续轨迹。

## 2. 冻结实验

输入复用 QPC-01 / FER-02：Peking 50k 与 200k 的机会 15，峡谷 50k 的机会 48，原线程、相机、源高度、Q、阈值和前缀不变。每场景只使用 QPC-01 已冻结第一见证，调查该机会开始状态的全部覆盖根；不按本次结果另挑快照。

每个覆盖根仅枚举其单侧域外边界边，稳定边身份排序、去重。每边仅一个中点几何，测试两个明确高度：

1. **原曲面线性高度对照**：边端点高度均值，只核查几何分割本身不改变旧曲面，不预期通过 0.01px 进展条件。
2. **双线性源高度候选**：新点取原始 U16 样本的双线性插值乘冻结高度比例，不拟合存活点或使用未来视图。

形状使用现行 `TransactionalPredicates::Shape`，即锐角 `cos²≤9/10`。质量复用 `SetProgressTarget`、`Measure`、`Accepts`：当前可见支持上的微像素目标与原算法完全相同。源高度候选不通过时保留原因，不临时加拟合、放宽阈值或改插点位置。独立参数域有理检查核对面积、方向、共享边、边界分段、旧点固定和形状。

输出覆盖根原排名、是否在前缀、旧支持最大值、新最大值、见证高度/误差、样本访问和费用。质量诊断同时报告支持内逐点最大退化，防止局部最大值下降掩盖其他样本退化；不能据此预设整个算法的允许退化值。

预算仅调查该有限接收提案：空余额是否足够支付 `+1`；不足时在**原冻结捐赠池**内按原顺序寻找满足质量、内部资源独立且净 `−1` 的单个捐赠提案。记录检查量、首个可配对项及失败类别，不将单对可行称为原批次必然选中，也不改命名额度/不回流策略。

## 4. 生产接入义务审计

根据实际有限结果形成一份具体设计，至少包括：

- `+1` 外边界细化和原 `+2` 内部细化如何按实际面数命名额度；捐赠 `−2` 后多出的一个空额度是否仅下一批可见，如何保留不回流。
- 新点稳定身份不与原每根八个提案临时身份冲突；边界类型有完整结构前提，不能只靠字符和净面数获得提交权限。
- 新点边界标记、两条单侧边、内部边、顶点邻接、活动槽位、样本闭面贡献、捐赠资格、优先级、法线、脏范围与 Pending 的局部恢复。
- 失败原子性、批内读写冲突、串并行同批逻辑等价，以及实际浮点输出质量。
- 当前逐批质量认证只能约束当前视图；源高度规则不自动证明未来视图单调、完整恢复或质量最优。

这里输出设计和成本，不提前修改 `Reservation`、`Commit` 或公共配置。若一面中点都无解，只关闭这一有限候选，不自动搜索更大域。
