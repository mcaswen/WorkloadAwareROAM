## 3. 必须拆开的误差与控制量

本节只冻结审计术语，不修改生产参数。

| 量 | 当前含义 | 不能推出的结论 |
|---|---|---|
| `Q_runtime` | Samples 六组整数六分格坐标，基于 raw U16 双线性参考 | 与独立评价器逐点、逐身份、逐位完全相同 |
| `Q_eval` | 固定参考栅格三角形的顶点、边中点、重心，k=0；UV 来自 float 栅格 | 连续曲面严格最大误差或屏幕面积均匀采样 |
| `E_runtime(t)` | 当前参考可见、贡献到闭三角形 t 的样本误差最大值 | DOD 的层次几何包络或任意未来视图误差 |
| `P(t)` | `max(E_runtime(t), 0.2 × projectedLongestEdge(t))`，生产存平方 | 纯几何误差或一次事务的真实收益 |
| `τ_request` | 当前 `SplitPixels`；有限评分严格大于它才进入索引 | 更新结束后 `E_eval ≤ τ_request` |
| `τ_proposal` | 旧局部支持见证误差向下取整至微像素，再减 0.01px | 固定的绝对质量目标，或每个样本至少改善 0.01px |
| `E*` | 本阶段拟明确的独立误差目标，当前尚无统一的新数值契约 | 可直接复用 `SplitPixels` 或从 DOD 某个点反推 |
| `Dmax`、分布、`Hmax` | 分别观察逐点误差转移、整体分布、相机无关残差 | 三者可以互相替代，或必须逐点逼近 DOD |

DOD 使用层次嵌套几何误差、保守投影函数和边长项，另有可见性、深度与迟滞规则；Transactional 使用当前样本误差与边长项。即使两个入口都叫像素阈值，也不能把它们当成同一个质量控制器。源码使用保守包络函数不等于本阶段已证明其对独立双线性参考的连续误差保证。

一个需要检验前提的单向关系是：在同一 `Q_runtime`、当前视图、完整闭面贡献、有限有效评分下，`E_runtime(t) > τ_request ⇒ P(t) > τ_request`。因此高误差样本若已被根正确表示，边长项不会让它低于触发门槛；边长项可能改变的是排序及有限前缀竞争。非有限评分、近面、可见域和缺失贡献必须独立处理，不能套用此关系。

## 4. 五个排查方向及所需证据

### C1：先核对线上和独立评价是否在说同一件事

建立参考曲面、坐标、可见性、投影、单位、近面拒绝、内部 double/实际 float、闭面贡献的对照表。共同样本数量相同不能代替 UV 一致；生产样本编号不能直接索引独立 `errors.f64`。

先用已有冻结见证比较 `E_runtime` 与 `E_eval`、批前与批后时刻。QPC-01 的有限见证差约 `1e-7px`，只支持这些点，不替全域作证。共享边必须核对全部覆盖根，不能只看唯一 owner。发现明显口径问题时，先报告它能解释哪些残差，停止继续归咎于策略；不在本阶段改评价定义或放宽容差。

**输出：** 已对齐项、存在差异项、未覆盖项；每个见证的实际差值。没有证据时保留未知。

### C2：区分目标已经满足、目标未定义与请求没有兑现

以 Sierra48/95 为主，Peking15、峡谷48/95 为对照。对 `E*∈{0.25,0.5,1,2,4}px` 只做已有数组的离线分类，明确这些是诊断操作点，不是已批准的运行参数或感知阈值。旧 `.1px` 分布统计继续保留，不能删掉不利档位。

记录实际 N、B、误差最大值、超目标样本数量/占可见样本比例，以及 DOD 的同表数据。区分：低于拟定目标仍继续花预算属于另一种“固定预算尽量降低误差”政策；有空额不会自动要求现行阈值型政策用满。低于当前触发数字却劣于 DOD，不能标作当前控制器违约。

**输出：** 哪些目标是当前质量已有条件下满足的，哪些需要新增请求，哪些已经有请求但被阻塞。不能据静态分类承诺新阈值下的最终状态或成本。

### C3：检查几何误差需求是否被密度需求挤出有限前缀

先分解 `E_runtime`、`0.2L`、最终 P、资格、排名和前缀成员，再结合原拒绝原因。Peking50k 的已知根明显由边长项主导，但仅凭这个根不能证明全局前缀被无收益项占满。

若现有全体根记录不足，只在预冻结快照补一次只读分解：统计前缀内外的几何主导、密度主导、无可见样本、非有限项；对同一快照离线计算纯误差排序下的排名，用来估计机会错位。后者是反事实查询，不产生新事务，不作为生产政策或加速证据。候选资格保持与排序反事实分别列账，不能同时改变两者后宣称定位了单一原因。

**输出：** 误差需求未形成/进入索引但被截断/进入目录后失败的独立数量和有限见证。根数、样本数和拒绝事件数分开，不用反复尝试次数冒充独立人口。

### C4：核对局部进展条件与全域误差目标的缺口

复核 `SetProgressTarget → Measure/Accepts → donor Accepts → batch publish`：接收方和捐赠方使用哪些当前可见支持、旧见证、目标和新误差；普通首次可行项与翻边规则分列。目标来自提案支持，不一定等于根自身的最大值；不同目录项支持不同，不能直接用目标值比较收益。

对已有 04B 峡谷 frame8 B 事件及 Peking200k/frame13 B 事件，解释：为何按当时规则可以通过，哪些点被当前视图覆盖，哪些退化在未来投影才暴露。区分单事务旧/新、同帧批前/批后和整条开启/关闭轨迹；整轨 Dmax 不能全部归因于一次 B。

当前固定视图的局部最大值下降不等于逐点不退化、达到绝对 E*、下轮一定继续改善或未来视图质量达标。0.01px 是可接受进展门槛，不是恢复时限。本阶段只说明缺少哪个义务，不优化 Fit、不改目录顺序、不新增 HeightGuard。

**输出：** 现有认证确实保证的有限命题、没有保证的质量维度，以及缺少证据的前提。

### C5：明确误差目标的作用时刻与有限恢复出口

分别描述：当前视图更新前、同一视图更新后、视图变化后、返回视图。未来相机仅用于离线归因。视图变化会改变屏幕误差，不能要求无需任何工作就立即达标；也不能把永远“下批再恢复”作为合格契约。

用原轨迹已给的机会数统计残差及首次阻塞位置，候选原因至少分为：未达触发值、无有效可见证据、前缀截断、形状/目录、质量认证、预算/捐赠、批内冲突、数值未知。静止且无执行不自动表示收敛；仅有样本/根记录不能证明一般操作空间无解。

**输出：** 对后续契约建议使用“达到目标 / 残差与原因可报告”的有限出口；若需要承诺若干更新机会内恢复，必须另有进展证明或相应实验，本阶段不补跑更长轨迹制造达标。

## 5. 有限实验与停止规则

1. **首先复用。** 上述六个帧、16份质量数组为固定面板；根和事件沿 QPC-01/04B 原选点，不另选易修复见证。完整已保存轨迹只用于检查同一见证的历史，不新增场景、线程或预算矩阵。
2. **只补缺字段。** C3 如需全根评分分解，最多补 Sierra 原96机会一次、Peking50k 原24机会一次的只读追溯；只在 Sierra48/95、Peking15 输出全根分解。先检查旧 raw 是否足够，足够则不运行。峡谷与200k优先完全复用旧证据。
3. **成本边界。** 每进程上限180秒、8GiB；预计纯数组归约为秒级，补追溯为数十秒级。到限保留未知，不放大配额、不换场景。全根诊断只扫描已有面/样本贡献，禁止每根全扫Q形成 O(NQ) 的新观察器。
4. **独立评价。** 不重跑12份04B质量计算，不替换参考曲面、采样级别、投影或质量程序。仅若证据身份不符则停止对应比较，记录缺项。
5. **出口控制。** 五方向能分类并形成误差契约建议即停止；若有限证据无法区分某原因，说明最小缺口，不用新增几何原语补研究结论。

## 7. 实施步骤与验收

### 步骤1：冻结证据与符号

完成C1对照表，核对原始文件身份、可见mask、根记录的平方/像素单位和批前后时刻；再现§2表格及原见证。**验收：** 数字可由保留数组重算，缺失和无效点不可从分母静默消失。

### 步骤2：分类目标、请求和接受义务

按C2—C5完成有限表格；缺少C3字段时才增加条件观察。建议每个见证输出 `E_eval / E_runtime / density / P / τ_request / rank / prefix / proposal target / first reason / N/B`，字段不存在明确写未知。**验收：** 阈值、前缀、目录和误差转移能分别归因，反事实排名不冒充持续策略效果。

### 步骤3：提出一份可 Review 的误差目标契约

建议以**独立 bilinear reference 上的当前可见 sampled Emax 为主要绝对指标**；实际面数、RMS/分布、Dmax、Hmax与恢复轨迹同时保留。DOD是质量/成本比较对象，不是逐点真值。数学拓扑/预算仍为硬约束，采样质量目标不升级为连续证明。

必须明确以下取舍，再建议至多一个下一阶段候选：

- 主政策是达到E*后停止，还是在预算/时间内持续降低误差；推荐先采用前者作为清晰的目标口径，固定预算优化另表分析。
- `τ_request` 与E*的关系、密度需求的角色，以及不能兑现时如何报告残差；不要求本阶段将两者数值强行设为相等。
- 是否需要新增退化约束、约束哪种支持和时刻；不能直接把04B“任一档计数增加即混合”升级为每事务逐点单调定理，也不能撤销其历史验收。
- 允许的恢复机会和质量—成本取舍目前有什么证据；没有证据的数值保持待决定，不宣称人眼不可感知。

**验收：** 能说明“何时算满足目标、何时只是局部有进展、未达标由哪层阻塞”，并给出一个范围有限的后续验证建议；不要求产生生产修复或性能胜出。

### 验证与性能边界

纯文档/离线阶段不构建生产、不跑全CTest。新增归约只验证身份拒绝、不可见样本、阈值严格大于与已知数据重算；不写大量镜像实现的测试。离线耗时/峰值内存与原重算任务比较，完整计费，不称CPU更新收益。
