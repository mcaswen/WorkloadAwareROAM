## 1. 问题、目标和结论边界

验证在同一快照贪心预留、硬预算、实际 binary64 几何与质量认证契约下，删除重复或未参与决策的工作是否足以显著降低完整成本。主线仍是全局优先级驱动、分阶段、事务化、面向数据的多核 CPU LOD，不新增重网格化、GPU 或目标发现理论分支。

历史关闭观测的八轮均值：test129 新 C4 为 18.397ms、DOD 为 0.589ms；Peking 为 29.226ms、2.977ms。不同算法的历史/质量/线程不同，这些是工程距离，不是同任务速度比。FPR 的另一组 Tracy 捕获显示：

| 路径 | 互斥完整帧比例 | 本轮处理对象 |
|---|---:|---|
| Peking 视图链 | 90.98% | 暂存、全 Q 投影、面评分、拓扑资格重查、建序和发布 |
| test129 接收/回收派发 | 58.84% | 目录、拟合、Measure、重复定位和误差证据 |
| test129 样本续接 / 预留 | 15.11% / 8.72% | 局部关联修复、足迹、配对和统计 |

Peking 该轨迹只有 0 个交换、5 个空额度细分，剔除视图后的低成本不证明繁忙交换便宜。数据证明当前实现不竞争，既没有证明全部上游成本可以删除，也没有证明剩余成本不可避免。

产物必须分别回答：保持了什么结果、减少了什么工作、加入了多少维护/空间、完整时间改变多少、仍缺什么证据。test129 保留为小工作量延迟边界，不要求它必须取胜，也不删除其慢结果；Peking 只是一个较大自然输入，不承担普遍扩展性结论。

## 2. 范围和授权边界

范围为现有实验模块、相关测试/探针和文档。固定原始双线性参考、Q、相机、预算、阈值、E/F/H 目录、一般 one-ring 耳切、旧中心改高范围、空额度命名和不回流规则。只使用现有 1/4 线程与 DOD 家族上下文。

不做新原语、2-ring、更多线程、新线程池、通用 profiler、GUI/上传/渲染接入、压力矩阵、长期质量修复或第二套误差系统。ClipPolygon 及数值内核只有重测仍指向它们时才可作一个有界候选；不凭坏复杂度抢占优先级。

本轮允许因性能结果撤回无收益候选，并在当前小规划内修正其实现问题；不保留复杂失败方案叠加成默认路径。涉及公共职责、问题定义或接受规则变化时停止该候选，不能借优化授权实施另一算法。

## 3. 同任务与认证契约

必须保持所有决策观察：原始候选资格和有限值规则、精确前缀和回收池、稳定同分键、被决策实际尝试的提案次序及首个成功项、预算命名、批准事务、实际几何、下一轮可观察状态、mesh/Pending 与失败原子性。

接收键为 `(-PrioritySquared, stableFaceId, slot)`，回收键为 `(incidentPriorityMaximum, stableVertexId)`；`PrioritySquared=max(sampledErrorSquared,0.04*projectedLongestEdgeSquared)` 不变。不删除密度主导/空样本请求再补尾部。改变物理布局或取消无副作用的尾部诊断不改变算法结果。

认证分为三类，不把所有几何谓词都移出运行时：

| 类别 | 处理 |
|---|---|
| 独立重复验证 | 有完整构造保证后才放到测试/诊断；已在 ROI 外的验证不计作可回收时间 |
| 构造必需的动态谓词 | 耳合法、最小角、实际事务冲突、有效槽/代际仍是运行时义务 |
| 动态质量决策 | 当前几何、相机和阈值相关的求值/保守界不能直接删除 |

拟合系数、包含真实值的区间、精确有理证据分别保存。普通 double 重心权重不能冒充精确证书。最终接受始终针对实际舍入后发布值；新浮点过滤只有具备完整误差界才可替代部分区间操作。

完整 `D_feasible` / 拒绝分布属于诊断；正常路径保留精确需求、执行结果和统计完整性标签。未检查项为未收集/已知下界，不填零或不可行。诊断与正常模式必须选同一批次；不能让额外审计决定正常事务。

## 4. 架构、职责和依赖

```text
Probe：输入、冻结轨迹、独立诊断、计时和文件
  ├─ DynamicReference A：独立逐事务反馈，保持竞争力
  └─ Pipeline B/C：视图与批次共同发布
       ├─ State / Commit：核心拓扑和结构事实的局部维护
       ├─ Samples：参考、owner、闭面关联和局部续接
       │    ├─ ViewState：当前/备用视图数组和代际
       │    ├─ PriorityIndex：连续键、精确前缀和持续摘要
       │    └─ ViewEvidence：仅条件 Gate 通过后建立
       ├─ Proposals：冻结顺序的惰性目录
       ├─ Certification → ProposalEvidence：局部事实复用和质量判断
       ├─ Reservation：顺序预留、足迹复用和诊断分离
       └─ Mesh / Execution：复用局部输出及同步线程能力
```

Samples 拥有样本、视图和索引，不让这些组件反向持有 Pipeline/Samples。几何证据不依赖预留；索引不决定质量或预算。State/Commit 维护结构事实，ViewState 不拥有拓扑。生产 DOD 不依赖原型，不导入 MPR/Legacy 目标。

生命周期：

- boundary/degree/adjacency 属于拓扑代际；degree 已由 Incident 表达，不再增加重复缓存。边界在合法矩形域内按既有边关联建立，事务固定外边界，新增内部点按原语维护；不在换相机时重查。
- 参数坐标和样本归属随连接变动；H 改高影响全部邻面及证书，但不改变参数坐标。先复用局部事实，不建立全 Q×提案缓存。
- 可见性/屏幕误差/投影系数随视图变动。持久静态样本与视图数组分离，准备写备用数组，全部成功后交换；后续消费者直接读取已发布数组。
- 暂存分配、初始化、旧索引释放、缓冲峰值与最终销毁计入对应边界。失败保留旧视图，备用存储不得被消费者持有或混代。

## 6. Track A：视图路径

先删除生命周期错误和多余内存遍历，再做持续精确选择：

1. 结构事实与视图事实分离，保存有效边界；密集投影结果双缓冲，发布交换所有权。备用数组稳定复用，已被完整覆盖部分不重复清零；合法对象寿命、异常与所有槽已写必须成立。
2. 面/点候选连续记录，按固定物理块保存有序有效记录，查询时确定性归并 top-r / bottom-m；原始资格数量精确维护。只有前缀结果而没有尾部记录不是完整持续索引。
3. 新/删/变分候选只修脏块；保证尾部提升、同分、槽复用及动态参考 A 连续查询。保留全排序作诊断 oracle，不让 A 每个事务全扫来换 B 的便宜。
4. 重测后只有全 Q 投影/归约仍是实质绝对瓶颈，才进入 §8。

GWR-03 冻结 K=256 的完整有序块与块首归并，取代逐层 R 项摘要：重建 O(n*log K)、查询 O(b+Rlog b)、h 脏块修复 O(hKlog K)，b=ceil(n*/K)，空间 O(n*)。查询块首与容量增长均计费，资格/incident 另计；A 若退化须修正或撤回。

## 7. Track B：事务路径

先做接收惰性目录和提案内证据复用，再做足迹/诊断分离；不先修改数值核。E→F→H 顺序、见证、旧中心及最终高度完全保持。单个接收成功后，不构造未尝试目录尾部。

同一提案中，参数位置/连接不变时可以复用规范覆盖面和权重事实；自由高度改变后只重算真正受影响的量。先保留可靠区间/精确算术，再判断调用是否减少。证据构建、空间、销毁和回退全部计入。

当前 B/C 已经每快照每 donor 认证一次并缓存；本轮不把重复增加缓存宣称收益。按需 donor 只作为一个条件候选：若必要搜索实际触达显著少于 m，评估固定顺序有限批量准备；完整触达时退化成本与新串行等待如实报告。A 已有按需缓存只作复用依据，不复用它的反馈控制器。不能用少几个 pair 推断上游 Measure 已省。

足迹按提案复用。正常模式成功后停止该需求必要搜索；完整审计仍记录精确四层分母。可先做廉价且可靠的排除，不能用粗代理认定质量合格。后续只在 profiler 仍显示主要成本时处理 Samples::Prepare/预留；ClipPolygon 保留尺度风险，不自动新增求解器。

## 8. 条件 Gate：精确按需视图查询

仅考察一个候选：参数域参考样本块的保守投影域排除。GWR-05 将首版收窄为整块不可见证明，保持全 Q 输出和所有观察；没有准入后不扩展为一般层次 top-r。先审计/小型证据，后决定是否实现；不是必须完成的第二科研平台。

必须同时覆盖：规范 binary64 优先值的上下界（含边长）、参考可见域、被测近面/非有限值、接收 top-r、回收 bottom-m 代理、精确见证与被尝试支持、D_raw 的统计口径、共享边/改高后的局部失效。仅保证 top-r 不足以保证整个算法观察等价。

上界落后于精确截止键才能跳过；同分按稳定 ID，不能用 stale/近似 P。全局非法视图检测不能延迟到碰巧使用某样本。不能跳过则按原规范展开，最坏全 Q 回退明确计费；构建、维护、域检查和内存也必须有界。当前轮最多一个机制，不因失败自动改评分、缩减 Q 或换误差系统。

若缺少可靠舍入/域界，或维护已需每视图全 Q，不创建 ViewEvidence，记录“当前机制未取得实现准入”，不扩大成所有次线性方案不可能。可以据剩余成本提前关闭本 GWR，无须造完条件设施才有资格判断。

本表为最大授权范围，必须完成一个小阶段的验证/审查后才进入下一阶段，不交叉修改多个未闭环阶段。

## 10. 测量与最小验证

输入固定 test129-a-b4096 / peking547-a-b20000，尺度 30/4 和 80/12，Q 为 98817 / 1790881；来源为 `benchmark-output/cpu-refinement/gmp-03/run-01/capture/<scene>-14.json`，视图序列 `14,14,14,15,16,17,18,14`。不重新从 Legacy 取中途状态。

所有命令在 WSL Ubuntu；同一存活会话，Release、编译器、Boost、严格浮点开关固定。保留修改前独立二进制、哈希、命令、源码身份。构建和性能任务不重叠；每配置默认一个独立进程/八轮，先 C4 和受影响的诊断；影响 A 才补最小 A 前后，必要 B/C 等价由同输入测试/诊断覆盖。不默认全家族或多次重复。

完整时间为 SetView+发现+拟合/认证+预留+准备+发布+样本续接+mesh；临时分配、析构不能移到窗口外。初始化、Consume、最终销毁和峰值内存另列。静止/换视图、逐轮/均值/最大值均报；独立进程才是统计单位，八个异质视图不是重复实验。DOD 默认 8 线程与 C4 不混成同资源加速。

回归筛查沿开发规范 §7.3：`max(0.05ms,5%×基线,已知波动)`，有明确风险才追加一次复测。无波动估计就注明，不追几微秒；未知不写“稳定”。每次自然进程最多 180 秒，原内部 120 秒配额保留；超时停止并保留数据。只运行当前修改涉及的测试，避免冗余。

最小账本：

| 方向 | 工作与成本 |
|---|---|
| 视图 | 全 Q 求值/关联访问，初始化/发布写入量，缓冲分配/字节，结构资格读取，建序/完整时间 |
| 索引 | 全量/脏块数量、比较/归并、尾部提升、D_raw、修复/重建、空间 |
| 提案/证据 | 真正构造/Fit/覆盖查询/复用数、证据字节、阈值与采用 ordinal、精确分支 |
| 预留 | 不同 donor 触达/认证数、足迹、必要/额外审计 pair、等待、交换与完整性标签 |
| 续接/最终 | 实际事务、预算、样本/mesh/Pending、绝对质量与返回 excess、端到端时间 |

不能将线程墙钟和称 CPU 总工作；不能从复制字节推硬件 cache 流量。perf/Tracy 复用 FPR 工具，仅对修改的主要阶段必要复采，正式收益以观测关闭的计时为准。原始数据和辅助分析在 `benchmark-output/cpu-refinement/gwr-xx/` 按 before/after/diagnostic 分离，报告在现有文档目录。

## 11. 类型化出口和退出机制

固定 **5× DOD** 为工程距离检查线，3× 不作为可变验收线，也不承诺追平。历史对应约 2.95ms/14.88ms，仅供距离说明；最后用同环境数据判断。test129 与 Peking 各列达标/未达标/证据不足，不互相抵消；test129 未取胜不自动否定较大输入，Peking 通过也不证明一般扩展性。
