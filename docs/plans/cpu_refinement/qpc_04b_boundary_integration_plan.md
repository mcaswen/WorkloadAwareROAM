# QPC-04B：外边界细分事务接入与持续质量验证

日期：2026-09-16；小规划；代码基线 `b1174d4`。承接 [QPC 大规划](transactional_quality_performance_closure_major_plan.md)中的 QPC-04，以及 [QPC-04A 结果](../../research/cpu_refinement/qpc_04a_boundary_feasibility_results.md)。用户以“ok，继续”确认本具体规划；当前实施和内部验收完成，生产接入通过，质量结果为混合，默认关闭。提交后交用户验收，不自动进入后续阶段。

## 1. 目标、依据与范围

目标是把已经有限验证的单侧外边界中点操作，接入现有持续事务链：从同一全局前缀产生提案，按实际面数预留预算，经原读写冲突筛选后，原子发布完整拓扑、样本和网格状态。随后回答：**它是否能在原 Peking/峡谷轨迹中实际解除边界表达限制，并保留可接受的整体质量和成本？**

QPC-04A 的两个不同局部几何上，源高中点通过原形状与当前视图认证。Peking 原见证约 `1.996557→0.496758px`，峡谷约 `9.274477→2.371741px`。但这些是私有局部反事实；峡谷另一个内部样本增加约 `2.916543px` 误差，Peking 50k 根在机会开始时排名 194，仍在前 160 之外。不能把这些结果当作本阶段的预期全局输出。

本阶段只增加一种 `+1` 边界细分能力及其必要接线。保留旧点高度、当前最小角、评分、精确前缀、捐赠顺序、既有 E/F/H 拟合和净零翻边。**不扩大前缀或恢复轮数，不增加边界回收、其他插点位置、2-ring、HeightGuard、Sierra 质量政策或预留性能优化。**

三个出口分别报告：生产接入正确性、有限持续质量、开启后的完整成本。任一出口通过都不自动代表达到 DOD、完整长期质量或论文竞争性。

## 3. 原语、认证与目录契约

### 3.1 单侧中点构造

新增独立生产组件 `TransactionalBoundaryRefinement`，只读快照，接收根、边和由目录分配的新身份，输出有限提案或明确拒绝原因：

1. 边存在、恰有一个活动面且属于根；端点位于单位参数域同一条外边界。不能把洞口单侧边当域边界。
2. 中点在边内且与端点可区分；旧三个点的 UV/高度保持逐值相同。
3. 唯一新点 UV 为中点，高度查询原始 U16 高度＋既有双线性规则；不读取未来相机、不调用 Fit、不移动旧点。
4. 沿原面方向，用原另两条边连向新点，得到两个正向面；净 `+1`。旧外边分成两条同向单侧边，其余补丁接口保持。
5. 两个新面满足现有 `Shape`，最小角约 `18.434949°`，合法等号保留。不另设更宽角度容差。

`Proposal.Kind='B'`，`Support={root}`，`Free={newId}` 只服务现有新点写入描述；源高度仍受专门结构证书限制，不能因为 `Free` 非空而进入自由拟合。新 `ExchangeKind::BoundaryRefinement` 明确标记 `+1` 事务，原 `Refinement(+2)` 与 `ConnectivityRepair(0)` 的默认含义不变。

组件提供三项清晰职责：`Construct` 生成局部几何；`Certify` 调用原认证器；`IsSourceMidpointSplit` 在提交前核对完整结构证书。名称可随实现作局部调整，但组件不决定全局顺序、空额度或捐赠对象，不发布状态。

连续源高查询归 `TransactionalSamples` 的参考数据职责，增加接受 `const HeightSource&`、UV 和高度比例的纯静态查询；旧整数格查询及其算术次序保持不变，避免影响旧认证。新方法与 04A 独立公式核对栅格点、格内点、四条域边和非 dyadic 资产。沿用现有源尺寸/有效性要求，不扩张支持的资产类型。不能复用 float `HeightMap` 采样冒充同一内部 double 候选，也不创建通用插值框架。

当前 Commit 只有状态，不持有源高度，不能假装它已经能检查源高证书。推荐给 `Prepare` 增加可选的只读 `HeightSource` 输入，由 Pipeline 从唯一所有者 Samples 借用，调用结束即释放借用，`PreparedTopology` 不保存源引用。B 必须有该输入并重新作一次有界源查询；旧事务不需要它，旧直接 Apply 入口收到 B 却未提供源时明确拒绝。这样无需复制高度图、让 State 再持有一份源，或让 Commit 调用 Samples 的可变维护接口。

### 3.2 有限分辨率与不可回收风险

水平边使用 `δu=1/(Source.Width−1)`，垂直边使用 `δv=1/(Source.Height−1)`。仅当两条新子边的参数长度都不小于对应 δ 时开放 B；旧种子中更短的边可保留，但不继续二分。用整数源间隔与明确浮点比较表达，恰好落界保持一致；不通过 epsilon 逐次突破下限。浮点输出还需检查新点不与端点坍缩。

对初始外边界一段长 `ℓ` 的边，中点二分产生的子段数至多为 `max(1,⌊ℓ/δ⌋)`。所有初始边求和给出有限的边界段/顶点上界；这是允许空间上界，不要求初始化扫描或每帧维护一棵新层次。正常路径只检查当前边长度与源尺寸。

这一限制不使原种子点自动变成源高，也不保证精确表达全部 raster knot。捐赠方继续排除所有边界点，边界自由度只增不减。对单连通三角域有 `F=2V_interior+V_boundary−2`；因此新增边界点会占用不可回收的预算下界，可能压缩以后内部细化空间。报告边界点净增、源尺度拒绝、实际面数及剩余空额；解析连续细分夹具核查终止，自然实验不另加长周期刷结果。

若原轨迹暴露边界积累导致实质预算锁死，按受限候选收口，不在本阶段追加边界合并或调大预算。

### 3.3 认证与目录顺序

B 使用原 `VisibleSupport`、`SetProgressTarget`、`Measure/Accepts`。目标仍为旧支持见证精确误差向下取整后减 `10000` 微像素；无可见样本、投影/数值不确定、配额不足均不能当认证成功。捐赠方仍按接收方同一目标认证。

每个根按稳定边身份排序：双侧边生成原 E，符合前提的单侧外边界边生成 B；之后仍是原 F、H 顺序。E/B 合计最多三项，F 至多两项、H 至多三项，保留每根八项临时身份空间。每个实际目录项消费自己的序号，失败项不重用身份；关闭 B 时原目录、序号、选择和结果必须不变。开启后的身份/选择变化属于政策变化，不要求与旧轨迹相同。

第一个认证成功项锁定接收方；预算不足或冲突时不返回目录寻找更便宜项，也不挑本根质量收益最大的项。Peking 50k 根仍可能在前缀外，按实际流失报告，不做额外边界专用前缀。

保留 PQ-05 的恢复触发含义：没有任何接收方成功，且已尝试的 **E/F/H** 非空、全部 `shape_infeasible`，才允许既有翻边兜底。B 的质量或分辨率失败不能反向取消原翻边机会，也不能独自触发翻边。需显式按提案种类判断，不能继续对混合 `Attempts` 无区别地使用 `all_of`。

## 4. 混合面数预算与统计

### 4.1 冻结命名规则

所有接收方先在同一快照完成认证并按原全局根序收集，然后命名预算；认证人口不依赖捐赠后端。令 `F0=B−N0`，从 `remaining=F0` 开始，依序处理非翻边项：

```text
c = B 原语的 1 面，或 E/F/H 的 2 面
若 remaining >= c：为该项命名 c 面，remaining -= c
否则：不命名任何空额，该项进入原单捐赠方分支
翻边：不命名、不消费空额
```

之后按原混合全局顺序预留资源。命名项失败后不返还额度，也不改走捐赠分支；未命名项不使用部分空额，仍需完整 `−2` 捐赠方。未命名项释放的净盈余不能资助同批其他项，下一批由实际 N 重新计算。

例如仅有 1 面空额、依序成本为 `2,1` 时，前者需要捐赠，后者获得这 1 面；获空额项不再一定是连续前缀。必须在批次里显式保存与原意图对齐的成本/资金来源，不再用 `ordinal<AssignedCredits` 推断。全为成本 2 时退化为原规则。

### 4.2 预算证明与真实提交

设实际执行的命名项为集合 F，实际执行的配对项为集合 P，翻边净零。独立支持及整笔发布成立时：

\[
N_{final}=N_0+\sum_{i\in F}c_i+\sum_{i\in P}(c_i-2)\le N_0+F_0=B.
\]

第一项之和不超过冻结命名总额，第二项非正。不得使用旧公式 `N0+2·FreeExecuted`。提交器仍由实际 removed/inserted faces 独立计算目标 N，与账本核对，并拒绝越界、错误事务种类和伪造 `+1` 提案。不能只相信统计字段，也不能以净面数正确代替结构正确。

配对事务不可拆分发布；准备内存并非活动预算，临时容量单独计费。已有发布先移除后添加的流程应保证外部只看到完整代际，不能渲染一个预算越界的中间状态。

### 4.3 数量和面数分账

- 保留 `Receivers/Need/Feasible/Executed/FreeExecuted` 的需求数量口径；B 和 E/F/H 均属细分需求，翻边仍单列。
- `AssignedCredits/UnusedCredits` 保留“获空额接收方数/未兑现接收方数”含义，不能悄悄改成面数。
- 新增明确面数账本：命名面数、实际空额消耗面数、未兑现命名面数、配对净释放面数、实际净面数变化。并记录每意图的 `None/Free/Donor/ZeroCost` 分支及接收成本。
- B 的尝试、认证、分辨率拒绝、空额执行、配对执行、冲突失败分别记录；它是上述总体计数的子集，不能重复相加。
- 必须满足 `Exchanges.size()=Executed+FreeExecuted+FlipExecuted`；配对边界项净释放一面，配对内部项净零。

正常路径只加有限整数账本；详细逐事务信息在诊断模式。共同 CSV 原列含义不变，必要新增字段优先独立的预算/边界明细文件，不重写 FER 历史数据。

## 5. 冲突、提交与完整续接

沿用 `Plan → Commit::Prepare → Samples::Prepare → Mesh::Prepare → Publish`，不另开边界发布通道。生产组件只依赖算法核心；04A 观察器保留独立反事实参考，不被生产调用。

| 义务 | 本阶段要求与归属 |
|---|---|
| 结构证书 | BoundaryRefinement 核对原单侧边、域边、根支持、唯一新点、固定旧点、源高度、两个面和分辨率；Commit 调用该证书，再检查实际面数/形状 |
| 资源依赖 | 核对旧面、旧/新边关联、端点及第三点高度、新点写入；同边重复或与捐赠支持相交必须冲突。固定配置/源数据在快照内只读 |
| 分配与身份 | 沿原预分配、规范面身份、槽复用；检查临时身份减法的可表示范围，溢出在发布前明确失败 |
| 边界标记 | 根据已经验证的 B 类型给新点设置 `Boundary=true`，旧边界点继续保持；不能把任意用户填写的标记直接当证书 |
| 邻接 | 旧单侧边删除，两条子边各一侧，新内部边两侧；旧点 link 保留路径结构，新点也是边界路径。共享旧点的邻接更新由统一准备合成 |
| 样本与评分 | 修复 owner、全部闭面贡献、旧边/新内部边样本及外接口评分；新边界点不进入捐赠索引。对照测试全量重算，正常路径禁止全域重建 |
| 输出 | 实际 float 坐标/高度、面法线、索引尾交换、脏范围及未消费 Pending 必须对应新状态；不因配对净−1漏掉新增顶点写入 |
| 失败与续接 | 过期批次、配额/分配失败保持旧逻辑状态；累计两批再消费、下一次评分/规划、视图变化和 Reset 均可继续 |

源高新点规则只保证该新点的生成来源，不保证新分片曲面逐点更好。最终 float 网格必须经独立评价，内部 double 证书不能代替实际输出验收。

## 8. 质量出口与允许退化边界

本规划推荐沿 PQ-05 的**有限轨迹改善**口径，保留原运行时最大误差规则。允许逐点非零退化，不为 B 新设 Dmax 上限；但这不意味着任何分布或跨视图退化都可接受。

- **有限改善成立**：自然轨迹实际执行 B；对应原见证在来源帧和轨迹结束时的同一固定投影下，相对关闭政策至少保留原 `0.01px` 进展尺度的改善；全部冻结关键帧的全域 Emax/Hmax/RMS 无新增可辨退化。分布另按共同可见样本的绝对误差超出 `.1/.25/.5/1px` 的数量比较；任一档增加则归混合结果，不事后挑选较有利档。各输入分别判定，不用峡谷收益抵消 Peking 退化。
- **取舍/混合结果**：原见证或 Emax 改善，但某关键视图、Hmax、RMS或分布恶化。列出绝对幅度、受影响样本及原因，保持默认关闭，交用户决定是否接受该操作点；不自行挑一个更宽阈值升级为修复通过。
- **能力未兑现**：未实际执行 B，或原见证仍因前缀、形状、源尺度、认证、预算/冲突被阻塞。接入可以正确，持续质量目标仍未通过；Peking 50k 尤其允许出现此出口。

上述分布条件是本次建议的保守验收选择，不是运行时新增硬约束，也不是每个点都不得退化的要求；它可能将有价值的质量交换留在混合结果，需要用户评审。相对 DOD 的分簇/超额只作诊断，不把逐点接近 DOD 作为上述接受目标。

`0.01px` 只沿用已有进展尺度，不称感知阈值或充分质量优势。数值可辨性沿独立评价器的既有有效性/精度证据；没有可用误差界的极小差值或恰在分布切点的归类差异标为未决，不事后加 epsilon 抹掉。04A 的 `+2.916543px` 显然不属于数值噪声，但若整体 Emax/分布改善，它也不能单独否定候选。

验收以完整报告为单位；局部构造成功、连续状态可运行、有限质量改善、默认政策准入分别标记。即使三个输入均达到有限目标，也不自动称长期动态质量已解决或默认开启新政策。

## 9. 成本、复杂度和停止条件

单个 B 的拓扑构造/源查询为有界工作，参数域几何支持只有一个旧面、两个新面。目录上限仍八项，但原来跳过的外边现在可能付费，因此实际提案/认证次数会增加。认证依赖支持样本数 `s`，必要区间/有理核查也计入；不能把完整 B 事务称作 `O(1)`。

命名额度遍历已认证接收集合为 `O(r)`，分支记录空间 `O(r)`。预留沿原最多 `r·m` 配对及已批准批宽相关冲突检查，不在这里承诺改善其上界。提交继承原变化支持排序/容器成本；样本续接依赖实际 `s_Δ` 和接口关联，不因为边界度数有限就视作常数。新增点的长期存储和容量增长完整记账。

正常计时包含 view、提案/认证、预留、拓扑/样本/网格准备发布和适配；冷启动、销毁、上传、帧包络单列。新增统计包含 B 尝试/执行、边界点数、源尺度停止、混合成本、配对数、冲突、样本触达、Pending和实际写入。禁止将新增源查询、结构检查或维护迁移到计时外。

关闭政策同任务前后性能按[开发规范§7.3](../../standards/development_guidelines.md#73-工程性能回归的实际影响门槛)筛查：`max(0.05ms,5%×基线,已知波动)`，明显问题至多一次定向复测。开启政策工作量/网格改变，只报告质量—实际面数—完整成本，不称等质量加速；不要求本阶段优于 DOD。

开发规模：每个上述配置先一独立进程，帧是相关样本；记录均值、中位数、P95、最大值和逐进程数据，不追正式统计重复。正常/追溯进程沿180秒/8GiB，独立质量每帧180秒，自动采集/评价目标30分钟，硬预算45分钟；到限保留已完成数据与未知项，不提高配额或扩大矩阵。构建与性能运行不并发。

出现以下情况即停止相应准入并完成问题报告：结构/硬预算/续接不成立；关闭路径分叉；1/8线程决策不一致；自然轨迹出现新增明显质量损害；不可回收边界导致明显预算锁死；开启后发生无法解释的工作/资源放大。有限负结果也可闭环，不通过扩大前缀、捐赠池、放松形状或新原语救本阶段。

稳定工程退化按规范单独分析，并交用户决定后续修复归属；不能以质量改善抵消未说明的性能问题，也不趁机启动 QPC-05。后续性能研究所用政策必须来自本阶段实际验收状态。
