# GMP-03：自然快照兑现与发现成本小规划

> 2026-09-14；在 GMP-02 提交 `e01cd06` 后开始。用户授权自主闭环，实施前冻结。范围为单轮诊断，不实现持续新算法。

## 1. 面板、工作配额与停止

在任何新后端运行前固定：`test129-a-b4096` 与 `peking547-a-b20000`，每场景 sample14 和 sample46，共四快照。14 为历史锚点，46 为原 64 点轨迹后半段内部时刻；不用新结果选择，不取更多压力样本。场景清单 `docs/parallel-roam/cpu-pilot-scenarios-v1.csv`，世界参数分别 30/4、80/12，预算、深度、原阈值和视图协议不改。

逐场景恢复 sample0..46，在两个指定 `SplitTopology` 前借用状态；只导出活动叶真实 UV/高度、稳定路径 ID、相机矩阵及原始 uint16 栅格。捕获前后用现有阶段输入哈希检查源状态不变。继续原管线只用于下一来源时刻，不作为新算法目标来源；不调用 `MaterializationDodBridge::Capture`。

每快照先完整检查几何与预算，再建立完整 k=0 公共样本归属、闭面评分和有序 D_raw。首轮认证只处理全局前 64 个原始需求，保留未处理数量；接收仍最多 8 个固定提案，回收池 64。对前 4 个已认证需回收需求，允许对快路径失败的前 8 个池中心作 DP oracle。每快照累计局部样本访问上限 1,000,000，认证/选择 90 秒，整体 180 秒；超限输出已得结果和未知，不换输入或参数。部分覆盖的 D_need 给前缀已知数量及尾部未知，绝不当全域分母。

若初始空额度已覆盖全部原始需求数量，则即使所有接收都可行也不会有 D_need，可在完成共同评分后直接报告“无预算竞争覆盖”，不为完成设施实现无用 oracle。若只是前 64 未触发，报告前缀覆盖不足，不推断全域没有竞争。

## 3. 数值与核查边界

Q 按原参考格点、边中点和重心生成，保留有理参数身份；源高度由原始 uint16 求双线性值。唯一归属只管存储，评分用闭面样本。来源及最终几何使用实际当前高度。

P 是调度数值，不承担质量上界：诊断固定 IEEE float64 操作次序、P² 排序及稳定面 ID，不借 NumPy/BLAS 可变归约决定同分。最终样本质量认证仍须精确有理投影平方检查；浮点拟合只是候选高度，失败或数值不确定不称数学无解。此精度区分不改变独立几何接受条件。

先检查导出网格恰好对应观察点及完整覆盖；公共样本数需吻合 `6(w−1)(h−1)+2(w−1)+2(h−1)+1`。当前来源为方形栅格，公共点集包含固定对角线中点和两面重心。独立抽样定位对照不能代替全域拓扑检查。

自然运行前跑仅相关解析例：共享边样本、多点高度变化、正交/透视的精确投影验证。若前置覆盖或预算竞争 Gate 已触发，明确停止后端路径，不把不存在的认证/提交填零作为测量结果。出现已认证交换则在诊断副本有限应用，核查预算、共形性、质量和下一轮评分；没有出现时原型准入不通过。

## 4. 成本对照与验收

生产未修改，仅新目标；来源 probe 支持 `baseline` 和 `capture`：前者相同原轨迹不导出，后者同步导出。各一次独立进程，记录 Build 总时间、捕获/hash/文件时间与输入身份；观测开销不从完整来源时间中隐去。新离线能力独立计费，不与零成本旧实现相除。相同无捕获模式在最终版本再运行一次作构建/入口影响核查，按开发规范 §7.3 筛查，不跑多后端或旧全矩阵。

总预算：单目标构建预计 2 分钟，来源两场景两个模式预计 2 分钟，四次离线每项最多 180 秒。原始文件、逐快照数据、脚本/资产/可执行身份和命令保留在 `benchmark-output/cpu-refinement/gmp-03/run-01/`，不可覆盖；必要摘要进入报告。

自审：输入与配额先冻结，产物方向单向；没有依赖 Legacy 得到目标。有限前缀、数值未知和后端未运行必须如实标记。完成或触发停止条件后写审查并单独提交，再进入 GMP-04 准入决策。

## 实施结果

共同评分与接收前缀已给出非空接收证据，因此按需增加独立回收/预留模块。首次来源加载错误地使用六场景相机清单匹配两场景子集，被原校验拒绝；改用已有 MPR-01 两场景冻结清单，资产/姿态和 sample index 不变。初次 CMake 链接遗漏既有 PerformanceTimer 源已补齐；未改生产代码。

阶段完成，详见[结果](../../research/cpu_refinement/transaction_backend_gate.md)和[自审](../../reviews/cpu_refinement/gmp_03_natural_backend_review.md)。四个冻结前缀的一般回收交换数为 21、23、0、1；三价共同池没有可用中心。Peking14 另有两个空额度接收，不能混入交换数。53 个有限 oracle 检查保留 4 个启发式漏解与 49 个类别内质量否证；未用 oracle 重新选择批次。全部批准批次完成有限应用、预算/几何与下轮评分核查，无配额截断。

发现两个重要限制：前缀认证未覆盖全部需求；固定视域屏幕最大误差不增不能防止视图外高度误差上升。分别有 0.078431→1.571242、0.081263→3.921359 的全域高度变化，原数据和契约不改。原型前证据只支持进入 GMP-04 的受限准入评估。

成本已覆盖来源、全量采样/排序、局部认证、选择、诊断复制和全量续接检查；每快照最终诊断为 3.001、3.688、30.453、18.044 秒。未添加逐字段/对象峰值内存 profiler，缺项明确登记，不能宣称完整微观成本已测。新来源无捕获前后各一进程，未见版本相关退化；末次注释修订重建后二进制身份不变，不再重复自然运行。按用户要求，提交本阶段后才创建 GMP-04 小规划。
