# PQ-04：固定局部域内的形状恢复可行性诊断

2026-09-15，小规划；修改前基线`f195fda`。用户已授权继续PQ-04及小阶段自主闭环、逐阶段提交。本阶段是有限离线诊断，不修改生产恢复政策。

## 1. 问题与目标

[PQ-02](../../research/cpu_refinement/pq_02_residual_provenance_results.md)定位到frame8根`-111`已进入前160，但E/F/H全部被形状判据拒绝。根的A角恰等于最小角；AB二分根侧合法、相邻侧失败，具体邻角尚未记录。[PQ-03](../../research/cpu_refinement/pq_03_fit_counterfactual_results.md)证明单自由高度存在未利用改善空间，但不能解除固定UV上的形状阻塞。

本阶段回答：**保持原形状约束、旧点几何与固定外边界，在一个预先限定的小域内，是否存在一次换连接或一次换连接加细化，使本见证能够继续获得当前视图的质量改善？**

先补清AB相邻侧坏角；再区分“原目录不足”“本轮有限目录未找到解”“几何可行但质量/数值/预算未解决”。不把有限失败解释成一般局部恢复无解，不把成功解释成持续恢复或生产算法已实现。

前置阅读：开发规范、规划/事实/审查规范、PQ-02/03规划与事实/报告；扫描`TransactionalProposals`、`TransactionalPredicates`、`TransactionalCertification`、`TransactionalSamples`、`TransactionalState`、原追溯入口和PQ-03区间查询。重要事实：生产Fit的基准使用旧曲面，而翻边后的固定高度曲面通常不同，不能原样调用Fit假定基准仍正确。

## 2. 冻结输入与有限目录

沿用Peking547²、尺度80/12、深度20、预算50000、前缀160、8线程及原24帧B轨迹。`PreserveSurvivingHeights=true`、`HeightGuard=false`；q2固定为(0.97985345125198364,0.94871795177459717)。只在frame8 / sample30原Plan后、Apply前借用状态；不采用PQ-03反事实，也不分叉未来轨迹。

局部域D为根`-111`及其三个直接边邻面，至多4个旧面。在生成任何新候选前记录D的原面、点、边关联、预算和当前/未来视图。外边界固定，不接入域外第二层邻域。

预冻结目录：

1. 复现根的原E/F/H全部提案，记录每个坏面的点和精确角度证据；H即使支持超过D也只作原目录失败记录，不成为扩大搜索域的入口。
2. 对根的每条内部边尝试一次标准2→2翻边，要求两侧均在D、四边形严格凸、新对角线不与域外既有边重名。
3. 每个翻边状态分别保留“仅翻边”，并对其中覆盖q2的面尝试一次细化：E为内部边中点且两侧都在D；F为该面的重心或冻结根当前最坏可见样本（必须严格位于该新面内）。同时记录不翻边的同类局部目录作对照。
4. 不连续翻第二条边、不多点插入、不删除旧点、不2-ring搜索。旧点UV/高度不可改；新点最多一个。H在B下的扇形连接不提供比F更多自由度，不另扩大H邻域。

候选总上限64；目录按旧边身份排列，面保留冻结小域向量顺序，再按规范化连接和新点UV去重。本例每个基础状态只有一个覆盖q2的面，不涉及多覆盖面重排。到限停止并报告`cap`，不得因未找到正例扩展目录。中间翻边是私有构形，最终复合替换才要求全部形状合法；若中间已有过小角，可记录“后续仅做三角形细分不能消除该角”的剪枝依据，不能假定任意后继操作也无解。

## 3. 几何、质量与预算分别验收

### 3.1 几何

原生生成使用既有精确方向/形状判据；离线独立检查导出的参数域数据：正方向、同外边界有向边、多重面/边、内部反向配对、无交叉/悬挂点、面积及旧点保留。使用输入double的精确有理表示，角度小数只作展示。

一次凸四边形翻边和合法E/F细分通过构造保持覆盖；独立检查审计实现是否正确兑现这些前提。成功候选须完整通过，不用Q采样覆盖替代几何合法性。

### 3.2 质量

每个候选从D的最终面集合提取真正改变的旧支持S，未改面直接排除；公开S及样本数量，不把不同支持上的最大值直接排名成统一目标。

诊断接受阈值统一定义为`floor(旧S上可见Q最大误差×10^6)−10000`微像素。先对原S曲面调用原`Measure`；只有上下界落在同一微像素整数格时才形成该阈值，否则报告`target_numeric_unknown`。这采用最大误差的保守认证格，不暗称为生产Fit内部单一见证选择的逐操作复现。

- 仅翻边：旧高度固定，直接原`Measure/Accepts`。
- 带新点：先以确定的双线性源高作候选；另在固定连接下重建仿射基准`h_new(s,δ)=h_base(s)+β(s)δ`，查询同一目标的一维可行区间，选择最接近源高度的可行值。每个几何最多两个实际高度，不做最小阈值搜索或未来视图调参。
- `h_base`必须由**新连接**插值得到；复用PQ-03的`FitSampleConstraint/Query`代数，不复用旧状态的`MeshHeight`常量。区间只产生候选，真实double高度仍经原认证。
- 同时记录q2当前误差、固定frame15投影、闭补丁高度误差和相对批前的最大逐点代价。局部认证通过但q2没有至少0.01px的观测改善，单列为“不构成本见证恢复证据”。

不启用新HeightGuard，不放宽最小角和原0.01px进展门槛；没有跨视图保证或连续地形最大误差证明。

### 3.3 预算与续接

逐候选记录新增/删除面数量、净面数、当前N/B及`N+净面数≤B`。仅翻边净0，单插点净+2；若空额度不足，明确需要一个−2回收方，**本轮不搜索donor或宣称完整预算交换可行**。即使空额度充足，也只表示冻结快照上单独应用不超上限，不表示原批次还有未预留额度。

不在生产状态提交，不改变下一轮缓存/队列/网格。局部几何存在性不能替代完整持续状态、批次冲突、预算配对和实际恢复速度验证。

## 5. 步骤、验证与停止条件

1. 冻结`f195fda`来源、当前原生程序及PQ-03同模式证据。旧默认5.356993s可复用；当前程序仅含PQ-03字段修正，若环境变化才补一次旧默认运行。
2. 先写有限几何/新基准解析夹具及独立几何检查；验证合法正例、凹四边形拒绝、域外边/悬挂点、角度等号，以及翻边后新基准与旧曲面不同的非共面例子。
3. 新默认q2与`--recovery-audit`各一次24帧。先复现原7项形状失败和AB坏角；有限目录全部保留，不因成功提前丢弃其他候选或重挑样本。
4. 检查24帧关键字段、三份原诊断及五份网格与PQ-03/PQ-02一致，复用既有全域质量。只构建相关探针/夹具，不跑全CTest、更多后端或大规模质量矩阵。
5. 画原局部域、AB二分坏角及存在的代表性合法候选；若无成功则画对应拒绝。图只用于参数域几何诊断，目视检查身份、边界、比例、角度和q2，不冒充持续平台验收。
6. 回填事实、结果和审查，按阶段授权独立提交，再决定后续恢复政策规划；本轮不自动实施新生产原语。

限额：64个几何、每个至多两个实际高度及一次区间查询；累计200万样本访问、60秒额外诊断，原生180秒/8GiB。自然运行正常两次、总上限5分钟；模型未知或耗尽保留原因，不提高限额。若出现具体实现错误，可先修正规划并定向验证，不把纠错运行当统计重复。

按开发规范§7.3对照默认完整进程，独立进程是统计单位；先一组快验，越过明显工程影响门槛才最多复测一次。新增枚举/几何/认证/输出费用、样本访问、约束及精确回退单列；局部面数有界不代表样本成本O(1)。

## 7. 实现结果

**2026-09-15闭环：有限局部恢复存在性有正面证据；生产持续质量未修复。** 详见[结果](../../research/cpu_refinement/pq_04_local_recovery_results.md)、[事实](../../codebase/cpu_refinement/pq_04_local_recovery_facts.md)和[审查](../../reviews/cpu_refinement/pq_04_local_recovery_review.md)。原始输出在显式忽略的`benchmark-output/cpu-refinement/pq-04/run-01/`。

- 原7项全部形状失败。AB中点失败补清为相邻面顶点`4`处11.309932°，cos²=25/26。
- 固定4面域产生10个新几何；2个根边翻转在严格凸性前提拒绝，外边界VB不生成E。只有AB翻边形状合法，原数值认证接受且q2改善。
- 正例不移动旧点、不新增点、净面数0：认证支持最大值1.348413→1.145203px；q2当前1.348412→1.114554px，固定frame15投影2.351050→1.943430px。
- 最大逐点代价0.026626px和0.003854高度仍保留。翻边后的4项有限插点全部形状失败，不能保证后续连续恢复。
- N=49999/B=50000，插点+2单独额度不足；净0翻边单独不超预算，但未进入原批次冲突/提交/续接。
- 自然带新点方案均未到质量层，因此模型查询0次；非共面解析夹具已核查必须使用新连接基准。没有为触发模型而增加自然输入。
- 17个完整几何均通过独立有理结构检查；逐面形状结果与C++一致。默认及诊断各一次，原24帧、三份追溯和五网格不变。
- 默认进程4.453036s对旧5.356993s，未见明显回归；不将单次下降当加速。额外诊断20.7845ms，16068次样本访问、10712次筛选，无精确回退，未触及上限。
- 相机事实修正：`Config.SampleIndex`不随平台视图更新；实际由探针frame8和导出矩阵绑定。只修正新诊断前提，未修改生产代码。
- 参数域图已目视核对；代码/CLI/注释/架构审查按阶段收口。没有跑全CTest、后端矩阵、分叉轨迹或继续扩原语。完成后按授权独立提交PQ-04。
