# QPC-06I 样本续接重复计算小规划

## 1. 问题与目标

06F的Sierra样本准备21.50ms，而Canyon1.64ms。`Enumerate→Weights→StoredWeights`已计算插值权重，后续Prepare丢弃后再算；`Evaluate`还重新计算固定源高度。本阶段在既有局部修复内减少重复操作，不引入全域重建或改变共享边语义。

## 2. 文件边界与方案

- Extend `TransactionalSamples.h/.cpp`：枚举与插值证据由Samples拥有。优先不让只需成员资格的调用计算随后丢弃的权重，或只在明确需要时保留结果；基于实际调用者决定，避免所有面样本永久存三倍系数。
- Reuse持久`SampleValue::ReferenceHeight`：仅在源/Q/HeightScale不变且值来自同一原表达式时复用，初始化仍完整构造。
- 条件审计一次批内最终owner确定：若证实重复投影明显，先归属后求值；否则不为小收益重排整个Prepare。不改变稳定身份最小owner、闭面贡献、优先级、捐赠键、Pending及准备/发布异常边界。
- Extend持续样本/执行专项；生产无新增策略参数或跨帧缓存。

## 3. 推导与计费

区分成员谓词和权重计算：几何成员资格由原过滤/精确边测试决定，未消费的权重没有决策副作用；保留实际需要处的同一`StoredWeights`表达式。固定参考高度复用须逐位一致，不将认证有理参考和运行时double参考混同。候选面/样本访问仍按实际量记录，不能把有界拓扑支持误称常数续接。

## 4. 实施、验证与出口

06H提交后扫描全部Weights/Evaluate调用。冻结前程序，针对源高Sierra/Canyon及旧Fit Sierra各一条96机会轨迹；选择覆盖共享边、样本归属、连续更新、Reset和发布的既有测试。完整曲面/逻辑结果一致且实际重复运算减少为首要验收，性能遵循7.3，最多补一次受影响复测。

没有收益的两遍重排不保留；最终报告列局部复杂度、剩余集合/优先级维护、不可省工作和任何退化分析。提交后进入06J有限总核查，不开启新质量算法。
