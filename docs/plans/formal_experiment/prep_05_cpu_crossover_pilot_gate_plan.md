## 1. 目标、前提与非目标

回答五个 CPU 阶段是否存在值得继续研究的、能够由工作量特征初步区分的双向执行优势。交付的是继续、收缩或暂停投入的证据与建议，单策略占优、覆盖不足和没有明确交叉都可以是有效结果。

用户已允许 P4 最后排查仍无法消除漂移时，写明限制进入 P5。P4 已完成严格等价、输入与记录核验；最后重算未发现统计错误，20/22 个目标/动作仍超过旧 5% 漂移上限。本规划承接这一风险，不将旧数据改写为环境稳定或新的研究样本。

已阅读开发、规划、事实及审查规范，P4 相关小规划和最后记录、大规划 PREP-05、24 号正式协议；核对已有配对 CLI、输入审计、配对差统计、来源分组及报告入口。现有能力足以完成本阶段，不新增生产代码、正式分析接口或模块。

非目标：OpenGL/D3D12 上传提取、修改连续前缀安全条件、制造自然并行正例、训练预测器、正式 bootstrap/Holm、正式全矩阵和轨迹 C 研究数据。用户允许进入 P5 不等于允许进入 PREP-06。

## 4. P5 探索判断契约

### 4.1 与旧 5% 门槛的关系

**本规划需要明确确认的取舍：** P5 以同一冻结输入的三次独立配对方向能否一致作为探索可靠性依据，旧 P4 的动作绝对耗时 5% 漂移保留为已知风险和量级信息，不继续作为 P5 整批数据的前置否决条件。原因是本阶段判断是否存在值得继续验证的相对执行优势，不验收绝对耗时预测或正式论文显著性。

这一选择仅适用于新采集的 P5 数据，判断契约标识为 `cpu-pilot-direction-v1`，随事前冻结记录和报告保存。C++ 配对 v2、测量协议 1、既有逐运行噪声规则 v1 全部保持；不修改 `short_run_stability`，不重新分析 P4 来消除原有排除。P5 普通分析只接收本轮三次 W=3/R=12 完整尝试，但报告必须引用 P4 最后核查并显式标明旧环境限制仍在，不能利用未提供 W=2/R=10 数据宣称环境通过。

若不接受这一探索取舍，则本轮应直接记为环境证据不足、暂停采样，不能一边沿用旧整批否决条件，一边重复采集相同环境的数据期待门槛自行消失。正式实验的 5% 稳定性及其他正式研究门槛不在本规划中调整。

### 4.2 每个输入的硬门槛

1. 三个尝试均通过完整来源、标定、输入及严格结果审计；相同目标的输入/结果身份一致。任一真实正确性错误立即停止，不将其解释为缺乏交叉。
2. 保持既有块内差 `d = tA - tB` 和阈值 `max(0.01 ms, 0.03 × 较快策略中位数, 标定噪声, 3 × 配对差 MAD)`。每个进程分别判断，不先合并三次的 36 个块再给出一个方向。
3. 一个目标策略对只有在恰好三个独立 RunId 中都未排除、都超过各自阈值且都为同一方向时，才支持该方向。`A/A/tie`、`A/B/A`、缺失或回退均不能写成三次稳定优势；不能直接使用忽略平局的 `directionAgreement` 字段作为充分条件。
4. 涉及并行的比较必须有实际至少 2 线程执行。安全块不足、无工作和回退分别保留。网格三组比较分别报告，纯串行脏写/全量比较可独立有效，但不能声称具备并行覆盖。
5. 原始动作中位数、绝对/相对漂移、三次配对中位差和 MAD 全部保留。方向不稳或差值落入噪声时记为证据不足，不追究几微秒差值，也不追加同一目标的第三轮环境排查。

### 4.3 从目标到阶段，再到投入决定

同一阶段、同一固定策略对，需要 A 方向和 B 方向各至少两个不同冻结输入，且各输入满足第 4.2 节，才能记为可复现双向信号。网格不能把不同策略对的相反符号拼成一次交叉，三个比较仍只算一个 CPU 阶段。目标身份按来源场景、阶段和采样点计，不把重复块、不同策略或复制目录算成新输入。

使用已冻结的 `selectionStratum`、`primaryWorkValue` 和获准 `pre_` / `planning_` 特征展示区域。分层使用发现时已有的 low/middle/high/coverage，先列原始值和分层结果，不用耗时重新分箱、不使用 `post_` 或阶段结束后的耗时分项作预测变量。相反方向若不能由这些执行前特征初步区分，标记可预测性不足；不拟合最优阈值证明自己选的区域。

| 阶段结论 | 条件与限制 |
| --- | --- |
| 有双向信号 | 同一策略对两侧各两个以上输入，三次均一致且超出噪声；是否容易由工作量区分另列 |
| 仅观察到单方向 | 有足够实际执行覆盖，但只找到一侧稳定优势；不宣称全域不存在交叉 |
| 差异无实际意义 | 覆盖足够，但多数有效比较未超过固定实际差/噪声阈值；只描述本次数据 |
| 覆盖或测量不足 | 实际并行不足、工作量范围不足、方向不稳、标定失败或来源不足，不能转写为负面研究证明 |

投入建议沿用大规划：至少三个阶段有可复现且可初步区分的双向信号，才建议 Review 完整路线；一至两个阶段则建议收缩范围；可靠且覆盖足够的数据只支持固定策略时建议停止通用路线；证据不足时暂停完整路线。所有建议均带 P4 环境风险说明，最终由用户选择，不自动启动 PREP-06。

## 5. 已知覆盖与补测上限

P4 的自然细分前缀为 0/24 个所选目标，合并拓扑实际并行仅 5/17 个目标。P5 如仍如此，就报告结构覆盖不足；不拿受控改分数正例补充自然研究数据，不在本阶段放宽连续前缀。其他三阶段虽有实际并行覆盖，仍须观察新的三次配对，不能沿用旧单次方向。

首轮后不自动扩大场景、换后端或重新采集同一环境。大规划允许的一次补测只用于具体的自然工作量覆盖缺口，最多新增 24 个阶段专用输入，继续 W=3/R=12/P=8 和三次独立重放；必要时才使用轨迹 B。实施前先书面列出缺口、只依赖工作量的选择依据和上限供 Review，不从全部结果中搜寻有利点。补测不能用于重试已失败的 P4 5% 门槛。

如果首轮已足以建议收缩或停止，则不补测。一次补测后仍不清楚，保存证据并暂停完整路线，不能继续扩充框架。正确性失败由独立修复流程处理，不动本阶段选择规则掩盖问题。
